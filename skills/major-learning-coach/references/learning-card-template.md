# 学习卡模板（Learning Card）

> `learn` 模式只用这一个结构。换结构会让用户每次都要重新适应阅读节奏。
> 长度目标：60–120 行。超过 120 行说明你想一次讲三个点，拆开。

## 九段结构（顺序固定，标题照抄）

```markdown
## 1. 学习目标
学完你能：<一个动词 + 一个可观察产物>

## 2. 前置自检
1) <问题>  → 答不上来请先看 <知识点 ID>
2) <问题>
3) <问题>

## 3. 核心概念
- **<术语>**（English）：<一句直觉解释>
- **<术语>**：<一句直觉解释>
- 它解决的问题是：<为什么需要这个东西，不给它会怎样>
- 一个反例：<最容易套错的情形>

## 4. 符号与约定
| 符号 | 含义 | 单位/取值范围 | 本专业习惯 |
|------|------|---------------|------------|
|      |      |               |            |

## 5. 由易到难
### 例 1（L1）
**题目**：
**这题在考什么**：
**思路**（为什么想到这一步）：
**分步**：
1.
2.
**答案**：
**变式**：<改一个条件，答案会怎么变>

### 例 2（L2）
（同上六项）

### 例 3（L3）
（同上六项；若当前知识点没有 L3 例题，写"本点的 L3 形态见 K0X-Y"，不要硬凑）

## 6. 常见误区
1. **<错误做法>**：错在第 <哪一步>，因为 <原因>；正确做法是 <替换动作>。
2. …

## 7. 自测（先只给题，等用户答完再判）
**Q1**（对应 L1）：

（用户答完后再给：对/错 + 一句解析 + 是否记为已掌握）

## 8. 卡住了怎么办
- 如果卡在 <概念>：回 <知识点 ID>，只需看其中的 <小节>。
- 如果卡在 <计算>：先用 <更小的数/更简单的例子> 手算一遍。

## 9. 下一步
```

## 每段的写作要求

| 段 | 必须做到 | 不要做 |
|---|---|---|
| 1 学习目标 | 动词 + 可观察产物；一句话 | "了解""熟悉""掌握" |
| 2 前置自检 | 3 个能用一句话回答的问题；答不上来直接指向 ID | 变成又一轮小测验（3 题封顶） |
| 3 核心概念 | 每个术语一句直觉；必须给"不给它会怎样" | 抄教材定义；列 10 个术语 |
| 4 符号与约定 | 表格化；标出本专业容易写反的记号 | 省略单位、省略参考方向/基准点 |
| 5 例题 | 三档齐全；每题必有"为什么想到这一步" | 只给答案；三个例子同一难度 |
| 6 误区 | 写"错在哪一步 + 换成什么" | "要细心""多练习" |
| 7 自测 | 先题后答；答错不前进 | 自测题就是例题原题 |
| 8 卡住 | 给出可执行的下一步动作 | "再看一遍" |
| 9 下一步 | 给 ID + 一句理由 | 一次给三个"可选下一步" |

## 语气

- 说人话。少用"综上所述""值得注意的是"。
- 每个概念先回答"这东西为什么存在"，再给定义。用户记不住没有动机的定义。
- 例题的「思路」段是最有价值的部分：写清"看到什么线索 → 想到哪个工具"。答案本身用户能搜到，思路搜不到。

## 一个填好的短样例（只示范密度，不是标准长度）

```markdown
## 1. 学习目标
学完你能：在不使用额外空间的前提下，写出单链表就地逆置的完整代码，并说清三个边界（空表、单结点、两结点）为什么不会崩。

## 3. 核心概念
- **头指针**（head）：指向第一个结点的指针；空表时它为 NULL。
  不给它会怎样：链表没有名字，你就再也找不回这条链。
- **就地逆置**：只改 next 指针方向，不新建结点。
  反例：把结点值倒着抄进新链表——这不是逆置，空间 O(n)。

## 5. 由易到难
### 例 1（L1）
**题目**：写出遍历单链表并打印的循环。
**思路**：看到"遍历"就想到 `p = head; while (p) { ...; p = p->next; }`——循环变量必须是"当前结点"而不是"下标"。
**答案**：…
**变式**：如果要求倒序打印，还能用这个循环吗？（不能，需要栈或递归）
```

## 与解题模式的分界

- 用户在学习卡里问"例 2 的第二步为什么这么写" → 就地解释，**不要**切换成 `solve` 的脚手架节奏（他已经在学习流程里了）。
- 用户拿一道**课外题**来问 → 转 `solve`。
