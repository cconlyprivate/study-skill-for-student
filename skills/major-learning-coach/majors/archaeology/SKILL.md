# 考古学（archaeology）

> 先读 `../../references/curriculum-rules.md`（难度与排序）与 `../../references/learning-card-template.md`（讲解结构）。
> 本文件只给这个专业的知识骨架与专业习惯。

## 1. 这个专业在训练什么

考古学的原料是**物质遗存**：一段剖面、一堆陶片、一座被切掉半边的灰坑。全部工作是把这些东西还原成四件事——什么时候（年代）、谁做的（文化与人群）、怎么生活（生业与聚落）、为什么会变（过程与动因）。所以核心不是"知道很多文物"，而是**在证据残缺、且发掘本身不可逆的条件下，做出别人能复核的推断**。

三条硬约束决定了这门学问怎么学：其一，**层位不可复得**，挖掉就没了，记录是唯一的原始材料；其二，**器物离开单位就贬值**，一件陶鬲摆在展柜里只是文物，出在 H12② 里才是年代证据；其三，**结论必须能在同一批材料上被别人重做一遍**，做不到就不叫结论，叫猜测。

**最容易误解的一点**：以为考古 = 挖宝 + 认文物。真正的分水岭在 K02 与 K03——会不会布方、会不会写层位关系式、会不会用器物组合而不是单件器物断代。这三样不会，读再多图录也只能"看图说话"。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能读一张探方剖面图，分出层位单位并写出层位关系式，箭头约定在开头声明。
2. 能给一组同出陶器分型分式，写出划分标准，并说明排序依据是形态梯度加层位验证。
3. 能为一个遗址排出分期方案，输出"期别—代表单位—器物组合—年代区间"四列对照表。
4. 能按三线图规范重绘一件器物，比例、剖面线、纹饰线、比例尺齐全。
5. 能读一篇考古报告，指出其地层描述里缺失的必要信息（土质土色、生土面、开口层位）。
6. 能把一组碳十四数据校正为 cal BP 区间，并说明区间为什么宽。
7. 能写 800 字遗存判读，每个结论都挂到具体单位号与器物号，不确定处写"待考"。
8. 能说清考古学文化与族属的界线，不把分类单位当人群。

## 5. 术语与符号约定

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| 层位学 | 以堆积的上下与先后关系建立相对年代 | 适用一切人工与自然堆积 | 层位只给先后，不给间隔多久；拿层位当年代是硬错 |
| 类型学 | 按形态特征分类排序，复原器物演变序列 | 必须与层位互证 | 单凭"像不像"排序是循环论证，只能用共存与层位检验 |
| 叠压 | 后形成的堆积压在先形成的堆积之上，界面近平行 | 记作 A 叠压 B | 叠压不等于紧邻，中间可能缺若干层，别补成连续堆积 |
| 打破 | 后形成的坑穴切穿先存堆积，有明确的口部与边壁 | 记作 A 打破 B | 图上被切穿的界线才是证据；只写"打破"不写方向等于没写 |
| 共存 | 同一单位、同一堆积面内同出 | 最小单位是"单位" | 共存只证"大体同时"，灰坑里的垃圾可能是几十年陆续倒进去的 |
| 遗迹单位 | 房址 F、灰坑 H、墓葬 M、灰沟 G、窑 Y、井 J | 单位号一经编定不得更改 | 单位号与地层号是两套系统，H12 不是"第 12 层" |
| 生土 | 未经人类活动的自然堆积，不含文化遗物 | 判遗迹开口层位的基准面 | 生土要与原生土、垫土分开；把垫土当生土会漏掉一层活动面 |
| 探方 | 正南北向的方形发掘单位，方间留隔梁 | 常见 5×5 米、10×10 米 | 探方号按行列编，T0501 指第 5 列第 1 行，不是序号 |
| 关键柱 | 相邻探方交界处有意保留的土柱 | 每四格交界处一根 | 打掉关键柱，四个探方的层位就对不上号 |
| 剖面 | 探方四壁或遗迹的垂直切面 | 平剖面图常用 1:20、1:50 | 剖面只能画实际切面，把平面图转 90 度充数是最常见的假图 |
| 三线图 | 器物图由轮廓线、剖面线、纹饰线三种线构成 | 轮廓粗、剖面更粗或涂黑、纹饰细 | 三线要能一眼分清；器物图不画阴影、不做透视、不写生 |
| 器物图比例 | 原大 1:1，常用 1:2、1:4 | 每幅图下必须标比例尺 | 缩放后忘改比例尺，或同一版图里比例不统一 |
| 出土编号 | 探方号 + 层位号 + 序号，如 T0501③:12 | 层位号用圆圈数字 | 缺层位号等于证据链断裂；编号不得发掘后补编 |
| 碳十四年代 BP | 以 1950 年为起点的放射性碳年龄 | 半衰期约定用 5568 年 | BP 不是"距今多少年"，也不是公元纪年，勿与 cal BP 混写 |
| 校正年代 cal BP | 用树轮校正曲线把 BP 换算成日历年代 | 结果是一个区间加置信度 | 校正后必须写区间；曲线平台处区间会突然变宽，别硬取中值 |
| 半衰期 | 碳十四物理半衰期 5730 年，测年惯用 5568 年 | 两套数值并存 | 两套相差约 3%，混用会让整批年代系统性偏移 |
| 考古学文化 | 同一时空内一群共同特征遗存的集合 | 命名用首次发现地的小地名 | 文化不等于族属，也不等于人群，别写"某族人创造了某文化" |
| 型与式 | 型按大类形态划分，式按演变阶段划分 | 型用大写字母，式用罗马数字或阿拉伯数字 | 型、式层级不能跳；同一批材料的分式标准要一次说清并全文沿用 |
| 器物组合 | 同一单位内稳定共出的几类器物 | 以单位为单位统计 | 只挑好看的那件断代，等于把组合证据丢掉 |
| 相对年代与绝对年代 | 早晚关系与日历或放射性年代 | 两者不能互相替代 | "早于"是相对判断，不能顺手写成"早 300 年" |
| 层位关系式 | 用箭头把单位间早晚写成表达式 | 箭头方向各校约定不同 | 答题开头必须声明箭头指向；A 与 B 写反，整题全错 |
| 开口层位 | 遗迹口部所在的层位，如"开口于②层下" | 与"属于②层"是两回事 | 写成"属于②层"就把晚的遗迹塞进了早的地层 |
| 打破关系传递 | 由 A 打破 B、B 打破 C 推得 A 晚于 C | 需检查表达式是否成环 | 出现环说明至少一处判断错，不能按"多数"取结论 |
| 遗迹开口与底 | 遗迹的层位上下界 | 表述为"开口于某层下，底深若干米" | 只写深度不写层位，别人无法复原也无法复核 |
| 埋藏学 | 遗存从废弃到被发现之间经历的全部过程 | 含扰动、再堆积、腐蚀、生物扰动 | 把出土位置直接当使用位置，是这个专业最常见的一步错 |
| 待考 | 材料不足以下确定结论时的标注 | 用于遗址、地层、编号、年代、族属 | 待考不是免责条款，须同时写出缺哪类证据才能定 |

## 6. 典型题型与解题套路

### 遗存判读题（给器物图、剖面描述或一件出土物，问是什么、属哪期）
1. 先锁单位再谈器物：出自哪个探方、哪个层位或遗迹单位，单位性质是房址、灰坑还是墓葬——单位定不下来，后面全是猜。
2. 按固定顺序写形制：口沿、腹部、底、足、耳、纹饰、陶质陶色、制法，一步不跳，术语要能对上报告图版。
3. 找对比标本：先在同遗址同层位找同类器，再扩到区域内的标准器与已发表材料。
4. 下判断并标置信度：能定的写"属某文化某期"，不能定的写"疑为某类，待考"，并写出缺哪类证据。
5. 反查一遍：若判断成立，该单位还应共出什么（如鬲、罐、豆的组合），写出来供他人检验。
**常见失分点**：跳过单位直接凭器形断代；把"看着像"写成"即为"。

### 地层关系分析（给剖面图或地层描述，写关系式、排早晚）
1. 先分层：按土质、土色、包含物把剖面分成若干层，自上而下编①②③，生土不编号或记"生土"。
2. 再找界面：逐层画出上下界面，重点标出被切穿的那条界线——它的位置就是打破关系的物证。
3. 逐对判断：相邻层写叠压；坑穴与地层的切穿写打破；同一面上同出的单位写共存。
4. 写成关系式：先在开头声明箭头约定（如 A→B 表示 A 晚于 B），再把每一对关系写全。
5. 排序列并验算：由关系式推出最早到最晚，出现环就回第 2 步重找界面，不许取"多数票"。
**常见失分点**：把"开口于②层下"写成"属于②层"；跳过中间层直接比较上下两层。

### 年代序列判断（给一组层位、器物与测年数据，排年代）
1. 三类材料先分开摆：层位关系给相对早晚、器物组合可交叉断代、测年数据给绝对年代，别一上来混着用。
2. 用地层把单位"分组"，组内再按共存关系排出顺序。
3. 用器物组合把每组挂到区域文化序列上，写清挂靠依据的是哪件标准器。
4. 测年数据先校正成 cal BP 区间，只比较区间是否重叠，不比较点值大小。
5. 处理冲突：测年与层位矛盾时先信层位，再查样品是否扰动、是否有老木效应，并把判断理由写出来。
**常见失分点**：拿 14C 的 BP 值直接比早晚；区间大幅重叠还硬排先后。

### 论述题（如"二里头是否已进入王朝""某文化为何衰落"）
1. 先拆题：分清问"是什么""为什么"还是"怎么证明"，圈出限定词（区域、时段、材料类型）。
2. 立一句可被反驳的判断，不写"很重要""意义重大"这类无法证伪的句子。
3. 证据分三层给：层位与聚落证据、器物与组合证据、测年与环境证据，每条都挂到具体单位或数据。
4. 主动给反例或限度：写出反向证据，或说明样本量、扰动、保存状况带来的局限。
5. 收尾写适用范围与下一步：结论覆盖到哪、还缺什么证据，缺的部分写"待考"。
**常见失分点**：只堆文化因素不谈层位；全篇都是"待考"却没有一句自己的判断。

## 7. 常见误区

1. **拿一件器物的照片就断代** → 错在跳过出土单位；应先确认单位与层位，再谈形制，最后才落到文化期别。
2. **把考古学文化当族属** → 错在把分类单位当人群；应只写"某文化某期"，族属问题标"待考"并说明缺文献或人骨证据。
3. **直接引用 BP 值当公元年代** → 错在漏了树轮校正；应写成 cal BP 区间并注明置信度。
4. **层位关系式里的箭头随手写** → 错在没声明方向；应在答题纸开头写一句约定，全文统一，否则自己都读不通。
5. **类型学排序按"越像越晚"** → 错在把相似度当年代；应用形态变化梯度加层位检验，两条一致才成立。
6. **器物图当素描画** → 错在加了阴影、透视与明暗；三线图只画轮廓、剖面、纹饰，剖面涂黑，图下必标比例。
7. **报告只写"出土陶片若干"** → 错在没有土质土色与层位；应写清层位、包含物、数量、保存状况，否则这批材料作废。
8. **编一个遗址名或单位号把论证凑圆** → 这是学术不端，一查即穿；没有的材料就写"待考"，并写清缺什么证据才能定。

## 9. 交叉专业与后续方向

- **和文物与博物馆学的区别**：文博问"这件东西值多少、怎么保管、怎么展"，考古问"它出自哪个单位、和谁共出、能说明什么"。同一件陶鼎，文博答价值与保存，考古答层位与组合。所以考古的作业里，**单位号比器物名重要**；只写器物名不写单位号，等于没有证据。
- **和历史学的区别**：历史学以文献证事实，考古以遗存证过程。史前没有文献，考古是唯一证据来源；有文献的时段，考古补的是文献不写的那部分（技术、生业、普通人的日常）。历史学能说"某年发生了某事"，考古通常只能说"某阶段某类行为变了"，精度不同，别互相套用结论。
- **和人类学、民族学的区别**：人类学能观察现存人群的行为，考古只能从行为的结果反推。民族志类比可以提假设，不能当证据用，写进答案要注明"类比，待验证"。
- **和地质学、科技考古的区别**：地质学与物理化学提供测年、成分、环境的手段，考古负责把这些数据放回文化序列；只报数据不做序列，等于没做考古。
- **一条底线**：**不虚构遗址、地层与出土编号**。写不出单位号，就说明这条证据还不成立；不确定的地方一律写"待考"，并写清缺哪类证据才能定。这条比任何一条答题技巧都重要——编一个 H13，整篇论证就废了。
- **后续方向**：史前考古、夏商周考古、历史时期考古、科技考古与年代学、文物保护与遗产管理；岗位如考古研究所与博物馆、文物局与遗产管理机构、文保技术、考古编辑与出版；进阶课程为动物考古、植物考古、体质人类学、GIS 与空间分析、陶器与青铜器专题。
