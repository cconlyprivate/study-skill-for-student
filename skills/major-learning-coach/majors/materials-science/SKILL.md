# 材料科学与工程（materials-science）

> 先读 `../../references/curriculum-rules.md`（难度与排序）与 `../../references/learning-card-template.md`（讲解结构）。
> 本文件只给这个专业的知识骨架与专业习惯。

## 1. 这个专业在训练什么

材料的人靠一条因果链吃饭：**成分与工艺决定结构，结构决定性能**。给一个性能指标或一次失效，要能反推该动哪一环——换成分、改冷速、还是改后续加工，并说清每一环的代价。

外人以为材料 = 磨金相 + 拉拉伸 + 背牌号。金相照片和拉伸曲线只是证据，核心能力是**把微观结构当自变量、把宏观性能当因变量**，并在两头之间做定量估算：晶粒多大、相占多少、位错密度多少、裂纹能容忍多长。

它和化学、化工、机械的分界在问题的终点：化学问"这物质怎么合成、结构是什么"，化工问"怎么放大到万吨级"，机械问"给定性能，零件做多粗"，材料问"这个成分与工艺做出来的东西，性能为什么是这样、还能不能更好"。

**最容易误解的一点**：以为材料靠实验堆经验。真正拉开差距的是 K01（晶体与缺陷）与 K03（相变与热处理）：它们让你在动手之前就能说出组织会是什么样，从而知道该测什么、不必测什么。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能由给定成分与冷速，在相图或 CCT 图上画出冷却路径，并算出各相与组织的相对量。
2. 能对给定零件做强度、硬度或断裂韧性校核，写出判据、安全系数来源与失效模式。
3. 能为一个性能要求排出"成分—工艺—组织"方案，并说明每一步在改哪一环、付出什么代价。
4. 能读 XRD 图谱定物相与晶格常数，说清峰位偏移与峰宽各自对应什么结构变化。
5. 能按观察尺度选 SEM 或 TEM，判断一张图与一个 EDS 结果能证明到什么程度。
6. 能画出 TTT 与 CCT 示意图，由冷速判断最终组织，并解释淬透性与淬硬性的差别。
7. 能写一份含试样、方法、原始数据、误差来源与结论边界的实验或失效分析报告，未测的量如实标注。

## 5. 术语与符号约定

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| 成分 wt% 与 at% | 质量分数与原子分数 | % | 相图与钢号按 wt%，扩散与占位按 at%；换算要用原子量，轻元素合金里 1 wt% 可能是十几 at% |
| 晶面指数 $(hkl)$ | 晶面在三个轴上截距的倒数化整 | 互质整数，可为负 | 截距为无穷时指数取 0；负号写在数字上方；一族晶面用 $\{111\}$，单个晶面才用 $(111)$ |
| 晶向指数 $[uvw]$ | 两点坐标差化成最小整数 | 互质整数，可为负 | 方向相反必须变号；立方晶系中 $[hkl]$ 垂直于 $(hkl)$，其他晶系不成立 |
| 六方指数 $(hkil)$ | 六方晶系的四指数表示 | $i=-(h+k)$ | 第四位 $i$ 不能省也不能独立取值；$[0001]$ 是 $c$ 轴，别写成 $[001]$ |
| 滑移系与独立滑移系 | 一个滑移面加一个滑移方向 | FCC 12 个、BCC 12 个、HCP 基面 3 个 | 滑移系数量不等于独立系数量：FCC 12 个滑移系只有 5 个独立系；HCP 塑性差是独立系少，不是键合弱 |
| 柏氏矢量 $\mathbf{b}$ | 位错造成的点阵畸变总和 | 方向与模长，nm | 刃型位错 $\mathbf{b}$ 垂直于位错线，螺型平行于位错线；滑移面必须同时包含位错线与 $\mathbf{b}$ |
| 位错密度 $\rho$ | 单位体积内的位错线长度 | 退火态约 $10^{10}$ m⁻²，强变形可达 $10^{15}$ m⁻² | 老教材常用 cm⁻²，$10^{8}$ cm⁻² 等于 $10^{12}$ m⁻²，代公式前先统一 |
| 四类强化机制 | 固溶、细晶、形变、第二相强化 | 强度增量用 MPa | 除细晶外其余三类都以损失塑性为代价，细晶是少数能同时改善强度与塑性的；第二相要区分切过与 Orowan 绕过，别只写"析出强化" |
| Schmid 因子 $m$ | 滑移系分切应力与轴向应力之比 | $m=\cos\phi\cos\lambda$，最大 0.5 | 最大值出现在 $\phi=\lambda=45^\circ$；多晶体取 $m$ 最大的滑移系先开动，不是取平均 |
| 工程应力应变与真应力应变 | 按原始尺寸与瞬时尺寸定义 | MPa 与无量纲 | 颈缩后工程应力下降而真应力仍上升；真应变用 $\ln(L/L_0)$，大变形时两者差别不能忽略 |
| 强度指标 $R_{eL}$、$R_{p0.2}$、$R_m$ | 下屈服强度、规定塑性延伸 0.2% 的应力、抗拉强度 | MPa | 无明显屈服平台的材料才用 $R_{p0.2}$；$R_m$ 是工程应力峰值，不等于断裂应力 |
| 塑性指标 $A$、$Z$ | 断后伸长率与断面收缩率 | % | $A$ 依赖标距，必须注明 $A_{50mm}$ 这类条件；不同标距的 $A$ 不能直接比较 |
| 硬度 HV、HBW、HRC | 维氏、布氏、洛氏硬度 | HV 常按 kgf/mm² 计，HBW、HRC 为标尺读数 | 三种标尺的压头与载荷不同，换算表只对特定材料与范围有效；渗层与薄片要用显微硬度并注明载荷 |
| 断裂韧性 $K_{IC}$ | 平面应变断裂韧度 | MPa·m$^{1/2}$ | 单位不是 MPa/m；$K_I$ 随裂纹长度变化，$K_{IC}$ 才是厚度足够时的材料常数 |
| 冲击吸收功 $KV_2$ | 夏比 V 型缺口冲击功 | J | 冲击功是能量，不是韧性指标本身；同一材料不同温度差数倍，必须注明试验温度 |
| 疲劳极限与 S-N 曲线 | 应力幅与循环寿命的关系 | MPa 与循环数 | 钢有疲劳极限，铝合金没有，只能给指定寿命下的条件疲劳强度；别把 10⁷ 次的值当无限寿命 |
| 相律 $F=C-P+2$ | 自由度、组元数与相数 | — | 凝聚态常压固定时写成 $F=C-P+1$；数的是"相"不是"组织"，珠光体是一种组织、两个相 |
| 杠杆定律 | 两相相对量反比于到合金成分的距离 | 0 到 1，或 % | 支点永远是合金成分，两端是两相成分；算反了不会报错但结论全错，算完用两相之和为 1 核对 |
| 共晶、共析、包晶 | 三相共存的特征反应 | 特征温度与成分点 | 共晶是液相同时析出两固相，共析是固相同时析出两固相，包晶是液相加固相生成新固相，三者别混 |
| 过冷度 $\Delta T$ | 实际温度与平衡转变温度之差 | °C 或 K | 形核率随 $\Delta T$ 先增后减；TTT 图鼻部对应孕育期最短，不是转变完成最快 |
| TTT 与 CCT | 等温转变图与连续冷却转变图 | 时间-温度坐标 | TTT 是等温保温，CCT 是连续降温；同一冷速下 CCT 曲线在 TTT 右下方，临界冷速要用 CCT 的切线求 |
| 淬透性与淬硬性 | 获得马氏体的深度能力与马氏体的硬度 | — | 淬硬性主要由碳含量决定，淬透性由过冷奥氏体稳定性决定；两者不能互换，也不能用硬度值反推淬透性 |
| $M_s$ 与 $M_f$ | 马氏体转变开始与结束温度 | °C | 只随成分（尤其碳含量）变，与冷速无关；冷到 $M_f$ 以下残余奥氏体才最少 |
| Hall-Petch 关系 | 屈服强度与晶粒尺寸的关系 | $\sigma_y=\sigma_0+k_y d^{-1/2}$，$d$ 用 mm 或 μm | $d$ 是晶粒直径不是半径；纳米晶会出现反 Hall-Petch，不能把直线无限外推 |
| 强塑积与强度塑性权衡 | 抗拉强度与延伸率的乘积 | MPa·% 或 GPa·% | 多数强化手段提高强度必牺牲塑性，细晶是少数能同时改善两者的；报性能必须成对报 |
| 布拉格方程 | $2d\sin\theta=n\lambda$ | $d$ 与 $\lambda$ 用 nm 或 Å，$\theta$ 为半角 | 图谱横坐标是 $2\theta$ 不是 $\theta$；$\theta$ 是入射线与晶面的夹角，不是与试样表面的夹角 |
| XRD 峰位与峰宽 | 物相、晶格常数、晶粒尺寸与微应变的信息载体 | $2\theta$ 用度，晶粒尺寸用 nm | 峰移可能来自固溶、残余应力或测角误差；峰宽要先扣仪器展宽，再用 Scherrer 公式估晶粒尺寸 |
| SEM 与 TEM 的分辨能力 | 成像分辨率与可分析体积 | SEM 二次电子像几 nm，TEM 点分辨率 0.1 到 0.2 nm | 放大倍数不是分辨率；EDS 的空间分辨率约 μm 级，由作用体积决定，远低于图像分辨率 |

## 6. 典型题型与解题套路

### 题型一：相图计算题（给成分与温度，求相组成与组织相对量）
1. 先定位：把成分点与温度点画到相图上，确认落在单相区还是两相区；单相区不套杠杆定律。
2. 找两端：过成分点作水平线，读出与相界的两交点，这两个成分就是两平衡相的成分。
3. 套杠杆：$w_\alpha=\dfrac{x_\beta-x_0}{x_\beta-x_\alpha}$，支点是合金成分 $x_0$，分母是两相成分差；算完用 $w_\alpha+w_\beta=1$ 核对。
4. 若问组织而不是相：先算先共析相，再按共析成分折算共析组织，最后相加，并在答案里分开写"相组成"与"组织组成"。
5. 结论带单位与百分比，并注明用的是哪个温度下的相界点，否则同一题不同温度会得到不同答案。
**常见失分点**：杠杆定律的支点与两端搞反，或者把组织组成物当相组成物，两个数字都能算出来但只有一个是对的。

### 题型二：强度与硬度校核题
1. 先定失效模式：静载屈服、疲劳、脆断还是磨损失效，四种模式对应 $R_{p0.2}$、S-N 曲线、$K_{IC}$、硬度四套判据，选错判据后面全错。
2. 算工作应力：把载荷折成名义应力，注明是否乘应力集中系数 $K_t$，冲击载荷另乘动载系数。
3. 取许用值：从标准、手册或实测取强度值，安全系数必须写出来源（规范给定还是课程给定），不能自己拍一个。
4. 比较并下结论：$\sigma_{\max}\le[\sigma]$ 才算通过；不通过时给出改法（加大截面、换材料、改热处理），并说明每种改法牺牲了什么。
5. 硬度校核单独处理：先确认是宏观硬度还是显微硬度，渗层、焊缝、薄片要标载荷与压痕位置；换算成强度只在同族材料内做。
**常见失分点**：拿 $R_m$ 除安全系数当许用应力却不说明，或把硬度换算表跨材料族直接套用。

### 题型三：工艺—组织—性能推理题
1. 画四链条：成分 → 工艺（加热温度、保温时间、冷速）→ 组织（相、晶粒、缺陷）→ 性能（强度、塑性、韧性），每一步只允许改一个变量。
2. 定冷却路径：在铁碳相图或 CCT 图上画出该工艺的冷却曲线，标出它穿过了哪些转变区、在哪个温度停留最久。
3. 定组织：按冷速判断得到珠光体、贝氏体还是马氏体，写清晶粒尺寸、第二相形态与残余奥氏体量。
4. 推性能：组织对应强度与塑性，晶粒细化用 Hall-Petch 估增量，第二相按 Orowan 绕过或切过机制判断强化幅度。
5. 反向验算：性能不达标时指出该改哪一环（成分、冷速、回火温度），并说明另一环为什么不动。
**常见失分点**：只说"淬火后变硬"，不写冷却曲线穿过了哪个转变区；忽略截面尺寸造成的心部冷速不足。

### 题型四：表征结果判读题
1. 先问三个问题：这方法测的是体相还是表面、空间分辨率多少、检出限多少；拿这三个数与待解释的特征尺度对比，再决定结论能不能下。
2. XRD：先由峰位定物相与晶格常数，再看峰宽、峰强比与峰形，分别对应晶粒尺寸与微应变、择优取向、重叠峰。
3. 电子显微：SEM 看形貌与断口（解理还是韧窝），背散射看成分衬度，EDS 只做半定量且要避开晶界与第二相；TEM 只看薄区，先排除制样损伤再谈代表性。
4. 交叉验证：至少用两种独立方法互相印证（XRD 物相加 EDS 成分加 DSC 热效应），单一证据不下结论。
5. 写结论时分成"数据支持"与"数据不能排除"两栏，并给出下一步该补测什么。
**常见失分点**：把 SEM 的放大倍数当分辨率，或用 EDS 的 μm 级成分结果去解释 nm 级析出相。

## 7. 常见误区

1. **把 wt% 与 at% 混用** → 错在成分基准没声明；相图与钢号用 wt%，扩散与占位用 at%，换算要除原子量，应先写清基准再代公式。
2. **杠杆定律支点找错** → 错在把某一端相当支点；支点永远是合金成分，算完立刻用两相之和为 1 验算，反了能查出来。
3. **拿 TTT 图查连续冷却** → 错在把等温当连续；连续冷却必须用 CCT 曲线与冷却曲线相切求临界冷速，TTT 只适用于等温退火与等温淬火。
4. **强度与塑性只报一个** → 错在把强化当免费；多数强化机制都以塑性为代价，报性能必须强度与塑性成对报，并注明是工程值还是真值。
5. **硬度换算当恒等** → 错在跨材料族套表；HV、HBW、HRC 的压头与载荷不同，换算表只在指定材料与范围内有效，超出范围要重测。
6. **XRD 只认最强峰** → 错在忽略择优取向与重叠峰；定物相至少核对三强峰，并用晶格常数与峰强比交叉验证。
7. **把 SEM 放大倍数当分辨率** → 错在混淆显示倍数与可分辨细节；分辨率由束斑与信号体积决定，EDS 的成分空间分辨率还要再差一个量级。
8. **编数据、编标准号、编牌号性能** → 错在把"看起来合理"当事实；没做实验就写"未测"，引标准要写全编号、年份与名称并核对现行版本，性能数据必须给出来源。

## 9. 交叉专业与后续方向

- **和化学的区别**：化学的终点是"这物质是什么、怎么合成、机理怎么走"；材料的终点是"这个成分与工艺做出来的块体，性能为什么是这样"。同一张 XRD，化学用它定结构，材料还用它算晶格常数、残余应力与晶粒尺寸。
- **和化学工程与工艺的区别**：化工问"怎么放大到万吨级，传热传质、能耗与设备怎么定"；材料问"放大之后冷却速度变了，组织与性能会怎么变"。化工管流程与设备，材料管流程参数落在材料上的后果。
- **和机械工程的区别**：机械在"给定材料性能"的前提下定几何（多粗、什么配合、怎么装），材料回答"这个性能从哪来、能不能再高、失效时是什么模式"。同一根断轴，机械算应力够不够，材料看断口是疲劳辉纹还是解理。
- **和物理学（凝聚态）的区别**：物理追求普适机制与干净体系，材料必须处理多相、缺陷、杂质与工艺历史，要在"不干净"的体系里给出可用结论。
- **不编造实验数据与标准号**：硬度值、强度值、衍射峰位、标准编号都必须来自实测、手册或可查证的正式标准。没做就写"未测"，记不清编号就只写标准名称并注明"编号待核"，绝不能凭印象编一个像真的编号（如把 GB/T 228.1 与 ASTM E8/E8M 这类常用标准张冠李戴）。
- **后续方向**：金属材料与热处理、无机非金属与陶瓷、高分子与复合材料、电子与新能源材料、材料表征与失效分析；考研常见方向为材料物理与化学、材料学、材料加工工程。
