# 英语（english）

> 先读 `../../references/curriculum-rules.md`（难度与排序）与 `../../references/learning-card-template.md`（讲解结构）。
> 本文件只给这个专业的知识骨架与专业习惯。

## 1. 这个专业在训练什么

训练对象是**两种语言之间可核对的对应关系**，不是"英语说得溜"。同一句中文，英语专业要回答四件事：这句话的信息结构是什么、英文里该由哪个成分承担、这样处理牺牲了什么、能不能给出理由。

**一句话画像**：在语言、文学、翻译三条线上做准确的中英转换。

外人常以为这专业 = 背单词加练口语。实际的基本功是四块：把语音、语法、语义说准（K01、K02），把文本读成可论证的判断（K03），把判断落到可核对的译文（K04），把结论写成合规范的英文并用数据与量表支撑它（K05–K07）。四块共用一套写法——**先给证据，再给判断**；没有证据的"我觉得这句译得好"一律不算分。

和汉语言文学的界线：中文系答"这段文本如何构成"，英语专业还要答"换成英文如何构成、译回中文时丢了什么"。和翻译专业的界线：英语专业把翻译当作四块能力之一，另三块是语言、文学、教学（教学是语言这一块的出口）；翻译专业把翻译当全部，口译、本地化、术语管理都要专门训练。

**最容易误解的一点**：以为词汇量决定水平。拉开差距的是句法与语篇——词可以查，句法错了整句都错，语篇错了整段读不通。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能给一段陌生语料做音位归纳或画出句法树，并把每一步测试写成别人能复核的步骤。
2. 能对一首诗或一段小说写出 500 字细读，含 1 个论点、3 处引文、1 个反例。
3. 能把 300 字中文译成英文，标出全部增补、省略、转换并逐条给理由。
4. 能对一篇现成译文写出评析，指出 5 处问题并按对等层次归类，各给改译。
5. 能按 APA 或 MLA 排一篇 3000 字论文的引用与文献表，全篇格式一致。
6. 能改掉自己作文里的中式英语，指出违反的是搭配、冗余还是信息结构。
7. 能用一节 45 分钟的课完成"目标—活动—评估"三件套，并交出一份可用的评分量表。

## 5. 术语与符号约定

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| 音素 phone / 音位 phoneme | 音素是实际音值，音位是能辨义的最小单位类 | 音素写 `[ ]`，音位写 `/ /` | 把变体当音位：英语送气与不送气的 p 属同一音位，不能据此立新音位 |
| 最小对立对 minimal pair | 只差一个音位而意义不同的两个词 | 如 pit/bit、ship/sheep | 两个条件要同时成立：只差一个音位、意义不同；差两个音位不算 |
| 互补分布 complementary distribution | 两个变体出现的语音环境不重叠 | — | 互补分布是归纳音位的主要证据，但还要加"语音相似"才能立音位 |
| 自由变体 free variant | 同一音位在不同环境可自由替换的变体 | — | 自由变体不辨义；能辨义的就不是变体，是不同音位 |
| 语素 morpheme / 形素 allomorph | 最小音义结合体 / 同一语素的不同语音形式 | 派生 derivational，屈折 inflectional | `-s` 的 /s z ɪz/ 是同一语素的三个形素，不是三个语素 |
| 句法树 syntactic tree | 节点标 NP、VP、PP、CP，姐妹节点合成短语 | 每个节点都要有测试依据 | 按词义分层画树是通病；成分边界要用替换、移动、并列三种测试确认 |
| 结构歧义 structural ambiguity | 同一表层结构对应两棵树 | 如 old men and women | 只有结构歧义要画两棵树；词汇歧义换词即消，不要混着答 |
| 时 tense / 体 aspect / 态 voice | 时=说话时间与事件时间的关系；体=事件内部阶段；态=主语与动作的角色 | 英语时只分 present / past | 三分为三个维度，不是 12 个"时态"标签；will 是情态，不是将来时 |
| 及物性 transitivity / 论元 argument | 动词必有的成分是论元，可选的叫附加语 adjunct | 论元个数即动词的价 valency | "他吃了"里吃仍是二价，省略的宾语是隐含论元；附加语不能算论元 |
| 题元角色 theta role | 施事、受事、经验者、目标、工具等语义角色 | 一个名词短语一个角色 | 主语不等于施事：被动句主语是受事，别把句法位置当语义角色 |
| 搭配 collocation / MI 值 | 词与词的共现倾向 | MI = log2(观察频次/期望频次) | 只看频次会让 the、of 排最前；MI 对低频过敏，须设最低频次阈值 |
| 预设 presupposition / 含义 implicature | 预设是句子成立的前提，含义是可取消的推理 | 预设触发语：定指、事实动词、again | 用否定测试区分：否定后仍成立的是预设，消失的是含义 |
| 言语行为 speech act | 言内 locution、言外 illocution、言后 perlocution | 施为句多为第一人称现在时直陈 | 言外之力是说话者意图，言后之效是听者反应，两层不能互换 |
| 直译 literal / 意译 free | 直译保形式（句法、意象），意译保功能 | 是连续体，不是二分 | 直译不等于逐字死译；写译评必须说明"在哪一层"直译（词、句、篇） |
| 形式对等 / 功能对等 | 对源语形式负责 / 对目标语读者反应负责 | Nida 提出 | 功能对等不是随便改写，仍受意义与意图约束；删文化信息属过度归化 |
| 归化 domestication / 异化 foreignization | 向目标语读者靠拢 / 保留他者痕迹 | Venuti 提出 | 与直译意译不是同一组：前者是伦理与策略，后者是操作层，别混答 |
| 可译性限度 limits of translatability | 语音、字形、双关、文化专有项最难译 | 按类别列举 | 只说"不可译"不给类别与补偿方案，等于没答；补偿手段有加注、替换 |
| 翻译单位 unit of translation | 译者实际处理的最小片段 | 词、短语、句、段、篇 | 单位越小越容易对字不对句；句以上必须看衔接与信息结构 |
| 显化 explicitation / 隐化 | 译文明示原文隐含的逻辑与指称 / 反过来省略 | 汉译英多显化主语与连接词 | 显化不等于加解释；补出的信息必须能从原文推出，否则是增译失当 |
| 韵式 rhyme scheme / 步格 metre | 行末押韵的排列用字母标；步格按音步类型与数量命名 | 如 abab、iambic pentameter | 数音步数的是重音组数，不是音节数；同韵必须同字母 |
| 跨行 enjambment / 行内停顿 caesura | 句法不在行末结束 / 行内停顿 | — | 分析前先分行标号；把跨行当断句错误是最常见的读诗错误 |
| 叙述者 narrator / 聚焦 focalization | 谁在说 / 谁在看 | 第一人称限知不等于作者 | 判不可靠叙述要文本证据（自相矛盾、信息缺口），不能凭印象 |
| APA / MLA | APA 用作者-年份，文献表叫 References；MLA 用作者-页码，表叫 Works Cited | 语言教育与社科多用 APA，文学多用 MLA | 同一篇不能混用；书名期刊名斜体、篇名加引号，两套标点规则不同 |
| 中式英语 Chinglish 的句法特征 | 冗余名词化、连缀式连接词、语序直搬、搭配硬配、主语缺失 | 如 learn knowledge、open the light | 语法对但搭配错也算中式英语；改法先改搭配与主语，不是加冠词 |

## 6. 典型题型与解题套路

### 语言学分析题（给一组语料，让你归纳音位、画树、判语义关系）
1. 先把语料整理成最小对立对表，只保留"差一个音位 + 意义不同"的对子，其余划掉并写明原因。
2. 音系题走三步：最小对立对定音位 → 互补分布定变体 → 写成规则 `A → B / 环境`。句法题先做替换、移动、并列三种测试，确认成分边界再落笔。
3. 树从 CP 往下画：先定时与情态节点，再挂论元，最后挂附加语；每个节点注明是词还是短语。
4. 语义与语用题先给判断（同义、反义、上下义，或预设、含义、言外之力），再用一对最小差异句证明这个判断。
**常见失分点**：只抄语料不作归纳；画树按词义分层，全卷没有一处成分测试依据。

### 文学 close reading（给一首诗或一段小说，写 400–600 字分析）
1. 通读两遍：第一遍求通，第二遍标出重复词、转折词、人称与时态的变化处。
2. 找一处语言上的"反常"（跨行、破格、突然的短句、视角滑移），把它写成一句可辩护的论点，格式是"文本中的什么，因此怎样"。
3. 选 3 处引文，每处按"引—释—扣"三步：引原文、解释字面与形式特征、说明它支撑哪个判断。
4. 处理一个反例或一个竞争读法，说明它为什么不推翻你的论点。
5. 结尾回到论点，并说明这个读法适用于哪类文本。
**常见失分点**：通篇复述情节或把诗句翻成中文当分析；意象、反讽等术语后面没有落到具体词。

### 翻译评析与实操（给原文要你译，或给原文加译文要你评）
1. 先定文本类型与读者（信息类、表情类、操作类），据此决定"保形式"还是"保功能"。
2. 划翻译单位：先切句，再在句内标出必须重排的成分——定语从句、状语位置、汉语无主句。
3. 逐句译，至少各标一处增补（主语、连接词）、省略（重复成分）与转换（词性、语态），并写明理由。
4. 评析题做四列对照表：原文片段、译文、问题类型（误译、漏译、过度归化、搭配错、语域不符）、改译。
5. 收尾判断哪些损失可补偿、哪些不可补偿，给出一个具体补偿方案（加注、替换、调整语序）。
**常见失分点**：只写"译文不通顺"不给问题类型与改译；把归化异化与直译意译混在同一题里答。

### 学术写作（摘要、文献综述、引用格式改错）
1. 先用一句话写研究问题，再按"背景—问题—方法—结论"四句压缩成摘要。
2. 综述做成"主题列 × 文献行"的表，每格写"谁 + 做了什么 + 结论"，空着的格子就是你的研究空间。
3. 引用逐条核三处：文中引用（作者、年份或页码）、文献表排序、斜体与标点。
4. 改中式英语按顺序来：先删冗余名词化与 there be，再补主语与限定词，最后改搭配。
5. 交稿前做一致性检查：术语、缩写、时态（方法与结果用过去时，普遍结论用现在时）。
**常见失分点**：APA 与 MLA 混用；文献表有条目而文中没引，或文中引了却不在表里。

## 7. 常见误区

1. **把音位变体当独立音位** → 错在跳过最小对立对测试；应先用"换一个音是否改变意义"筛一遍，再谈分布。
2. **按语义画句法树** → 错在没有成分测试；应先用替换、移动、并列三种测试确认边界，再决定节点。
3. **把英语时态当成 12 个标签背** → 错在混淆时、体、态三个维度；应先定时（present / past），再依次叠加体与态。
4. **把主语等同于施事** → 错在把句法位置当语义角色；被动句与心理动词句里两者经常分离，答题要分两层写。
5. **直译就是逐字译、意译就是随便改** → 错在把操作层与策略层混为一谈；先定翻译单位与文本类型，再选策略。
6. **写"此处不可译"就收笔** → 错在缺类别与补偿；应指明是语音、双关还是文化专有项，并给加注或替换方案。
7. **先套理论再找文本** → 错在让证据为术语服务；应先用细读找出反常，再选能解释它的概念，并写出该概念的失效处。
8. **以为语法没错就是好英语** → 错在漏了搭配与语域；中式英语多数句子语法成立，错在搭配、冗余与信息结构，改稿要专查这三项。
9. **引用格式留到最后统一改** → 错在返工成本；应边写边录入文献管理条目，交稿前只做格式抽查。

## 9. 交叉专业与后续方向

- **和翻译专业的区别**：英语专业把翻译当作四块能力之一，理论够用即可；翻译专业以翻译为本体，口译、本地化、术语管理与项目管理都是必修，考核看交付质量与交期。
- **和汉语国际教育的区别**：汉语国际教育把汉语作为目标语教给外国人，本体是汉语语音、汉字与二语教学法；英语专业的教学线（K06）把英语作为目标语，本体是英语语言学与英语课堂。
- **和汉语言文学的区别**：同样做文本分析，中文系的底气在古代汉语与文献，英语专业在语言对照、英文原文与理论译介；同一首诗，中文系讲格律与典故，英语专业讲韵式、跨行与译本取舍。
- **和新闻传播的区别**：新闻对事实与时效负责，英语专业对语言准确与转换负责；国际新闻岗要两套能力叠加。
- **后续方向**：考研走英语语言文学、外国语言学及应用语言学、翻译硕士（MTI）、学科教学（英语）；岗位如中学英语教师、高校与培训机构教研、外事与外企沟通、出版编辑与版权引进、本地化与术语管理；进阶课程为音系学、句法学、文体学、比较文学、语料库语言学、翻译技术。
