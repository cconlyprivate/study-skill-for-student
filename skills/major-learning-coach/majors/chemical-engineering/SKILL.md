# 化学工程与工艺（chemical-engineering）

> 先读 `../../references/curriculum-rules.md`（难度与排序）与
> `../../references/learning-card-template.md`（讲解结构）。
> 本文件只给这个专业的知识骨架与专业习惯。

## 1. 这个专业在训练什么

把烧杯里的反应搬到万吨级装置上，同时算清三本账：物料去哪了、热量怎么进出、设备要做多大。给一张流程图，要能说出每一股物流的流量与组成、每一台设备的负荷、以及卡住产能的那一步在哪。

外人以为化工 = 把化学实验做大。放大不是等比放大：管径变了雷诺数就变，单位体积的传热面积随尺寸线性下降，混合时间与停留时间跟着变——同一套条件在 1 L 与 100 m³ 里是两件事。

它和化学的分界线很干脆：化学回答"这个反应能不能发生、主产物是什么、机理怎么走"，化工回答"怎么把它连续地做出来、热量怎么移走、物料怎么循环、设备多大、出事时怎么不炸"。化学给的是可行性，化工给的是可实施性。

**最容易误解的一点**：以为化工是"化学 + 设备"。真正的功夫在**基准与自由度**——先把基准选对、把独立方程数点清，再动笔算，否则算得再快也是错的。

**最陡的三门课**：化工原理（因为流体、传热、传质三套完全不同的分析方法塞在一门课里，且每套都有自己的经验式）、化工热力学（因为逸度与活度这套符号要贯穿全流程，概念不清就只剩代公式）、化学反应工程（因为要把实验室的速率数据换成工业反应器的体积，中间隔着返混与移热）。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能对一张给定的流程图标出全部物流编号与自由度，判断还缺几个条件才能求解。
2. 能独立完成带循环与旁路的物料衡算，同时给出单程转化率与总转化率。
3. 能对一条实际管路算出雷诺数、直管与局部阻力，定出泵的流量与扬程工作点。
4. 能由两侧膜系数、污垢热阻与壁厚算出总传热系数，再反算需要的换热面积。
5. 能对精馏塔算出理论板数、实际板数与最小回流比，并说明回流比加大后能耗怎么变。
6. 能对同一动力学分别算出 CSTR 与 PFR 的体积，说清差在哪、为什么。
7. 能判断一张流程图的瓶颈在反应、分离还是换热，并给出三条带代价的改进方案。
8. 能对涉可燃物的工段查出现行爆炸极限，写出惰化或稀释的具体措施。

## 5. 术语与符号约定

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| 衡算基准 | 物料衡算所取的时间、质量或摩尔基准 | kg/h、kmol/h、批 | 基准一旦选定全流程不得中途换；给"年产 10 万吨"要先除以年操作时数折成 kg/h |
| 能量衡算基准态 | 焓的零点，常取 25 ℃、1 atm 下的稳定单质 | kJ/kmol | 元素基准与化合物基准不能混用；换基准要整表重算，不能只改一项 |
| 参考温度 $T_0$ | 计算显热与焓差的下限温度 | K、℃ | 用 $C_p$ 积分时 $T_0$ 必须写进公式；两张基准不同的表直接相减会得到假热量 |
| 表压 / 绝压 / 真空度 | 三种压力基准 | Pa、kPa、MPa | 表压 = 绝压 − 大气压，真空度 = 大气压 − 绝压；三者符号最容易写反 |
| 摩尔分数 $y$、$x$ | 气相与液相的组成 | 无量纲 | 平衡关系式一律用摩尔分数；拿质量分数代进亨利定律结果差一个分子量比 |
| 质量流量 / 摩尔流量 / 体积流量 | 物流量的三种写法 | kg/s、kmol/s、m³/s | 气体体积流量随 T、P 变，做衡算必须换成质量或摩尔流量 |
| 雷诺数 $Re$ | 惯性力与黏性力之比 | 无量纲，判据 2000 / 4000 | 特征尺寸取管内径；非圆管用当量直径 $d_e = 4A/\Pi$，别直接套内径 |
| 流型判据 | 层流、过渡流、湍流的分界 | $Re<2000$；2000–4000；$>4000$ | 过渡区没有唯一关联式，工程上按湍流保守处理；题目不提就别把过渡流当层流 |
| 三种传热方式 | 导热、对流、辐射 | W/(m²·K) | 串联时是热阻相加而不是系数相加；辐射在高温段才不可忽略，低温流程可先行略去 |
| 总传热系数 $K$ | 串联热阻的倒数合成 | W/(m²·K) | $\frac{1}{K}=\frac{1}{h_i}+\frac{1}{h_o}+R_f+\frac{\delta}{\lambda}$；两侧面积不等时 K 必须注明以哪一侧为基准 |
| 对数平均温差 $\Delta t_m$ | 换热器两端温差的平均值 | K | 逆流才可直接用；多程或错流要乘温差校正因子，并核对它不低于 0.8 |
| 传质推动力 | 实际组成与平衡组成之差 | 摩尔分数或分压 | $\Delta y$ 与 $\Delta x$ 指向相反；塔顶塔底推动力不同，要取对数平均而非算术平均 |
| 传质单元数 $N_{OG}$ 与高度 $H_{OG}$ | 分离难度与填料效率的分解 | 无量纲 / m | $Z=H_{OG}N_{OG}$；低浓度才可简化成对数平均推动力，高浓度必须沿塔积分 |
| 最小液气比 | 吸收剂用量的下限 | kmol/kmol | 操作线在塔底与平衡线相交时达到；实际取 1.1–2 倍，取等号则塔高无穷大 |
| 相对挥发度 $\alpha$ | 气液分离难度的度量 | 无量纲，$\alpha>1$ | $\alpha$ 随温度变，全塔取平均值要写明取法；$\alpha$ 接近 1 时理论板数急剧上升 |
| 回流比 $R$ | 回流量与塔顶产品量之比 | 无量纲 | R 增大板数减少但再沸器负荷上升；最小回流比对应理论板无穷多，不是最省钱点 |
| 理论板 / 实际板 / 板效率 | 理想平衡级与实际级的折算 | 块 | 实际板数 = 理论板数 ÷ 全塔效率；效率取 0.5–0.7 是经验值，必须写明来源与适用物系 |
| 停留时间 $\tau$ | 物料在反应器内的平均停留时间 | s、min | CSTR 与 PFR 的 $\tau$ 都定义为 $V/v_0$，但达同一转化率所需体积差很多；$\tau$ 不是每个分子的实际逗留时间 |
| 空时与空速 | 反应器处理能力的另一种写法 | s、h⁻¹ | 空速是空时的倒数，量纲要统一；气时空速与液时空速不能互相代换 |
| 转化率 $X$ | 已反应量与进料量之比 | % | 分母是限制反应物的进料量；带循环的流程有单程与总转化率两个值，先看清题目问哪个 |
| 选择性 $S$ 与收率 $Y$ | 目标产物占比与总账 | % | $Y = X\cdot S$；选择性分母是已反应的原料，收率分母是进料，三者分母各不相同 |
| 放大效应 | 尺寸变化引起的传递过程失真 | — | 单位体积传热面积随特征尺寸线性下降；放大后混合时间变长、移热变差，实验室最优条件不能直接搬 |
| 爆炸极限 LEL / UEL | 可燃物在空气中的可燃浓度范围 | 体积 % | 随温度、压力与惰性气含量变化；低于 LEL 和高于 UEL 都不可燃，只有中间区间才危险 |
| 工艺数据与安全规范 | 设计取值及其法规来源 | — | 工艺数据以现行国家标准与安全规范为准；教材例题可能已过期，引用时必须写清规范号与年份 |

## 6. 典型题型与解题套路

### 题型一：物料衡算与能量衡算题
1. 先画流程框图，给每股物流编号，把已知量与未知量直接标在图上，不要在文字里空想。
2. 选基准：连续过程取单位时间（kg/h 或 kmol/h），间歇取一批；含惰性组分时以惰性组分为联系组分最省事，基准写在解题第一行。
3. 列方程并核自由度：每个单元写总物料衡算与关键组分衡算，未知量个数必须等于独立方程数，多了就说明还缺条件。
4. 能量衡算另立基准态：取 25 ℃、1 atm 的稳定单质为零焓，把显热、潜热、反应热全部换算到同一基准再相加。
5. 回代检验：总量闭合、每个组分进出相等、焓差的正负与吸放热方向一致。
**常见失分点**：物料用一个基准、能量换另一个基准，两套数字一相加就全错。

### 题型二：精馏与吸收计算
1. 先把平衡关系写出来：精馏用 y-x 平衡曲线或相对挥发度，吸收用亨利定律并确认是 E、H 还是 m 的写法。
2. 精馏先做全塔物料衡算求塔顶与塔底量，再写精馏段与提馏段操作线；吸收先定液气比，由最小液气比反推实际用量。
3. 定推动力：塔顶塔底各算一次，再取对数平均；浓度高时改用积分式，不能图省事取算术平均。
4. 精馏从塔顶开始逐板画阶梯，跨过进料点后换用提馏段操作线，数出的阶梯数才是理论板数；吸收用 $Z=H_{OG}N_{OG}$。
5. 结果检查：回流比必须大于最小回流比、理论板数随 R 增大而减少、液气比必须大于最小值。
**常见失分点**：α 取错温度、推动力取算术平均、把进料板在两条操作线上各数一次导致板数偏多。

### 题型三：反应器设计题
1. 先写清目标：是给定产量与转化率求体积，还是给定反应器求出口组成——两者的方程形式不同。
2. 定动力学：由实验数据回归级数与速率常数，写明 k 的单位（它随级数变），温度变化时用 Arrhenius 修正。
3. 选模型：CSTR 用 $V=\frac{F_{A0}X}{-r_A}$，PFR 用 $V=F_{A0}\int_0^X\frac{dX}{-r_A}$；同一动力学同级转化率下 CSTR 体积恒大于 PFR，多级串联按出口浓度逐级算。
4. 多重反应用选择性判断而不是只看转化率：平行反应看级数定该浓还是该稀，串联反应看返混定该用 CSTR 还是 PFR。
5. 校核三件事：停留时间、空速、移热量必须同时对得上，绝热温升超过允许值就改换热方案。
**常见失分点**：把转化率当收率、忘了 k 的单位随级数变、给 CSTR 直接套 PFR 的体积公式。

### 题型四：工艺流程分析题
1. 先读图：找到原料入口、产品出口、循环回路与排放点，把流程切成"反应—分离—循环"三段。
2. 标出每段的操作条件与关键控制指标，分清哪些由分离要求决定、哪些由设备或安全限制决定。
3. 找瓶颈：看哪一步转化率低、哪一股循环量大、哪个换热器温差最小；瓶颈通常落在循环量与温差上。
4. 提改进：从反应条件、分离序列、热集成三个方向各给一条，并说明每条改动会让哪台设备变大或变小。
5. 对齐安全：涉可燃物的工段标出爆炸极限与惰化措施，涉压力的工段说明设计压力与泄放去向。
**常见失分点**：只复述流程不指瓶颈，改进方案不交代代价，等于没提。

## 7. 常见误区

1. **不写基准就开算** → 错在中途换了基准还不自知；正确做法是第一行写明"以 1 h 为基准、以惰性组分为联系组分"。
2. **把实验室最优条件按比例放大** → 错在忽略比表面积与混合时间随尺寸的变化；应先算 $Re$ 与单位体积传热面积，判断哪一项先失真。
3. **质量分数直接代进摩尔分数的平衡关系** → 错在单位与基准都不对；先换成摩尔分数再查平衡数据，并注明换算所用的分子量。
4. **把转化率当收率报上去** → 错在分母不同；收率 = 转化率 × 选择性，报收率必须同时给另外两个数。
5. **CSTR 与 PFR 套同一个体积** → 错在没做体积分；同一转化率下 CSTR 需要更大体积，正反应级数越高差得越多。
6. **精馏只算板数不看回流比** → 错在把板数当唯一成本；R 增大板数减少而再沸器能耗上升，应取设备费与操作费之和的最低点。
7. **换热器用算术平均温差** → 错在两端温差相差大时误差可超 10%；两端温差之比大于 2 就必须用对数平均。
8. **安全数据凭记忆写** → 错在爆炸极限、闪点随温度与惰性气含量变化；必须查现行规范，并在答案里写清出处。

## 9. 交叉专业与后续方向

- **和化学的区别**：化学问"这个反应能不能发生、机理怎么走、选择性从哪来"；化工问"怎么连续生产、热量怎么移走、物料怎么循环、设备做多大"。同一张流程图，化学看主产物与副产物，化工看收率、能耗与瓶颈。
- **和材料科学与工程的区别**：材料把工艺当手段，追的是成分—工艺—组织—性能这条链；化工把工艺当对象，追的是产能、能耗与设备投资。结晶、干燥、粉体输送是两者的交汇处，材料关心粒度分布带来的性能，化工关心粒度分布带来的过滤与输送负荷。
- **和环境工程的区别**：环境工程从排放标准倒推处理工艺，化工从流程内部减少三废；末端治理的单元操作两家都学，但化工必须先算清物料平衡才知道该减哪一股。
- **和过程装备与控制工程的区别**：装备专业管"这台塔器、换热器怎么设计得扛得住"，化工工艺管"该不该用这台、放在流程哪个位置"；同一台设备，工艺定负荷，装备定壁厚。
- **数据与安全**：工艺数据（爆炸极限、闪点、毒性、设计压力、排放限值）一律以现行国家标准与安全规范为准，教材例题只能当练习；查不到就写明需要实测或查哪本规范，不给编造的数字。
- **后续方向**：石油化工与炼油、精细化工与制药工程、聚合反应工程、化工过程模拟与优化、新能源材料与碳捕集；考研常考化工原理与物理化学（或化工热力学），设计类岗位还看流程模拟软件的实操。
