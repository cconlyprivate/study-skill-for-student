# 电子信息工程（electronic-information）

> 先读 `../../references/curriculum-rules.md`（难度与排序）与 `../../references/learning-card-template.md`（讲解结构）。
> 本文件只给这个专业的知识骨架与专业习惯。

## 1. 这个专业在训练什么

用电路把信号搬进来、处理掉、再送出去，并且全程说得清"这个信号在时域长什么样、在频域占多宽、经过这一级之后还剩多少"。

三件套的关系是固定的：**电路**决定能不能实现，**信号**决定用什么数学描述，**系统**决定输入和输出怎么对应。考试与工程都在考这三者的接口——拿到一个方波，要能说出它经过一个 RC 网络后哪条边沿变缓、频谱上哪一段被压掉。

外人以为电子 = 焊板子 + 修电器。焊板只是 K07，真正拉开差距的是 K01（列方程）、K04（变换）、K05（链路预算）：这三块决定你能不能解释"为什么这个滤波器要这么设计、为什么这个误码率降不下来"。

它和电气工程的分界线是**信息还是能量**：电子关心毫瓦级信号有没有被噪声淹没，电气关心千瓦级功率能不能安全高效地送出去。同一门电路课，电子后面接信号与系统，电气后面接电机学与电力系统分析。

**最容易误解的一点**：以为频域分析是"另一种算法"。频域和时域是同一个信号的两种坐标，傅里叶变换不改变信息，只改变你看它的角度——所以时域算不出来的卷积，频域是乘法。

**最陡的三门课**：信号与系统（因为要建立"任何信号都能拆成正弦"的新直觉，旧直觉会拖后腿）、模拟电子（因为非线性器件必须先线性化才能算，工作点错了全题作废）、通信原理（因为同时要握带宽、噪声、判决三件事）。

电磁场与电磁波、微波技术通常排在选修或考研科目里，本表不单列知识点：它直接建立在 K01-6（相量）与 K04-3（频谱）上，学之前把这两个点过一遍。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能对任意一个含受控源的两端网络，用节点法或戴维南等效算出指定支路的电压电流，并用功率守恒验算。
2. 能由一个实际波形说出它该用傅里叶级数、傅里叶变换、拉氏变换还是 z 变换，并写出收敛域。
3. 能由系统函数的零极点图判断稳定性、写出冲激响应，并说明闭环后会不会自激。
4. 能按带宽与噪声算出接收端信噪比，判断给定调制方式能否达到目标误码率。
5. 能给一个采样系统定出采样率与抗混叠滤波器的截止频率，并解释混叠后为什么无法恢复。
6. 能读懂器件手册前几页的关键指标，判断它是否满足设计指标要求。
7. 能用示波器测出上升时间与纹波，并区分哪些是电路真实行为、哪些是探头引入的。
8. 能对一个不工作的单板，按"供电—时钟—复位—接口"的顺序定位到具体网络。

## 5. 术语与符号约定

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| 参考方向 | 事先假定的电压或电流正方向 | — | 方向选反不扣分但结果带负号；同一元件的电压电流必须成对标，只标一个等于没写 |
| 关联参考方向 | 电流从电压的正端流入元件 | — | 关联时 $p=ui$ 是吸收功率；把非关联当关联写出 $p=ui$，符号会整题反过来 |
| 吸收功率 / 发出功率 | 元件实际消耗或提供的功率 | W、mW | 算出负值说明实际在发出，不要改参考方向重算；用 $\sum p=0$ 验算 |
| 受控源 | 电压或电流受另一处电量控制 | VCVS、VCCS、CCVS、CCCS | 控制量必须先写成未知量；叠加定理里把受控源"置零"是最常见的错 |
| 相量 | 用复数表示同频正弦量的有效值与初相 | — | 相量只在单一频率下有定义；不同频率的相量相加没有任何意义 |
| 复阻抗 $Z$ | $Z=R+jX$，相量电压与相量电流之比 | Ω | $X_L=\omega L$ 为正、$X_C=-1/(\omega C)$ 为负，符号最容易反 |
| 有效值 | 均方根值，正弦量 $U_m/\sqrt 2$ | V、A | 相量默认取有效值，算平均功率时不要再乘 $1/2$ |
| 时间常数 $\tau$ | 一阶电路的 $RC$ 或 $L/R$ | s、ms、μs | $\tau$ 不是"到达稳态的时间"，工程上按 $3\tau$ 到 $5\tau$ 估调节时间 |
| 静态工作点 $Q$ | 直流工作点，直流通路决定 | V、mA | 画直流通路时把电容开路、电感短路，交流通路反之，两套图不能混用 |
| 虚短 / 虚断 | 负反馈下运放两输入端等电位、无电流 | — | 只有工作在放大区才成立；输出饱和时两条都不成立 |
| 拉普拉斯变换与收敛域 | 使积分收敛的 $\sigma$ 范围决定它能代表哪类信号 | — | 同一个系统函数配不同收敛域对应不同信号；判稳定必须极点与收敛域一起看 |
| z 变换与单位圆 | 离散信号的 $z$ 域表示与稳定性判据 | — | 连续系统看 $s$ 左半平面，离散系统看 $z$ 单位圆内，两套判据不可互换 |
| 傅里叶级数与变换的适用域 | 周期信号用级数，能量有限信号用变换 | — | 周期信号直接套变换公式会发散；功率信号的频谱要用冲激或功率谱描述 |
| 采样定理与奈奎斯特频率 | $f_s>2f_{\max}$，否则频谱周期延拓后重叠 | Hz | 2 倍是下限不是保证；带通采样看的是信号带宽而不是最高频率 |
| 混叠 | 高于 $f_s/2$ 的分量折回低频 | — | 混叠发生在采样瞬间，之后再滤波无法挽回；抗混叠滤波器必须放在 ADC 之前 |
| dB | 功率比取 $10\lg$，电压比取 $20\lg$ | — | 功率用 10、电压电流用 20；级联增益是 dB 相加而不是相乘 |
| dBm | 以 1 mW 为基准的绝对功率 | dBm | $0$ dBm 就是 1 mW；dBm 加 dB 仍是 dBm，dBm 加 dBm 没有物理意义 |
| 带宽 $B$ | 系统或信号能通过的频率范围 | Hz | $-3$ dB 带宽与占用带宽不是一回事；算噪声功率要用等效噪声带宽 |
| 信噪比 SNR | 信号功率与噪声功率之比 | dB | 比较前先统一到同一带宽；SNR 与 $E_b/N_0$ 差一个 $B/R_b$ 因子 |
| 香农容量 | $C=B\log_2(1+S/N)$，无误码传输的上限 | bit/s | 公式里的 $S/N$ 是线性比值不是 dB；它是上限，不是实际能达到的速率 |
| 调制指数与调制度 | AM 的 $m_a$、FM 的 $\beta$ | — | AM 过调制 $m_a>1$ 会让包络失真；FM 带宽按卡森公式取 $2(\beta+1)f_m$ |
| 星座图与 $M$ 阶 | 每个符号携带 $\log_2 M$ 比特 | — | 16QAM 是 4 bit 每符号，不是 16 bit；阶数越高对 SNR 要求越高 |
| 符号率与比特率 | $R_b=R_s\log_2 M$ | Bd、bit/s | 两者只在二进制时数值相等；频带利用率按 $R_b/B$ 算 |
| 逻辑电平与门 | 高低电平的定义与门电路的硬指标 | V | 正逻辑改负逻辑会翻转真值表；扇出与噪声容限是选型的硬约束 |
| 触发器与时钟沿 | 边沿触发的 D、JK 触发器 | — | 上升沿与下降沿看符号上的小圈；锁存器是电平敏感，不能当时钟触发器用 |
| 建立 / 保持时间 | 数据在时钟沿前后必须稳定的窗口 | ns、ps | 建立时间不足是数据来晚了，保持时间不足是数据来早了，两者改法完全相反 |
| 时钟偏斜与路径延时 | 时钟到达差与组合逻辑最大最小延时 | ns | 最高频率由最长路径定，保持时间违例由最短路径定，别只算一个 |

## 6. 典型题型与解题套路

### 电路分析题（列方程求支路量）
1. 在图上把参考方向标全，待求量写成符号，数清未知量个数。
2. 数独立节点数与独立回路数，选一套方程：节点少用节点法，网孔少用网孔法，不要两种混用。
3. 受控源先当独立源列方程，再把控制量用未知量表示，补足方程数。
4. 解完回代一个没用的 KVL 方程，再用功率守恒核对一次。
**常见失分点**：控制量没写成未知量导致方程数不足；叠加时把受控源当独立源置零。

### 信号变换题（求频谱或变换式）
1. 先分类：周期、能量有限、右边指数，还是双边——这决定用级数、傅里叶变换还是拉氏变换。
2. 化成标准形式，把幅度与尺度因子提到变换号外面。
3. 用性质（移位、尺度、微分、卷积）逐步推进，每步写明用的是哪条性质。
4. 写出收敛域，再画幅度谱，标清频率轴刻度与主瓣宽度。
**常见失分点**：只写变换式不写收敛域；$\mathrm{sinc}$ 的归一化定义与教材版本不一致。

### 系统响应题（求输出并判稳定）
1. 先判系统性质（线性、时不变、因果、稳定），把响应拆成零输入与零状态两部分。
2. 求冲激响应或系统函数 $H(s)$，把零极点画在复平面上。
3. 零输入响应用初始条件定系数，零状态响应用卷积或部分分式展开求。
4. 用终值定理或极点位置校验稳态值，再合成全响应。
**常见失分点**：把零输入响应算成零状态响应；用终值定理前没检查极点是否都在左半平面。

### 通信链路计算题
1. 画链路框图，把每级增益与损耗写成 dB，发射功率写成 dBm。
2. 逐级相加减得接收功率，再算噪声功率求信噪比；噪声可从 $-174$ dBm/Hz 起算再叠加噪声系数与带宽。
3. 由调制方式与目标误码率查所需 $E_b/N_0$，按 $B/R_b$ 换算成 SNR 门限。
4. 比较接收 SNR 与门限得链路余量；余量为负时逐一说明该改哪一级、代价是什么。
**常见失分点**：dBm 与 dB 混加；算噪声时漏掉带宽或把噪声系数当噪声温度。

## 7. 常见误区

1. **参考方向只标一半** → 错在只标电流不标电压；应该每个二端元件同时标 $u$ 与 $i$，再按关联与否决定 $p=ui$ 还是 $p=-ui$。
2. **把叠加定理用到功率上** → 错在功率是电压电流的二次量；应该只对电压电流叠加，功率由叠加后的总量重新算。
3. **以为采样率够高就不会混叠** → 错在混叠由模拟前端的带宽决定；应该先核对抗混叠滤波器的截止频率，再谈采样率。
4. **把 dB 当线性单位加减** → 错在 dB 相加等于相乘；应该先分清是功率比（10）还是电压比（20）。
5. **用 $s$ 平面的结论直接判离散系统稳定** → 错在两套稳定域不同；应该把单位圆内映射到左半平面后重新判。
6. **示波器探头地线随便夹** → 错在长地线引入电感，测到的是振铃而不是真实边沿；应该用短地弹簧并做单点接地。
7. **数字电路只验功能不验时序** → 错在忽略了组合逻辑延时；应该同时算最长路径（定最高时钟）与最短路径（查保持时间）。

## 9. 交叉专业与后续方向

- **和电气工程及其自动化的区别**：电子处理弱电信号（毫瓦级、MHz 以上、以信息保真为目标），电气处理强电功率（千瓦级、50 Hz、以能量转换与安全为目标）。同一门电路课之后分道：电子接信号与系统、通信原理、DSP；电气接电机学、电力电子、电力系统分析。判据是"信号失真了有没有关系"——关心保真就是电子，关心效率与绝缘就是电气。
- **和计算机科学与技术的区别**：计科从指令集往上，问"这个问题能不能算、代价多少"；电子从物理层的信号与电路往下，问"这个波形经过这一级还剩多少"。交汇点是数字系统、嵌入式与体系结构：同一个 ADC 采样，计科答数据怎么存与算，电子答采样率、量化位数与前端驱动够不够。
- **和自动化的区别**：自动化问"加了反馈之后系统会不会稳、多久收敛"，电子问"这条链路能不能把信号不失真地送到"。自动化的核心是控制律，电子的核心是信号与电路，两者在 K02-5 的稳定性分析上会重叠。
- **和物理学（电子科学方向）的区别**：物理问"这个器件为什么会有这种特性"，电子问"给定这个特性，电路该怎么设计、指标够不够"。
- **后续方向**：考研常考信号与系统加通信原理（信息与通信工程一级学科），或电路加模电数电（电子科学与技术）；典型岗位是基带算法、射频与天线、嵌入式与 FPGA、IC 验证与模拟设计；进阶课程是随机过程、数字通信、电磁场与微波技术、VLSI 设计。
