# 经济学（economics）

> 使用前先读 `../../references/curriculum-rules.md`（难度与排序规则）与
> `../../references/learning-card-template.md`（讲解结构）。
> 本文件只提供"这个专业的知识骨架与专业习惯"，不要在这里重复通用协议。

## 1. 这个专业在训练什么

把任何一句"人会怎么选"改写成"谁在什么约束下最大化什么"，再把推出来的预测拿去和数据对账。

外人常以为它是"一套立场"或"教人赚钱"。它其实是一条可被否证的工作流：假设 → 最优化 → 比较静态 → 可检验预测 → 用数据检验；预测错了就改模型，而不是改数据。

**最容易误解的一点**：以为经济学等于背供需曲线。曲线只是语言，真正的活儿是把文字题写成带约束的最优化问题，再判断哪个约束真的绑得住——绑不住的那条可以删掉，结论往往因此改变。

**最陡的三门课**：微观经济学（下）（因为要在同一道题里同时握住约束、一阶条件和经济学解释）、计量经济学（因为估计、推断、识别是三件事，错一件整张表就白读）、宏观专题（因为索洛与预期菲利普斯曲线的结论和直觉相反）。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能把一段文字题写成"目标函数 + 约束 + 参数"，解出内点或角点最优，并写明二阶条件。
2. 能在供需图或 IS-LM 图上标出外生冲击后的新均衡，并逐条说明曲线为什么往那个方向移。
3. 能读完一张回归表，说清每个系数的单位、置信区间、经济含义与最可能的偏误方向。
4. 能对一项政策给出"机制链条 + 量级估计 + 一个可被数据否证的预测"三段式论证。
5. 能用国民收入恒等式与部门收支，把一则宏观新闻拆成"谁的钱从哪来、到哪里去"。
6. 能判断一篇实证论文的识别策略是否成立，并说出最可能推翻它的那种情形。
7. 能把一个含时间的问题写成现值哈密顿或贝尔曼方程，解出稳态与转移动态方向。

## 5. 术语与符号约定

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| $\varepsilon$（需求价格弹性） | $\varepsilon=\frac{dQ}{dP}\cdot\frac{P}{Q}$，需求量对价格的相对敏感度 | 无量纲 | 导数通常为负，报弹性时按惯例取绝对值；同一份作业里符号与绝对值混用会被判错 |
| 弹性正负号约定 | 需求价格弹性记为负、供给弹性为正、收入弹性可正可负 | 无量纲 | 说"弹性大于 1"指绝对值大于 1；吉芬品的收入效应为负，别与价格弹性的负号混为一谈 |
| 弹性 vs 导数 | 弹性是导数乘上比值，无量纲；导数的数值随单位换算而变 | 无量纲 vs 有量纲 | 比较两种不同单位的商品只能比弹性；写"价格涨一元需求降 2 单位"不是弹性 |
| 弧弹性（中点法） | $\frac{\Delta Q}{\Delta P}\cdot\frac{(P_1+P_2)/2}{(Q_1+Q_2)/2}$ | 无量纲 | 价格大幅变动必须用中点法；拿点弹性算跨区间变化，结果会差出一倍 |
| 边际量 $MC,MR,MU$ | 多一单位带来的增量，等于总量的导数 | 元/单位 | $MC$ 是总成本对产量的导数，不是平均成本；利润最大是 $MR=MC$，只有完全竞争才退化成 $P=MC$ |
| `ceteris paribus` | 其他条件不变 | — | 它保证的是曲线位置不动；外生变量一变就必须整条曲线平移，不能再沿原曲线读"需求量变化" |
| 沿曲线移动 vs 曲线移动 | 价格变导致沿曲线移动；非价格因素变导致整条曲线平移 | — | 把"需求增加"写成"需求量增加"是最常见的扣分点，答题第一句先标明是哪一种 |
| 增长率与对数差分 | $g_t\approx \ln y_t-\ln y_{t-1}$ | 无量纲小数 | 小数与百分数要统一；对数差分是连续增长，多期年化要用几何平均而不是算术平均 |
| 实际 vs 名义 | 名义用当期价格，实际用基期价格 | 元、无量纲 | 换基期只改水平不改增长率；跨年比较必须用实际值，否则会把通胀读成增长 |
| GDP 平减指数 vs CPI | 前者覆盖全部国内产出，后者是固定消费篮子 | 指数，基期取 100 | 两者不等是正常的；平减投资与政府支出要用平减指数，不能拿 CPI 代替 |
| 存量 vs 流量 | 资本、债务是存量；投资、赤字是流量 | 元 vs 元/年 | "债务占 GDP 比重"是存量比流量，量纲是年；赤字率同理，别当无量纲比例随意比较 |
| 内生 vs 外生 | 模型内被解释的变量 vs 模型外给定的参数 | — | 外生不是"不变"，而是"与误差项不相关"；同一个变量在不同模型里可以换身份 |
| 结构参数 vs 简约式系数 | 前者来自偏好与技术，后者来自数据回归 | — | 简约式系数要等于因果效应，需要识别条件；看到一个系数先问"它识别的是什么" |
| $\lambda$（拉格朗日乘子） | 约束的影子价格，即目标对约束放宽的边际反应 | 目标单位/约束单位 | 量纲是两种单位之比；不等式约束要换成 KKT 并补上互补松弛条件 |
| FOC / SOC | 一阶条件定驻点，二阶条件定极大或极小 | — | 只解一阶条件得到的是候选点；角点解与边界解必须单独拿出来比较 |
| `argmax` / `s.t.` | 在约束下取最大值的自变量集合 | — | 写 $\max$ 时必须带约束集与非负约束；漏写约束既是排版错也是逻辑错 |
| $MRS$ / $MRT$ / $MRTS$ | 无差异曲线、生产可能性边界、等产量线的斜率 | 无量纲 | 内点最优是 $MRS$ 等于价格比；两边都取正数比较，别一边带负号一边不带 |
| $Y=C+I+G+NX$ | 支出法国民收入恒等式 | 元（不变价） | $I$ 含存货变动与住宅投资；$G$ 只含政府购买，不含转移支付 |
| $i$ / $r$ / $\pi^e$ | 名义利率 / 实际利率 / 预期通胀率 | % | 精确式是 $(1+i)=(1+r)(1+\pi^e)$，$r\approx i-\pi^e$ 只在小通胀下可用；决策看预期，不看事后值 |
| $\hat\beta$ 与模型形式 | 半对数系数是半弹性，对数-对数系数是弹性 | 因变量单位/自变量单位 | 半对数要乘 100 才是百分比；对数-对数不用乘，混用会把效应放大 100 倍 |
| $s.e.$ / $t$ / $p$ | 标准误、$t=\hat\beta/s.e.$、双侧检验的尾概率 | — | $p$ 值不是"原假设为真的概率"；显著不等于重要，必须同时报系数大小与置信区间 |
| 显著性水平 $\alpha$ | 允许犯第一类错误的概率，常取 0.05 | 0–1 | $\alpha$ 事前设定、$p$ 值事后算出；"5% 水平显著"指 $p<0.05$，不是 $p>0.05$ |
| $R^2$ 与调整 $R^2$ | 被解释的方差比例 | 0–1 | 加变量 $R^2$ 不会下降，比较模型要看调整 $R^2$；$R^2$ 再高也救不了遗漏变量偏误 |
| 稳健/聚类标准误 | 允许异方差或组内相关的标准误 | — | 换标准误只改 $t$ 与置信区间，不改 $\hat\beta$；星号变少不等于效应变小 |
| `ITT` / `LATE` | 意向处理效应 / 依从者的局部平均处理效应 | 因变量单位 | 有非依从时 OLS 给的是 ITT；只有用工具变量分离出依从者才是 LATE |
| 弹性与对数模型 | $\Delta\ln Q/\Delta\ln P$ 即对数-对数回归的系数 | 无量纲 | 系数 0.3 读作"价格升 1% 需求降 0.3%"，不是"需求降 0.3 单位" |

最常写反的三处：把需求价格弹性的负号带进"弹性大小"的比较；把"需求量变化"当成"需求变化"；把 $p$ 值当成原假设成立的概率。

## 6. 典型题型与解题套路

### 最优化计算题（效用最大化、成本最小化、利润最大化）
1. 先写三件事：目标函数、约束集合（含预算与非负约束）、参数取值范围。
2. 先按内点做：列拉格朗日函数，写全部一阶条件，解出候选点。
3. 回代检查：候选点是否满足所有约束、是否为正；不满足就转去比较角点与边界点。
4. 用二阶条件或凹凸性确认极大还是极小，再解出 $\lambda$ 并说明它的经济含义。
5. 把数值代回原目标函数，答一句"所以最优产量是 X、此时边际成本等于边际收益"。
**常见失分点**：只写 $MR=MC$ 不验证二阶条件与角点，把驻点当成最优点。

### 图形分析题（供需变动、税收归宿、IS-LM）
1. 先在图上标清坐标轴、单位，写出每条曲线对应的方程和它的外生变量。
2. 判断是"沿曲线移动"还是"整条曲线平移"，把触发变动的因素归到外生那一侧。
3. 画新均衡，逐项标出价格、数量、剩余区域的变化方向，不要只画一个箭头。
4. 用代数复核一遍：斜率变没变、交点解出来的符号对不对。
**常见失分点**：把曲线平移方向画反（利率上升使投资下降、IS 左移），以及福利分析漏标无谓损失。

### 计量结果解读
1. 先读表头：被解释变量是什么、样本量与样本期、标准误是普通还是稳健或聚类。
2. 逐个系数按模型形式换算：线性读单位效果，半对数乘 100，对数-对数直接读弹性。
3. 报系数时同时给置信区间与经济显著性判断，别只圈星号。
4. 追问识别：遗漏变量、反向因果、测量误差各会把系数推向哪一边，写出方向。
**常见失分点**：把相关当因果，把 $p<0.05$ 说成"效应很大"，换了稳健标准误就说"结果变了"。

### 政策论述题
1. 第一句定标准：目标是效率、公平还是稳定，约束是预算、时滞还是政治可行性。
2. 写机制链：工具→中间变量→目标变量，每一步注明依赖什么假设。
3. 方向用理论给，量级用数据给（弹性、乘数、回归系数），两段分开写，不混成一句。
4. 补代价与副作用（扭曲、挤出、通胀预期），最后给一个能被数据否证的预测。
**常见失分点**：只表态不给机制，用"应该"代替"若 A 则 B"的条件句，把局部均衡结论直接推成一般均衡结论。

## 7. 常见误区

1. **把"需求增加"与"需求量增加"混用** → 错在没区分曲线平移与沿曲线移动；应先写清是哪个外生变量变了，再画图。
2. **点弹性代入负号后说"弹性为 −2，所以缺乏弹性"** → 错在比较时没取绝对值；应报 $|\varepsilon|=2$ 并单独注明符号。
3. **认为所有厂商都按 $P=MC$ 定价** → 错在把完全竞争的结论当成通例；垄断是 $MR=MC$ 且 $P>MC$，加成幅度由弹性决定。
4. **把显著当成重要，或把 $p$ 值当原假设为真的概率** → 错在混淆统计显著与经济显著；应同时给系数大小、置信区间和现实量级。
5. **把回归系数直接读成因果效应** → 错在跳过识别；应先写出可能的遗漏变量与反向因果，再判断偏误方向。
6. **用名义值做跨年比较，或用算术平均算年均增长率** → 错在把通胀混进增长；应改用实际值与几何平均（或对数差分）。
7. **把恒等式当行为方程做预测** → 错在 $Y=C+I+G+NX$ 恒成立、不含行为假设；要预测政策效果必须写出消费函数与投资函数。

## 9. 交叉专业与后续方向

- **和金融学的区别**：经济学问"这个选择为什么发生、福利如何"，金融学问"这笔未来现金流今天值多少、风险怎么定价"。同一则加息新闻，经济学答总需求与产出缺口，金融学答贴现率与久期。
- **和财政学的区别**：财政学只研究政府收支那一块（税制设计、预算、转移支付、地方财政），经济学把政府当成众多个体之一，用同一套最优化与均衡框架处理它，问的是"这项收支改变了谁的约束"。
- **和统计学的区别**：统计学问"从这点样本能推断到什么程度"，只要估计量与推断正确就够；经济学必须给系数一个结构解释（参数对应偏好或技术），并额外处理内生性。同一张回归表，统计看标准误，经济看识别。
- **后续方向**：考研可走理论经济学、应用经济学、数量经济学；就业常见于政策研究、央行与监管、咨询与互联网的因果推断岗；进阶课程是博弈论、产业组织、发展经济学、时间序列与结构模型。
