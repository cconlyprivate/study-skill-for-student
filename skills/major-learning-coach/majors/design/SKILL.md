# 设计学（design）

> 先读 `../../references/curriculum-rules.md`（难度与排序）与 `../../references/learning-card-template.md`（讲解结构）。
> 本文件只给这个专业的知识骨架与专业习惯。

## 1. 这个专业在训练什么

设计学的活儿是**在约束里做决定**：给定一群用户、一道工艺、一笔预算，产出一个能被使用、能被验证的方案。约束不是创意的敌人，而是题目本身——预算决定工艺，工艺决定尺寸与色彩，尺寸与色彩又反过来决定信息能放几条。所以日常不是"想个点子"，而是连续做取舍并留下理由：为什么这一版砍掉三个功能、为什么这行字是 10pt、为什么这个按钮放在拇指能碰到的地方。

外人常以为设计 = 审美，好看就行。真正的分水岭在**能不能说清方案为什么这样做、改完之后哪个指标变好了**：只交图不交理由，评审追问一句就崩；有取舍有数据，方案哪怕朴素也站得住。所以每交一稿，必须同时交"依据"和"判据"两样东西。

三条硬约束决定这门课怎么学：其一，**约束先行**——先写清用户、工艺、预算三行再动手，否则所有稿子都在解一道错题；其二，**产物必须能被第三方验收**，一张版面要能被指到网格与层级，一个流程要能被指到任务完成率；其三，**引用他人作品必须注明来源**，临摹、改编、商用是三种不同的授权，混为一谈是学术与法律的双重风险。

**最容易误解的一点**：以为设计学是美术学的近亲。美术学交付"表达"，成功标准是作品能否成立；设计学交付"解决方案"，成功标准是问题有没有被解决。这条界线在第 9 段展开。

## 2. 课程地图

| 学期 | 课程 | 模块 | 先修 | 难度感受 |
|------|------|------|------|----------|
| 大一上 | 设计素描 | K01 | — | 不考"画得像"，考结构线准不准，转不过弯的人会一直描表面 |
| 大一上 | 平面构成 / 色彩构成 | K01 | — | 规则简单但排出好版面很难，容易做成填格子 |
| 大一下 | 设计史 | K02 | — | 记年表不难，难在把风格特征和当时的工艺条件对上 |
| 大二上 | 字体与版式设计 | K04 | K01 | 门槛在量化：栏宽、基线、层级都要算，凭手感会一直改不好 |
| 大二下 | 人机工程学 | K03 | — | 公式少，坑在百分位取值和"舒适"与"最大"两档的范围 |
| 大三上 | 材料与印刷工艺 | K05 | — | 要去印厂看一次，才知道出血和色差不是纸面概念 |
| 大三上 | 用户研究与可用性 | K06 | K04 | 方法都会，难在问对问题、样本量说得清 |
| 大三下到大四 | 专业设计 / 毕业设计 | K07 | K03、K04、K05、K06 | 要在一学期里跑完整流程并答辩，四门课在这里合并结算 |

**最陡的三门课**：人机工程学（因为要在毫米级尺寸里同时满足"够得到"与"容得下"）、字体与版式（因为要把"好看"翻译成可计算的栏宽与层级）、专业设计（因为要在一次答辩里同时证明过程、形式与效果）。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能在 30 分钟内把一句模糊需求写成"用户—场景—约束—成功判据"四行问题陈述。
2. 能对一张版面指出层级、网格、对比三处具体问题，并给出改版稿而不是形容词。
3. 能按 P5/P95 查表校核一处操作空间或界面尺寸，写出取了哪个百分位以及为什么。
4. 能独立跑一轮 5 人可用性测试，算出任务完成率、中位耗时与错误率。
5. 能按成品尺寸设置出血、分辨率与色彩模式，交出一份过十项印前检查的文件。
6. 能对 20 个概念草图用权重矩阵收敛到 3 个，并说清被否的方案否在哪一条约束。
7. 能写一份 10 分钟提案：约束、取舍、证据、下一步各一页。
8. 能对自己的方案写一轮迭代说明，含改前改后的同一指标对比。

## 5. 术语与符号约定

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| 设计流程 | 调研—定义—发散—原型—测试，前一段的产物是后一段的输入 | 五段，不可跳 | 最常跳"定义"直接画图，后面每稿都在解错题；每段结束必须落一页可验收产物 |
| 双钻（发散/收敛） | 先在问题空间开合，再在方案空间开合 | 两轮 | 把"发散"当"多画几版"；发散阶段要先放宽判断标准，收敛阶段才排序 |
| 格式塔·接近 | 间距小的元素自动被读成一组 | 组内间距小于组间间距的一半 | 想分组只改颜色不改间距；分组的第一手段永远是间距 |
| 格式塔·相似/连续/闭合/图底 | 同形同色成组；视线沿连续路径走；缺口被补全；主体与背景可互换 | — | 图底关系写反，把负空间当"没用到的空白"，留白就永远调不对 |
| 色彩三属性 | 色相 H、明度 L、饱和度 S | H 0–360°，L/S 0–100% | 说"深一点"多半只是明度变化，动饱和度会偏色；评图先看明度再看色相 |
| 对比度 | 前景与背景的相对亮度比 | 正文至少 4.5:1，大字至少 3:1 | 把"看着够黑"当合格；灰度稿能过不代表色觉异常的用户能过 |
| 相对亮度 $L$ | $L=0.2126R+0.7152G+0.0722B$，先做 gamma 线性化 | 0–1 | 直接拿 sRGB 值代入算，忘了线性化，算出的对比度偏乐观 |
| 色域 | 设备或工艺能表示的颜色范围 | sRGB 窄于 P3，与 CMYK 互不包含 | 把"屏幕看着一样"当"印出来一样"；荧光高饱和色在 CMYK 里根本印不出 |
| RGB / CMYK | 加色模式 / 减色模式 | 8 位 0–255 / 0–100% | 交印刷却给 RGB；正文黑用四色黑，套印不准时字边发虚 |
| 分辨率 | 单位长度内的像素数，必须按成品尺寸算 | 印刷 300ppi，屏幕按 1x/2x/3x | ppi 与 dpi 混用；只把 DPI 数值改大不重采样，像素数一点没变 |
| 出血 | 成品线之外预留的裁切余量 | 通常每边 3mm | 只把底色拉出画布却没设出血，裁切后露白边 |
| 成品线/裁切线/安全区 | 三套不同的线，间距固定 | 文字距成品线至少 3–5mm | 字压到安全区外，裁切切掉半个字；三套线在文件里没分开图层 |
| 网格与栏 | 版心等分出的栏与基线 | 12 栏常用，栏距约为字号的一半到一倍 | 算栏宽不扣栏距；正文不落基线，左右页行与行错位 |
| 版式层级 | 字号、字重、间距、位置共同构成的阅读顺序 | 三到四级够用 | 同一件事用四种手段一起强调，等于没有重点；层级要从第一眼落点倒推 |
| 字号与行距 | 字号用 pt（印刷）或 px/sp（屏幕），行距是字号的倍数 | 中文正文行距 1.4–1.7 | 中文套西文的 1.2 行距会挤；行距与字号单位混算，一改字号全乱 |
| 字距 tracking / 字偶 kerning | 全局字距 / 特定字对间距 | 千分之一 em | 大字号标题不做 kerning，引号与标点之间出现空洞；用加空格代替字距调整 |
| 避头尾（禁则） | 行首不能出现的标点、行尾不能出现的开引号 | 标点与括弧 | 手动敲空格把标点"挤"进去，文字重排后全部错位 |
| 人机尺寸百分位 | P5/P50/P95 分别对应小、中、大身材 | 身高、坐高、臂长等 | 拿 P50 设计所有尺寸，结果一半人够不到；够得到按 P5，容得下按 P95 |
| 可达域 / 作业域 | 上肢在三维空间能到达与能舒适操作的范围 | 分舒适域与最大域两档 | 把最大可达当舒适可达，短期能用长期劳损；图注必须写清是哪一档 |
| 触摸目标 | 可点击区域的最小尺寸，不等于图标的视觉尺寸 | 至少 44×44pt（iOS）或 48×48dp（安卓） | 只放大图标不放大热区；元素挨太近导致误触，热区要留间隙 |
| 任务完成率 | 成功完成的人数除以总人数 | 0–100% | 分母写成"尝试次数"；把"完成但求助"算作成功，应单列自助完成率 |
| 任务耗时 | 从开始到完成的时长 | 秒或分钟，报中位数与四分位 | 只报平均值，被一两个极端值拉偏；不写计时起点在哪一步 |
| 错误率 | 出错次数除以任务数或操作数 | 0–100% | 错误定义不写清；把"放弃"和"出错"混成一类，两个指标都失真 |
| 五人测试发现率 | 至少发现一个问题一次的概率 $1-(1-p)^n$ | p 取 0.3 时 n=5 约为 83% | 用 5 人证明"没有严重问题"；小样本只能发现问题，不能证明问题不存在 |
| 原型保真度 | 从纸面线框到可点击高保真的三级 | 三级 | 早期就上高保真，用户被配色牵着走，反馈的全是视觉不是流程 |
| 迭代与版本 | 一轮"假设—改动—复测"，同一个指标前后对比 | 每轮记改前改后 | 只改不加度量，评审时无法证明变好；把加功能当迭代，掩盖原问题没解决 |

## 6. 典型题型与解题套路

### 设计提案题
1. 先写约束四行：用户是谁、在什么场景用、工艺与预算上限、验收判据（一句可测的话）。
2. 再写问题陈述与目标，用"谁在什么情况下做不到什么"的句式，不用"提升体验"这类词。
3. 方案固定三件套：三个方向的草图 → 选中方向的形式说明（网格、层级、色彩）→ 关键版面或界面的成品图。
4. 证据只给一条但给足：调研原话、竞品对照或一轮测试数据，注明来源与样本量。
5. 结尾写取舍与被否方案，说清被否的是约束里的哪一条。
**常见失分点**：只贴效果图不写约束与判据，评审无法判断好坏，只能凭喜好打分。

### 用户研究题
1. 先把研究问题改成可观察的行为："用户会不会用"改成"用户在哪一步停下来"。
2. 选方法并说明为什么：早期访谈与情境观察找问题，中期问卷做定量排序，后期可用性测试验证方案，三者不能互相替代。
3. 抽样写清人数、招募渠道、筛选条件；5 人测试只用于发现问题，不用于证明没有问题。
4. 记录只留行为与原话，每条结论后面挂一到两条编号证据，删掉自己的解释。
5. 收敛成三条以内的需求，每条写"现象—推断—待验证"三段。
**常见失分点**：把用户说的"我想要 XX"直接当需求；引导性提问把答案写进了问题里。

### 版式评析题
1. 先描述事实：版心尺寸、栏数、字号与行距、图文比例，全部量化，不用"大气""拥挤"。
2. 再排层级：把信息按视觉权重排序，对照设计意图看是否一致，不一致处就是问题点。
3. 再查网格：元素是否落在栏线与基线上，栏距是否一致，留白有没有节奏。
4. 再看对比与可读性：明度对比够不够、正文对比度是否到 4.5:1、字重有没有被滥用。
5. 最后每条问题配一个具体动作（改字号、并栏、加间距），并写预期效果。
**常见失分点**：通篇形容词没有数字；只批评不给可执行的改法，等于没评。

### 方案迭代说明题
1. 先写这一轮的假设：你判断哪里有问题、预期改完哪个指标会动。
2. 写证据来源：几个人、什么任务、怎么记录，样本量必须出现。
3. 列发现并按严重度排序，每条附证据编号，区分"阻塞"与"抱怨"。
4. 列改动：一条发现对一条改动，写出改前改后的具体值（字号 12→14、步骤 5→3）。
5. 写复测结果与未解决项：哪个指标动了、动了多少，哪些这轮不改以及为什么。
**常见失分点**：只写"优化了体验"却没有改前改后的同一指标；拿新增功能当迭代，原问题仍在。

## 7. 常见误区

1. **先画图再补约束** → 错在跳过了"定义"段，后面每版都在改皮；应该先用四行写清用户、场景、工艺、判据再动笔。
2. **把"多看优秀作品"当学习** → 错在只存图不拆解；应该每存一张就写下它的网格、层级、配色关系三行，否则审美不会变成手上的决定。
3. **所有尺寸按 P50 设计** → 错在把"平均人"当真实用户；够得到的地方按 P5、容得下的地方按 P95，并在图注写明取哪个百分位。
4. **屏幕稿直接当印刷稿交** → 错在没转 CMYK、没设 3mm 出血、分辨率按屏幕算；应该在成品尺寸下按 300ppi 出图并跑完十项印前检查。
5. **一次测试就宣称验证成功** → 错在样本量与指标都没写；应该报人数、任务、完成率与错误率，并把"没发现问题"与"证明没问题"分开说。
6. **拿别人的作品改两笔当自己的方案** → 错在既没标来源也没拿授权；应该注明参考出处，商用方案要么原创要么取得授权，这里没有灰色地带。

## 9. 交叉专业与后续方向

- **和美术学的区别（解决问题 vs 表达）**：美术学从表达出发，交付一件能被反复观看和解释的作品，成功标准是作品是否成立、是否值得看；设计学从需求出发，交付一个能被使用和验证的方案，成功标准是问题有没有被解决。同一张海报，美术学问画面形式关系是否自洽、与哪条绘画传统对话，设计学问信息有没有传达到、工艺与预算是否可控。所以作业必须能指到用户与约束：只写创作理念不写判据，是设计作业掉档的第一原因；反过来把作品分析写成需求分析，也会在美术学的课里失分。
- **和心理学、人因工程的区别**：心理学要一般规律与效应量，设计学只要"这一处该怎么改"，用的是查表与校核，不是实验设计。所以引用人因数据时要写清样本与适用人群，别把实验室结论直接当普适尺寸。
- **和计算机（交互设计/HCI）的区别**：HCI 关心可测量的交互机制与算法，设计学关心在工期与成本内把流程做成能用的东西；交汇点是可用性测试与设计规范，两边用同一套指标，但设计学要交付视觉与工艺方案。
- **和建筑学、广告学的区别**：建筑学管空间与结构安全，广告学管传播与说服，设计学管"约束下的形式决定"；三者共用形式训练，但验收标准分别是规范、转化率与任务完成率。
- **底线一：引用他人作品必须注明来源**——作者、作品名、出处或链接、获取日期四项齐全，改编要写明改了什么，缺一项就算抄袭。所以提案的参考页不能只放缩略图，得让人能顺着查回去。
- **底线二：不给可直接商用的抄袭方案**——参考别人的结构可以，但产出必须是你按本题约束重新做的决定，交付时标清参考与原创的边界。这两条比任何技巧都重要，因为它们决定别人敢不敢用你的稿子。
- **后续方向**：考研（设计学理论、视觉传达、环境设计、工业设计工程、交互设计）；岗位（品牌与视觉设计、UI/UX、展陈设计、包装与印前、设计管理）；进阶课程为设计研究方法、服务设计、信息可视化、可持续设计。
