# 自动化（automation）

> 先读 `../../references/curriculum-rules.md`（难度与排序）与 `../../references/learning-card-template.md`（讲解结构）。
> 本文件只给这个专业的知识骨架与专业习惯。

## 1. 这个专业在训练什么

自动化的人靠"给一个不听话的对象套上闭环"吃饭：先测出被控量，跟给定值比出偏差，用偏差去推执行机构，让输出按预期收敛。整套本事是三件事的组合——把物理对象写成能算的模型（微分方程 / 传递函数 / 状态空间）、判断这个闭环会不会稳、以及稳了以后有多快多准。

它和"电气""电子"最容易混：电气与电子研究能量与信号本身怎么产生、怎么传，自动化研究"拿一个控制器把别人的对象掰到目标值上"。所以自动化的人常常不设计对象，只设计围着对象的那个圈。

自控原理里九成的公式只回答两个问题：**稳不稳**（K03–K05）、**差多少**（K03-3、K06）。建模（K02）存在的唯一理由，是让这两个问题有东西可算。

**最容易误解的一点**：以为自动化 = 会调 PID。PID 只是 K06 里的一个点；真正卡人的是 K02 的建模和 K05 的频域判稳——你连对象传函都写不对，三个旋钮调到天亮也没用。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能对给定机械、电气、热工对象列出微分方程，并在零初始条件下写出传递函数与零极点。
2. 能用劳斯表、根轨迹、伯德图三种方式判断同一个闭环的稳定性，并解释三者结论为什么一致。
3. 能由 $\zeta$、$\omega_n$ 算出 $\sigma\%$、$t_p$、$t_s$，并说清题目用的是 2% 还是 5% 误差带。
4. 能算出 0/Ⅰ/Ⅱ 型系统对阶跃、斜坡、加速度输入的稳态误差，并说明型别只看开环积分环节个数。
5. 能按相位裕度指标设计超前或滞后校正器，回代验算全部指标后才交卷。
6. 能写出状态空间模型，用秩判据判断可控可观，并配置极点、设计全维观测器。
7. 能把连续控制器离散化，量化采样周期对相位裕度的侵蚀。
8. 能在仿真或实验台上复现"振荡 / 超调 / 积分饱和"，并把现象定位到具体环节。

## 5. 术语与符号约定

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| 开环 / 闭环 | 开环：控制器不取输出作反馈；闭环：用偏差驱动 | — | 题里的"开环传递函数"指 $G(s)H(s)$，不是"没有反馈的系统"；两者混用，整题方向就反了 |
| $G(s)H(s)$ | 开环传递函数 = 前向通道乘反馈通道 | 无量纲或带量纲 | 有的教材 $G$ 只指前向通道、$G_k$ 才是开环；写 $\Phi(s)=G/(1+GH)$ 前先确认 $G$ 是哪一段 |
| 负反馈极性 | $e=r-c$（单位反馈）或 $e=r-H(s)c$ | — | 闭环分母是 $1+GH$；写成 $1-GH$ 就是正反馈。少一个符号，判稳结论全反 |
| 零初始条件 | $G(s)=C(s)/R(s)$ 只在全部初值为零时成立 | — | 非零初值要另加零输入响应；把初值直接乘 $G(s)$ 是最常见的建模错误 |
| $\zeta$ | 阻尼比，决定二阶系统超调 | $0<\zeta<1$ 欠阻尼 | 符号是 $\zeta$ 不是 $\xi$；$\zeta=0$ 是等幅振荡（临界稳定），不能算稳定 |
| $\omega_n$ | 无阻尼自然振荡角频率 | rad/s | 单位是 rad/s 不是 Hz；只在报频率指标时才除以 $2\pi$ |
| $\sigma\%$ | 超调量 $=(c_{\max}-c(\infty))/c(\infty)$ | % | 基准是稳态值 $c(\infty)$，不是给定值 $r$；有静差时两者不等 |
| $t_s$ | 调节时间，进入并保持在误差带内 | s | 2% 带约 $4/(\zeta\omega_n)$、5% 带约 $3/(\zeta\omega_n)$；题目不说清就两种都写 |
| $t_p$ | 峰值时间，第一个峰的时刻 | s | 过阻尼系统没有峰值，别硬套公式 |
| 系统型别 $v$ | 开环传函在 $s=0$ 处的极点个数 | 0/Ⅰ/Ⅱ 型 | 看开环积分环节个数，不是闭环极点个数，也不是系统阶数 |
| $e_{ss}$ | 稳态误差 $\lim_{s\to0}sE(s)$ | 与被控量同量纲 | 用终值定理前先确认 $sE(s)$ 的极点全在左半平面；不稳定系统谈稳态误差没有意义 |
| 误差 vs 偏差 | 误差 $e=r-c$；偏差 $\varepsilon=r-b$ | — | 非单位反馈要先化成等效单位反馈；直接把偏差当误差会差一个 $H(0)$ |
| 劳斯判据 | 由特征多项式系数表数右半平面根 | 只能判绝对稳定 | 给不出裕度；首列出现零元用 $\epsilon$ 替换、整行为零用辅助多项式求导，别直接判"不稳定" |
| 奈奎斯特判据 | $Z=N+P$，$N$ 为净包围 $(-1,j0)$ 的圈数 | — | $N$ 逆时针为正；$P$ 是开环右半平面极点数。漏掉 $P$，开环不稳定系统的结论全错 |
| 伯德判据 | 用对数频率特性数 $-180°$ 穿越 | — | 只对最小相位开环好用；有右半平面极点时要数穿越次数，不能只看裕度符号 |
| $\gamma$ | 相位裕度 $180°+\angle G(j\omega_c)$ | ° | $\omega_c$ 是幅值穿越频率（幅值为 1 处），不是相位穿越频率 |
| $K_g$ | 幅值裕度 $1/\lvert G(j\omega_g)\rvert$ | 常以 dB 计 | 用 dB 时 $K_g=-20\lg\lvert G(j\omega_g)\rvert$，正值为稳定；教材正负号约定不统一，答题写清用哪种 |
| 根轨迹增益 $K^*$ | 首一形式 $G(s)H(s)=K^*\prod(s-z_i)/\prod(s-p_j)$ 的系数 | 负反馈 $0\to+\infty$ | 正反馈画零度根轨迹，$K^*$ 取 $0\to-\infty$、相角条件变 $0°$；方向画反，整张图废掉 |
| 开环增益 $K$ | $K=\lim_{s\to0}G(s)H(s)$ | — | $K=K^*\prod(-z_i)/\prod(-p_j)$；问"使稳定的 $K$"时要换算，直接报 $K^*$ 会扣分 |
| 分离点 | 根轨迹离开或进入实轴的点 | — | 由 $\sum 1/(d-p_i)=\sum 1/(d-z_j)$ 求；"两极点中点"只在个别对称情形巧合成立 |
| PID 形式 | $u=K_p e+K_i\int e\,dt+K_d\dot e$ | — | $K_i=K_p/T_i$、$K_d=K_pT_d$；增量式与位置式的 $K_i$ 还差一个采样周期 $T_s$，抄参数必错 |
| 积分饱和 | 输出限幅后误差仍继续积分 | — | 现象是给定回落后输出迟迟不降；靠限幅加反计算或条件积分解决，只调小 $K_i$ 是拖慢响应 |
| 采样周期 $T_s$ | 离散化步长 | s | $T_s$ 越大相位滞后越多，粗估 $-180°\cdot\omega T_s/\pi$；工程上常取 $\omega_cT_s\le0.1\sim0.2$ |
| 离散化映射 | $z=e^{sT_s}$，左半平面映到单位圆内 | — | 双线性变换有频率畸变 $\omega=(2/T_s)\tan(\omega T_s/2)$，s 域指标要先预畸变 |
| 可控 / 可观 | $\operatorname{rank}[B\ AB\ \cdots\ A^{n-1}B]=n$，可观对偶 | — | 传函零极点对消会藏起不可控或不可观模态；传函阶次小于状态维数时先查对消 |
| 状态空间四元组 | $\dot x=Ax+Bu$，$y=Cx+Du$ | — | $B$ 的列数等于输入数、$C$ 的行数等于输出数；把维度写反是最常见的扣分 |

## 6. 典型题型与解题套路

### 题型一：建模与传递函数推导
1. 先在图上圈定输入量、输出量和中间变量，写清每个符号对应的物理量，别急着列方程。
2. 按物理定律逐个元件写方程（牛顿第二定律、KCL/KVL、热平衡、力矩平衡），中间变量一律保留。
3. 对线性方程取拉氏变换，化成代数方程组消元；不要在原微分方程上硬代入，容易漏项。
4. 在零初始条件下取比 $G(s)=Y(s)/U(s)$，通分成 $K\prod(s-z_i)/\prod(s-p_j)$，标出零极点并写出增益。
5. 用两个检查收尾：量纲对不对、$G(0)$ 是否等于该对象的静态增益（如弹簧系统的 $1/k$）。
**常见失分点**：把非零初值带进 $G(s)$；消元时把输出量也消掉，最后写出一个恒等式。

### 题型二：稳定性分析与判稳
1. 先把闭环特征方程 $1+G(s)H(s)=0$ 化成首一多项式，列清每一阶系数，系数缺项要先补零。
2. 选工具：三阶以内用劳斯最快；含纯延迟或开环本身不稳定用奈奎斯特；要裕度用伯德图。
3. 劳斯表首列变号数就是右半平面根数；出现零首元用 $\epsilon$ 替换，整行为零用辅助多项式求导继续。
4. 奈氏：先数开环右半平面极点数 $P$，再数曲线净包围 $(-1,j0)$ 的圈数 $N$（逆时针为正），$Z=N+P=0$ 才稳。
5. 结论要写成"稳定 / 临界 / 不稳定 + 允许的参数区间"，只写一个"稳定"拿不到过程分。
**常见失分点**：劳斯首列出现零就断言不稳定；有积分环节时漏画 $\omega\to0$ 的无穷远段，包围圈数就数错了。

### 题型三：PID 参数整定
1. 先给对象定性：自衡还是非自衡、有没有纯延迟、时间常数比 $\tau/T$ 多大，决定能不能用齐格勒-尼科尔斯法。
2. 只留比例，加大 $K_p$ 到等幅振荡，记下临界增益 $K_u$ 与振荡周期 $T_u$；到不了等幅振荡就说明该换方法。
3. 查整定表得 $K_p$、$T_i$、$T_d$，按题目要求的口径换算成 $K_i=K_p/T_i$、$K_d=K_pT_d$，别把 $T_i$ 当 $K_i$ 填。
4. 按先 P、后 I、再 D 的顺序微调：超调大就减 $K_p$ 或加 $T_d$；有静差就加大 $1/T_i$；振荡周期变长说明积分太弱。
5. 补上执行器限幅与抗饱和，再给一组打了七折的保守参数作为工程版本，并说明为什么留余量。
**常见失分点**：把积分时间当积分增益；忽略限幅，仿真出一条实物系统根本走不出来的曲线。

### 题型四：控制系统设计（校正器 / 状态反馈）
1. 把指标翻译成可算的量：$\sigma\%\to\zeta$、$t_s\to\omega_n$、$e_{ss}\to$ 需要的开环增益与型别。
2. 先算原系统的 $\gamma$、$\omega_c$、$e_{ss}$，列出缺口——差多少度相位、差多少倍增益，这一步决定选哪种校正。
3. 缺相位选超前、缺低频增益选滞后、两样都缺选滞后-超前；纯延迟很大时别硬用超前。
4. 算出参数后回代验算全部指标，再画一次伯德图确认裕度；不达标就改 $\omega_c$ 重来，不要微调凑数。
5. 状态空间题固定三步：验可控性 → 配置极点解出 $K$ → 写闭环方程核对极点位置，最后补观测器。
**常见失分点**：只算不验，把设计题做成计算题；超前校正把 $\omega_c$ 推得太高，被未建模的高频动态拖成不稳定。

## 7. 常见误区

1. **把"开环传递函数"当成"没有反馈的系统"** → 错在术语：题目给的 $G(s)H(s)$ 已经是闭环系统的开环部分；正确动作是先写 $\Phi(s)=G/(1+GH)$ 再谈性能。
2. **用劳斯判据给出"稳定裕度 30°"** → 错在把绝对稳定性判据当相对稳定性判据；裕度只能从奈氏曲线或伯德图读。
3. **套稳态误差公式前不查闭环稳定性** → 错在终值定理的前提；闭环有右半平面极点时误差发散，算出的数值没有物理意义。
4. **认为阻尼比越大越好** → 错在超调与快速性互斥：$\zeta$ 从 0.4 加到 1，超调确实降了，但 $\zeta\omega_n$ 变小、$t_s$ 反而变长。
5. **调 PID 时不看执行器** → 错在忽略饱和与速率限制；实物系统里积分饱和比参数不准更容易把系统搞崩。
6. **采样系统直接套连续域结论** → 错在忽略 $z=e^{sT_s}$ 的相位侵蚀：连续域算出 $\gamma=45°$，采样后可能只剩 20°。
7. **传函没有零极点对消就断言可控可观** → 错在把"输入输出可观"当"状态可观"；被对消的模态在传函里看不见，在状态空间里照样漂。

## 9. 交叉专业与后续方向

- **和 `electrical-engineering` 的分界**：电气工程及其自动化研究电能的产生、传输、分配与转换，核心量是电压、电流、功率、绝缘与继电保护，落点是电机、电力电子与电力系统分析；自动化把电气设备当"被控对象"，核心量是偏差、增益、极点与裕度，落点是控制器与算法。同一门《自动控制原理》两边都学，电气用它守发电厂与电网的回路，自动化用它设计围着任意对象的那一圈。
- **和 `electronic-information` 的分界**：电子信息工程研究信号的表示、变换、传输与提取（通信、射频、信号处理、集成电路），它的频域分析是为了滤波、调制与信噪比；自动化的频域分析是为了判稳与校正，问的是"相位还剩多少度、会不会振"。一句话：电子关心信号有没有失真，自动化关心闭环会不会跑飞。
- **和 `computer-science` 的分界**：计科处理离散符号与计算代价，自动化处理连续物理量的闭环；交汇点是嵌入式系统、机器人与工业软件。
- **和 `mechanical-engineering` 的分界**：机械定结构、强度与运动副，自动化给这台机器配传感、驱动与闭环；交汇点是机电一体化与运动控制。
- **后续方向**：考研 0811 控制科学与工程（控制理论与控制工程、检测技术与自动化装置、模式识别与智能系统）；典型岗位是过程控制/仪控工程师（化工、电力、制药）、运动控制与伺服、机器人控制、飞控与自动驾驶、嵌入式控制；进阶课程有非线性控制、最优控制、鲁棒控制、系统辨识、模型预测控制。
