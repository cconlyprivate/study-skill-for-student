# 美术学（fine-arts）

> 先读 `../../references/curriculum-rules.md`（难度与排序）与 `../../references/learning-card-template.md`（讲解结构）。
> 本文件只给这个专业的知识骨架与专业习惯。

## 1. 这个专业在训练什么

美术学的原料是**看**和**做**：一张画、一件雕塑、一页手稿，以及你自己留在纸上的痕迹。全部工作围绕四件事——它长什么样（形式）、它画的是什么（内容）、它在什么条件下被做出来和被看（语境）、它凭什么算好（评价）。所以核心不是"会画几笔"也不是"知道很多画家"，而是**让手上的功夫和眼里的判断互相校正**：画得出，才看得见结构；看得准，才改得动画面；判断得住，才说得清好坏。三者循环，断一环就退化成模仿或空谈。

三条硬约束决定这门课怎么学：其一，**判断必须指到画面的具体位置**，"很有气势""很有意境"不是判断，是形容词；其二，**技法有材料成本**，油画改一笔和生宣改一笔的代价完全不同，选材料本身就是表达决定；其三，**作品信息不可编**，尺寸、材质、年代、藏地四项错一项，整篇分析的可信度归零。

**最容易误解的一点**：以为美术学 = 画画，技法好就够。真正的分水岭在 K08 与 K06——能不能把一张画拆成形式要素、说清每项要素在画面上的效果；能不能把作品放回它自己的时代标准里评价。只会画不会说，作业拿不到高分，考研史论直接失分；只会说不会画，创作阐述空转，技法说明题答不出步骤。

| 大三下 | 作品分析与美术批评 | K08 | K04、K05、K06 | 四步缺一步就变观后感，最容易在这里掉档 |

**最陡的三门课**：透视与构图（因为灭点和视平线是可验证的几何，画"感觉对"会被当场指出）、绘画技法（因为干燥、洇散、覆盖都不给重来的机会）、作品分析（因为每句话都要落到画面坐标，形容词一律不算分）。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能对一组静物量出长宽比与主要形体的倾斜角，把误差控制在十分之一以内。
2. 能在球体与衬布上标出明暗五调子的分界位置，并说明光源方向。
3. 能画出同一场景的一点、两点、三点透视图，把灭点位置写在画面内外并注明依据。
4. 能用色相、明度、纯度三项定量描述任意色块，并指出画面中的冷暖转换处。
5. 能按朝代与世纪排出中外美术史分期，为每期举一件代表作并注明可查的收藏机构。
6. 能为一件作品写出规范信息卡（作者、名称、材质、尺寸、年代、藏地），不确定项标注来源。
7. 能按"形式—内容—语境—评价"四步写 800 字作品分析，每个论断指到画面具体位置。
8. 能为自己的创作写 500 字阐述，说明每个技法选择解决了什么表达问题。

## 5. 术语与符号约定

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| 比例 | 画面中各段长度之间的比值，用来校正形体 | 无量纲，写成比值或分数 | 量的是"投影到画面后的长度"而不是实物长度；视点一动比例就变，所以先定点再量 |
| 视平线 | 与观者眼睛等高的水平线，水平灭点都落在它上面 | 位置由视高决定 | 视平线不是画面中线；平视在画中，俯视在画面上方，仰视在下方 |
| 一点透视 | 画面平行于一个主立面，只有一个纵深方向 | 一个主灭点，另两方向保持平行 | 判据是"有没有纵深方向"，不是"正面是不是矩形"；侧墙一出现深度就是它 |
| 两点透视 | 画面与两个立面都成角 | 两个灭点在同一条视平线上 | 两灭点必须同高；一高一低，立刻出现"歪楼" |
| 三点透视 | 在两点上加坡仰，第三灭点在垂直方向 | 第三灭点在过主视点的垂直线上 | 俯视的第三灭点在下、仰视在上；方向写反，整张图变成倒立的 |
| 灭点 | 一组平行线在画面上的交点 | 一点、两点、三点透视分别有 1、2、3 个主灭点 | 两点透视的第二个灭点常在画布外，必须在页边标出位置，否则无法复核 |
| 明暗五调子 | 亮面、灰面、明暗交界线、反光、投影 | 与光源方向、形体转折一一对应 | 明暗交界线是一个面不是一条线；画成黑线，球体就变成铁球 |
| 反光与投影 | 反光是暗部受环境反射的部分，投影是遮挡形成的地面暗区 | 反光属于物体，投影属于承托面 | 反光画亮过灰面，体积会散；投影画成一块均匀灰，空间会塌 |
| 色相 | 颜色的相貌，如红、黄、蓝 | 色环 0–360°，或用色名 | 色相相同不等于颜色相同；明度差很大时仍认成同一色相，于是误判"同一块颜色" |
| 明度 | 颜色的明暗程度 | 常用 0–10 档，或 CIELAB 的 $L^*$ | 明度不是"加白"；加白同时降纯、偏色相，需要换色相或换光源 |
| 纯度（饱和度） | 颜色的鲜艳程度 | 0–100%，与明度独立 | 偏灰不等于偏暗；把纯度当明度调，画面会脏，层次也会糊 |
| 冷暖 | 色相的倾向，红黄偏暖、蓝青偏冷 | 相对判断，不是绝对属性 | 冷暖必须写"相对于谁"：同一块灰在暖色旁显冷，在冷色旁显暖 |
| 固有色、光源色、环境色 | 物体本色、照射光色、周围反射色 | 三者叠加在同一个像素上 | 只画固有色画面必脏；条件色写反，光源方向就错，五调子全跟着错 |
| 补色与颜料三原色 | 色环上相对 180° 的两色；颜料三原色为红、黄、蓝 | 颜料是减法混合，光是加法混合 | 两套规则结论相反：红加绿在光里变黄，在颜料里变灰 |
| 构图法则 | 三分、对角、框架、S 形等组织画面的方法 | 是检验工具，不是评分模板 | 法则只描述"多数情况有效"；用时要写清它在这张画里解决了什么，否则是套话 |
| 视觉重心 | 视线最先停留的区域 | 由对比、位置、面积共同决定 | 重心不等于几何中心，也不等于主体；主体可以偏，重心必须稳 |
| 负形 | 主体之外被围出的空白形状 | 与正形互为边界 | 只看正形轮廓会歪；检查比例最快的办法是看负形是否也像 |
| 笔触 | 工具在基底上留下的运动痕迹 | 与工具、压力、速度、媒介有关 | 笔触不是越明显越好；古典罩染几乎不见笔触，同样是表达选择 |
| 材质（媒材） | 颜料、基底与媒介的组合，如布面油画、纸本水墨设色 | 著录时写在"材质"一项 | 只写"油画"不完整；布、板、纸要写清，否则判断不了工艺与保存状况 |
| 书画同源 | 书法与绘画共用同一套用笔与结体 | 见于画论与题跋 | 说的是用笔同，不是"画画要像写字"；工笔与写意对应的用笔方式不同 |
| 皴法 | 用笔触表现山石结构与质地的程式 | 披麻、斧劈、折带、雨点等 | 皴法同时管结构与质地；只描纹理不看石质，会画成花纹 |
| 留白 | 有意不画的部分 | 是画面的实体，不是未完成 | 留白承担空间与节奏；把"空"当"没画完"补满，气就散了 |
| 艺术史分期 | 按时代、风格或制度划分的段落 | 中国按朝代，西方按世纪与风格 | 分期是工具不是事实；同一画家常跨两期，别硬塞进一格 |
| 流派 | 共享方法或主张的艺术家群体 | 常以地区、画室、刊物命名 | 流派不等于风格；同一流派内部的差异可能大于流派之间 |
| 图像志与图像学 | 先辨认母题来源，再解释其文化含义 | 两步先后不可颠倒 | 跳过图像志直接讲象征就是猜；母题认错，后面全错 |
| 作品信息六项 | 作者、名称、材质、尺寸、年代、藏地 | 尺寸写"高 × 宽，cm" | 六项缺一不可；记不清就标来源，编一个数字整篇作废 |
| 作品分析四步 | 形式、内容、语境、评价 | 固定顺序，不可跳 | 只写形式是图解，只写语境是史学；评价必须建在前三步上 |
| 头身比与黄金比 | 身高除头高，古典常见 7.5 至 8 头身；$\varphi=(1+\sqrt{5})/2\approx1.618$ | 无量纲 | 量头高从颅顶到下巴，不含发髻；起点错，整组比例全错 |

## 6. 典型题型与解题套路

### 作品分析题（给一件作品或图版，问它如何成立、好在哪里）
1. 先写信息卡：作者、名称、材质、尺寸、年代、藏地六项。记不清的写"据某图录"，绝不填数字。
2. 形式分析（K08-2）：按构图、明暗或色彩、笔触、空间四层写，每句指到画面位置，写"左下三分之一处的暖灰"而不是"背景很漂亮"。
3. 内容与图像志（K08-3）：先认母题与人物身份，再谈象征；认不出就写"题材待考"，不许直接跳到意义。
4. 语境（K04-1、K05-1）：放回时代分期与流派，说明当时的委托、观看方式、技术条件改变了什么。
5. 评价（K06-3）：给一句可被反驳的判断，并写明依据哪条标准——技法完成度、观念突破，还是当时的接受效果。
**常见失分点**：写成观后感，通篇形容词，没有一处指到画面位置与可查的出处。

### 技法说明题（问某个效果怎么做出来、为什么选这种材料）
1. 先定材料链：基底（纸、布、板）→ 媒介（油、胶、水）→ 颜料（透明或不透明），三者决定能做什么。
2. 写步骤与顺序：按底层、中层、上层写，标出每层的干燥或洇散条件，如肥盖瘦、生宣半干时落墨。
3. 点明变量：哪一步不可逆（生宣上先落的笔改不了），哪一步可覆盖修正（油画的提白与刮除）。
4. 落回原理：效果差异对应明度对比、洇散、覆盖力中的哪一条，不写"手感好"。
**常见失分点**：只写"多练就会"，不给步骤与变量；把油画的层序套到水墨上。

### 史论题（分期、流派、风格为何这样变）
1. 先划时段与地域，声明分期口径（中国按朝代，西方按世纪与风格），不混用两套时间轴。
2. 立一句可被检验的演变判断："从叙事转向观看"比"越来越自由"有用。
3. 每段配两件代表作加一条外部条件（赞助人、技术、宗教、市场），作品必须能查到。
4. 处理反例：指出不顺从主线的画家或地区，并说明它为什么仍是反例而不是主线。
5. 收尾给限度：这套分期解释不了什么，哪一段最薄弱。
**常见失分点**：背画家名录当史论；把流派名当世纪用，如把"巴洛克"写成"17 世纪"。

### 创作阐述（为自己的作品或方案写说明）
1. 先说问题：这幅画要解决什么视觉问题（空间太扁、色彩太吵），一句话讲清。
2. 再说选择：列三个关键决定（画幅与尺寸、材料、主色域或笔触方式），每个都说明它排除了什么。
3. 接过程：写清哪一步失败过、怎么发现的、改成了什么，这是评委最看重的部分。
4. 最后定位：说明它与哪条绘画传统或哪类当代实践对话，给一到两个可比对象。
5. 自检：全文不出现"表达内心情感"这类无法验证的句子，每句都能被作品本身检验。
**常见失分点**：把阐述写成感受散文；正文里的尺寸与材料跟作品标签不一致。

## 7. 常见误区

1. **照照片起形，然后说"我画的写实"** → 错在跳过整体观察与比例测量；应先量长宽比与倾斜角，照片只当参考，不当底稿。
2. **一幅画里每个物体都点高光** → 错在没分材质；高光只出现在光滑表面，粗糙材质的亮面是漫反射。
3. **用"感觉很准"代替灭点检查** → 错在透视本可验证；把纵深线延长，看是否交于同一灭点，不交就是错的。
4. **把纯度当明度调** → 错在以为提亮就是加白；加白会降纯偏色，要提亮应该换色相或提高光源强度。
5. **作品分析通篇形容词** → 错在句子没有画面坐标；每句都要能指到具体位置与具体手法，否则删掉。
6. **尺寸、藏地、年代凭印象填** → 错在把记忆当证据；六项信息卡里不确定的写"据某来源"或标"待核"，编一个数字整篇作废。
7. **把画册印刷色当原作色** → 错在忽略印刷与屏幕色差；判断色彩关系要看原作或可靠图版，并说明依据的是哪一种。
8. **先画完再补创作阐述** → 错在文字和画面互不承认；应在动笔前写下三个关键决定，完成后再逐条核对。

## 9. 交叉专业与后续方向

- **和设计学的区别（表达 vs 解决问题）**：设计学从需求出发，交付一个能被使用、被验证的方案，成功标准是"问题解决了没有"；美术学从表达出发，交付一件能被反复观看与解释的作品，成功标准是"它是否成立、是否值得看"。同一张海报，设计学问信息有没有传达到、成本与工艺是否可控，美术学问画面形式关系是否自洽、它和哪条绘画传统对话。所以美术学的作业必须能指到画面，设计学的作业必须能指到用户与约束；把设计作业写成作品阐释，或把作品分析写成需求分析，都会掉档。
- **和考古学、博物馆学的区别**：考古学管出土与层位，博物馆学管收藏、保管与展陈，美术学管作品本身的形式与意义。三者的交汇点是藏品信息，引用时一律以博物馆著录为准，不用二手转述。
- **和建筑、雕塑等造型艺术的关系**：同属造型艺术，共用 K01 至 K03 的观察、结构与透视基础；分界在材料、尺度与"是否可使用"。所以转专业时造型基础可以平移，史论与材料课要重修。
- **一条底线**：**不虚构作品的尺寸、藏地与年代**。信息六项里任何一项记不清，就写"据某图录"或"待核"，并注明依据是图版、展览标签还是数据库；编一句"纵 120 厘米，某馆藏"，一查即穿，整篇论证作废。这条比任何一条答题技巧都重要。
- **后续方向**：考研（美术学理论、美术史、绘画实践）、美术馆与博物馆（策展、公共教育、藏品研究）、画廊与艺术市场（鉴定、经纪、拍卖图录）、美术教育与出版、文物修复与保护；进阶课程为中国画论、西方现代艺术批评、材料与修复、书法篆刻。
