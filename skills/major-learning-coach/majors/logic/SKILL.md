# 逻辑学（logic）

> 先读 `../../references/curriculum-rules.md`（难度与排序）与 `../../references/learning-card-template.md`（讲解结构）。
> 本文件只给这个专业的知识骨架与专业习惯。

## 1. 这个专业在训练什么

把一段自然语言说出来的推理，翻译成没有歧义的形式语言，再用**机械可检查的步骤**回答一个问题：结论是不是被前提逼出来的。这里"逼出来"有精确含义——不存在一种解释，使前提全真而结论假。这就是有效性。

逻辑学不管你的前提在事实上对不对（那是各门具体学科的事），只管前提能不能撑住结论。所以它允许"有效但不可靠"的论证存在：前提假、推理合法，结论照样可能假。**所以你判一道题时先拆成符号再评价内容，顺序反了就一定被内容带跑。**

它和数学的分界：数学**使用**逻辑，逻辑学**研究**数学所用的这套逻辑本身凭什么可靠。它和哲学的分界：哲学追问"应该相信什么、什么是好的理由"，逻辑学只追问"从这些前提出发，能合法地走到哪一步"。它和计算机的分界：计算机问"这个判定能不能在多项式时间内做完"，逻辑学问"这个系统里什么是可证的、什么是可判定的"。

**最容易误解的一点**：以为逻辑学就是背一堆谬误名字。谬误名字只占 K01；真正拉开差距的是 K02—K03 的自然演绎和 K07 的元定理——那里要求你区分"我暂时证不出来"和"它在系统里不可证"，后者需要一整套编码技术。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能把一段 500 字的社论改写成"前提—结论"清单，并标出哪条前提是补上去的。
2. 能对任意给定的命题逻辑公式列真值表、判类型、写出主析取范式与主合取范式。
3. 能在 10 步内完成一个自然演绎证明，每步标注规则与引用行号，且所有假设都已解除。
4. 能把含"只有 A 才 B""除非 A 否则 B""没有 A 是 B"的中文句子译成一阶公式并回译校验。
5. 能对给定的一阶公式构造使其为真的模型与使其为假的模型各一个。
6. 能证明两个集合等势或不等势，并用对角线论证证明实数集不可数。
7. 能在给定 Kripke 框架上计算模态公式的真值，并说明某条公理对应哪条框架条件。
8. 能复述第一不完备定理的前提与结论，并说清它究竟否定了哪个计划。

## 5. 术语与符号约定

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| `⊢` | 语法可证：存在一串逐行合法的证明 | 只谈符号操作，不谈真假 | 证不出来不等于不可证；`Γ⊢φ` 里的 Γ 是前提集，不是公式的一部分，别写成 `Γ→φ` |
| `⊨` | 语义有效：所有使前提为真的解释都使结论为真 | 谈模型，不谈步骤 | `⊢` 与 `⊨` 相等靠可靠性定理与完全性定理，不是定义；答题时先问"题目要证哪一侧" |
| `¬` 的优先级 | 最高，只作用于紧邻的子公式 | — | `¬P∧Q` 读作 `(¬P)∧Q`；否定整个合取必须写 `¬(P∧Q)` |
| `→` 的结合性 | 右结合 | — | `P→Q→R` 是 `P→(Q→R)`；写成左结合，定理会变成非定理 |
| 五联结词优先级 | `¬` > `∧` > `∨` > `→` > `↔` | — | `P∨Q→R` 一律读 `(P∨Q)→R`；答题时括号宁可多加，别赌阅卷习惯 |
| 辖域 | 量词后紧跟的那个子公式 | — | `∀xP(x)→Q` 里 `∀x` 只管 `P(x)`；要管全句必须写 `∀x(P(x)→Q)` |
| 自由变元 / 约束变元 | 在辖域内被量词约束的是约束出现，否则自由 | — | 同一变元可以既自由又约束；有自由变元的公式还不是命题，没有真值 |
| 代入与变元捕获 | 用项替换自由变元 | — | 往 `∀y` 辖域里代 `y` 会捕获变元；代入前先给约束变元改名，这一步漏了整题作废 |
| 真值表行数 | n 个变元共 2ⁿ 行 | n 是变元个数 | 3 个变元是 8 行不是 6 行；行序固定成 000、001 这样排，两张表才能逐行比 |
| 重言式 / 矛盾式 / 偶然式 | 恒真 / 恒假 / 可真可假 | 三分互斥 | 重言式是"形式真"，与事实上真假无关；`P→P` 是重言式，`今天下雨` 不是命题逻辑的对象 |
| 主析取范式 / 主合取范式 | 极小项之和 / 极大项之积 | 每个真值表唯一 | 取值为 1 的行写极小项、为 0 的行写极大项；漏一项就叫析取范式，不叫"主"范式 |
| `≡` 与 `↔` | 前者是元语言断言"两式等值"，后者是对象语言的联结词 | — | `P≡Q` 说的是两张真值表相同；`P↔Q` 只是一个公式。把 `≡` 写进公式里是层次混淆 |
| MP（肯定前件） | 由 `φ→ψ` 与 `φ` 得 `ψ` | 消去规则 | 只能往前推；由 `ψ` 与 `φ→ψ` 推 `φ` 是逆推谬误 |
| MT（否定后件） | 由 `φ→ψ` 与 `¬ψ` 得 `¬φ` | 消去规则 | 由 `¬φ` 与 `φ→ψ` 推 `¬ψ` 不合法，那是否定前件谬误，与 MT 只差一个位置 |
| CP（条件证明） | 假设 `φ` 推出 `ψ`，解除假设得 `φ→ψ` | 引入规则 | 假设必须在结论前解除；忘了 discharge 等于证了一个带前提的命题 |
| RAA（归谬） | 假设 `¬φ` 推出矛盾，得 `φ` | 引入规则 | 与 CP 混用会多叠一层假设；直觉主义只认 `φ⊢⊥` 得 `¬φ`，反方向不成立 |
| 全称引入 / 存在消去 | `∀I` 要求常元任意，`∃E` 要求常元是新名 | 量词规则 | 用前提里已出现过的常元做 `∃E` 会伪造结论；每次都得挑一个没出现过的字母 |
| 反模型 | 使前提真而结论假的一个解释 | 一阶要给论域与谓词外延 | 判"无效"只需一个反模型，判"有效"要对一切模型论证，两者工作量不对称 |
| `M⊨φ` 与 `⊨φ` | 前者在某模型下为真，后者在所有模型下为真 | — | 少了 `M` 就是有效，多了 `M` 只是满足；漏写 `M` 在考试里直接改判 |
| `□` / `◇` | 必然 / 可能，互为对偶：`◇φ ≡ ¬□¬φ` | 模态算子 | 别把 `□` 读成"永远"；它相对某条可达关系而言，换个框架结论就变 |
| 框架 `F=(W,R)` 与模型 | W 是世界集，R 是可达关系，模型再加赋值 V | — | 只谈框架时不能提变元真值；对应定理谈的是框架类，不是单个模型 |
| `⌜φ⌝` | φ 的哥德尔编码，是一个自然数 | 编码方案不唯一 | 编码把语法对象变成算术对象；别把 `⌜φ⌝` 与 φ 本身混为一谈，自指全靠这层区分 |
| `ℵ₀` 与 `2^ℵ₀` | 可数无穷的基数 / 实数集的基数 | 后者严格大于前者 | 可数不是有限；`ℵ₀+ℵ₀=ℵ₀`，别拿有限算术的直觉套无穷 |
| AC（选择公理） | 任意非空集族都有选择函数 | 与 Zorn 引理、良序定理等价 | AC 不告诉你函数怎么取；写"任取一个代表元"时已经用了 AC，要标明 |
| 可靠性 / 完全性 | 可证的都是有效的 / 有效的都可证 | 方向相反的一对元定理 | 论证层面的"可靠"指前提真且形式有效，系统层面的"可靠"指 `⊢` 蕴含 `⊨`，两处别混 |
| de re / de dicto | 对物的模态 / 对言的模态 | — | "必然存在一个数等于 8"与"有一个数必然等于 8"不是一回事；量词与模态词的先后决定读法 |

## 6. 典型题型与解题套路

### 题型一：真值表与归谬（有效性判定）
1. 先符号化：每个原子命题给一个字母，写清前提集与结论，别在自然语言上直接判。
2. 二选一：变元不超过 3 个就列全真值表，只看"前提全真、结论假"的行；变元多就改用归谬——假设结论假、前提全真，往下推矛盾。
3. 真值表按 2ⁿ 行列全，行序固定，每行末尾标"是否反模型"。
4. 找到反模型立刻停手，判定无效，并把该赋值写成一个具体场景；找不到就写明"无使前提真而结论假的行，故有效"。
5. 题目要范式时，取值为 1 的行写极小项、为 0 的行写极大项，项数必须等于对应行数。
**常见失分点**：3 个变元只列 4 行；把"我没找到反模型"当成"有效"写在结论里。

### 题型二：自然演绎证明（命题与谓词）
1. 先看结论的主联结词定策略：结论是 `→` 用 CP，结论是 `¬` 用否定引入（假设 `φ` 推 `⊥`），结论是原子式或合取就先用 RAA 或分两支证。
2. 把前提逐条编号抄下，顺手标注它能被哪条规则消去，别边证边回头找。
3. 从结论倒推：要 `φ→ψ` 就先假设 `φ`；要 `¬φ` 就假设 `φ` 去推 `⊥`。倒推出的缺口就是下一步要用的规则。
4. 每行只写一条规则，标清引用行号；量词步额外注明常元是否首次出现。
5. 收尾查三件事：假设全部解除、引用的行号都存在、结论与题目逐字一致。
**常见失分点**：CP 的假设到最后没解除；`∃E` 用了前提里已有的常元。

### 题型三：谓词翻译（自然语言到一阶公式）
1. 第一行先写论域，论域一变，量词形式与谓词含义全变。
2. 拆骨架：主语对应谓词，`所有/每个` 对应全称量词，`有的/至少一个` 对应存在量词。
3. 记两条模板：全称句写 `∀x(A(x)→B(x))`，存在句写 `∃x(A(x)∧B(x))`，把 `→` 与 `∧` 用反是最高频错误。
4. 处理固定读法：`只有 A 才 B` 译作 `B→A`；`除非 A 否则 B` 译作 `¬A→B`；`没有 A 是 B` 译作 `¬∃x(A(x)∧B(x))`。
5. 回译：把公式按字面读回中文，与原文逐词对，重点查"唯一""除了""都"这三个量词陷阱。
**常见失分点**：`只有 A 才 B` 写成 `A→B`（方向反了）；存在句用 `→`，导致论域里没有 A 时句子反而为真。

### 题型四：集合与基数证明
1. 证两集合相等，一律"任取 x，证 x 属于左边当且仅当属于右边"，不要用文氏图当证明。
2. 关系题先写定义域与值域，再逐条验自返、对称、传递，三条验完才敢说是等价关系。
3. 证可数：构造从自然数到该集合的单射或双射，枚举方案必须写成公式；有理数用对角线枚举，画个图不算完成。
4. 证不可数：假设已枚举成序列，用对角线造一个与每一项都不同的元素，再证明它仍在集合内，得矛盾。
5. 超限归纳分三段写：初始情形、后继情形、极限情形，缺极限情形是典型的不完整证明。
**常见失分点**：用"显然可以一一对应"代替双射的构造；对角线论证忘了证明造出的元素属于原集合。

## 7. 常见误区

1. **把"有效"当成"正确"** → 错在混淆形式与内容；有效只保证前提真则结论真。判题时先只写符号做形式判定，内容评价另起一段。
2. **证明里默认要证的结论** → 错在循环论证，用 `φ` 本身或它的等价式去证 `φ`；应该先列可用前提，每行只许引用前面出现过的行。
3. **量词否定只改一个** → 错在把 `¬∀x∃yP` 写成 `∃x∃y¬P`；应该从最外层开始逐层套 `¬∀→∃¬`、`¬∃→∀¬`，剥完再检查变元是否被意外约束。
4. **把 `→` 与 `⊨` 混作一个符号** → 错在把对象语言的"如果 P 那么 Q"与元语言的"所以"写成同一个记号；答题时对象语言用 `→`，元语言断言用 `⊨` 或直接写中文。
5. **模态推理照搬经典等值** → 错在 K 里使用 `□P→P`，或把 `□(P∨Q)→(□P∨□Q)` 当定理；应该先确认题目给的是哪个系统，再只用该系统的特征公理。
6. **集合论里默认"取一个"** → 错在没说明就用了选择公理；应该在用到的那一步标注"此处用 AC"，并写出等价形式（Zorn 引理或良序定理）。

## 9. 交叉专业与后续方向

- **和数学的区别**：数学在既定逻辑框架内证明定理，逻辑学把框架本身当对象，问它可靠不可靠、完全不完全、可判定不可判定。同一句话，数学问"这个定理对不对"，逻辑学问"证明这个定理需要多强的系统"。
- **和哲学的区别**：哲学追问"应该相信什么、理由好不好"，允许价值判断与解释分歧；逻辑学只给"从这些前提出发能走到哪一步"的判决，而且这个判决必须能写成可复核的步骤。逻辑哲学的题目（K06）才重新回到哲学侧。
- **和计算机的区别**：计算机关心"能不能在有限时间算完"，逻辑学关心"在这个系统里什么是可证的"；两边的交汇点是可计算性、类型论与程序验证，同一批定理在两边名字不同。
- **和语言学的区别**：语言学用逻辑做工具分析量化、辖域与预设，逻辑学关心这套形式语言本身的表达力与语义模型，不负责描写具体语言。
- **后续方向**：现代逻辑（模型论、证明论、递归论、集合论四个方向）、数学基础与哲学逻辑、人工智能中的知识表示与自动定理证明、法律与政策论证分析；考研常按逻辑学或外国哲学（逻辑方向）招生，复试多考一阶逻辑与集合论。
