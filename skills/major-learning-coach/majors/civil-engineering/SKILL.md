# 土木工程（civil-engineering）

> 先读 `../../references/curriculum-rules.md`（难度与排序）与 `../../references/learning-card-template.md`（讲解结构）。
> 本文件只给这个专业的知识骨架与专业习惯。

## 1. 这个专业在训练什么

把甲方一堆互相冲突的要求——几层、多大跨度、多少预算、多久完工、场地是什么土——变成一张能施工的图，并且对图上每个尺寸都能回答"为什么是这个数、凭什么说它安全"。

核心能力是**判定**而不是算：判定哪个荷载组合控制设计、哪个截面最危险、哪种破坏形式会先发生、哪个环节的误差正在吃掉安全储备。算只是判定的执行手段，算得再准，判错了也是零分。

外人以为土木 = 搬砖 + 画图。画图是表达，K03（结构力学）与 K05（可靠度）才是分水岭：它们决定你能不能解释"这根梁为什么配 3 根 20 而不是 2 根 25"。

它和建筑学的界线：建筑学决定"长什么样、怎么用"，土木决定"凭什么站得住、怎么造出来、花多少钱"。同一张图，建筑学答空间，土木答受力路径与配筋。

**最容易误解的一点**：以为安全 = 多放钢筋。配筋率有上限，越过界限就是没有预兆的脆性破坏；保护层与钢筋净距还受耐久性和粘结约束，钢筋塞得越多截面越挤。正确动作是先看 $\xi$ 与 $\rho_{\min}$，再谈加多少。

## 2. 课程地图

| 学期 | 课程 | 模块 | 先修 | 难度感受 |
|------|------|------|------|----------|
| 大一上 | 理论力学（静力学） | K01 | — | 受力图错一次后面全错；约束反力的方向是第一个坎 |
| 大一下 | 材料力学 | K02 | K01 | 内力图与应力公式必须同时正确，中间没有容错 |
| 大二上 | 结构力学 | K03 | K02 | 从一根梁跳到一整个体系，几何组成分析最抽象 |
| 大二下 | 荷载与结构设计方法 | K05 | K03 | 概念不难，但"标准值 vs 设计值"会一直混到毕业 |
| 大二下 | 混凝土结构 | K04 | K02、K05 | 公式套路固定，难在构造要求与规范查用 |
| 大三上 | 土力学与地基基础 | K06 | K02 | 从确定性力学进入"土是概率性材料"，要重建直觉 |
| 大三下 | 施工组织 | K07 | K04 | 不考算得准，考的是把工序、资源、工期排得不打架 |
| 大四 | 课程设计 / 毕业设计 | 全部 | 全部 | 第一次为一张图上的每个数字负责 |

**最陡的三门课**：结构力学（因为要先把实际结构抽象成计算简图，简图画错则全题作废）、材料力学（因为内力图的符号约定与叠加必须同时正确）、土力学（因为有效应力、固结、抗剪强度三套概念互相牵制，而且没有"标准答案"可以对）。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能对给定的梁、刚架、桁架画出计算简图与受力图，列出足够的平衡方程解出全部支座反力。
2. 能画出剪力图与弯矩图，标出危险截面，并用控制截面数值回代校验图形。
3. 能判断结构是静定还是超静定、超静定几次，并选力法或位移法给出可解的方程。
4. 能完成单筋矩形梁的配筋计算，并逐项校核最小配筋率、$\xi_b$、保护层与裂缝宽度。
5. 能完成地基承载力验算与沉降计算，判断这个基础是承载力控制还是变形控制。
6. 能把一个单位工程排成网络计划，找出关键线路并说清工期压缩一天要付什么代价。
7. 能对公式里每个符号说明取值来源（标准值还是设计值、有无折减系数），不凭记忆填数。

## 5. 术语与符号约定

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| 荷载效应 $S$ / 抗力 $R$ | 荷载引起的内力或应力 / 构件能承受的同类量 | kN、kN·m、N/mm² | 比的是设计值 $\gamma_0 S_d \le R_d$，不是标准值；两边单位不统一是常见扣分 |
| 荷载标准值 $G_k$、$Q_k$ | 不乘分项系数的代表值 | kN、kN/m² | 常被直接代进承载力公式，漏了分项系数与重要性系数 |
| 分项系数 $\gamma_G$、$\gamma_Q$ | 设计值 = 标准值 × 分项系数 | 通常大于 1 | 恒载有利时取 1.0，抗浮抗倾覆时甚至取小于 1；方向一写反结论就反 |
| 弯矩正负 | 梁以使其下部受拉（下凸）为正 | kN·m | 材力用"下缘受拉为正"，结构力学要求"画在受拉侧"且不标正负，混凝土又用"跨中正、支座负"；一道题只许一套并写明 |
| 剪力正负 | 使微段顺时针转动的剪力为正 | kN | 必须与 $V = \mathrm{d}M/\mathrm{d}x$ 配套；符号一错，弯矩图的峰谷就全部颠倒 |
| 轴力正负 | 材力拉为正、压为负 | kN | 混凝土柱习惯把压力记作正号，两门课直接照抄会错 |
| 支座反力 | 竖向 $R$、水平 $H$、反力矩 $M$ | kN、kN·m | 固定端是 3 个未知量不是 2 个；可动铰只有 1 个，数错就解不出 |
| 静定 / 超静定 | 未知力数等于 / 多于独立平衡方程数 | 超静定次数 $n$ | 反力数不等于总未知力数，还要算杆端内力；温度变化与支座位移只在超静定中产生内力 |
| 力法 | 以多余未知力为基本未知量 | — | 基本体系必须几何不变；单位弯矩图与荷载弯矩图要分开画再图乘 |
| 位移法 | 以结点位移为基本未知量 | — | 未知量数 = 独立结点角位移 + 独立线位移；与力法不能混用在同一步 |
| 图乘法 | $\int M\bar{M}\,\mathrm{d}s / EI = \sum A y_c / EI$ | — | 两个弯矩图都必须是直线段才能乘；$y_c$ 要取自直线图形，取错图是高频错误 |
| 保护层 $c$ | 最外层钢筋外缘到混凝土表面的距离 | mm | 环境类别决定最小值；按箍筋外缘还是主筋外缘量，差一个箍筋直径 |
| 配筋率 $\rho$ | $A_s/(b h_0)$ | % | 分母是 $b h_0$ 不是 $bh$；而 $\rho_{\min}$ 按全截面 $bh$ 算，两处分母不同 |
| 有效高度 $h_0$ | $h - a_s$ | mm | 双排配筋时 $a_s$ 变大、$h_0$ 变小，还按单排取会让承载力虚高 |
| 相对受压区高度 $\xi$ | $x/h_0$ | — | 要与界限值 $\xi_b$ 比；$\xi > \xi_b$ 即超筋，破坏无预兆，不能靠加钢筋解决 |
| 地基承载力特征值 $f_a$ | 由载荷试验、经验公式等确定的承载力代表值 | kPa | 它叫"特征值"，既不是标准值也不是设计值；深度与宽度修正别漏 |
| 沉降 $s$ | 最终沉降量 | mm | 分层总和法算的是附加应力引起的部分；用总应力代替附加应力是最常见错法 |
| 压缩模量 $E_s$ | 侧限条件下的应力应变比 | MPa | 用 $E_s$ 不是无侧限的 $E$；要取与计算应力段对应的那一段，不能整条曲线取一个值 |
| 黏聚力 $c$ | 莫尔-库仑强度参数 | kPa | 与保护层同名不同物；用有效应力指标时必须写成 $c'$、$\varphi'$ |
| 内摩擦角 $\varphi$ | 莫尔-库仑强度参数 | ° | 与内摩擦系数 $\tan\varphi$ 混用会差一个函数；指标来源要说清是固结快剪还是固结不排水 |
| 主动 / 被动土压力 | 墙后土推墙 / 墙推土到极限 | kN/m | 主动是土压墙、被动是墙压土；被动值大得多，常达数倍，写反则挡土墙结论全错 |
| 安全系数 $K$ | 抗力与荷载效应的单一比值 | 大于 1 | 与可靠度指标不是一回事：$K$ 是确定性的比值，$\beta$ 是概率意义上的失效度量 |
| 可靠度指标 $\beta$ | 功能函数均值与标准差之比 | 2.7–4.2 量级，随安全等级与破坏类型变 | 现行设计用分项系数近似表达它，不要求手算；要说清 $\beta$ 越大失效概率越小 |
| 施工缝 | 因浇筑中断被迫留下的缝 | — | 有位置禁区：剪力大、弯矩反弯点附近不宜留；留在跨中必须给出理由与处理措施 |
| 后浇带 | 为释放收缩或沉降差先留、后浇的带 | 通常 0.7–1.0m，按设计确定 | 与伸缩缝、沉降缝不是一回事；要等两侧主体施工到一定阶段再浇，且需凿毛清浆 |
| 关键线路 / 总时差 | 决定总工期的线路 / 不影响总工期的机动时间 | d | 总时差为零的线路才是关键线路；自由时差与总时差不是同一个量 |

## 6. 典型题型与解题套路

### 内力图计算（剪力、弯矩、超静定弯矩图）
1. 先定计算简图与支座反力：数清未知反力个数，取整体列平衡方程，解完用另一个方程回代。
2. 分段：按集中力、集中力偶、均布荷载的起止点把梁切开，保证每一段内部荷载连续。
3. 逐段画：无载段剪力为常数、弯矩为直线；均布段剪力为直线、弯矩为抛物线；集中力处剪力跳变，集中力偶处弯矩跳变。
4. 用微分关系复查：$V = \mathrm{d}M/\mathrm{d}x$，弯矩极值出现在 $V = 0$ 处，铰处弯矩必为零。
5. 超静定先判次数再选方法：数出多余约束数与独立结点位移数，谁的未知量少用谁；两者都不小就上矩阵位移法。

**常见失分点**：反力算对了但符号带错，整张图上下颠倒；铰、自由端、固定端的边界值没校验就直接交卷。

### 配筋计算（正截面、斜截面、柱）
1. 先统一到设计值：把荷载标准值乘分项系数得到 $M$、$V$、$N$，并确认结构重要性系数。
2. 判类型：单筋还是双筋、矩形还是 T 形、大偏心还是小偏心，用 $x$ 与 $\xi_b h_0$ 的关系确定。
3. 列平衡方程：由 $\alpha_1 f_c b x = f_y A_s$ 先解 $x$，再代入弯矩方程解 $A_s$。
4. 过三道校核：$\rho \ge \rho_{\min}$、$x \le \xi_b h_0$、构造要求（保护层、净距、锚固长度）。
5. 选配钢筋：按实配面积略大于计算面积选直径根数，再回算实际 $\rho$ 与实际受弯承载力。

**常见失分点**：$h_0$ 用成 $h$，或双排配筋仍套单排的 $a_s$，承载力被虚高。

### 地基沉降计算
1. 先算基底附加压力：基底压力减去基底处自重应力得到 $p_0$，再用角点法叠加求各层附加应力。
2. 分层：按土层界面与约 $0.4b$ 的厚度分层，记下每层中点的深度与上下界。
3. 定压缩层厚度：算到附加应力约为自重应力的 0.2 倍处为止，软土取 0.1 倍。
4. 逐层算：$s_i = \bar{\sigma}_{zi} h_i / E_{si}$，用与应力段对应的 $E_s$，求和后乘经验系数。
5. 校核：把总沉降与允许值比，同时检查相邻基础的沉降差与整体倾斜。

**常见失分点**：用总应力代替附加应力；$E_s$ 取整条压缩曲线的一个值，没取对应应力段。

### 施工组织设计
1. 先算量与分解：按施工图算出主要分部分项工程量，据此定班组人数与机械台班。
2. 定施工方案：划分流水段与流水方向，确定主导施工过程，其余过程按它配节奏。
3. 排进度：画双代号网络图，算最早时间、最迟时间与总时差，标出关键线路。
4. 配资源与场地：画施工总平面，定塔吊位置与覆盖半径、堆场、临时道路，检查是否与基坑或相邻建筑冲突。
5. 做约束检查：把工期、造价、安全文明施工之间的冲突列出来，给出一个能辩护的取舍。

**常见失分点**：网络图逻辑关系画错（把可平行的画成必须先后），关键线路随之全错；总平面图不看塔吊覆盖半径。

## 7. 常见误区

1. **把荷载标准值直接代进承载力公式** → 错在漏乘分项系数与重要性系数；应先算出效应设计值，再与抗力设计值比，两边都必须是设计值。
2. **弯矩图不标约定，也不画在受拉侧** → 错在把材力、结力、混凝土三套记法混在一张图上；一道题只准一套，并在图旁写明按哪套。
3. **认为超静定一定比静定安全** → 错在忽略超静定对支座沉降和温度变化敏感；多出的约束既是储备，也是附加内力的来源。
4. **配筋越多越安全** → 错在越过界限相对受压区高度后变成脆性破坏，且净距与保护层被挤占后粘结、耐火都不满足；应改截面、改混凝土等级、改钢筋级别。
5. **沉降算到压缩层底还用总应力** → 错在没扣自重应力；必须先求附加应力，且压缩模量要取对应应力段。
6. **施工缝随手留在跨中** → 错在跨中弯矩最大、剪力也不小；应留在剪力较小且便于施工的位置，并写明凿毛、清浆、接浆的处理。

## 9. 交叉专业与后续方向

- **和工程管理的区别**：土木回答"这个东西怎么算才安全、怎么造得出来"，工程管理回答"谁在什么时候、用多少钱把它造出来"。同一根梁，土木算配筋，工程管理算它占多少工日、排在哪个流水段、拖一天罚多少。分界点是**要不要为承载力公式签字**。
- **和建筑学（本仓库未收）的区别**：建筑学定功能、空间与形体，是施工图的前提；土木定受力路径、构件尺寸与配筋。建筑学画得出形状但不能保证站得住，土木要签字保证。分界点是**谁对"塌不塌"负责**。
- **和机械工程的区别**：机械构件可批量、可拆卸、可更换；土木构件多在现场浇筑、不可更换、要服役几十年，所以土木更依赖荷载统计、规范与耐久性构造。
- **和材料科学的区别**：材料问"这个配合比、这个钢号的性能上限是多少"，土木问"给定这个性能，截面与配筋取多少才够"。
- **后续方向**：结构工程（考研最热）、岩土工程、桥梁与隧道工程、防灾减灾工程及防护工程、市政与地下空间；典型岗位是结构设计、施工技术、造价与监理、检测鉴定。
- **规范口径**：本文件只讲方法与符号习惯，不替代规范。所有承载力公式、系数取值、构造尺寸、材料强度设计值一律以现行版本的规范、标准与地方规定为准；需要具体数值时查现行文本，不要背条文号，也不要相信二手转述。
