# 电气工程及其自动化（electrical-engineering）

> 先读 `../../references/curriculum-rules.md`（难度与排序）与 `../../references/learning-card-template.md`（讲解结构）。
> 本文件只给这个专业的知识骨架与专业习惯。

## 1. 这个专业在训练什么

靠"把电能从发电机安全送到负荷"吃饭：电压要合格、频率要稳、故障要能切除、设备不能烧。这套本事最后落在四个可算的量上——电压、电流、功率、阻抗，一切题目都是在它们的约束下做选择。

外人以为电气 = 拉电线、修电器。拉线只是施工，真正的活是算：算潮流看末端电压掉多少，算短路看故障电流多大，算整定看保护会不会误动，算稳定看机组会不会失步。

它和电子信息工程的分界是**能量还是信息**：电气搬千瓦级功率，关心效率、绝缘与安全；电子搬毫瓦级信号，关心保真、带宽与信噪比。同一门电路课之后，电气接电机学、电力电子、电力系统分析；电子接信号与系统、通信原理。

**最容易误解的一点**：以为强电"粗"所以不用精细算。恰恰相反，电网电压允许偏差只有百分之几，一次误整定就是大面积停电——算错一个小数点比接错一根线更贵。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能对给定三相电路判定接法，算出线值相值、三相功率与功率因数，并用功率平衡验算一次。
2. 能由空载与短路试验数据画出变压器等效电路，算出电压调整率与效率，说清铁损铜损各占多少。
3. 能由铭牌与实测转速算出异步机转差率与电磁转矩，判断降压或变频之后还能不能带载起动。
4. 能建立多电压等级网络的标幺值模型，用迭代法算出各节点电压与支路功率。
5. 能算出故障点短路电流与冲击电流，据此完成三段式保护的定值计算与灵敏系数校验。
6. 能画出正常、故障中、故障后三条功角曲线，用等面积定则判断切除后能否保持暂态稳定。
7. 能对照现行规程核对学生答案里的整定值、电压偏差与并网要求，指出哪一条已经过期。

## 5. 术语与符号约定

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| 参考方向与关联参考 | 事先假定的电压电流正方向 | — | 强电题一律先标方向再列方程；方向反了结果带负号，不要改标号硬凑成正数 |
| 有效值 $U$、$I$ | 与相量对应的均方根值 | V、A | 电气全用有效值，$u=\sqrt2 U\sin\omega t$；把电子习惯的峰值代进去会差 $\sqrt2$ |
| 下标约定 | 1 与 2 表示一次侧与二次侧、m 表示最大值、d 与 q 表示直轴与交轴 | — | $U_1$ 指的是一次侧电压而不是"第一个电压"；$X_d$ 的 d 是直轴不是动态，抄公式时下标比数字更容易错位 |
| 相电压 $U_p$ 与线电压 $U_L$ | 相与中性点、相与相之间的电压 | V、kV | 星接 $U_L=\sqrt3 U_p$ 且线电压超前相电压 $30°$；角接线电压等于相电压，两者整反 |
| $\sqrt3$ 的来源 | 两个相差 $120°$ 的相量之差 | — | 推一次 $\dot U_{ab}=\dot U_a-\dot U_b$ 就记住；三角形接法里 $\sqrt3$ 出现在电流上而不是电压上 |
| 三相功率 $S=\sqrt3 U_L I_L$ | 三相视在功率 | kVA、MVA | 代线值才乘 $\sqrt3$，代相值要乘 3；$P=\sqrt3 U_L I_L\cos\varphi$ 里别把 $\cos\varphi$ 漏掉 |
| 有功 $P$、无功 $Q$、视在 $S$ | $S=P+jQ$ | kW、kvar、kVA | $S$ 不等于 $P+Q$，而是 $\lvert S\rvert^2=P^2+Q^2$；$\cos\varphi$ 只能由 $P/\lvert S\rvert$ 算 |
| 感性/容性无功的符号 | 感性吸收无功、容性发出无功 | kvar | 发电机进相运行是吸收无功；把 $Q$ 的正负与电压升降直接挂钩，调压方向会判反 |
| 标幺值与基准 $S_B$、$U_B$ | 实际值除以同量纲基准值 | 无量纲 | $Z_B=U_B^2/S_B$ 里 $U_B$ 取线电压、$S_B$ 取三相容量；单相公式混进来会差 3 倍 |
| 基准变换 | 把不同电压等级归算到同一基准 | — | 阻抗按变比平方折算；变压器的标幺电抗两侧不变，写成"除以变比"是最常见错 |
| 变压器 T 型等效电路 | 励磁支路加短路阻抗 | Ω 或标幺 | 空载试验测励磁支路与铁损，短路试验测绕组阻抗与铜损，两个试验数据对调必错 |
| 铁损与铜损 | 铁损近似不变、铜损随电流平方变 | kW | 铁损与负载无关，铜损与负载率平方成正比；效率最高点不在满载而在某一负载率处 |
| 变比 $k$ 与分接头 | 一次二次匝数比与调压抽头 | — | 变比不等于额定电压之比，要按分接头电压算；调压改变的是变比，不是负荷大小 |
| 转差率 $s=(n_1-n)/n_1$ | 同步转速与转子转速之差 | 0–1（电动） | $n_1=60f/p$ 里的 $p$ 是极对数；$s$ 为负是发电、大于 1 是制动，别只看数值大小 |
| 电磁转矩 $T$ | 异步机 $T$ 与电压平方成正比 | N·m | 电压降 10% 转矩约降 19%；串转子电阻只改临界转差率与起动转矩，最大转矩不变 |
| 功角 $\delta$ | 发电机电势 $E_0$ 与端电压 $U$ 的相位差 | 度、rad | $\delta$ 不是功率因数角 $\varphi$；$P=\frac{E_0U}{X_d}\sin\delta$ 里的 $X_d$ 是同步电抗 |
| 潮流节点类型 PQ/PV/平衡 | 三类节点给定量不同 | — | PQ 给 $P$、$Q$ 求 $U$、$\delta$；PV 给 $P$、$U$ 求 $Q$、$\delta$；平衡节点全网只有一个且 $\delta=0$ |
| 短路电流 $I''$ 与冲击电流 $i_{sh}$ | 短路瞬间周期分量与最大瞬时值 | kA | $i_{sh}=\sqrt2 K_{sh}I''$，高压系统 $K_{sh}$ 约 1.8；把 $I''$ 直接当冲击电流是典型错 |
| 短路容量 $S_k$ | $\sqrt3 U_N I''$ | MVA | 它衡量系统"硬不硬、抗扰动强不强"，不是故障点实际消耗的有功功率 |
| 整定三系数 $K_{rel}$、$K_{re}$、$K_{sen}$ | 可靠系数、返回系数、灵敏系数 | 无量纲 | $I_{set}=K_{rel}I_{L\max}$，灵敏度要用最小运行方式的最小短路电流校验，三个系数不能互相替代 |
| CT/PT 二次额定值 | 5A 或 1A、100V 或 100/√3 V | A、V | 定值算在二次侧，写结论要说明有没有折到一次侧；CT 极性接反会让差动保护误动 |
| 中性点接地方式 | 直接接地、不接地、经消弧线圈接地 | — | 它决定单相接地电流大小与零序保护配置；不接地系统单相接地允许短时运行 |
| 静态稳定与暂态稳定 | 小扰动后能否保持同步、大扰动首摆能否拉回 | — | 静态判据是 $dP/d\delta>0$；暂态要用等面积定则，别拿静态裕度当暂态结论 |
| 极限切除角与极限切除时间 | 等面积定则给出的临界值 | 度、s | 加速面积等于最大减速面积时达极限；切除越快，留给系统的极限切除角裕度越大 |
| 并网条件与 LVRT | 幅值、频率、相位、相序四项；低电压穿越 | — | 非同期并列产生冲击电流与轴系扭振；LVRT 曲线按现行规程取，不是"跌一点就跳" |

## 6. 典型题型与解题套路

### 电路与电机计算题（相量、三相、变压器、异步机）
1. 画图标全参考方向，待求量写成符号，先把已知量统一到有效值与同一电压等级。
2. 三相题先判接法：星接 $U_L=\sqrt3U_p$、$I_L=I_p$；角接反过来，再决定 $\sqrt3$ 出现在电压还是电流上。
3. 变压器题先分清空载与短路试验各测什么，按数据算出 $R_m$、$X_m$ 或 $R_k$、$X_k$，再画等效电路。
4. 电机题先算 $n_1=60f/p$ 与 $s$，再按 $T\propto U^2$ 判断电压变化的影响，最后回代功率平衡。
5. 用 $P_1=P_2+\sum p$ 与效率验算数量级，效率超过 100% 立刻回查哪项损耗漏了。
**常见失分点**：三相题里 $\sqrt3$ 用错位置；把铁损当铜损代入效率计算。

### 潮流与短路计算题
1. 先选基准 $S_B$、$U_B$，把各电压等级元件化到同一基准，画出等值电路。
2. 标节点类型：PQ、PV、平衡；把已知量填进功率方程，数清待求量个数与方程数是否相等。
3. 潮流用迭代：给电压初值，逐次修正，看两次迭代的电压修正量是否小于阈值再收。
4. 短路先化简网络求对故障点的等值电抗，算 $I''=U_B/(\sqrt3 X_\Sigma)$，再乘冲击系数得 $i_{sh}$。
5. 结果检查：末端电压应落在 0.95–1.05 标幺附近，短路电流要与短路容量彼此对得上。
**常见失分点**：换基准时忘了按变比平方折算；PV 节点无功越限后没转成 PQ 就继续迭代。

### 继电保护整定题
1. 先定保护对象与故障类型，画出一次接线与 CT/PT 位置，明确整定算在哪一侧。
2. 按可靠系数与最大负荷电流算启动值，按上下级时间级差与定值级差逐段配合。
3. 用最小运行方式下的最小短路电流校验灵敏系数，不满足就改段或改配合关系。
4. 写成"定值—时限—校验"三栏表，并说明这一级为什么带方向、为什么要加闭锁。
**常见失分点**：只用最大运行方式校验灵敏度；定值没说明是二次侧值还是已折算到一次侧。

### 系统分析与稳定论述题
1. 先给结论句（稳定或不稳定、该调什么），再按"机理—计算—措施"三层展开。
2. 稳定题画三条功角曲线：正常、故障中、故障后，标出加速面积与减速面积。
3. 调压调频题按"无功调压、有功调频"分工，列出可选手段（电容器、分接头、励磁、调速器）及各自代价。
4. 并网与新能源题先交代控制方式（跟网或构网）与规程要求，再谈对稳定的影响。
**常见失分点**：只背"提高稳定性的措施"，不说明每条措施作用在哪条曲线的哪块面积上。

## 7. 常见误区

1. **三相功率直接套 $3U_pI_p$ 却代入线值** → 错在混用线值与相值；应该先判接法，用线值时系数是 $\sqrt3$。
2. **标幺值换基准按电压比一次方折算** → 漏了平方；应按 $\left(U_{B1}/U_{B2}\right)^2$ 折算阻抗，变压器两侧标幺值不变。
3. **空载试验与短路试验数据对调** → 铁损与铜损跟着反过来；空载测励磁支路，短路测绕组阻抗，先写清各测什么再代数。
4. **潮流迭代一直把 PV 节点当 PV** → 忽略无功越限；每轮结束检查 $Q$ 是否越界，越界就转 PQ 重算。
5. **短路电流不乘冲击系数** → 把周期分量当成最大瞬时值；设备动稳定校验用 $i_{sh}$，热稳定校验用周期分量。
6. **整定只算定值不校验灵敏度** → 灵敏度用最大运行方式算会偏乐观；必须用最小运行方式下本线路末端的最小短路电流。
7. **把静态稳定裕度当暂态结论** → 两者扰动性质不同；暂态必须走等面积定则或时域仿真，不能用 $dP/d\delta$ 代替。

## 9. 交叉专业与后续方向

- **和 `electronic-information`（电子信息工程）的分界**：电气搬千瓦级功率、以 50 Hz 为主，目标是效率、绝缘与不烧设备；电子搬毫瓦级信号、频段高得多，目标是保真、带宽与信噪比。判据只有一句："这条支路是在搬能量还是在搬信息"。同一门电路课之后两边分流：电气接电机学、电力电子、电力系统分析，电子接信号与系统、通信原理、DSP。同一个 MOS 管，电子看它做开关放大，电气看它的通态压降与开关损耗。
- **和 `automation`（自动化）的分界**：自动化给别人的对象套闭环，核心量是偏差、增益、极点与裕度，落点是控制器与算法；电气设计对象本身（电机、变压器、电网），并在故障时把它切出去，核心量是电压、电流、功率与整定值。两边都学《自动控制原理》，电气只取判稳与调频调压那一段，用 K06 去守发电厂与电网的回路。
- **和 `mechanical-engineering`（机械）的分界**：机械定结构、强度与运动副，电气定驱动与供电；交汇点是电机本体设计、伺服系统与电动车辆，两边对"转矩从哪来、损耗在哪"的回答方式完全不同。
- **强电安全是第一条纪律**：任何实验先断电、验电、挂接地线，遵守工作票与操作票制度、五防闭锁，不带电作业、不单人操作高压设备；不许把低压弱电的经验直接搬到 10 kV 及以上。答错一道题可以重做，误送一次电没有第二次。
- **参数与整定必须以现行规程为准**：教材上的动作时间、保护配置、允许电压偏差、并网与低电压穿越要求，都可能被新版国家标准或电力行业规程替代。答题时按教材方法推，工程落地前查现行版本，并在结论里写明依据的是哪一版；不要拿十年前的整定值直接下现场。
- **后续方向**：考研 0808 电气工程（电力系统及其自动化、电机与电器、电力电子与电力传动、高电压与绝缘技术）；典型岗位是电网调度、变电运维、继电保护调试、新能源并网与场站电气、电气设计院与成套设备研发；进阶课程是高等电力网络分析、电力系统稳定与控制、高压直流输电与 FACTS、电机控制与宽禁带器件应用。
