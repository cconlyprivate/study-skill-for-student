# 动物医学（animal-medicine）

> 先读 `../../references/curriculum-rules.md`（难度与排序）与 `../../references/learning-card-template.md`（讲解结构）。
> 本文件只给这个专业的知识骨架与专业习惯，不重复通用协议。
> 本文件是学习方法指导，不替代执业兽医诊断；涉及真实动物须由执业兽医处置。

## 1. 这个专业在训练什么

动物医学训练的是**带物种前提的临床推理**：先问清"什么动物、多大、什么用途、养在哪"，再把症状收到器官、收到病变、收到病因，最后给出能执行的处置与预防。同一个呕吐，在幼犬、老猫、奶牛和赛马身上是四种不同的病，所以第一步永远不是想病名。

它和"给宠物看病"不是一回事。宠物临床只占一半，另一半是群体：一个猪场或牛场发病，要先算罹患率与病死率，再判断是管理、营养、传染病还是中毒，还要算治疗成本与休药期。

**最容易误解的一点**：以为动医 = 小动物临床。真正决定对错的常常是**物种差异**（解剖、参考区间、剂量、麻醉耐受），而不是病名背了多少。

与临床医学的分界线：人医记一套参考值，动医要记一套按物种分叉的参考值；人医只对病人负责，动医还要同时对畜主、对食品安全与对人畜共患病负责。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能把一段口述病情写成含物种、年龄、用途、病程、主诉的病例头，且主诉里不出现诊断。
2. 能按 TPR 顺序完成犬、猫、牛各一次系统查体，写出阳性与阴性所见，并说出该物种的正常区间。
3. 能对一组症状列 3–5 个鉴别方向，每个方向写一条支持证据、一条反对证据与一项关键检查。
4. 能把"症状"翻译成"病变"、再落到至少 2 个候选病因，并说明哪项检查能把它们分开。
5. 能为一台常规手术写出 ASA 分级、麻醉方案、5 项监护指标与苏醒期观察要点。
6. 能写出含物种、剂量、途径、频次、疗程的处方，并核对食用动物的休药期与弃奶期。
7. 能对一起群发疫情算出罹患率与病死率，并按传染源、传播途径、易感动物三环节排出现场处置顺序。
8. 能画出一条人畜共患病的传播链，并写出采样防护、暴露后处置与报告流程。

## 5. 术语与符号约定

动医的记号坑集中在三处：**数值带物种前提**、**推理分三层不可跳**、**同一个词在人医与兽医里指的不是一回事**。下面每条都对应一个真实扣分点。

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| 参考区间 | 特定物种、年龄、品种与方法下 95% 个体的波动范围 | 随物种、年龄、品种、仪器变 | 拿人医区间或犬的区间套猫；不同实验室与仪器不可直接比，必须抄报告单自带区间 |
| 体温 T | 体核温度 | 犬约 37.5–39.0 ℃，猫约 38.0–39.2 ℃，牛约 38.0–39.0 ℃ | 不能照搬人的 36–37 ℃；肛温、耳温、腋温不可混用；应激与运动可使体温暂升 |
| 心率 HR | 每分钟心搏次数 | 犬约 70–160，猫约 140–220，牛约 60–80 | 体型越小越快、幼年比成年快；不能套人的 60–100，也不能只报一个数不报物种 |
| 呼吸频率 RR | 每分钟呼吸次数 | 犬约 10–30，猫约 20–30，牛约 10–30 | 只数胸廓起伏会把喘当快；发热、疼痛、酸中毒、胸腔积液都会升，要写伴随所见 |
| TPR | 体温、脉搏、呼吸三项生命体征 | — | 顺序固定为 T→P→R；先保定再测，别把挣扎后的数值当基线 |
| 症状 sign | 主人能描述或检查者能观察到的异常 | — | 症状不是诊断：写"呕吐"不写"胃炎"；主人说"不吃"要换算成采食量下降的比例与天数 |
| 病变 lesion | 肉眼或镜下可定位的形态改变 | — | "肝肿大"是病变，"肝炎"是病因层假设；症状→病变→病因三层，跳层就是蒙病名 |
| 病因 etiology | 病原、毒物、营养、遗传、管理中的直接原因 | — | 同一个病变可对应多个病因；写"病因待查"必须附鉴别清单与取证计划，不能空着 |
| 潜伏期 | 感染到出现症状的时间 | 因病而异，如狂犬病数周至数月 | 潜伏期不是检疫期；潜伏期内可能已排毒，别用"还没发病"判定安全 |
| 检疫期 | 法规或场规要求的观察隔离时长 | 按病种与法规确定 | 检疫期按最长潜伏期加安全边际定；"观察 3 天没事"不是结论 |
| 隔离与封锁 | 分开病畜与健康畜；限制区域移动 | 分级不同 | 先隔离再封锁；消毒顺序是先清除有机物再消毒，反过来等于白做 |
| ASA 分级 | 麻醉前全身状态分级 | I–V 级，急诊加 E | 按全身状态分，不按手术大小分；一只休克犬做小手术也是 IV–V E |
| 麻醉监护 | 心率、呼吸、血压、SpO2、EtCO2、体温 | 连续或每 5 分钟记录 | 小动物术中体温掉得比人快，保温本身就是监护项；反刍动物要防瘤胃臌气与误吸 |
| 无菌术 | 杜绝微生物进入术区的一整套操作 | — | 无菌不等于消毒；术者手、器械、术区任一环破功即污染；手套破了要换，不能擦一下继续 |
| 手术通路 | 到达目标器官的解剖入路 | 腹中线、旁正中、肋间、侧腹 | 通路选错会暴露不足、牵拉过度；腹部默认腹中线，泌尿生殖可旁正中，别凭手感开口 |
| mg/kg | 按体重计算剂量 | mg/kg | 必须写清是每次还是每日；物种间可差一个数量级，幼龄与肝肾功能不全还要再校正 |
| 休药期 | 停药到可上市的最短时间 | 按药物与物种定 | 食用动物必须查；肉、奶、蛋分别计算，猪与牛不同；开方前先确认用途是伴侣动物还是食用 |
| PCV 与 TP | 红细胞压积与总蛋白 | 犬 PCV 约 37–55% | 脱水时两者同升；急性失血早期两者都不降，不能用一次结果排除出血 |
| 尿比重 USG | 尿浓缩程度 | 犬约 1.015–1.045 | 一次尿比重不能定肾功能，必须结合水合状态；输液后测会假性稀释 |
| 脱水程度 | 体重丢失的百分比 | 约 5%、7–8%、10% 分级 | 补液量按体重乘百分比算，不按"看起来干"；老年动物皮肤弹性会假阳性 |
| 瘤胃 pH | 瘤胃液酸碱度 | 约 5.5–7.0 | 采样部位与采食后时间影响结果；亚急性瘤胃酸中毒看的是低于 5.8 持续了多久 |
| 疼痛评分 | 物种专用行为与生理量表 | 如犬猫 Glasgow CMPS-SF | 不能用人脸量表；猫要专用量表，先看行为再补生理参数，镇静后评分会失真 |
| 人畜共患病 | 可在动物与人之间传播的病 | 狂犬病、布病、弓形虫、钩端螺旋体病 | 接诊先问暴露史；采样戴手套口罩，锐器单独处置，针刺伤按流程报告而不是自行观察 |
| 动物疫病分类 | 一类、二类、三类法定疫病 | 按国家名录 | 名录与报告时限会更新，以最新主管部门公告为准；疑似即报，不等确诊 |
| 罹患率与病死率 | 发病比例与病死比例 | 0–100% | 分母不同：罹患率用暴露动物数，病死率用发病动物数，混用会低估疫情 |
| 灭菌与消毒 | 杀灭全部微生物含芽孢；减少病原数量 | — | 高压蒸汽看温度、压力、时间三参数；化学消毒剂穿不透有机物，必须先清洗 |

## 6. 典型题型与解题套路

### 病例分析题（给主诉、TPR 与化验，问最可能诊断和下一步）
1. 先补病例头：物种、年龄、性别、用途、病程、免疫与驱虫史；缺哪项就在答案里写明"需追问"。
2. 把主诉拆成"什么异常 + 从何时开始 + 频次或程度 + 伴随表现"，并把主人的口语换成体征。
3. 按 TPR 与系统顺序写阳性与阴性所见，先圈出危险信号：呼吸困难、黏膜苍白、脱水超过 8%、意识改变。
4. 按症状→病变→病因三层写推理：症状指向哪个器官，病变属于哪类过程，病因列 2–3 个候选并排序。
5. 只开能改变处置的检查，每项后面写"阴性时下一步做什么"。
**常见失分点**：一上来写病名，没有物种与年龄前提；把主人的描述直接当体征。

### 鉴别诊断题（给一组相似表现，问怎么分开）
1. 按"最常见、最致命、最易漏"三列排序，不按教材章节顺序。
2. 给每个候选写一条支持证据与一条反对证据，证据必须落到具体病史、查体或检验项。
3. 找"一分就开"的关键点：特征性体征、特异性化验、影像征象或病原检测，并说明它能排除谁。
4. 收尾写剩余不确定度、复查时间点，以及"如果治疗无效该改查什么"。
**常见失分点**：只列病名不写证据；把一次检查阴性当成排除。

### 处置/手术方案题（问怎么治、要不要开刀）
1. 先判断是否需要稳定：气道、呼吸、循环与液体复苏优先于确诊。
2. 处置写四件套：病因治疗、支持治疗、对症治疗、预防复发；每项带物种、剂量、途径、频次、疗程。
3. 需要手术时写全：适应证、禁忌证、术式与通路、ASA 分级、麻醉与镇痛方案、围术期监护。
4. 写"无效时的下一步"与复评时点；食用动物补休药期与弃奶期。
**常见失分点**：只写药名不写剂量途径；手术题不写麻醉、镇痛与保温。

### 公共卫生题（群发疫情、人畜共患病、检疫）
1. 先算三个数：存栏、发病、死亡，得出罹患率与病死率，再判断是点状暴发还是持续传播。
2. 按控制传染源、切断传播途径、保护易感动物三环节写措施，每条给可执行动作与责任方。
3. 写采样与送检：采几只、采什么、怎么保存运输；再写报告时限与向谁报告。
4. 人畜共患病补一段：接触者防护、暴露后处置、健康监测与登记。
**常见失分点**：只喊"隔离消毒"不给对象与顺序；把检疫期写成潜伏期。

## 7. 常见误区

1. **拿人医参考值套动物** → 错在忽略物种与年龄；应先查该物种、该年龄、该仪器的区间，并在报告里注明来源。
2. **看到症状就写病名** → 错在跳过病变层；应先写器官与病理过程，再列病因候选与取证检查。
3. **体温升高就判感染** → 错在忽略应激、运动、环境与测量途径；应静息复测，并结合白细胞、血色与病程判断。
4. **手术只想着切哪儿** → 错在忽略麻醉风险、无菌与保温；应先做 ASA 评估，备好监护、保温与镇痛。
5. **食用动物开药不查休药期** → 错在只治眼前的病；应同时写休药期与弃奶期，并口头告知畜主。
6. **群发病只治个体** → 错在不算群体指标；应先算罹患率与病死率，查管理、营养与环境，再定群体干预。

## 9. 交叉专业与后续方向

- **和动物科学（本仓库未收）的区别**：动科问"怎么养得又多又省"，管遗传育种、饲料配方、畜舍与环境；动医问"哪里坏了、怎么治、怎么防"。同一头奶牛产量下降，动科先查日粮与舒适度，动医先查瘤胃、蹄与代谢病。用户若问育种值、料肉比、配方设计，说明那属于动科，本文件只从疾病角度回答。
- **和预防医学的区别**：预防医学的群体是人，动医的预防兽医学群体是动物，但同时守人畜共患病的第一道关口。两者共用"三环节"框架，动医多一层动物—人界面，以及检疫、封锁、扑杀这类法定权限。
- **和临床医学的区别**：共享症状→诊断→处置的推理链，但动医多两个约束：物种差异（解剖、参考值、剂量、麻醉耐受）与经济约束（治疗成本对比动物价值）；而且不能问诊，只能靠畜主转述与现场观察。
- **后续方向**：执业兽医资格考试（全科与水生动物类）、小动物临床（内科、外科、影像、急诊）、大动物与反刍（奶牛、猪场）、禽病与水产、实验动物、海关与公共卫生检疫、兽药与疫苗研发；考研走兽医学一级学科下的基础兽医学、预防兽医学、临床兽医学。
- **边界提醒**：本文件是学习方法指导，不替代执业兽医诊断；涉及真实动物须由执业兽医处置，疫情报告与扑杀按当地主管部门规定执行。
