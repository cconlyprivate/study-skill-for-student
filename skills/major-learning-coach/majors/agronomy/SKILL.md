# 农学（agronomy）

> 先读 `../../references/curriculum-rules.md`（难度与排序）与 `../../references/learning-card-template.md`（讲解结构）。
> 本文件只给这个专业的知识骨架与专业习惯。

## 1. 这个专业在训练什么

农学把**人能调的参数**当成自变量：品种、密度、播期、水肥、植保，把**产量与品质**当成因变量，在气候与土壤的硬约束下求一个可执行、可复现、能算得清投入产出的方案。

它和"种地靠经验"不是一回事。经验只给方向，农学要求每条建议都落到可测的数上：亩穗数、叶面积指数、施氮量 kg/亩、灌溉定额 m³/亩、千粒重 g。没有数的"多施点肥、看天浇水"，在本专业等于没说。

它也不是纯生物学。植物生理回答"为什么能长"，农学还要回答"这一块地今年怎么种才划算"——因此必须同时握住机制、土壤条件、气象风险与成本。

**最容易误解的一点**：以为农学就是植物生理加田间操作。真正拉开差距的是**把机制换算成参数**的能力：同一份光合数据，能不能落成密度、追肥期和灌水定额，是这门专业的分水岭。

## 2. 课程地图

| 学期 | 课程 | 模块 | 先修 | 难度感受 |

| 大一下 | 植物生理学 | K01 | 植物学 | 水势与光合两处最陡，公式不多但方向与单位容易写反 |
| 大二上 | 土壤肥料学 | K02 | 植物生理学 | 记忆量大；施肥与灌溉计算一旦通了就是送分题 |
| 大二上 | 遗传学 | K03 | 植物生理学 | 概率与比例一起上，一步错整题作废 |
| 大二下 | 作物育种学 | K04 | 遗传学 | 概念不难，选择差与配合力必须亲手算一遍 |
| 大三上 | 作物栽培学 | K05 | 植物生理学、土壤肥料学 | 综合性强，要把前面几门拼成一套能执行的决策 |
| 大三上 | 田间试验与生物统计 | K06 | 遗传学 | 公式不多，"该用哪个设计"最容易错 |
| 大三下 | 耕作学与农作制度 | K07 | 作物栽培学 | 尺度从一块田升到一个轮作周期，单田直觉会误导 |

**最陡的三门课**：作物栽培学（因为要把生理、土壤、气象、农机拼成一套方案，没有唯一正确公式）、遗传学（因为每一步都带概率，比例还有前提）、田间试验与统计（因为误差是设计出来的，不是算出来的）。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能对一块具体的地写出"品种—密度—播期—水肥—植保"完整方案，并写明每个参数的取值依据。
2. 能由亩穗数、穗粒数、千粒重算出理论产量，与实测产量对账，并指出差额落在哪一环。
3. 能按目标产量法算出氮磷钾纯养分量、实物肥量与基追比，并说明土壤供肥量与利用率从哪来。
4. 能算出灌水定额与灌溉定额，并说明水源不足时先保哪个生育时期、为什么。
5. 能读懂一张品种区域试验表，判断一个品种是广适稳产还是只在一个点突出。
6. 能为品种比较试验写出小区面积、形状、重复数、排列方式与保护行，并说明误差从哪来。
7. 能用选择差与遗传力预估下一轮选择的遗传进度，并把世代间隔换算成年进度。
8. 能对一个栽培方案做量级校验：播量与密度是否自洽、施肥量与目标产量是否匹配、灌水量是否超过水源。

## 5. 术语与符号约定

农学的记号坑集中在四处：**基准面**（按土地面积还是叶面积）、**分母**（亩还是公顷、纯量还是实物量）、**方向**（水势与养分流向）、**统计基准**（对照、重复、显著差）。下面每条都对应一个真实扣分点。

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| 水势 $\Psi$ | 单位水量水的化学势差，表示水的可用程度 | MPa（1 MPa = 10 bar），常为负 | 越负＝越缺水；写成"水势高所以缺水"是最常见的反写，根—土—叶—气必须一路递减 |
| 叶水势 $\Psi_{leaf}$ | 叶片的水势 | −0.2 ~ −2.0 MPa | 一天内随蒸腾大幅波动，不写取样时刻（清晨还是正午）的数不能互相比较 |
| 蒸腾系数 | 生产 1 g 干物质所蒸腾耗水的克数 | 200–1000 g/g | 与需水系数（每 kg 籽粒耗水 m³）不是一回事，单位一换数字全变 |
| 净光合速率 $P_n$ | 单位叶面积净同化 CO₂ 的量 | μmol CO₂/(m²·s) | 已扣呼吸；与总光合混用会高估光能利用率，答"光合强"时要写清是哪个 |
| 光饱和点/补偿点 | 光合不再随光强增加 / 净光合为零的光强 | μmol/(m²·s) 或 klx | 补偿点是"净"光合为零，不是总光合为零；阴生植物两点都低 |
| 叶面积指数 LAI | 单位土地面积上的绿叶面积 | 0–8，大田多在 3–6 | 分母是**土地面积**不是单株叶面积；只计绿叶，含不含黄叶要说明 |
| 净同化率 NAR | 单位叶面积单位时间的干物质增量 | g/(m²·d) | 与相对生长率 RGR 混用；NAR 已把叶面积归一，RGR 没有 |
| 经济系数 HI | 经济产量与生物产量之比 | 0.3–0.5 常见 | 分子是经济产品（籽粒、块根），不是全部干重；只说产量不说 HI 判断不了源库是否协调 |
| 源、库、流 | 制造同化物 / 储存与消耗同化物 / 运输通道 | — | 库不只是籽粒，扩展中的叶片与根系也是库；只把籽粒当库会漏掉营养生长竞争 |
| 产量构成三要素 | 亩穗数 × 穗粒数 × 粒重 | 万穗/亩、粒/穗、g 千粒重 | 三者此消彼长，不能各取最大值相乘；粒重必须用千粒重并除以 1000 |
| 千粒重与容重 | 1000 粒风干种子重 / 单位容积种子重 | g/1000 粒；g·L⁻¹ | 千粒重是重量指标、容重是体积指标；容重受水分影响，必须注明含水量 |
| 理论产量与实测产量 | 由三要素算出 / 实收称重 | kg/亩 或 kg/hm² | 理论值永远高于实测，差额落在缩值系数上；方案里要写清报的是哪一个 |
| 亩与公顷 | 面积单位 | 1 hm² = 15 亩 = $10^4$ m² | 施肥量常按亩给、产量常按公顷给，换算错 15 倍是典型失分；代公式前先统一 |
| 土壤 pH | 土壤酸碱度 | 4–9，多数作物 6.0–7.5 | 是氢离子活度的负对数，差 1 就是 10 倍；不能按线性估"酸一点" |
| 阳离子交换量 CEC | 单位质量土壤吸附交换性阳离子的量 | cmol(+)/kg | 旧写法 meq/100 g 数值相同但记法不能混；CEC 大＝保肥强，不等于含肥多 |
| 盐基饱和度 | 交换性盐基占 CEC 的比例 | % | 必须与 pH 同看：饱和度低而 pH 高是钠质土，不能按普通酸性土调 |
| 土壤容重与田间持水量 | 单位容积干土重 / 毛管悬着水的最大量 | g/cm³；%（质量） | 灌水定额用的是容积含水量，质量含水率要乘容重才能换算，漏乘是常见错 |
| 灌水定额与灌溉定额 | 一次灌水量 / 全生育期各次之和 | m³/亩 或 mm | 灌溉定额＝各次灌水定额之和，还要除以灌溉水利用系数；当成单次量会超灌数倍 |
| 养分平衡法施肥量 | （目标产量需肥量 − 土壤供肥量）÷ 肥料利用率 | kg/亩（纯量） | 算出来是纯养分（N、P₂O₅、K₂O），不是实物肥；换算实物肥要除含量，磷钾别忘折算 |
| 肥料利用率 | 当季作物吸收的肥料养分占施入量的比例 | 氮 30–45%、磷 10–25%、钾 40–60% | 磷最低是因为被固定；三种元素套同一个利用率是典型错误 |
| 选择差 $S$ 与选择强度 $i$ | 入选个体均值减群体均值 / 标准化后的选择差 | 与性状同单位 / 无单位 | $S=i\sigma_p$，$i$ 由入选率查表得出；把入选率当选择差是最常见的错 |
| 遗传力 $h^2$ | 遗传方差占表型方差的比例 | 0–1 | 预测遗传进度只能用狭义 $h^2$；广义 $h^2$ 大不代表能稳定传给后代 |
| 配合力 GCA/SCA | 亲本一般配合力 / 组合特殊配合力 | 与性状同单位（离差） | GCA 是亲本平均表现，SCA 是特定组合的额外优势；只看 SCA 会选出不可重复的组合 |
| 对照 CK 与保护行 | 用于比较的基准品种 / 小区四周不计产的行 | — | CK 必须同期同法栽培；保护行面积不计入产量，漏扣会系统性高估 |
| 重复与小区 | 同一处理的独立地块数 / 一个处理占的地块 | 重复 3–4 次，小区 10–30 m² | 同一小区取样三次是取样不是重复；小区过小，边际效应会盖过处理效应 |
| 随机区组与裂区 | 按肥力方向划分区组 / 因素分主副区 | — | 裂区的主区精度低；把需要高精度的因素放主区，是设计层面的错误 |
| 变异系数 CV 与 LSD | 试验数据的相对误差 / 最小显著差数 | % / 与性状同单位 | CV 大于 15% 先查管理是否一致；LSD 只用于两两比较，处理多时要用多重比较 |

## 6. 典型题型与解题套路

### 题型一：产量构成分析（三要素对账）
1. 先统一口径：穗数用万穗/亩、粒数用粒/穗、粒重用千粒重 g，三个量写在同一行，别混用株或穗。
2. 用 $Y = N \times G \times W / 100$ 算理论产量（$Y$ 为 kg/亩，$N$ 为万穗/亩，$G$ 为粒/穗，$W$ 为千粒重 g），并当场用单位反推一遍，确认没多除或少除 1000。
3. 与实测产量比，把差额分摊到三要素上，再做敏感度：固定两个、动一个，看哪一要素变动 10% 对产量影响最大。
4. 定位限制环节：穗数不足查群体起点与成穗率，粒数不足查穗分化期水肥与光照，粒重不足查灌浆期光合与早衰。
5. 给措施时同时给代价：增密度会压低单株穗粒数，增氮会推迟成熟并加倒伏风险。
**常见失分点**：千粒重不除 1000、穗数不乘 $10^4$，结果差 100 倍还照抄结论；或把三要素各自的最大值直接相乘。

### 题型二：施肥与灌溉计算
1. 先分清问的是纯养分还是实物肥：纯量按 N、P₂O₅、K₂O 计，实物量要除以肥料含量。
2. 施肥走养分平衡式：施肥量 =（目标产量需肥量 − 土壤供肥量）÷ 肥料利用率；土壤供肥量由无肥区产量或土壤养分校正系数给出，用哪个要写明。
3. 磷钾先折氧化物（P → P₂O₅ 乘 2.29，K → K₂O 乘 1.20），再除含量与利用率；氮不用折。
4. 灌溉先算单次灌水定额 $m = 667 \times H \times \rho \times \Delta\theta / 100$（$m$ 为 m³/亩，$H$ 为计划湿润层 m，$\rho$ 为容重 g/cm³，$\Delta\theta$ 为质量含水率差 %）。
5. 再把各次定额相加得灌溉定额，或由"需水量 − 有效降水"除以灌溉水利用系数校核；两法不一致先查有效降水口径。
**常见失分点**：把纯养分量当复合肥重量；P、K 忘记折 P₂O₅ 与 K₂O；把灌溉定额当单次灌水量，超灌三到五倍。

### 题型三：田间试验设计
1. 先写试验目的与处理数，确定单因素还是多因素、要不要考察交互作用，处理数决定小区大小。
2. 定小区：面积 10–30 m²（稻麦可 6–15 m²），取长方形，长边与肥力梯度方向垂直；四周设保护行。
3. 定重复：一般 3–4 次，土壤差异大或预期差异小时加到 5–6 次；重复是唯一能估计误差的来源，不能用同小区多次取样顶替。
4. 定排列：单因素用随机区组，因素有主次用裂区，能控双向梯度用拉丁方；画一张带区组号与小区号的排列图。
5. 先写统计方法与判别阈值（LSD 或字母标记），再写"什么结果算差异成立"，避免看到数据再挑方法。
**常见失分点**：把同小区的多次取样当重复；忘设保护行与对照；处理太多而小区太小，边际效应盖过处理效应。

### 题型四：栽培方案制定（综合题）
1. 先列约束：积温与无霜期、降水与水源、土壤质地与 pH、CEC、速效养分、前茬，逐条写成可核对的数。
2. 定品种：按生育期与安全齐穗/成熟期倒推，只用通过审定且适合本区的品种，不用跨区未审定材料。
3. 定群体：由目标产量反推亩穗数，再按分蘖成穗率与千粒重定播量与密度，播量与密度必须互相验算。
4. 定水肥：按目标产量法算总养分与基追比，按水分平衡算灌水次数与定额，把穗分化期与灌浆期的水肥排在优先位。
5. 写风险预案：倒伏、病虫、霜冻、涝渍各一条措施，并写清触发信号（如拔节期 LAI 超过上限就控水控氮）。
**常见失分点**：只报参数不做校验，播量与密度不自洽，施肥量和产量目标对不上，方案里没有一个可核对的数与判断阈值。

## 7. 常见误区

1. **按"多施肥多打粮"往上加量** → 错在无视报酬递减与倒伏、贪青风险；应先算目标产量需肥量，再按土壤供肥量与利用率定用量，超出部分必须说明理由。
2. **把三要素各自最大值相乘当目标产量** → 错在忽略三者此消彼长；应先定一个要素（通常先定穗数），再按当地试验的相互关系定另两个。
3. **拿理论产量当实收产量上报** → 错在没乘缩值系数；理论值高于实测 10–20% 是常态，方案里必须写清报的是哪一个。
4. **把 pH 差 1 当成"差一点"** → 错在忽略它是对数标度；差 1 就是氢离子浓度差 10 倍，按线性估石灰用量会差一个数量级。
5. **用单次灌水量当灌溉定额** → 错在漏了"全生育期各次之和"与灌溉水利用系数；直接照抄会超灌数倍，还把产量差异误判成品种差异。
6. **一次一点的结果就下结论** → 错在没有重复与多年多点；一年一点只能当趋势，报告必须写清外推边界与适用生态区。
7. **跨区引种只看产量** → 错在忽略生育期与安全齐穗期；应先核对积温需求与光周期反应，再看产量，否则高产材料可能根本不能成熟。

## 9. 交叉专业与后续方向

- **和园艺的区别**：园艺管果、菜、花，面积小、单株价值高、设施与季节调控精细，考的是单株品质与上市茬口；农学管稻麦玉米大豆油菜棉这类大田作物，考的是群体与投入产出。同一句"提高产量"，园艺先问品质与上市期，农学先问亩穗数与水肥效率。用户问果树蔬菜花卉的修剪、设施与采后，转园艺；问大田作物的品种与群体，留在农学。
- **和植物保护的区别**：植保以病虫草害为对象，核心是识别、发生规律与防治决策（选药、轮换、抗性治理）；农学把植保当方案里的一个约束，只需写清"防什么、什么时候防、用哪类药"。同一块地，农学答"这套栽培方案能不能稳产"，植保答"这株是什么病、打什么药"。
- **和农业资源与环境、植物营养的区别**：那两个方向以土壤过程与养分循环本身为研究对象；农学只取其中能落到施肥量与灌溉定额上的那部分，机制细节要转过去查。
- **数据口径（本专业的硬规矩）**：产量、施肥量、灌溉定额、品种生育期与抗性，都必须注明来源——当地多年试验、品种区域试验报告、品种审定公告、现行国家标准或行业标准。不同生态区的数不能互相搬用；引用标准要写标准号与年份，标准会修订，一律以现行有效版本为准。答不出出处的数，宁可写"需按当地试验确定"，也不要编一个看起来合理的值。
- **后续方向**：考研常走作物栽培学与耕作学、作物遗传育种、植物营养学、土壤学；岗位包括种子企业与育种站、农技推广与农资服务、规模化种植基地与农场管理、农业保险与遥感估产；进阶课程有作物生理生态、分子育种、农业气象、农业经济与政策。
