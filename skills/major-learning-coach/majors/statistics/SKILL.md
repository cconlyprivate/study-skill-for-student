# 统计学（statistics）

> 先读 `../../references/curriculum-rules.md`（难度与排序）与 `../../references/learning-card-template.md`（讲解结构）。
> 本文件只给这个专业的知识骨架与专业习惯。

## 1. 这个专业在训练什么

统计学处理的是**信息不完整时的判断**：手上只有 30 个样本，却要对三千万人的总体说点什么，还要同时说清这句话错的可能性有多大。核心动作是把"我不知道"翻译成可计算的量——标准误、置信水平、$p$ 值、功效——于是"我不太确定"变成"若结论不成立，出现眼前数据的概率不超过 5%"。

它和"会算概率题"不是一回事。算分布、算期望是 K01 的手艺；真正拉开差距的是 K02-4（估计量凭什么好）、K03-1（$p$ 值到底在说什么）、K04-4（回归假设破了怎么看出来）、K06-4（样本是怎么来的、还能不能推断）。这四处决定你是"跑了个软件"还是"知道结果能信到哪一步"，所以每算完一个数，都要能说出它依赖哪条假设。

**最容易误解的一点**：把 95% 置信区间读成"参数有 95% 的概率落在里面"。参数是固定的数、不随机，随机的是区间；正确读法是"反复抽样时约 95% 的区间会盖住真值"。这一句写反，后面所有区间题都会连带解释错。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能对一份数据说出它的抽样机制，并判断这个结论还能不能推回目标总体。
2. 能写出一个估计量的偏差与方差，并据此比较两个估计量该选哪个。
3. 能对研究问题写出 $H_0$ 与 $H_1$、选出检验统计量，给出 $p$ 值、效应量与置信区间三件套。
4. 能读懂一张回归表：系数、标准误、$t$ 值、$R^2$、调整 $R^2$，并指出哪条假设最可能不成立。
5. 能设计一份抽样方案或对照实验，写清抽样框、样本量、分组方式与偏倚控制。
6. 能识别多重比较与 p-hacking，并给出校正后的结论。
7. 能用 Monte Carlo 或 bootstrap 复核一个解析结论，而不是只信公式。

## 5. 术语与符号约定

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| $N$ 与 $n$ | 总体大小与样本量 | 正整数 | 大小写反了有限总体校正就整体错；$n/N$ 超过 0.05 必须加校正因子 |
| $X_1,\dots,X_n$ | 样本，独立同分布的随机变量 | 与观测值 $x_i$ 区分 | $x_i$ 是它的一次实现；$\bar X$ 有分布而 $\bar x$ 只是一个数，符号写错等于把随机性丢了 |
| $\bar X$ / $S^2$ | 样本均值 / 样本方差 | $S^2$ 分母取 $n-1$ | 除以 $n$ 的那个是有偏的；`var()` 用 n−1、`std(ddof=0)` 用 n，抄结果前先看默认值 |
| 统计量 | 只含样本、不含未知参数的函数 | $\bar X$、$S^2$、$T$ | 式子里混进 $\mu$ 或 $\sigma$ 就不是统计量，检验统计量必须先能算出来 |
| 估计量 / 估计值 | 随机变量 / 一次实现 | 估计量有分布 | "无偏"说的是估计量的性质，不是"这次算出来的数很准" |
| 无偏性 | $E(\hat\theta)=\theta$ | 对一切 $\theta$ 成立 | 无偏不等于每个样本都接近真值；$\hat\theta$ 无偏时 $g(\hat\theta)$ 一般不是 $g(\theta)$ 的无偏 |
| 有效性 | 同无偏下方差更小 | 只在无偏估计量之间比 | 两个都有偏时不能只比方差；完整指标是均方误差 = 偏差平方 + 方差 |
| 一致性 | $\hat\theta$ 依概率收敛到 $\theta$ | $n\to\infty$ | 一致性只谈大样本；无偏不一定一致（只用第一个观测当估计量就是反例） |
| $\alpha$ / $\beta$ | 第一类 / 第二类错误概率 | 常取 0.05 / 0.2 | $\alpha$ 是 $H_0$ 真时误拒，$\beta$ 是 $H_1$ 真时误受；功效等于 $1-\beta$，两者位置最容易被换 |
| 功效 | $H_1$ 真时正确拒绝的概率 | 0–1 | 功效依赖真实效应量与样本量；不说效应量只报功效没有信息量 |
| $p$ 值 | $H_0$ 成立时出现当前或更极端结果的概率 | 0–1 | 不是"$H_0$ 为真的概率"，也不度量效应大小；$p$ 小只能说"难用偶然搪塞过去" |
| 置信区间 | 随机区间，覆盖概率 $1-\alpha$ | 双侧或单侧要声明 | 95% 指反复抽样时约 95% 的区间盖住真值，不是真值有 95% 概率落在里面 |
| 标准误 $SE$ | 估计量的标准差 | 与样本标准差差 $\sqrt{n}$ | $SE=s/\sqrt{n}$；把 $s$ 直接叫标准误是最常见的口误 |
| 自由度 $df$ | 独立信息个数 | 正整数 | 单样本 $t$ 检验取 $n-1$；两样本方差不齐时用 Welch 近似，不再是 $n_1+n_2-2$ |
| $H_0$ / $H_1$ | 原假设 / 备择假设 | 单双侧必须写清 | $H_0$ 必须含等号，否则拒绝域无定义；把想证明的结论放进 $H_0$ 就永远证不出来 |
| 拒绝域 | $p<\alpha$ 时拒绝 $H_0$ | 与单双侧一致 | 单侧检验套双侧临界值，会让真实 $\alpha$ 翻倍 |
| 效应量 | 标准化后的差距，如 Cohen's $d$ | 无单位 | 显著不等于重要；$n$ 大时 0.1 个标准差的差距也能显著 |
| 多重比较 | 同一份数据做 $m$ 次检验 | 族错误率约 $1-(1-\alpha)^m$ | 做 20 次 0.05 检验，至少一次假阳性的概率约 64%；要么校正，要么预先注册比较计划 |
| $R^2$ / 调整 $R^2$ | 解释方差比例 / 按变量数惩罚 | $R^2$ 在 0–1，调整 $R^2$ 可降 | 加变量 $R^2$ 必不降，所以不能拿它比变量数不同的模型；比模型用调整 $R^2$ 或 AIC |
| 回归四条假设 | 线性、独立、同方差、正态 | 四条都针对误差项，不是自变量 | 正态只影响小样本检验，异方差才真正毁掉标准误；别去检验自变量是否正态 |
| 哑变量与基准组 | $k$ 个类别只需 $k-1$ 个哑变量 | 基准组效应并入截距 | 放满 $k$ 个会与截距完全共线；换基准组后所有系数都变而拟合不变 |
| 相关与因果 | $r$ 只度量线性关联 | $r$ 在 −1 到 1 | 相关为 0 不代表无关（可能落在非线性曲线上）；有相关更不能推因果 |
| $\lambda$ | 泊松过程的强度 | 单位时间事件数 | $\lambda$ 是速率，$\lambda t$ 才是期望个数；两者混用会让方差量纲直接错 |
| 抽样误差 / 非抽样误差 | 随机性偏差 / 系统性偏差 | 前者可估，后者不可估 | 加大样本只压抽样误差；抽样框漏掉的人，样本再大也补不回来 |
| 有限总体校正 | $\sqrt{(N-n)/(N-1)}$ | 不放回抽样才乘 | 有放回抽样不加这个因子；方差公式里漏乘会让区间偏宽 |
| 分层与整群 | 层内同质 / 群内异质 | 取决于抽样单元 | 分层要"层内相似、层间不同"，整群正好相反；写反了方差估计会比简单随机还差 |

## 6. 典型题型与解题套路

### 计算题（分布、期望、估计量、区间）
1. 先把随机变量定义清楚：谁是随机变量、取值域在哪、参数是什么，写成 $X\sim$ 某分布再动笔。
2. 判断方向：是"给定参数算概率"，还是"给定数据反推参数"。方向错了公式再熟也全错。
3. 先符号后数值，$\bar x$、$s$、$n$ 一路保留到最后一式，中间不四舍五入。
4. 算完做范围检查：概率落在 0 到 1、方差非负、区间包住点估计、标准误小于样本标准差。
**常见失分点**：样本方差除以 $n$ 而不是 $n-1$，或在求和的方差里漏掉协方差项。

### 推断题（检验、比较、显著性）
1. 先用一句话写清研究问题，再落成 $H_0$ 与 $H_1$，并声明单双侧与 $\alpha$。
2. 逐条核对前提：独立性、分布假设、方差是否齐；不满足就换 Welch 或秩检验，而不是硬算。
3. 选统计量，写出它在 $H_0$ 下的分布与自由度，再算统计量或直接算 $p$ 值。
4. 结论给三件套：$p$ 值、效应量、置信区间。只报"显著"会被判为结论不完整。
**常见失分点**：把 $p$ 值解释成"$H_0$ 为真的概率"，或用 $p$ 值大小代替效应量。

### 结果解释题（读回归表、读软件输出）
1. 先定位模型：因变量是什么、样本量多少、每个系数对应哪个变量、基准组是哪一类。
2. 逐列对账：系数、标准误、$t$ 值、$p$ 值要互相自洽，出现矛盾说明你读错了行或单位。
3. 用固定句式翻译系数："控制其他变量后，X 每增加 1 个单位，Y 平均变化 $b$ 个单位"，单位不能丢。
4. 再查模型质量：$R^2$ 与调整 $R^2$、残差图、共线性，指出哪条假设最可能不成立。
**常见失分点**：把回归系数直接说成因果效应，或忽略变量单位去比较系数大小。

### 调查/实验设计题
1. 先写目标总体与抽样框，明确"框里覆盖不到的人"会带来哪个方向的偏倚。
2. 选抽样方法并给理由：简单随机、分层、整群、系统，各自的方差与实施成本不同。
3. 定样本量：给出预期效应量、$\alpha$、功效，反解 $n$，再按无回答率放大。
4. 写实施与质量控制：问卷预试、访员培训、随机化分组、盲法，每条对应一种偏倚。
5. 最后补一句"这个设计能支持什么结论、不能支持什么"。
**常见失分点**：只写"随机抽样"却不写抽样框，或样本量与功效目标互不挂钩。

## 7. 常见误区

1. **把 95% 置信区间说成"参数有 95% 概率落在里面"** → 错在把参数当随机变量；应改成"反复抽样时约 95% 的区间会盖住真值"，并记住随样本变的是区间，不是参数。
2. **用 $p$ 值大小判断效应大小** → 错在 $p$ 值同时受效应量与样本量影响；应同时报效应量与置信区间，$n$ 大时 0.1 个标准差也能显著。
3. **不显著就说"没有影响"** → 错在把"没有证据"当成"证据表明没有"；应先看功效与区间宽度，功效不足时结论只能写"未发现"。
4. **不做诊断就解释回归系数** → 错在异方差会让标准误偏小、共线性会让系数符号翻转；应先看残差图与 VIF，再决定变换或删变量。
5. **拿多个模型的 $R^2$ 比高低，或反复换变量直到 $p$ 小于 0.05** → 错在 $R^2$ 随变量数单调不减、多次比较会抬高假阳性；应改用调整 $R^2$ 或 AIC，并做多重比较校正。
6. **把相关说成因果** → 错在忽略混杂变量与反向因果；应把措辞降级为"相关"，或明确写出用了哪种识别策略。

## 9. 交叉专业与后续方向

- **和数学的分界**：数学证"对任意分布都成立"的命题，统计只要求"在这组假设下推断是对的"，并额外关心假设破了偏差有多大。同一道题，数学问证明是否完整，统计问它对应哪条假设。
- **和经济学的分界**：经济学要求系数有结构解释（参数对应偏好或技术），统计只要求模型与推断正确。同一张回归表，经济学追问系数能不能当弹性，统计先问标准误算对了没有。
- **和计量经济学的分界**：计量把回归当因果识别工具，核心是内生性与识别策略；统计把回归当条件期望的估计，核心是假设与方差。所以计量会为识别牺牲精度，统计会为精度放弃结构解释。
- **和数据科学、机器学习的分界**：后者以样本外预测为目标，误差越小越好；统计要可解释的推断与不确定性，模型错了必须能说清错在哪条假设上。
- **和精算、生物统计的分界**：那两支是统计在特定行业的落地（寿险定价、临床试验），工具相同，但合规与数据来源的约束完全不同。
- **不把相关说成因果**：$r$ 或回归系数只说明"在这个模型里两者同向变动"。要谈因果，必须有随机化、自然实验或写明的识别假设；否则措辞只能是"相关"或"预测"，并在结论里点出可能的混杂变量。
- **后续方向**：应用统计专硕与统计学学硕、生物统计与临床试验、金融风控与精算、因果推断、市场与用户研究、质量与可靠性；进阶课程是多元统计、时间序列、贝叶斯统计、非参数统计。
