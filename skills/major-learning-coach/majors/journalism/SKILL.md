# 新闻学（journalism）

> 先读 `../../references/curriculum-rules.md`（难度与排序）与 `../../references/learning-card-template.md`（讲解结构）。
> 本文件只给这个专业的知识骨架与专业习惯。

## 1. 这个专业在训练什么

新闻学训练的是**在时限压力下把事实做成可发表结构**的本事，顺序永远是"先证实，再写作"：宁可少写一条，不写一条核不实的。

**一句话画像**：在时限内核实事实，并把事实组织成可发表的结构。

这行靠三件事吃饭：找得到人、问得出话、拿得准分寸（K02 采访、K01 判断、K04 边界）。写作是最后一公里，写不好前面全废；但只会写、不会核，是这行最危险的新人。

**最容易误解的一点**：以为"写得像新闻"就是新闻。决定一篇稿子能不能发的，是信源结构而不是句式；把通稿改写得再顺，也还是单信源。

外人的第二个误解是"客观=没有立场"。客观性是一套可检查的方法：引语逐字、事实与观点分离、给被批评方回应机会，而不是作者心里怎么想。

和汉语言文学的界线：中文对文本负责，问"这篇是怎么写成的"；新闻对事实与公共知情负责，问"这条能不能证实、该不该发"。

**最陡的三门课**：新闻评论（因为要在证据不完美时仍下一个可辩护的判断）、新闻采访（因为要在陌生人面前把不知道的事问出来）、媒介伦理与法规（因为同一个行为在伦理与法律两层结论常常不同）。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能在 90 分钟内就一场发布会写出 500 字消息，导语含 4 个 W，且每条事实都指得出信源。
2. 能为一个选题写出 12 问采访提纲，含 3 个开放式追问与 2 个文件核实点。
3. 能对一条传言完成交叉核实，交出"已证实/未证实/证伪"三栏结论，每栏附依据。
4. 能就一个公共议题写 800 字评论，含 1 个可被反驳的判断、2 条论据、1 段让步。
5. 能判定一篇稿件是否触碰隐私、名誉、版权三条红线，并给出不损害信息量的改法。
6. 能分别用议程设置、框架、沉默螺旋解释同一传播现象，并说明哪个解释力最强、为什么。
7. 能把 2000 字深度稿压成 300 字快讯，事实不丢、引语不失真。
8. 能对一篇转载稿完成授权与出处核查，写出可直接发布的转载说明。

## 5. 术语与符号约定

新闻学的"符号"是结构与分级：同一批事实，换个排列顺序就换了一种判断。

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| 新闻价值五要素 | 时效、接近、显著、重要、趣味 | 五个维度，不是五条及格线 | 把"显著"（名人、知名地）当"重要"（影响多少人），排序立刻失真 |
| 倒金字塔 | 按重要性递减排列，首段给最要紧的事实 | 消息的默认结构 | 它不是"按时间倒序"；最重要的事实常常不是最新的事实 |
| 消息 / 通讯 / 特写 | 消息快而短、第三人称；通讯有过程与场景；特写只放大一个切片 | 消息 300–800 字，通讯 1000–3000 字 | 把通讯写成消息的拉长版；特写一旦编细节就不是特写，是小说 |
| 信源分级 | 一级：当事人与原始文件；二级：机构通报与权威媒体；三级：转载与自媒体 | 三级 | 三级只能当线索不能当证据；两家转载同一篇稿，不算两个信源 |
| 交叉核实 | 至少两个相互独立的信源指向同一事实 | ≥2 个独立信源 | 同一人换身份说两次、同源转载，都不构成独立 |
| 客观性 / 平衡 | 客观性是方法（可核实、事实与观点分离）；平衡是给各方回应机会 | — | 平衡不是五五开，不是给无证据的主张与有证据的主张同等篇幅 |
| 匿名信源 | 仅在信息重大、无法具名、且已交叉核实时使用 | 最后手段 | 匿名不能用来放人身攻击；须向编辑披露身份、向读者说明为何匿名 |
| 议程设置 | 媒介通过突出某些议题影响公众"想什么" | 议题显著性转移 | 它解释不了"怎么想"；拿它解释态度变化就是套错理论 |
| 框架 | 通过选择、强调、排除给事件划定解释边界 | 影响"怎么想" | 框架不等于立场，同一框架下可以得出相反结论 |
| 沉默螺旋 | 感知意见气候后，少数意见趋于沉默 | 影响"敢不敢说" | 需同时具备"气候可感知"与"孤立恐惧"，缺一条就不成立 |
| 5W1H / 六要素 | who、what、when、where、why、how | 六要素 | 消息最常缺 why；how 不是过程细节的堆砌 |
| 导语（硬/软） | 硬导语直给最要紧事实；软导语用场景或悬念切入 | 消息首段 | 软导语也得在第一段让人知道发生了什么，不能只写画面 |
| 消息头（电头） | 本报讯、据新华社、记者某某发自某地 | 稿头固定格式 | 没到现场不能写"发自"；转载不能把来源改成"本报讯" |
| 由头 | 为什么现在报道这件事 | 时间锚点 | 无由头会被判旧闻；由头要真，不能拿"近日"顶替具体日期 |
| 新闻敏感 | 从日常信息里识别新闻的能力 | — | 不等于"觉得有意思"；判据是五要素里至少一条明确成立 |
| 直接引语 / 间接引语 | 原话照录 / 转述大意 | 引号内必须逐字 | 间接引语加引号是最常见的编造；口语病句也不能顺手改完仍算原话 |
| 事实与观点分离 | 消息只陈述可核实事实，判断归评论 | 文体分工 | "专家指出这很危险"要先分清：这是事实陈述还是判断 |
| 把关人 | 编辑对稿件做取舍与核实的角色 | 流程节点 | 把关不是改错别字，是把不该发的挡下来 |
| 拟态环境 | 媒介呈现的是被选择过的环境，不是现实本身 | 李普曼提出 | 别把它当成"媒体造假"，它是结构性偏差，不是主观恶意 |
| 使用与满足 | 受众主动选择媒介以满足自身需求 | 受众视角 | 与"媒介很强"的效果传统相反，同一题里别混用 |
| 意见领袖 / 两级传播 | 信息经意见领袖再流向普通受众 | 两级 | 平台时代层级可被跳过，但"中间人可信度"仍在起作用 |
| 版权与转载授权 | 时事新闻本身不受著作权保护，转载仍须注明出处；评论、图片、深度稿受保护 | — | "注明出处"不等于"获得授权"；图片与图表最常出事 |
| 合理使用 | 为介绍、评论、说明问题而适当引用 | 范围有限 | 引用不能替代原作；整段搬运不叫合理使用，叫侵权 |
| 名誉权三要件 | 有侮辱诽谤内容、已公开传播、造成社会评价降低 | 民事侵权 | 内容真实也可能侵权（措辞侮辱）；"基本属实"不是免责 |
| 更正与答辩权 | 出错后更正，被批评方有答辩机会 | 事后救济 | 更正不是删稿了事，须在原位置可被看到 |
| 脱敏 | 隐去可识别个人身份的信息 | 姓名、住址、单位、面部、声音 | 化名要前后一致并声明；马赛克打一半等于没打 |

## 6. 典型题型与解题套路

### 消息写作题（给一段材料，写 400–600 字消息）
1. 先通读材料，用一句话写出"发生了什么"，再圈出谁受影响、影响到什么程度。
2. 按新闻价值排序，挑 1 条放首段；首段写清 4 个 W 加信源，背景一律挪后。
3. 第二段起按重要性递减，一段一个事实块，每段不超过 3 句。
4. 把形容词与判断句删掉，改成可核实表述："3 人受伤"而不是"伤亡严重"。
5. 交稿前逐条给事实标信源，标不出的删掉或补采，不留"听说"。
**常见失分点**：首段写成会议流程或领导讲话；把通稿原句抄进导语，等于没核实。

### 采访提纲设计题（给一个选题或人物，设计 10–15 问）
1. 先写"我要拿到哪 3 个事实、哪 2 句引语"，提纲围绕这几件事，不围绕话题清单。
2. 分三段：破冰与背景（封闭问）—核心事实（开放问）—追问与对质（带证据的问）。
3. 每个核心问题后预设 2 个追问，例如"具体是哪一天""当时还有谁在场"。
4. 标出 2 个文件核实点（通报、合同、判决书），采访不能只靠一张嘴。
5. 逐条检查诱导性提问（"你是不是也觉得他不对"），改成中性问法再定稿。
**常见失分点**：提纲全是"你怎么看"；把问题写成观点陈述；没有对质环节，对方一说"记不清"就断了。

### 新闻评论题（给一则新闻，写 800 字评论）
1. 先写一句可被反驳的中心判断，例如"问题不在标准高低，而在没有申诉渠道"，不写"值得深思"。
2. 给 2 条论据，一条事实、一条机制或横向对比；每条论据后跟一句"所以"。
3. 加一段让步：承认对方最强的反驳，再说明它为什么不推翻你的判断。
4. 落一个可操作的主张（谁、做什么、多久），不落"希望有关部门重视"。
5. 通读删掉纯情绪词（"荒唐""令人愤怒"），保留能指向事实的形容词。
**常见失分点**：通篇有立场没论证；把评论写成消息复述加感想；只批评不给方案。

### 传播现象分析题（给一个热点，用理论解释）
1. 先写清现象的可观察指标（热搜位次、评论情绪分布、转发路径），没有指标就没有分析。
2. 选一个理论做主轴，先写它的成立条件，再逐条对照案例；对不上的地方要认。
3. 用第二个理论做补充或竞争解释，指出两者在哪个环节分歧。
4. 指出解释边界（样本、平台、时间窗），给一个可验证的预测。
5. 结论回到"所以报道该怎么做"，让理论落到业务动作上。
**常见失分点**：三个理论各写一段谁也没解释清楚；用议程设置解释态度变化（那该用框架）；案例与理论条件对不上还硬套。

## 7. 常见误区

1. **一上来就写导语** → 错在没先排事实的重要性；先把材料拆成事实卡片按五要素排序，再写首段。
2. **把通稿当核实** → 错在把"有人说过"当成"事情如此"；关键事实找第二独立信源，找不到就在稿中注明"仅单一信源"。
3. **匿名信源用来放狠话** → 错在保护了说话人却没有可核实内容；匿名只用于重大且可交叉核实的信息，攻击性表述必须具名或删除。
4. **平衡报道=各打五十大板** → 错在把证据强度不同的一方等量并列；平衡是给回应机会，不是给错误主张同等版面。
5. **直接引语"整理"得太顺** → 错在把转述当原话；引号内逐字照录，需要顺句就改成间接引语并去掉引号。
6. **图片图表随手拿来用** → 错在只注明出处没取得授权；转载前确认授权状态，自制图表标明数据来源与统计口径。
7. **三个效果理论混着用** → 错在没区分"想什么/怎么想/敢不敢说"；先定被解释的行为，再选理论。
8. **出错后删稿了事** → 错在没留下更正记录；在原位置发更正说明错在哪，并给被误伤一方答辩机会。

## 9. 交叉专业与后续方向

- **和广告学的区别**：新闻对事实负责，广告对效果负责。同一套文案技巧，伦理约束正好相反——新闻不许有偿，广告的付费版位就是它的商业模式；写了"新闻式软文"两边都不认。
- **和汉语言文学的区别**：中文对文本负责，追求解释的深度与自洽；新闻对公共知情负责，追求核实的密度与时限内的可发布性。同一事件，中文问"叙述如何造出这个印象"，新闻问"这条事实有几个独立信源"。
- **和传播学的区别**：传播学解释效果与机制，回答"为什么有效"；新闻学做采集与发布，回答"该怎么报"。做传播现象分析题时，理论是工具，落点仍要回到报道动作。
- **和法学的区别**：法学给事后归责与构成要件，新闻学在发布前做风险预判；同一篇稿，法学问"够不够成侵权"，新闻问"能不能通过脱敏与补采避开"。
- **写这类内容的硬底线**：不编造引语、不虚构采访对象、不替真实人物编造身份与对白；涉及真实人物一律脱敏，化名前后一致并在文中声明，可识别细节（单位、住址、罕见病、具体日期）一并处理掉。
- **后续方向**：考研走新闻学、传播学或新闻与传播专硕（MJC）；岗位有记者、编辑、事实核查、政务与品牌传播、内容运营；进阶课程为数据新闻、国际传播、视听传播、媒介经营管理。
