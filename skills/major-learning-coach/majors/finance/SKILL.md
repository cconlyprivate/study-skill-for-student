# 金融学（finance）

> 使用前先读 `../../references/curriculum-rules.md`（难度与排序规则）与
> `../../references/learning-card-template.md`（讲解结构）。
> 本文件只提供"这个专业的知识骨架与专业习惯"，不要在这里重复通用协议。

## 1. 这个专业在训练什么

把未来不确定的一串现金流，折成今天的**一个数**；再给这份不确定性**标价**（风险溢价）；最后用这两个结果解释市场为什么这样反应。

它和"炒股、看 K 线、猜涨跌"不是一回事。核心是三件工具：**折现**（钱有时间价值）、**无套利**（未来一样的两样东西今天必须同价）、**风险补偿**（承担波动要拿到溢价）。这三件工具推出来的结论经常与直觉相反，这正是它值得学的地方。

**最容易误解的一点**：以为金融学是"预测价格"。它做的是"在给定假设下算出价格，并说清假设错了会错多少"。说不出关键假设的估值不是估值，是猜。

**最陡的三门课**：金融工程（要先建立"无套利"的直觉，再动公式）、计量经济学（从算指标变成判断识别策略）、公司金融（增量现金流、税盾、营运资本，每一处都能错）。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能把一笔投资写成时间轴上的现金流，选对折现率并算出价值，同时说出 3 个关键假设。
2. 能算出债券的久期与凸性，并据此说出收益率上行 50bp 时价格大致变动多少。
3. 能用 DCF 与相对估值各给同一家公司估一次价，并解释两者差异来自哪三个假设。
4. 能估计 β、算出要求回报率，并判断一个项目是否真的在创造价值。
5. 能用看涨看跌平价校验一组期权报价，指出哪一边存在可执行的套利。
6. 能读懂三张报表的勾稽关系，并用杜邦分解定位两家公司 ROE 差异的来源。
7. 能对一则市场新闻（加息、汇率贬值、信用利差走阔）给出"价格往哪边动、为什么、幅度多大"的机制解释。
8. 能对一段策略收益做归因，区分"承担了更多风险"与"真的有能力"。

## 5. 术语与符号约定

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| `r` | 折现用的利率 | 通常按年报价 | 题目写"12%，按月计息"时先问清 12% 是 APR 还是 1% 的月利率 |
| APR | 名义年利率，按期数单利摊 | 报价习惯 | 月利率 1% 的 APR 写 12%，但一年真实增长是 12.68% |
| EAR | 有效年利率，$(1+\mathrm{APR}/m)^m-1$ | 与 APR 同口径才可比 | 比两个产品先都换成 EAR，APR 不能直接比 |
| 期间利率 | 一期（月/季/半年）的利率 | 与期数 $m$ 对应 | 单利摊才除以 $m$；复利下要先换成 EAR 再开 $m$ 次方 |
| 贴现因子 | $1/(1+r)^t$ | 大于 0 且不超过 1 | $t$ 的单位必须是年，手里是月数先除 12 |
| 单利 / 复利 | 利息是否再生息 | — | 单利终值 $P(1+rt)$，复利 $P(1+r)^t$，三年以上差距不能忽略 |
| YTM | 使全部现金流现值等于价格的折现率 | 年化 | 年化口径有两种（年复利/半年复利），报出来的数会差一点 |
| 当期收益率 | 年息票除以价格 | % | 不等于 YTM；折价债券的 YTM 高于当期收益率 |
| 久期 $D$ | 现金流现值的加权平均到期时间 | 年 | 修正久期 $=D/(1+y/m)$，漏掉除数是最高频错误 |
| 凸性 $C$ | 价格对收益率的二阶敏感度 | 年² | $\Delta P/P\approx -D_{mod}\Delta y+\tfrac12 C(\Delta y)^2$，第二项别丢 |
| bp | 基点，万分之一 | 1bp = 0.01% | 50bp 代入公式要写 0.005，不是 0.5 |
| 收益率 vs 回报率 | 前者是买入时锁定的口径，后者是实际拿到的 | % | 持有期回报 = 票息 + 价格变化；利率上行时债券回报可以是负的 |
| 实际 / 名义利率 | 是否剔除通胀 | % | 精确式 $(1+r)=(1+i)(1+\pi)$，近似式 $r\approx i-\pi$ 在高通胀时偏差大 |
| `β` | 个股对市场组合的敏感度 | 无量纲，市场为 1 | 回归要用超额收益对超额收益，别用价格对指数 |
| `r_f` | 无风险利率 | % | 期限要与现金流期限匹配，题目里常见 1 年期国债 |
| `r_m - r_f` | 市场风险溢价 | % | 是预期溢价，不是过去十年的平均涨幅 |
| `α` | 实际收益减 CAPM 要求回报 | % | 回归的 α 不显著时不能说"有能力" |
| 年化波动率 | 期波动率乘 $\sqrt{\text{每年期数}}$ | % | 月度乘 $\sqrt{12}$、日度乘 $\sqrt{252}$，两者别互换 |
| 看涨看跌平价 | $C-P=S-K/(1+r)^T$ | 同执行价、同到期日 | 忘记折现 $K$ 或漏掉分红，套利方向就写反 |
| 远期价格 | $F=S(1+r)^T-\text{分红现值}$ | 货币单位 | 有分红或便利收益时必须减项，不能直接乘 $(1+r)^T$ |
| 基差 | 现货价减期货价 | 货币单位 | 展期收益的方向由期限结构决定，与基差不是一回事 |
| FCFF / FCFE | 企业自由现金流 / 股东自由现金流 | 货币单位 | FCFF 配 WACC，FCFE 配股权成本，折现率必须与现金流口径配对 |
| WACC | 加权平均资本成本 | % | 权重用市值不用账面值；税后债务成本是 $r_d(1-T)$ |
| `t` / `T` | 现金流时点 / 到期期限 | 年 | 期初投资记 $t=0$ 且不折现，第一期现金流记 $t=1$ |
| 百分比变化 | 变化率的分母是原值 | — | "从 4% 到 5%" 是 100bp，也是 25% 的相对变化，两种说法别混 |

**最容易搞混的一件事**：年化与期间。看到"年利率 6%，按季付息"，就要立刻分成两个数：期间利率 $6\%/4=1.5\%$，期数 $4T$；若题目要的是有效年利率，还得算 $(1.015)^4-1=6.14\%$。凡是折现，先确认"利率和期数是不是同一频率"，这一条能挡掉本专业一半的计算错误。

## 6. 典型题型与解题套路

### 估值计算题（债券、股票、项目）
1. 先画时间轴，把每笔现金流标在 $t=0,1,\dots,T$ 上；期初支出永远在 $t=0$，不折现。
2. 判断现金流是"已确定的"（债券票息）还是"要预测的"（FCF、股利）；后者必须显式写出 3 个关键假设。
3. 选折现率：名义配名义、税后配税后、FCFF 配 WACC、FCFE 配股权成本。
4. 先写符号公式再代数，中间不四舍五入；算完做量级检查（债券价格应围绕面值，股价不该为负）。
5. 结论带区间与敏感性：关键假设各动 1% 时，估值变多少。
**常见失分点**：折现率与现金流口径不配对，最典型是用税后 WACC 去折税前现金流。

### 风险与收益计算题（β、波动率、久期、VaR）
1. 先确认数据频率与年化方式：月度乘 $\sqrt{12}$、日度乘 $\sqrt{252}$，全题统一。
2. 收益率用简单还是对数，全题统一；组合收益是加权平均，组合方差不是。
3. 写清公式再代数：$\beta=\mathrm{Cov}(r_i,r_m)/\mathrm{Var}(r_m)$，久期是现值权重加权的时间。
4. 结果做边界检查：相关系数落在 $[-1,1]$、权重和为 1、VaR 随置信度上升而变大。
**常见失分点**：把组合方差写成两只资产方差的加权平均，整项漏掉协方差。

### 市场现象解释题（加息、汇率、信用利差）
1. 先用一句话定位"哪个价格在动"：利率、汇率、股价、还是信用利差。
2. 再写传导链：政策利率 → 短端 → 长端 → 折现率 → 资产价格，每一环注明是预期还是已实现。
3. 用定价公式反推方向与幅度：$P=\sum_t C_t/(1+y)^t$，$y$ 上升则 $P$ 下降，幅度由久期决定。
4. 给一个可被证伪的伴随观察：如果解释成立，还应该同时看到什么（期限利差、成交量、信用利差）。
**常见失分点**：只给"利好/利空"的判断，没有传导链，也没有幅度概念。

### 案例分析 / 论述题（这家公司该不该投、该怎么融资）
1. 先写清决策问题与约束：投什么、多久、钱从哪来、谁承担下行。
2. 拆成三块：值多少（估值）、风险多大（情景与敏感性）、怎么融资（资本结构）。
3. 每个结论后面挂一个数字或一条可比证据，不要只堆形容词。
4. 主动写反面：最可能让这个结论错的那一个假设是什么。
**常见失分点**：通篇定性描述，没有一处落到具体数字或可检验的假设上。

## 7. 常见误区

1. **把 APR 当成年折现率直接按年折** → 错在没换频率；应先折成期间利率或先换成 EAR，再动贴现因子。
2. **NPV 为正就说项目好** → 错在折现率没和项目风险匹配；应换用同类项目的资本成本，并给出情景区间。
3. **用可比公司 PE 中位数直接当目标价** → 错在没对齐口径与成长性；应先统一扣非口径与 EV 口径，再用 2–3 个倍数给区间。
4. **把久期当成到期时间** → 错在只有零息债券两者才相等；付息债券的 Macaulay 久期必定小于到期时间，修正久期还要再除 $(1+y/m)$。
5. **回归出一个 β 就直接用** → 错在把点估计当结论；应给出置信区间，并说明窗口期与数据频率会改变 β。
6. **用过去三年涨得好来预测未来收益** → 错在把实现收益当成预期收益；应回到"承担了什么风险、拿到了什么溢价"。

## 9. 交叉专业与后续方向

- **和经济学（economics）的区别**：经济学问"人为什么这样选"，金融学问"这个选择在市场上值多少钱"。同一则加息新闻，经济学讲总需求，金融学讲折现率与久期。
- **和会计学（accounting）的区别**：会计负责把业务记成可核对的报表，金融负责把这些报表折成一个价值数字。会计问"记对了吗"，金融问"值多少"。
- **和统计学（statistics）的区别**：统计提供估计与不确定性的工具，金融负责判断哪个参数有经济含义、哪个相关不该读成因果。
- **后续方向**：金融学硕士/金融专硕、量化与固收方向；买方的行业研究与组合管理、卖方的研究与投行、风险管理与合规、金融科技；进阶课程有固定收益、衍生品定价、资产配置、公司治理。
- **一句边界**：本文件只讲方法与原理，不构成投资建议。
