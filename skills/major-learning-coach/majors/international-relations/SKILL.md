# 国际政治（international-relations）

> 先读 `../../references/curriculum-rules.md`（难度与排序）与 `../../references/learning-card-template.md`（讲解结构）。
> 本文件只给这个专业的知识骨架与专业习惯。

## 1. 这个专业在训练什么

国关靠回答一个条件句吃饭：**在什么结构、什么制度、什么观念下，国家间更可能合作；在什么条件下，冲突会被放大**。它不给"哪年哪月会打仗"的预言，只给可被反例推翻的条件命题。

核心动作只有三步：**定层次**（这件事的解释落在个人、国家还是体系）→ **给竞争性解释**（现实、自由、建构三支各自预期什么）→ **用案例与反例检验**（哪一支的预期被观察到了）。

它和政治学的分界在于解释项的层级：政治学在单元内部问"权力怎么配置"，国关把国家当单元、把体系当解释项。它和历史学的分界在于目标：历史学还原"发生了什么"，国关要解释"为什么在类似条件下反复发生"，所以必须给机制与反例。

**最容易误解的一点**：以为国关 = 背时事 + 表态度。时事只是题干，采分点是你能不能说出"这个结果在哪支理论下是意外的、在哪支理论下是必然的"——把事件翻译成可检验的推论，才是专业动作。

**最陡的三门课**：国际政治理论（三支范式共用一套词汇但假设相反，必须用同一案例横着比才能立住）、国际安全（安全困境与威慑模型给出的政策处方正好相反，写反方向整段作废）、国际关系史（史实密度最高，一个年份记错会连带整段论证失去可信度）。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能对一个给定事件写出个人、国家、体系三个层次的解释各一条，并指明哪一层是主解释、为什么。
2. 能用三支范式对同一现象给出竞争性预期，并指出它们在什么观察上会分道扬镳。
3. 能从一段史料或新闻中提取"行为体—利益—约束—结果"四要素，写成 300 字的归因链。
4. 能对一个军备互动或同盟承诺，画出安全困境或威慑的因果图，并标出经验上可观察的环节。
5. 能对一项对外政策写出支持与反对各两条理由，并说明"什么证据会让我改变结论"。
6. 能比较同盟与集体安全、均势与霸权稳定，各自说出成立条件与一个失效场景。
7. 能在引用史实时标明证据层级（条约原文、档案、回忆录、二手研究），不把推论写成事实。

## 5. 术语与符号约定

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| 现实主义 / 自由主义 / 建构主义 | 关键变量分别是权力分布、制度、观念 | 三支范式 | 差异在核心假设的变量，不在"悲观/乐观"；写成态度差别是最常见的跑偏 |
| 无政府状态（anarchy） | 国家之上没有共同的权威 | 体系层次属性 | 写成"没有秩序"是头号硬错：无政府说的是缺上级，不是缺规则 |
| 无政府的三副面孔 | 霍布斯式、洛克式、康德式 | 建构主义的划分 | 三支范式对无政府的定性不同，当成同一常量比较必然写崩 |
| 身份 / 利益（identity / interest） | 身份界定利益 | 建构主义的核心命题 | 现实与自由把利益当给定，建构认为利益被观念构造；两类前提混用即自相矛盾 |
| 体系 / 单元（structure / unit） | 力量分布与互动结构 / 国家等行为体 | 两个分析层次 | 用单元属性解释体系结果、或用结构解释个人决定，都叫层次谬误 |
| 极（polarity） | 体系内主要力量中心的数目 | 单极、两极、多极 | 按能力分布数，不按同盟数；把盟友算成"极"是常见错 |
| 结构 / 进程（structure / process） | 力量分布 / 互动、制度与规范 | 沃尔兹的两分 | 制度与规范属"进程"，塞进"结构"会与体系层次混为一谈 |
| 均势（balance of power） | 力量大致均衡的状态，或维持均衡的政策 | 状态义 / 政策义 | 两义混用会自相矛盾：当政策用的词不能同时又当结果来解释 |
| 制衡 / 追随 / 推卸 | 面对威胁的三种回应 | — | 追随不等于结盟；推卸是让别人去制衡，不反应不是推卸 |
| 安全困境（security dilemma） | 一方增力自保，被他方读作威胁，形成螺旋 | 需意图不可知 + 进攻占优 | 把任何军备增长都叫安全困境；只缺"意图不确定"这一条就不成立 |
| 螺旋模型 / 威慑模型 | 怕对方进攻而强硬 / 怕对方退让而强硬 | 两种相反的政策处方 | 两者对同一事件给出相反的"该硬还是该让"，方向写反整段作废 |
| 相对收益 / 绝对收益 | 关心双方差距 / 只关心自己拿多少 | — | 说"合作必然因绝对收益"漏了相对收益顾虑；两者可同时起作用 |
| 敏感度 / 脆弱性 | 变化传入多快多贵 / 改结构要付多少代价 | 相互依存的两个维度 | 相互依存不是"越深越和平"；它同时是权力来源，方向写反就全错 |
| 层次分析（个人/国家/体系） | 解释变量落在哪一层的三档框架 | 个人、国家、国际体系 | 三层各写一段却不指定主解释，等于没有归因 |
| 主权（sovereignty） | 对内最高、对外独立 | 法理地位，不是能力 | 主权平等是法理平等，不等于能力平等；当实力用是硬错 |
| 干涉（intervention） | 从外部以强制手段介入他国管辖事项 | 与斡旋、援助区分 | 斡旋、调停、援助不构成干涉；说"任何批评都是干涉"就丢了边界 |
| 集体安全 / 同盟 | 对全体成员的侵略共同应对 / 针对特定外部威胁 | 承诺对象不同 | 集体安全承诺普遍且近于自动，同盟特定且可选；混用会判错案例 |
| 威慑（deterrence）三要件 | 能力、决心、沟通 | 缺一不成威慑 | 只写"有核武器所以威慑成功"；决心与可信信号同样是要件 |
| 安全化（securitization） | 把议题从常规政治提升为生存威胁 | 言语行为 + 受众接受 | 单方宣布"这是安全问题"不算成功，须受众接受才成立 |
| 双层次博弈 / 赢集（win-set） | 国内批准约束下的国际谈判 | 赢集越大越易达成协议 | "国内约束越强越强硬"是直觉错；赢集过小反而谈不成 |
| BATNA | 谈不成时的最佳替代方案 | 决定底线 | 底线不是开价；把开价当 BATNA 会算错让步空间 |
| 现状国 / 修正国 | 满足于现有秩序 / 想改变秩序 | 意图分类，非能力分类 | 修正国不等于崛起国；由实力增长直接推意图是跳步 |
| 修昔底德陷阱 | "守成—崛起"必然冲突的强命题 | 经验假说，不是定律 | 它是待检验命题，不能当史实引用；举例须同时给反例 |
| 霸权稳定论 | 霸权国供给公共品，秩序才稳定 | 国际政治经济学 | 相关不等于因果：霸权衰落与秩序动荡常同现，须排除其他解释 |
| 实证 / 规范 | 解释"是什么" / 论证"应如何" | 两类不同问题 | 用"应该"反驳事实命题（或反之）是无效反驳，政策题要先分栏 |
| 证伪 / 事后解释 | 可被反例推翻 / 事后编故事 | — | 能解释任何结果的理论等于没解释；答案要写出什么观察能推翻它 |
| 案例选择偏差 | 只挑符合理论的案例 | — | 只拿"合作成功"验证制度主义就是抽样偏差；要补反例或选最不利案例 |

## 6. 典型题型与解题套路

### 理论解释题（指定一支范式，解释一个给定现象）
1. 先把理论的核心假设写成 2–3 句（无政府、单元、关键变量），**只写假设，不写结论**。
2. 从假设推一个可观察预期："若该理论对，应看到 X 而不是 Y"。这一步是主要采分点。
3. 把现象拆成结构条件、互动过程、结果三段，逐段对应到预期上，说明哪段吻合、哪段不吻合。
4. 补一句竞争性解释：另一支范式会怎么讲，你的证据为什么更支持前者。
5. 收口写边界：这个解释在什么条件下会失效。
**常见失分点**：只复述理论不推预期，读起来像教材摘抄，采分点一个没踩到。

### 案例归因题（给一段事件，问"为什么"）
1. 先做**事实与推论分栏**：左栏只写能由史料支持的事实，右栏写推断，两栏不许混。
2. 定层次：主解释落在体系（力量分布）、国家（国内政治与决策）还是个人（决策者认知）。
3. 用**反事实**检验：如果抽掉那个因素，结果会不会不同（"若没有 A，还会不会有 B"）。
4. 排除替代解释：至少写一个竞争性原因，并说明为什么它解释力不够。
5. 结论标注置信度与适用条件，不要写成"证明了"。
**常见失分点**：把相关性当因果（"两国贸易多所以没打仗"），全程不设反事实。

### 政策分析题（"你建议怎么做"）
1. 先写目标与约束：要达成什么、不能付出什么（成本、法理、同盟信誉）。
2. 列至少三个选项（必须含"不作为"），每个写收益、代价、可逆性。
3. 用理论做预期：该选项在威慑、制度、国内政治三条线上分别会引发什么反应。
4. 选定一个并给执行细节：谁来做、用什么工具（外交、经济、军事）、怎样验证有效。
5. 写退出与止损条件：出现什么信号就调整。
**常见失分点**：只给立场不给选项，或选项不写代价，等于没做分析。

### 论述题（理论与案例结合，自拟论点）
1. 开头三行内给定**可被反驳的论点句**，不要用"随着全球化的发展"铺垫。
2. 用"理论—案例—反例—回应"四段，理论与案例一一对应，不堆互不相关的例子。
3. 案例只写机制：行为体、约束、结果，不写故事。
4. 主动写一个反例并回应：它在什么条件下成立、为什么不推翻你的论点。
5. 结尾交代适用边界，史实标注证据层级。
**常见失分点**：案例讲三段、机制一句没有；或把"修昔底德陷阱"这类假说当史实引用。

## 7. 常见误区

1. **把无政府当成混乱** → 错在把"没有上级权威"读成"没有规则"；应先写出无政府下仍存在的规则（主权、互惠、条约），再解释冲突为何仍可能。
2. **用范式贴标签而不推推论** → 错在只写"这是现实主义解释"；应写成"若现实主义对，应观察到 X；若自由主义对，应观察到 Y"，让证据来选。
3. **三个层次各写一段就算归因** → 错在没有权重；应指定一层为主解释，另两层作为条件或干扰项，并说明凭什么这样排。
4. **把相互依存当和平保证** → 错在漏了敏感性与脆弱性的不对称；应说明谁更脆弱、谁因此握有施压筹码。
5. **把威慑失败归因于"实力不够"** → 错在漏了决心与信号可信度；应分别检查能力、决心、沟通三要件，指出断在哪一环。
6. **史实凭印象写** → 错在把"大概 1945 年前后"写进答案；只写能确认的事件与条约名称，年份记不准就用"20 世纪 40 年代中后期"这种可辩护表述。

## 9. 交叉专业与后续方向

- **和政治学与行政学的区别**：政治学在国家内部问"权力怎么配置、制度怎么影响行为"；国关把国家当单元，把体系（力量分布、制度、观念）当解释项。同一场危机，政治学看国内联盟与决策过程，国关看体系压力与信号传递。
- **和国际经济与贸易的区别**：国贸问"跨国交换的收益从哪来、关税与汇率怎么算"，落点在效率与核算；国关问"同样的贸易为什么会被安全化、国内谁在反对、制度能否约束强权"，落点在条件与权力。一句话：国贸算得失，国关问条件。
- **和历史学的区别**：历史学要还原"发生了什么"，国关要解释"为什么在类似条件下反复发生"，因此必须给机制、给反例、给适用边界。
- **后续方向**：国际关系理论、比较政治、区域国别研究的学硕；外交学与国际安全方向；岗位包括政策研究、涉外事务、国际组织与智库、媒体国际报道。
- **一条硬规矩**：史实以权威史料与条约原文为准，不编造事件细节。年份、人名、条款记不准时，写"20 世纪 40 年代中后期"这类可辩护的表述，不要为了好看编一个假精确的日期。
