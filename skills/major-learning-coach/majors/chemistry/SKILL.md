# 化学（chemistry）

> 先读 `../../references/curriculum-rules.md`（难度与排序）与 `../../references/learning-card-template.md`（讲解结构）。
> 本文件只给这个专业的知识骨架与专业习惯。

## 1. 这个专业在训练什么

化学的人靠两件事吃饭：**从结构推性质**、**从机理推产物**。给一个分子式或一张谱图，要能还原出结构；给一组反应物和条件，要能说出电子往哪走、主产物是什么、为什么不是另一个。

外人常以为化学是"背反应式 + 做实验"。实际上反应式是推导的结论，实验是用来证伪结论的。真正拉开差距的是 K02（结构）与 K06（物理化学）：前者决定你看不看得懂"这个键为什么容易断"，后者决定你判不判断得出"这个反应在给定温度下到底走不走"。

**最容易误解的一点**：以为化学是记忆学科。它是在少数几条原理（电负性、轨道重叠、守恒、自由能）上做大量推理，记不住的是结论，推得出来的是能力。

**最陡的三门课**：物理化学（因为要把化学问题翻译成状态函数与偏导，一个符号错到底）、结构化学（因为要用对称性描述轨道，抽象层突然拔高）、有机化学（因为反应数量大，不建机理框架就只能是死记）。

## 3. 能力目标（毕业时能做的可检验的事）

1. 拿到一个分子式，能先算不饱和度圈定骨架范围，再用谱图确定具体结构。
2. 能画出反应机理的弯箭头图，并逐步说明电子流向与电荷守恒。
3. 能对一个陌生反应判断机理类型，并预测主产物与立体化学。
4. 能在热力学与动力学两套语言间切换，分别回答"能不能反应"与"反应多快"。
5. 能独立完成一次滴定，给出含量结果、误差来源与不确定度。
6. 能读 IR、NMR、MS 并写出含"被排除候选"的结构解析报告。
7. 能设计含空白、平行、加标回收的分析方案，并说明干扰如何消除。

## 5. 术语与符号约定

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| `n` 物质的量 | 粒子数除以阿伏加德罗常数 | mol | 只用于粒子计数；`n(H2O)` 与 `n(H)` 差两倍，别互代 |
| `c` 摩尔浓度 | 溶质物质的量除以**溶液**体积 | mol/L | 分母是溶液体积不是溶剂体积；换算 `c = 1000ρw/M` 时 ρ 用 g/cm³ |
| `w` 质量分数 | 溶质质量除以溶液质量 | 无量纲，常写 % | 与 `c` 差一个密度；仅稀溶液可近似 `c ≈ 1000ρw/M` |
| 有效数字 | 只保留一位可疑数字 | — | 加减看小数位、乘除看有效位数；pH 只取小数部分；中间量多留一位 |
| `ΔH` | 焓变，常压下的反应热 | kJ/mol | 放热为负；写"ΔH 为负"而不是"放出负值"；注明是哪种焓 |
| `ΔG`、`ΔG°` | Gibbs 自由能变、标准态下的值 | kJ/mol | 判自发只看实际 ΔG；ΔG° 只管标准态，不能直接判非标准态方向 |
| `ΔS` | 熵变 | J/(mol·K) | 单位是 J 不是 kJ，与 ΔH 相加前必须换算 |
| 标准态 | p° = 100 kPa，溶质常取 1 mol/L | — | 老教材用 1 atm；标准态不等于"常温常压"，温度要另写 |
| `K` 与 `Q` | 平衡常数、反应商 | 无量纲（相对活度） | Q 小于 K 时正向；K 只随温度变、Q 随浓度变；纯固体纯液体不进表达式 |
| `Ka`、`pKa` | 酸解离常数及其负对数 | pKa 无量纲 | pKa 越小酸性越强；共轭酸碱对的 pKa 之和为 14（水，25 ℃） |
| 氧化数 与 电荷 | 形式电子转移数、真实电荷 | — | Fe³⁺ 的氧化数 +3 与电荷 +3 数值同而概念不同；配离子要按整体加和 |
| `E°` 电极电势 | IUPAC 约定的还原电势 | V | 半反应统一写还原式；电动势等于正极减负极，符号别反 |
| 活度 `a` 与浓度 | 有效浓度 | 无量纲 | 高离子强度下必须用活度；近似 `a ≈ c` 要写明条件 |
| 弯箭头 | 从电子丰富处指向电子缺乏处 | — | 起点必须是键或孤对电子而非原子；一个箭头最多移动两个电子 |
| 共振式 | 同一物种的电子分布写法 | — | 只动电子不动原子骨架；用双箭头 ↔，不是平衡箭头 ⇌ |
| 杂化 | 原子轨道的线性组合模型 | sp、sp²、sp³ | 杂化是模型不是事实；先定几何再定杂化，别反过来推 |
| 轨道对称性 | 相位（+/−）与对称元素 | — | 相位不是电荷；节面数对应反键级；同号重叠才成键 |
| `R/S`、`E/Z` | 手性碳与双键的构型 | — | 优先级按原子序数逐层比较；最小基团在横键时 R/S 要取反 |
| `ee`、`dr` | 对映过量、非对映比 | % / 比值 | ee 用两对映体百分数之差；dr 写比值不写百分数 |
| 产率、转化率、选择性 | 实得比理论、已反应比投料、目标产物占比 | % | 三者分母不同不能互替；产率超 100% 说明没干燥或含杂质 |
| 波数 `ν̃` | 红外吸收位置 | cm⁻¹ | 与波长成倒数，λ 要换成 cm 再取倒数 |
| 化学位移 `δ` | NMR 相对 TMS 的偏移 | ppm | TMS 定零点；要认得溶剂峰（CDCl₃ 约 7.26）与水峰 |
| 偶合常数 `J` | 裂分峰间距 | Hz | J 与仪器兆赫数无关；n+1 律只对等价邻接核成立 |
| 指示剂变色点 | 约在 pH = pKa(HIn) 处 | — | 变色区间必须落在突跃内；强酸滴弱碱要选酸性范围变色的指示剂 |
| 终点误差 | 终点与计量点的偏差 | % | 终点不等于计量点；指示剂加太多会拖偏终点读数 |
| 反应级数 与 分子数 | 实验测得的浓度指数、基元反应的粒子数 | — | 级数可为分数或零；只有基元反应两者才一致 |
| 活化能 `Ea` | Arrhenius 式的斜率项 | kJ/mol | ln k 对 1/T 作图斜率为 −Ea/R，R 取 8.314 J/(mol·K) |

## 6. 典型题型与解题套路

### 计算题（平衡、滴定、热力学、动力学）
1. 先把题面所有量统一到 mol、L、K、kJ，并在草稿上逐个写单位。
2. 写出守恒式（物料、电荷）与 K 表达式，确认未知量个数不超过方程数，再代数。
3. 做近似前先声明条件（如 c/Ka 大于 500 才可忽略解离），近似后回代检查误差是否小于 5%。
4. 算完做量级与符号检查：pH 在 0 到 14 之间、产率不超过 100%、ΔG 的符号与自发性一致。
**常见失分点**：把质量分数直接当浓度代入稀释公式，或 ΔH 用 kJ、ΔS 用 J 不换算就相加。

### 机理推断题（给反应物与条件，写机理与主产物）
1. 标出所有亲电中心与亲核位点，先判断反应类型：极性、自由基还是周环。
2. 画第一步弯箭头，从电子丰富处指向电子缺乏处，同时写清新的成键与断键。
3. 逐级检查中间体是否合理：碳正离子会不会重排、是否满足芳香性、价层是否超八隅体。
4. 由中间体推产物，再核对立体化学（背面进攻导致构型翻转或消旋）。
5. 补一句"为什么不是另一条路"，用溶剂、温度、位阻给出排除理由。
**常见失分点**：箭头起点画在原子而不是键或孤对上，导致电子数不守恒，整题连锁扣分。

### 结构推断题（由分子式与谱图定结构）
1. 由分子式算不饱和度，先圈定骨架范围，排除不可能的组合。
2. 按 IR、¹H NMR、¹³C NMR、MS 的顺序读，每步只下一个结论：有什么官能团、几类氢、分子量多少。
3. 列两到三个候选，对每个候选问"哪个峰能证伪它"，写清被排除的理由。
4. 用裂分与偶合常数定相邻关系，再用化学位移确认所处环境。
5. 最后核对总氢数与对称性，对不上就说明结构没闭合，回第 3 步。
**常见失分点**：抓一个峰就定结构、不做证伪；或把溶剂峰、水峰当成样品峰。

### 实验设计题（含量测定、分离提纯、条件优化）
1. 写清待测物、基体、预期含量范围与允许误差，这三项决定方法选择。
2. 选方法并说明为什么不用另一种：看选择性、灵敏度、干扰是否可消除。
3. 写步骤：取样量、标准溶液浓度、指示剂或检测波长、终点判据。
4. 补对照：空白、平行样、加标回收，各写一句它能排除什么。
5. 给结果表达方式：平均值加减标准差，说明保留几位有效数字。
**常见失分点**：只有主实验、没有空白与回收，无法证明干扰被消除，方案不得分。

## 7. 常见误区

1. **把质量分数当浓度代进稀释公式** → 错在没乘密度换体积；应先写 $c = 1000\rho w / M$ 算出浓度再代数。
2. **ΔH 用 kJ、ΔS 用 J 直接代 $\Delta G = \Delta H - T\Delta S$** → 错在单位不统一；先把 ΔS 换成 kJ/(mol·K)。
3. **用 ΔG° 判断实际条件下的方向** → 错在把标准态当成实际态；实际方向要用 $\Delta G = \Delta G^\circ + RT\ln Q$。
4. **写机理时弯箭头从原子指向原子** → 错在电子来源不明；箭头必须起于键或孤对电子，且每步核对电荷守恒。
5. **把共振式当成互相转化的异构体** → 错在把电子移动当成原子核移动；共振式只描述同一份真实结构。
6. **滴定到颜色刚变就读数** → 错在终点超量；接近突跃时改为半滴加入并摇匀，记录实际消耗体积。
7. **谱图只做数据库检索不做推导** → 错在把检索结果当证明；必须用不饱和度与裂分独立验证候选结构。
8. **报产率不写理论产量怎么来** → 错在没定限量试剂；先算限量试剂的物质的量，再折成理论产量做分母。

## 9. 交叉专业与后续方向

- **和化学工程与工艺的区别**：化学回答"这反应能不能发生、主产物是什么、机理怎么走"；化工回答"怎么放大到万吨级，传热传质与能耗怎么算"。同一张流程图上，化学看选择性，化工看收率与设备。
- **和材料科学与工程的区别**：材料把结构当手段去换性能（力学、电学、服役寿命），化学把结构当结论去解释与合成。材料会做拉伸与疲劳测试，化学会做谱图表征。
- **和药学的区别**：药学要回答"这个分子在体内怎么代谢、剂量与安全性如何"，终点是临床；化学只回答"怎么造出来、纯度多少、结构是否确证"。
- **不编造数据是硬规矩**：谱图峰位、产率、回收率、文献值，只有在你有实测数据或明确文献来源时才能写出来；没有就写"需要实测"，并给出该测什么、怎么测、预期看到什么。宁可交一份方案，也不给一个假数字。
- **后续方向**：有机合成方法学、分析化学与质谱、物理化学与计算化学、高分子与材料化学、化学生物学；考研常考覆盖无机、有机、分析、物化四门的化学综合。
