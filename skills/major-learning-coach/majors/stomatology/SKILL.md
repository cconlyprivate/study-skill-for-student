# 口腔医学（stomatology）

> 先读 `../../references/curriculum-rules.md`（难度与排序）与 `../../references/learning-card-template.md`（讲解结构）。
> 本文件只给这个专业的知识骨架与专业习惯，不重复通用协议。

## 1. 这个专业在训练什么

在毫米级、不可直视、全程有唾液与细菌污染的空间里，把"这颗牙还能不能留"转成一组可执行的动作：先判读牙位与影像（K03），再确证牙体、牙髓、牙周的支持条件（K02、K04），最后在固位、抗力、美观、费用之间选一个能交付的方案（K05、K06）。

它和"看牙"不是一回事。看牙是操作，口腔医学是**先用证据证明这个方案不会让情况更糟**。同样是磨一颗牙，训练过的人知道该磨 1.0 mm 还是 1.5 mm、磨完还剩多少牙本质、失败时怎么补救；没训练过的人只知道"要磨小一点"。

**最容易误解的一点**：以为口腔 = 牙齿。牙周、口腔黏膜、颌骨、颞下颌关节、唾液腺都在范围内；而且牙髓炎的疼痛与上颌窦炎、三叉神经痛、甚至心肌缺血高度重叠，不会鉴别的人会把好牙磨开，或者把心梗当成牙痛放走。

与临床医学的分界线：临床医学问"这个人的全身风险是什么"，口腔医学问"这颗牙还能不能留、怎么留"。但底线相同：任何有创操作之前，先排除会让你改变方案的东西（未控制的高血压、糖尿病、头颈部放疗史、抗凝药）。

## 2. 课程地图

| 学期 | 课程 | 模块 | 先修 | 难度感受 |
|------|------|------|------|----------|
| 大一 | 口腔解剖生理学 | K01 | — | 名词与形态密度最高，靠牙模与雕牙记，抄笔记记不住三维关系 |
| 大一 | 口腔组织病理学 | K02 | K01 | 镜下形态要对到临床诊断上，第一次要求"看图说话" |
| 大二 | 口腔颌面影像学与检查 | K03 | K01、K02 | 片子的黑白要还原成三维结构，投照角度会骗人 |
| 大二 | 牙体牙髓病学 | K04 | K02、K03 | 精度要求最高：差 0.5 mm 就决定留还是拔 |
| 大三 | 口腔修复学 | K05 | K01、K04 | 力学与美学的折中，固位与抗力是最容易漏的一步 |
| 大三 | 口腔颌面外科学 | K06 | K01、K03 | 解剖层次错一层就是并发症，风险比牙体操作高一个量级 |
| 大四 | 口腔预防医学与儿童口腔 | K07 | K02、K05 | 看似简单，实际要按人群、年龄与依从性改策略 |
| 大四至大五 | 口腔临床实习 | K08 | 全部 | 真实病例不按教材排序，靠带教复盘与病历倒推 |

**最陡的三门课**：牙体牙髓病学（因为毫米级操作、影像判读、存留判断三件事同时要）、口腔颌面外科学（因为要在解剖层次上做不可逆决策）、口腔修复学（因为要在固位、抗力、美观、费用四个约束里交付一个方案）。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能在一张根尖片或曲面上，用 FDI 与 Universal 两套编号各报一遍牙位，并指出投照角度造成的变形。
2. 能对一段牙痛描述判定牙髓炎类型，并列出 3 个必须排除的牙外来源（上颌窦炎、三叉神经痛、心肌缺血、颞下颌关节痛）。
3. 能写出根管治疗的完整步骤，并用影像、根测仪、手感三种方法互相校验工作长度。
4. 能对一个牙体缺损说出该做嵌体、全冠还是桩核冠，并给出固位形与抗力形各一条处理。
5. 能对一个缺牙病例给出固定桥、可摘局部义齿、种植三种方案，并各写一条禁忌。
6. 能在拔牙前完成禁忌证筛查，写出高血压、糖尿病、抗凝药三类患者的术前处理。
7. 能给一个多学科病例排出分期治疗计划，并写出 3 个可测的疗效指标与复查节点。
8. 能写出一份含诊断、计划、替代方案、风险与随访的病历，且不把诊断写进主诉。

## 5. 术语与符号约定

口腔的记号核心是"以谁为基准"和"往哪个方向量"。下面每条都对应一个真实的扣分点，尤其是牙位、方向与象限。

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| FDI 牙位记录 | 两位数字：十位是象限，个位是牙位 | 恒牙 11–48，乳牙 51–85 | 十位 1–4 从右上顺时针到右下；个位 1 是中切牙、8 是第三磨牙。46 指右下第一磨牙，不是"第 46 颗牙" |
| Universal 编号 | 1–32 连续编号，乳牙用 A–T | 1 起于右上第三磨牙，32 止于右下第三磨牙 | 与 FDI 不能混用也不能换算着报；同一份病历只能出现一套，换套必须重写牙位 |
| 近中 / 远中 | 以牙弓中线为基准，靠近中线为近中 | 面名 | 基准是中线不是医生站位；同名牙左右两侧的近中面朝向相反 |
| 颊面 / 唇面 / 舌面 / 腭面 | 后牙朝颊、前牙朝唇、上颌内侧为腭、下颌内侧为舌 | 面名 | 上前牙写"颊面"错，应写唇面；下颌后牙内侧写"腭面"也错，应写舌面 |
| 𬌗面 / 切端 / 邻面 | 后牙咬合面、前牙切缘、与邻牙相接的面 | 面名 | 后牙用𬌗面、前牙用切端；"咬合面"是口语，答题写𬌗面或咬合面要统一 |
| 覆𬌗 | 上前牙切缘盖过下前牙唇面的垂直距离 | mm，正常约盖住下前牙冠长的 1/3 | 垂直向的量；深覆𬌗不等于深覆盖，这两个字常被写反 |
| 覆盖 | 上前牙切缘到下前牙唇面的水平距离 | mm，正常约 2–4 | 水平向的量；正畸记录必须覆𬌗与覆盖各写一个数，只写一个不合格 |
| 龋病四联因素 | 细菌、食物、宿主、时间 | 四要素 | 漏掉"时间"是最常见错误；四联解释群体风险，不解释单颗牙的洞有多深 |
| 牙髓炎疼痛特点 | 自发痛、夜间痛、冷热激发痛、放散痛、不能定位 | 症状组合 | 不能定位指向牙髓炎，能定位且叩痛明显指向根尖周炎；两者写反是经典扣分点 |
| 根尖周炎定位 | 患牙可定位，叩痛与咬合痛明显 | 症状组合 | 根尖周炎是"咬下去痛"，牙髓炎是"冷热刺激后痛"，机制不同不能互换 |
| 工作长度 | 从参考点到根尖狭窄部的距离 | mm，通常比影像根尖短 0.5–1.0 | 不是"到片子上的根尖"；根尖孔破坏或再治疗时要下调，且必须三种方法互校 |
| 根管治疗步骤 | 开髓、拔髓、定工作长度、成形、消毒、充填、冠修复 | 7 步 | 漏"冠修复"等于没做完；橡皮障是第 1 步不是可选项，次氯酸钠不能接触黏膜 |
| 主尖锉 / 主牙胶尖 | 到达工作长度的最大锉号，与同号同锥度的牙胶尖 | 常规 15 号起 | 号数与锥度都要匹配；只对号数不对锥度，结果不是欠填就是超填 |
| 修复体类型 | 嵌体、高嵌体、部分冠、全冠、桩核冠、固定桥、可摘局部义齿、种植冠 | 按缺损与缺牙数选 | 缺损越大越该往"覆盖"走；桩核冠要求足够的根长与骨支持，不是有根就能打桩 |
| 固位形 | 让修复体不脱位的几何形：环抱、侧壁、钉洞、沟 | 几何要素 | 固位形防脱位、抗力形防折裂，是两个问题；答题要分开写，只写一个必丢分 |
| 抗力形 | 让牙体与修复体不折裂的形：洞深、洞底平、轴壁平行、去无基釉 | 几何要素 | 只做固位不做抗力会留薄壁弱尖，修复体没坏牙先裂 |
| 牙体预备量 | 全冠各面磨除的牙体厚度 | 金属烤瓷约𬌗面 1.5–2.0、轴面 1.0–1.5，单位 mm | 必须写 mm 与"最薄处"；预备不足会穿髓或修复体过薄崩瓷 |
| 种植禁忌证 | 绝对：未控制全身病、头颈部放疗史、静脉双膦酸盐、正在化疗、极差口腔卫生。相对：吸烟、已控制的糖尿病 | — | 把吸烟与已控制的糖尿病说成绝对禁忌会扣分；绝对禁忌要写"未控制"这个限定 |
| 橡皮障 | 隔离术区的橡胶膜，配夹、架与打孔器 | — | 不只防口水：防误吞误吸、防冲洗液烧伤黏膜、防气溶胶交叉感染，根管治疗与树脂充填都该上 |
| 根管冲洗液 | 次氯酸钠溶有机物、EDTA 去玷污层、氯己定抗菌 | 次氯酸钠 0.5%–5.25%，EDTA 17% | 次氯酸钠与氯己定直接混合会生成沉淀，两者之间必须用生理盐水隔开 |
| 探诊深度 / 附着丧失 | 龈缘到袋底 / 釉牙骨质界到袋底 | mm，健康探诊深度 ≤ 3 | 牙周炎看附着丧失不看探诊深度；牙龈退缩时探诊深度正常也可能已有附着丧失 |
| 松动度 | 牙在牙槽窝内的动度 | I–III 度 | 写"松动 2 mm"代替分度会扣分；颊舌向与垂直向要分开记 |
| Angle 分类 | 按上颌第一恒磨牙近中颊尖与下颌第一恒磨牙颊沟的关系分 I、II、III 类 | I–III 类 | 以第一磨牙关系定类，不以切牙突度定类；II 类还要再分 1 分类与 2 分类 |

## 6. 典型题型与解题套路

### 病例分析题（给主诉、牙位与影像，问诊断与治疗计划）
1. 先把主诉拆成"牙位 + 症状 + 时间"三要素，主诉里不写诊断，不超过一句话。
2. 按牙体、牙髓、根尖周、牙周、黏膜五层逐层定位，每层写一条支持证据与一条反对证据。
3. 对疼痛必须回答"能不能定位"：能定位多指根尖周或牙周来源，不能定位多指牙髓炎。
4. 只选能改变处理的检查（冷测、叩诊、根尖片、必要时 CBCT），并写清这项阴性时下一步做什么。
5. 计划按"急症、病因、功能重建、维护"四段排序，每段给一个复评节点。
**常见失分点**：直接写"牙髓炎，建议根管治疗"就收尾，没有鉴别、没有分期、没有替代方案。

### 牙位与影像判读题（给一张根尖片、曲面断层或 CBCT）
1. 先报片子类型与左右侧，再报牙位：FDI 先象限后牙位，如 46 为右下第一磨牙。
2. 用 Universal 复述一遍核对左右，两套编号对不上说明其中一次报错。
3. 按"龋、充填体、牙髓腔、根管、根尖周、牙槽骨、邻牙"固定顺序扫，避免只盯主诉牙。
4. 对每个透影区问三件事：边界清不清、与哪颗牙根尖相连、周围有没有骨白线。
5. 最后说明投照或重建角度可能造成的假象（重叠、拉长、变形），并指出还需补什么检查。
**常见失分点**：把 FDI 的 46 当成"第 46 颗牙"；把 Universal 的 19 说成左上（19 是左下第一磨牙）。

### 治疗方案设计题（缺牙、牙体缺损、错𬌗）
1. 先写约束：余留牙数量与分布、牙周支持、对颌牙与咬合空间、全身禁忌、费用与依从性。
2. 按"可逆、微创、固定、种植"的顺序逐个淘汰，每淘汰一个写明理由。
3. 给出主方案加一个替代方案，并说明在什么条件下改选替代方案。
4. 写出失败模式：最可能坏在哪、多久复查、复查看哪三个指标。
**常见失分点**：只给一个"最佳方案"，不提禁忌与替代，也不写复查。

### 操作流程题（根管治疗、窝洞预备、拔牙、橡皮障放置）
1. 先写术前：适应证复核、影像、麻醉、橡皮障、器械与冲洗液。
2. 分段写流程：入路、定位、成形、消毒、封闭；或分离、拔除、清理、止血。
3. 每段给一个判断点，并写"如果不对怎么办"（工作长度差 1 mm、断针、上颌窦穿孔）。
4. 最后写术后医嘱、复查时间与需要回访的症状。
**常见失分点**：漏橡皮障与术前影像；把流程写成器械清单，没有一个判断点。

## 7. 常见误区

1. **FDI 与 Universal 混着报牙位** → 错在把十位当成"第几颗"，或在不同段落换编号；应固定一套并在病历首行注明，换套时整份重写。
2. **把牙痛直接推成牙髓炎** → 错在没做定位与激发试验；应先问能否定位、是否夜间加重，再排上颌窦炎、三叉神经痛与心肌缺血。
3. **覆𬌗与覆盖混用** → 错在一个是垂直向、一个是水平向；写"深覆𬌗 3 mm"时必须说明量的是哪个面到哪个面。
4. **以"根充完成"作为根管治疗终点** → 错在漏了冠方封闭与最终修复；未做冠的根管治疗牙折裂风险明显升高，计划里必须写"修复完成"。
5. **把吸烟、糖尿病一律当成种植绝对禁忌** → 错在没区分控制状态；绝对禁忌是未控制的全身病、头颈部放疗史、静脉双膦酸盐等，吸烟与已控制的糖尿病属相对禁忌，要写戒烟期与糖化血红蛋白目标。
6. **洁治后只看牙石与出血就判定治好** → 错在没复查附着丧失；牙周疗效要同时看探诊深度、附着丧失与出血指数，否则把"看起来干净"当成治愈。

## 9. 交叉专业与后续方向

- **和临床医学的区别**：临床医学按系统与全身状态决策，口腔医学按牙位与局部结构决策。同一份血常规，临床看是否需要调整全身治疗，口腔只看"能不能今天做这个有创操作"。交汇点是颌面部感染、外伤、肿瘤、麻醉与抗凝管理。
- **和药学的区别**：药学负责药物本身的吸收、代谢、剂型与质量控制；口腔医学只负责"这个局部用什么药、什么浓度、接触多久"（次氯酸钠、氯己定、氟化物），不开系统用药方案。局部用药浓度算错就是黏膜烧伤，和药学关注的血药浓度不是一回事。
- **和生物医学工程的区别**：口腔医学提临床约束（就位道、咬合空间、生物相容性），工程做材料与器械（陶瓷、钛合金、CAD/CAM、CBCT 重建）。交汇点是种植体表面处理与数字化修复。
- **后续方向**：牙体牙髓、口腔修复、口腔颌面外科、口腔正畸、牙周、儿童口腔、口腔种植、口腔病理与影像；考研初试多为院校自命题的口腔综合（科目代码各校不同），毕业后进入口腔住院医师规范化培训与专科培训。
- **边界提醒**：本文件是学习方法指导，不替代执业医师诊断，真实病例以临床检查与影像为准。
