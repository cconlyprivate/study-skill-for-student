# 哲学（philosophy）

> 先读 `../../references/curriculum-rules.md`（难度与排序）与 `../../references/learning-card-template.md`（讲解结构）。
> 本文件只给这个专业的知识骨架与专业习惯。

## 1. 这个专业在训练什么

哲学靠"把说不清的问题说清楚"吃饭，具体是三件事：把模糊的抱怨改写成可真可假的命题；把支持它的理由排成能逐句检查的论证；为结论找到文本、反例和最强反驳都能对得上的位置。三件事缺一件，剩下的就只是感想。

外人最常误解的一点是以为哲学讨论"没有答案的问题"。相反，训练的第一课是承认有些问题暂时没有公认答案，但**每个立场都必须有可反驳的形式**——一个任何证据都动摇不了的说法，在哲学里不算答案，只算态度。

它和隔壁专业的分界：历史学问"这件事怎么发生"，哲学问"支持这个说法的理由成不成立"；法学问"依现行规范合不合法"，哲学问"这条规范本身的依据是什么"。

**最容易误解的一点**：以为哲学是背哲学家的观点。实际考的是你能不能拿哲学家的论证去打哲学家的结论——所以先补 K01（论证）与 K02（逻辑），再进哲学史，比一上来读原著效率高得多。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能把一段口语化困惑改写成 3 个含明确主词、非真即假的可判定命题。
2. 能对任意一段议论圈出结论、显前提、隐前提，并分开回答"有效吗、可靠吗"。
3. 能对一个哲学概念给出定义、构造反例、再按反例修正定义，全过程可复核。
4. 能对同一个道德争议分别用义务论、后果论、德性论写出三份结论不同的评价。
5. 能区分"文本说了什么"与"作者主张什么"，并给出卷次、页码级的引证。
6. 能设计一个只改一个变量的思想实验，并说清它想逼出的直觉是什么。
7. 能写出一篇 3000 字论文：问题、立场、论证、最强反驳、回应五部分齐全。
8. 能在 20 分钟口头报告里把对手立场复述到对手认可，再提出反驳。

## 5. 术语与符号约定

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| 有效性（valid） | 前提真则结论必真的形式性质 | 只看形式，不涉及前提真假 | 有效不等于正确；判有效性要写出形式，不能凭"读着顺" |
| 可靠性（sound） | 有效且全部前提为真 | 两个条件缺一不可 | 常被写成"有道理"；可靠蕴含有效，反之不成立，答题必须分两句 |
| 必要条件 / 充分条件 | P 是 Q 的必要条件即 Q→P；充分条件即 P→Q | 箭头方向是唯一判据 | "只有…才…"是必要，"如果…就…"是充分；写完回读一遍箭头 |
| 当且仅当（iff） | 充分且必要 | P↔Q | 把"如果…那么…"写成"当且仅当"，等于偷偷加强了命题 |
| 先验 / 后验 | 不依赖经验而成立 / 依赖经验而成立 | 认识论来源，与时间先后无关 | "先验"不是"天生就有"；数学是先验的，但学会它需要经验训练 |
| 分析 / 综合 | 凭意义为真 / 靠经验内容为真 | 与先验/后验是两个独立轴 | 两者常被当成同一条线；具体命题归哪类取决于你选哪种意义理论，答题要声明 |
| 义务论 | 按准则与义务评价行为 | 评价对象是行为准则 | 义务论不是"讲道德"；它看准则能否普遍化，不看后果好坏 |
| 后果论 | 按事态后果评价行为 | 评价对象是事态 | 后果论不等于利己主义；功利主义要的是总体效用最大 |
| 德性论 | 按行动者品质与实践智慧评价 | 评价对象是人与判断力 | 它不给"这次该不该做"的直接判据，问的是有德者会怎么看 |
| 绝对命令 / 假言命令 | 无条件要求 / 以目的为条件的工具性要求 | 康德术语 | 假言命令不是"坏命令"，只是有条件；把两者对立成道德与不道德是硬错 |
| 效用（utility） | 后果论中善的度量 | 序数、基数或仅可比较，须声明 | 不说明可加性与可比性，效用计算题就无法判对错 |
| 事实 / 价值（实然—应然） | 描述是什么 / 规范应当怎样 | 休谟断头台 | 从"是"直接推"应当"是跳步，必须补一条规范性前提 |
| 描述伦理 / 规范伦理 / 元伦理 | 记录道德现象 / 给行为标准 / 分析道德语言与真理 | 三层问题不可混答 | "道德判断有没有真假"是元伦理问题，不能用"应该怎么做"回答 |
| 思想实验 / 直觉泵 | 控制变量的假想情境 | 只改一个变量 | 一次改两个变量，结论就无法归因，读者不知道是哪条原则在起作用 |
| 归谬法（reductio） | 从对方前提出发推出不可接受的结果 | 推理过程必须有效 | 推出"我不喜欢"不算荒谬；荒谬须落到自相矛盾或公认不可接受 |
| 乞题 / 循环论证 | 结论（或其等价式）被当作前提 | — | 与"前提恰好为真"难分辨，判据是撤掉结论后前提还能不能支持它 |
| 稻草人 | 反驳被弱化后的对手观点 | — | 引用对手原话加页码，是唯一可靠的防稻草人手段 |
| 滑坡 | 无依据地推出连锁恶果 | 每一步都要单独给机制 | 举不出中间机制，滑坡就只是修辞，不是论证 |
| ∀ / ∃ 与辖域 | 全称量词 / 特称量词 | 否定时 ∀ 与 ∃ 互换 | "所有 S 都是 P"的否定是"有的 S 不是 P"，不是"所有 S 都不是 P" |
| ⊃ 与 ⊢ / ⊨ | 真值函数蕴含 / 可证 / 语义后承 | 三个符号不能混用 | 用 ⊃ 当"所以"是最常见的记号错，它只是联结词 |
| 引注格式 | 作者·著作·卷次·页码 | 外文：作者, 书名, 卷次, 页码；中文：作者·书名·卷次·篇名·页码 | 只写书名不写卷次页码等于没引；版本不同页码就不同，必须注明 |
| 古典页码体系 | 柏拉图 Stephanus 页、亚里士多德 Bekker 行号、康德 A/B 版 | 跨版本可查，通行引法 | 拿现代中译本页码引柏拉图，别人无法核对；应引 Stephanus 页再注中译本 |
| 中文古籍引法 | 书名·卷次·篇名·条次 | 如《朱子语类》某卷某条 | 只写"朱熹说过"无法核对，卷次与条次必须精确到位 |
| 物自体 / 现象 | 独立于认识方式的存在 / 被形式化后给予的存在 | 康德术语 | 把"现象"当"假象"是硬错；现象是必然显现，不是幻觉 |
| 理 / 气 / 心 / 性 | 宋明理学的四个基本范畴 | 互为定义，无独立定义 | 直接套西方"实体—属性"框架会错位；先看它在原文中与谁对立 |
| 工夫论 / 知行合一 | 修养实践及其与认识的关系 | 中哲特有 | 把"知行合一"读成"先知道再做到"正好相反，它反对的正是知先行后 |

## 6. 典型题型与解题套路

### 论证重构题
1. 先用一句话写出结论，并标出它的模态（必然/应当/很可能）；模态丢了，后面全歪。
2. 逐句圈前提，把修辞句、举例、反问划掉，剩下的才是论证骨架。
3. 补隐前提：问"从这些前提推到结论还缺哪一句"；补上的句子必须比原文更不讨喜，否则你补的是结论的复述。
4. 写成标准形式（P1、P2、∴ C），逐步检查是不是有效推理。
5. 分开三问：有效吗？前提真吗？可靠吗？三问答完才算重构完。
**常见失分点**：把作者举的例子当前提，或把结论改写成前提（乞题）。

### 概念辨析题
1. 先给两个概念各写一句最小定义，只留能区分二者的那一层。
2. 找一个边界案例：按 A 的定义归 A、按 B 的定义归 B，看它落在哪边。
3. 比较两者的反例承受力：哪个更容易被反例击穿，谁在退化。
4. 交代理论位置：谁依赖谁，能否用一个定义另一个。
5. 收口一句"所以本题语境下取 A 的哪一层含义"。
**常见失分点**：只列词典式差异、不给边界案例，等于没辨析。

### 思想实验题
1. 先写清它要检验哪条直觉或原则，一句话说破。
2. 只改一个变量，其余条件逐条固定并写出来。
3. 预测两种直觉反应，说明各自会推出什么理论后果。
4. 给一个反思想实验：改哪个条件能让直觉翻转，翻转暴露了什么隐含前提。
5. 结论落到"这个实验能支持什么、不能支持什么"。
**常见失分点**：把"我觉得荒谬"当结论，没说出它推翻了哪条原则。

### 文本解读题
1. 先定位出处：哪本书、哪一卷、针对谁的什么主张，引注写到卷次页码。
2. 逐句译成现代汉语的论证句，术语先保留原词，不要急着换当代术语。
3. 标出转折词（然而、因此、固然），它们是论证结构的路标。
4. 区分"文本说了什么"与"作者主张什么"，再用同书另一处互证。
5. 最后给评价：今天最强的反驳是什么，作者手里还有没有可用的回应。
**常见失分点**：用二手导论替代原文，引注只写书名，页码对不上所用版本。

## 7. 常见误区

1. **把"有效"当"正确"** → 错在用结论的可信度反推论证质量；应分三问答：形式有效吗、前提全真吗、两者都满足吗。
2. **必要与充分条件写反** → 错在顺着语序抄；应先把句子译成箭头（Q→P 或 P→Q），再回读中文是否等值。
3. **先站队再找理由** → 错在结论先于论证，所有前提都成了装饰；应先写出对手最强版本，再决定站哪边。
4. **用二手导论代替原典** → 错在引注无法核对且导论会丢掉限定条件；应核到卷次页码，并标明哪句是二手概括。
5. **把"先验"读成"天生"** → 错在把认识论来源混成发生学时间；应先问"撤掉经验后它还成立吗"，成立才算先验。
6. **思想实验一次改多个变量** → 错在结论无法归因；应逐条固定条件，一次只动一个。
7. **用规范伦理回答元伦理问题** → 错在层次错位；"道德判断有没有真假"不能用"应该怎么做"来答。

## 9. 交叉专业与后续方向

- **和思想政治教育的区别**：思政以马克思主义理论的系统教育与立场形成为目标，考试考"原理表述 + 政策对应"；哲学要求把包括马克思主义在内的一切立场还原成可检验的论证与文本依据，允许并鼓励追问前提。同一句"实践是检验真理的标准"，思政要你说清它的理论地位，哲学要你给出它的论证与反例边界。
- **和逻辑学（logic）的区别**：逻辑学只问形式有效性，可以形式化、可以判定，工具是模型论与证明论；哲学把逻辑当工具（K02），还要问前提真假、概念含义与价值排序——一个论证在哲学里"有效但无用"，通常是因为前提站不住，而不是形式有问题。
- **和伦理学（ethics）的区别**：伦理学专业聚焦规范理论与应用裁决；哲学把它当 K05 这一个模块，还要用形而上学与认识论的结论去约束它（比如"道德判断有没有真假"要先有真理观）。
- **和历史学的区别**：历史学要还原思想发生的语境与因果；哲学史要重新评估那些论证今天还成不成立。同一段文本，历史学问"他为什么这么想"，哲学问"他这么想对不对"。
- **后续方向**：哲学一级学科下马哲、中哲、外哲、伦理学、逻辑学、美学、宗教学的学硕；跨考法硕、新闻传播、公共政策；出版编辑与学术翻译、中学政治与语文教师、科技伦理与 AI 合规、政策研究与公共说理训练。
