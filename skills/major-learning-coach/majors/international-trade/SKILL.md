# 国际经济与贸易（international-trade）

> 使用前先读 `../../references/curriculum-rules.md`（难度与排序规则）与
> `../../references/learning-card-template.md`（讲解结构）。
> 本文件只提供"这个专业的知识骨架与专业习惯"，不要在这里重复通用协议。

## 1. 这个专业在训练什么

把一句"这批货从宁波出、卖到鹿特丹"，拆成三层可算的东西：**为什么换**（比较优势与规模经济决定的贸易方向）、**换的代价**（关税、汇率、运费、合规成本各打掉多少）、**钱怎么安全收回来**（合同条款、贸易术语、信用证与单据）。

它和"英语好 + 会报关"不是一回事。报关只是 K06 的最后一公里；真正决定结论的是前两步：贸易方向由机会成本定，成交价格由汇率与术语定，能不能收款由单据一致性定。

**最容易误解的一点**：以为国贸 = 经济学加一点外贸流程。实际要同时握住三套语言——模型（经济学）、报价与折算（金融）、条款（法律与单证）；失分几乎都发生在两套语言的交接处，比如用 CIF 价当关税完税价格、用间接标价法去读升水。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能对两国两商品的产出或成本表算出机会成本，判出比较优势、贸易方向与贸易所得区间。
2. 能在供需图上算出关税、配额、出口补贴的福利四块，并给出净损失的数字。
3. 能读懂任意一组外汇报价，换算出两种标价法、交叉汇率与升贴水年率，并指出版价方。
4. 能由国际收支平衡表判断一笔交易的借贷方，并用弹性条件与 J 曲线解释贬值效果。
5. 能对一份合同判出术语下的交货点、风险转移点与费用分担，并指出条款之间的冲突。
6. 能对一套信用证单据逐项比对，列出不符点并判断开证行是否可以拒付。
7. 能对一笔外币应收款算出敞口，并给出远期与期权两套对冲方案及各自成本。
8. 能对一项贸易政策写出"机制—福利—可检验预测"三段式论证，并写明结论反转的条件。

## 5. 术语与符号约定

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| 直接标价法 | 1 单位外币折成若干本币 | 中国、日本采用 | 数值上升是本币贬值；写成"汇率上升即本币升值"会把整题方向做反 |
| 间接标价法 | 1 单位本币折成若干外币 | 英国、美国、欧元区报价习惯 | 与直接标价法互为倒数，取倒数后升贴水的方向要重新判一次 |
| 买入价 / 卖出价 | 银行买入或卖出外汇的价格 | 卖出价高于买入价 | 客户换汇永远吃对己不利的那个价，价差就是交易成本，不能忽略 |
| 升水 / 贴水 | 远期价高于或低于即期价 | 用点数或年率报 | 主语不写清必错：外币升水等价于本币远期贴水 |
| 升贴水年率 | 远期与即期差额折成年率 | %/年 | 分母是即期价 $S$，期限按 $12/n$ 折年；拿远期价当分母会把年率算小 |
| 交叉汇率 | 由两个含美元的报价推出非美元汇率 | 无量纲 | 该乘还是该除取决于两个报价的标价方向，先统一成同一种标价法再动笔 |
| 比较优势 | 机会成本较低的那一种商品 | 相对概念 | 与绝对优势混用；一国两种商品都更贵，仍可能在一种商品上有比较优势 |
| 绝对优势 | 单位投入的产出更高 | 绝对概念 | 绝对优势不决定贸易方向，只决定两国工资水平的高低 |
| 贸易条件 | 出口价格指数比进口价格指数 | 指数，基期记 100 | 数值上升才叫改善；用贸易额代替价格指数会得出反向结论 |
| 关税福利四块 | 生产效应、消费效应、贸易效应、税收效应 | 货币单位 | 净损失只算两块三角形；政府税收是转移，不能记成损失 |
| 有效保护率 | 对国内增加值的保护程度 | % | 分母是增加值不是产成品价格；投入品税率高于产成品时它可以是负数 |
| 配额租金 | 配额造成的国内外价差收益 | 货币单位 | 租金归谁取决于配额如何分配，不会自动进政府口袋 |
| 倾销幅度 | 正常价值与出口价格之差相对出口价格 | % | 正常价值的口径（国内价、第三国价、构成价）不同，幅度会差很多 |
| 最惠国待遇 | 给一方的优惠自动给所有成员 | WTO 原则 | 它是"不歧视"不是"最优惠"；区域协定与普惠制是明文例外 |
| 国民待遇 | 进口品与本国货物同等对待 | 只管境内措施 | 管的是清关之后，不覆盖边境关税；与最惠国待遇的适用阶段不同 |
| Incoterms 版本 | 贸易术语规则的第几版 | 现行 2020 版 | 合同不写版本就有争议；2010 版的 DAT 在 2020 版已改为 DPU |
| FOB 风险划分点 | 货物在装运港装上船 | 仅海运与内河 | 风险在装船时转移，海运费与保险由买方负担；集装箱货应改用 FCA |
| CIF / CFR 风险划分点 | 同样在装运港装上船 | 仅海运与内河 | 卖方多付运费（CFR）或运费加保险（CIF），风险并不延到目的港 |
| 提单 B/L | 承运人签发的收据与物权凭证 | 常见正本一式三份 | 收货人栏与背书方式决定谁能提货；签发日晚于装运期即构成不符点 |
| 保险加成 | 按 CIF 价加成投保的惯例比例 | 通常 110% | 加成基数是不含佣金的 CIF 价；只按发票金额投保会低于惯例 |
| 信用证流程 | 申请开证→开证行开立→通知行通知→受益人交单→议付或付款→开证行偿付 | 受 UCP600 约束 | 通知行只通知不付款；开证行只凭相符单据付款，与货物质量无关 |
| 单据一致性 | 单据之间、单据与信用证之间互不矛盾 | 字面相符 | 严格相符不是"差不多"：品名、数量、日期、金额四处最容易出不符点 |
| 不符点 | 交单与信用证条款不一致之处 | 按处计 | 开证行须在 5 个银行工作日内一次性提出，逾期即视为接受 |
| HS 编码 | 商品分类编码 | 前 6 位国际统一，后几位本国细分 | 归类差一位，税率与原产地规则同时变；先看品目条文再看类注章注 |
| 原产地规则 | 判定货物"国籍"的标准 | 完全获得或实质性改变 | 实质性改变有归类改变、增值百分比、特定工序三种标准，不能混用 |
| 出口退税 | 退还出口货物国内环节的增值税与消费税 | 按退税率 | 退税率不等于征税率，差额进成本；买单出口属违规操作 |
| 三元悖论 | 汇率稳定、资本自由流动、货币政策独立三者取二 | — | 不是口号，答题必须说清放弃了哪一个、代价落在谁身上 |
| 马歇尔-勒纳条件 | 贬值改善贸易收支的弹性条件 | 弹性之和大于 1 | 用的是长期弹性；短期不满足才画出 J 曲线的先贬后升 |

**最容易写反的一件事**：汇率方向。拿到任何一组报价，先把等号写成"1 单位外币 = X 单位本币"，再说升贬；拿到任何远期价，先写主语（外币升水还是本币升水）。这两句能挡掉本专业计算题一半的方向性失分。

## 6. 典型题型与解题套路

### 贸易模型计算题（比较优势、关税福利、有效保护率）
1. 先认表：手里是"单位产出所需的劳动投入"还是"单位劳动的产出"，两种表的机会成本互为倒数，认错表后面全反。
2. 算机会成本而不是算绝对成本：分别写出两国的 $a_{LC}/a_{LW}$，比值小的那边生产布，另一边生产酒。
3. 定贸易方向与价格区间：贸易条件必须落在两国自给自足的相对价格之间，落在区间外说明有一方不愿交易。
4. 关税题先画图再分块：生产效应、消费效应、贸易效应、税收效应逐块列式，净损失只取两块三角形。
5. 有效保护率用增加值口径：$\mathrm{ERP}=(t-t_i a_i)/(1-a_i)$，$a_i$ 是投入品成本占产成品价格的比例，不是进口额占比。
**常见失分点**：拿绝对成本低的一方当出口方；关税题把政府税收算进净损失。

### 汇率与国际收支分析题
1. 先固定标价方向：全题只写一种——"1 外币 = X 本币"或"1 本币 = X 外币"，中途换写法必错。
2. 判升贬与升贴水主语：外币远期升水就是本币远期贴水，主语写在等号左边再下结论。
3. 折算方式由标价法决定：直接标价法下外币金额乘汇率，间接标价法下除，算完做一次单位检查。
4. 算升贴水年率并与利差比较：$(F-S)/S\times 12/n$，只有超出买卖价差与交易成本的部分才是可执行的套利。
5. 国际收支题先判借贷方再谈平衡：出口收汇记贷方、进口付汇记借方，储备变动是平衡项，最后用误差与遗漏项对账。
**常见失分点**：把汇率数值上升直接说成本币升值；算年率时误用远期价作分母。

### 单证与合规案例题
1. 先定三件事：适用法律（CISG 还是国内法）、贸易术语及其版本（是否写明 Incoterms 2020）、结算方式（信用证、托收还是汇付）。
2. 画时间轴：合同成立—备货—订舱—装运—交单—付款，每一步标出风险与费用由谁承担。
3. 信用证题逐项比对，不凭印象：受益人名称、金额与增减幅度、装运期与交单期、品名与数量、提单收货人与背书、保险金额与险别，逐条记不符点。
4. 判开证行责任：相符交单即须付款，不符点须在 5 个银行工作日内一次性提出；货物质量问题另案处理，不能当拒付理由。
5. 合规题做四项筛查：交易方、最终用户、最终用途、运输路径，任何一项命中就停下并留痕。
**常见失分点**：把 CIF 当成"到岸交货、风险到目的港"；只答"单据有问题"而不列具体不符点。

### 政策论述题（关税、汇率、贸易救济）
1. 先定位工具与作用环节：边境税、境内规制、汇率、补贴，工具不同福利图也不同。
2. 写机制链：工具→价格→数量→谁受益谁受损，每一环给出方向与量级。
3. 用福利框架收口：消费者剩余、生产者剩余、政府收入、净损失四本账分开算，再分配与效率损失不能混说。
4. 给一个可被数据否证的预测：论证若成立，还应同时观察到什么（进口量、转口贸易、价格传递率）。
5. 写结论反转条件：小国假设不成立、存在市场势力、对方报复，这三种情形要单独交代。
**常见失分点**：只写"加关税保护本国产业"，既没有净福利也没有分配，更没有量级。

## 7. 常见误区

1. **把绝对优势当比较优势** → 错在比的是绝对成本而不是机会成本；应先算两国各自的机会成本比，再定贸易方向。
2. **看到汇率数值上升就说本币升值** → 错在没先确认标价法；直接标价法下数值上升是本币贬值，动笔前先写出"1 外币 = X 本币"。
3. **把 CIF 当"到岸价、风险到目的港"** → 错在把费用划分点当风险划分点；CIF 风险仍在装运港装船时转移，卖方只是多付运费与保险。
4. **合同里只写 CIF 不写版本** → 错在默示版本有争议；应显式写"Incoterms 2020"，并核对 DAT 已改为 DPU 这类版本差异。
5. **信用证下拿货物质量问题要求开证行拒付** → 错在混淆基础合同与信用证两个法律关系；银行只管单据，质量问题走买卖合同索赔。
6. **把关税收入算成社会损失** → 错在把转移支付当效率损失；净损失只算生产扭曲与消费扭曲两块三角形。
7. **认为本币贬值一定改善贸易收支** → 错在跳过弹性条件与时滞；先验马歇尔-勒纳条件，再谈 J 曲线的先恶化后改善。

## 9. 交叉专业与后续方向

- **和经济学（economics）的区别**：经济学问"为什么会发生交换、福利如何变化"，国贸在这套模型前面加了一道边境——关税、配额、原产地、汇率制度，并把结论落到合同条款与单据动作上。同一道比较优势题，经济学答贸易所得，国贸还要答用什么术语成交、由谁付运费与保险。
- **和金融学（finance）的区别**：金融学把汇率当成资产价格来定价与对冲，问"这笔未来现金流今天值多少"；国贸把汇率当成报价与换算参数，问"这笔生意按这个价还能不能做、汇率动了利润还剩多少"。同一则加息新闻，金融学答折现率与久期，国贸答出口报价与结算币种。
- **和国际商法 / 法学的区别**：法学从规范出发找构成要件，国贸从交易出发找可执行条款；国贸不追求教义体系完整，只要求条款能落地、单据能对上。
- **后续方向**：考研可走国际贸易学、世界经济、国际商务专硕（MIB）；岗位常见于外贸业务与单证、跨境电商运营、关务与贸易合规、贸易融资与汇率风险管理、政府与商协会的贸易政策岗；进阶课程有 WTO 规则与争端解决、贸易救济实务、供应链金融、跨境电商合规。
- **一句边界**：本文件只讲方法与原理，不构成贸易合规、法律或投资意见；具体归类、税率、管制清单与制裁要求，以海关、商务主管部门和官方规则的最新文本为准。
