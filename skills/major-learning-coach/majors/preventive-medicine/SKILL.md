# 预防医学（preventive-medicine）

> 先读 `../../references/curriculum-rules.md`（难度与排序）与 `../../references/learning-card-template.md`（讲解结构）。
> 本文件只给这个专业的知识骨架与专业习惯。

## 1. 这个专业在训练什么

预防医学靠两件事吃饭：**把"谁在生病、为什么生病"换算成可比的人群指标**，以及**在预算与可执行性约束下设计能降低发病的干预**。

它和"打疫苗、发宣传单"的关系，大致等于会计和记账的关系：都是入口，都不是核心。核心是测量与推断——发病率的分母错一位，结论就反了；设计选错，数据再多也证明不了因果。

它和临床医学的分界是**决策单位**：临床的决策单位是一次就诊里的一个人，预防的决策单位是一群人、一段时间和一份预算。同一份体检报告，临床决定要不要复查，预防决定这类人该不该筛、几年筛一次、花这份钱划不划算。

**最容易误解的一点**：以为预防医学 = 健康教育。真正拉开差距的是 K01（频率指标）、K02（研究设计）、K03（偏倚）——这三块决定你说的"危险因素"站不站得住。

**最陡的三门课**：流行病学（因为考的是"选哪个设计 + 怎么排除偏倚"，不是背定义）、卫生统计学（因为要先判断前提才能选检验）、职业卫生与职业医学（因为要同时握住采样时长与限值口径）。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能对一份监测数据算出正确的发病率、患病率与死亡率，并逐项写明分子与分母各是什么。
2. 能按研究问题在横断面、病例对照、队列、试验之间选一个，并写出含纳排标准、对照与随访的方案。
3. 能在一段研究描述里定位选择偏倚、信息偏倚与混杂，说明偏倚方向并给出设计阶段的补救动作。
4. 能算出并解释 $RR$、$OR$、$AR$、$PAR$ 以及筛检的灵敏度、特异度、阳性预测值。
5. 能用区间估计、卡方检验、回归与生存分析处理人群数据，并说明每种方法成立的前提。
6. 能查标准原文核对一项环境或职业暴露是否超标，并说清限值对应的采样时长与保护对象。
7. 能写出一份含目标、措施、指标与评价设计的社区或职业干预方案，并说明它不能证明什么。

## 5. 术语与符号约定

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| 发病率 $I$ | 一定期间内新发病例数除以同期暴露人口 | 1/10 万、1/10 万·年 | 分母必须是"有可能发病的人"；分子里混进现患病例，算出来的就是患病率 |
| 患病率 $P$ | 某时点现患病例数除以同期平均人口 | 1/10 万 | 与发病率、病程满足 $P \approx I \times D$；治疗延长生命会让患病率升而不是降 |
| 死亡率 | 某期间全死因死亡数除以同期平均人口 | 1/10 万 | 分子是全死因；即使只算某病死亡，分母仍是全人群，不是该病病人 |
| 病死率 | 某病死亡数除以该病病例数 | % | 分母是病例不是人口；病死率高不等于该病在人群中常见 |
| 人年与发病密度 | 新发病例数除以暴露人年 | 例/人年 | 人年按每人实际观察时间逐段累加，失访后不再计；不能用"人数 × 年数"硬乘 |
| 粗率与标化率 | 直接标化按标准人口年龄构成加权 | 1/10 万 | 标化率只用于组间比较，不能当真实水平；间接标化算出来的是 $SMR$，不是率 |
| $RR$ | 暴露组发病率除以非暴露组发病率 | 无量纲，>1 提示危险 | 只有队列研究能直接算；病例对照没有分母，算不出 $RR$ |
| $OR$ | 病例组暴露比值除以对照组暴露比值 | 无量纲 | 只有疾病罕见时 $OR$ 才近似 $RR$；发病率高时 $OR$ 会把 $RR$ 夸大 |
| $AR$ | 暴露组发病率减非暴露组发病率 | 与率同单位 | 有单位，不能写"倍"；$RR$ 说相对强度，$AR$ 说绝对多出来的病例 |
| $AR\%$ | $AR$ 除以暴露组发病率 | % | 分母是暴露组发病率；与 $PAR\%$ 的分母（全人群发病率）不同，两个百分比不能互换 |
| $PAR$ 与 $PAR\%$ | 全人群发病率减非暴露组发病率 | 与率同单位 / % | 依赖人群暴露比例，换人群就换值；把 $AR$ 当 $PAR$ 报是高发错误 |
| $SMR$ | 实际死亡数除以按标准人群算出的预期死亡数 | 无量纲 | 预期数来自标准人群的年龄别死亡率；$SMR$ 不是标化率，也不能反过来算率 |
| 选择偏倚 | 入选对象不能代表目标人群 | 方向可正可负 | 一旦发生，加大样本和统计方法都纠正不了，只能改设计 |
| 信息偏倚 | 测量或回忆错误造成的错误分类 | 差异性、非差异性两类 | 非差异性错分通常把效应拉向无效值；差异性错分方向不定，不要一律说"低估" |
| 混杂偏倚 | 第三变量同时与暴露、结局相关，又不在暴露到结局的通路上 | 可正可负 | 不能用 $P$ 值判定混杂；判断标准是它在上游还是在下游 |
| 效应修饰 | 暴露效应随第三变量水平不同而不同 | 分层报告 | 与混杂相反：效应修饰是要找出来报告的，不是要被"控制"掉的 |
| 灵敏度 $Se$ | 真阳性数除以全部实际病人数 | 0–1 | 由试验与切点决定，不随患病率变；漏诊率是 $1-Se$，不是 $1-PPV$ |
| 特异度 $Sp$ | 真阴性数除以全部实际非病人数 | 0–1 | 与 $Se$ 同由切点决定；提高切点则 $Sp$ 升、$Se$ 降，不能两头都要 |
| 阳性预测值 $PPV$ | 真阳性数除以全部阳性数 | 0–1 | 随患病率上升而上升；低患病率人群里筛检，阳性中假阳性可能占多数 |
| 阴性预测值 $NPV$ | 真阴性数除以全部阴性数 | 0–1 | 同样随患病率变；不能把 $1-Se$ 写成 $NPV$ |
| 似然比 $LR$ | $LR+$ 等于 $Se$ 除以 $1-Sp$ | 无量纲 | 与患病率无关，是跨人群搬运证据的正确工具；$PPV$ 不能跨人群搬 |
| 剂量-反应关系 | 反应随暴露量单调变化 | 单位随介质而定 | 支持因果但不是必要条件；阈值效应与无阈值效应的外推方式完全不同 |
| 卫生标准/限值 | 职业接触限值如 PC-TWA、PC-STEL、MAC；饮用水与食品限量 | 各自单位与平均时间不同 | 限值绑定特定采样时长与保护人群，不能跨介质套用；它是风险管理线，不是绝对安全线 |
| 队列与病例对照 | 由因到果随访 / 由果溯因回看暴露 | 时间方向不同 | 罕见病、长潜伏期用病例对照；要算发病率、要确认时序用队列 |
| 罹患率 | 一次暴发中发病人数除以该次暴露人数 | % | 分母只算该次暴露的人，不是总人口；与发病率不能混着报 |
| 潜伏期与领先时间 | 暴露到发病 / 筛检提前发现的时间 | 天、年 | 筛检后生存期变长可能只是提前发现，叫领先时间偏倚，不等于真延长生命 |

## 6. 典型题型与解题套路

### 题型一：指标计算题（发病率、效应指标、筛检四格表）
1. 先把四格表摆正：是"暴露 × 结局"还是"试验 × 金标准"，两行两列各是什么，写清再代数。
2. 逐个确认分母：新发还是现患、全人群还是病例、人还是人年。分母错了，公式再对也是零分。
3. 先符号后数值，$RR$、$OR$、$AR$、$AR\%$ 各占一行并带单位，中间不四舍五入。
4. 做方向与范围检查：$RR<1$ 要说"保护因素"，不能写成"危险度 0.x 倍"；$AR$ 不可能大于暴露组发病率。
5. 结论落到可执行的一句话：这个暴露在人群中能少多少例，而不只是报一个比值。
**常见失分点**：把 $OR$ 直接当 $RR$ 解释，或给 $AR$ 加上"倍"。

### 题型二：研究设计题（给定研究问题，选设计并写方案）
1. 先用一句话写清暴露、结局、时间方向与目标人群，判断是"由因到果"还是"由果溯因"。
2. 按结局频率、潜伏期与可行性选设计：罕见病用病例对照；要算发病率或确认时序用队列；要证因果用随机对照试验。
3. 写五要素：对象与纳排标准、暴露或干预定义、对照怎么设、结局怎么测、随访多久。
4. 按三类偏倚各写一条控制动作：抽样框与应答率（选择）、盲法与统一测量（信息）、限制匹配随机化与多变量（混杂）。
5. 补样本量估算与统计方法，最后一句写"这个设计能支持到哪一步结论"。
**常见失分点**：只写设计名称，不写对照与随访，方案既不可执行也不可评价。

### 题型三：偏倚识别题（给一段研究描述，找偏倚并给补救）
1. 先复述研究对象是怎么进来的，与目标人群差在哪一类人，判断是否为选择偏倚。
2. 再看暴露与结局分别怎么测：谁回忆、谁记录、有无盲法，判定信息偏倚并区分差异性还是非差异性。
3. 列出所有同时与暴露、结局相关的第三变量，逐一检查它在不在暴露到结局的通路上，确定混杂。
4. 给方向：偏倚把效应拉向无效、放大还是方向不定。方向说不清，后面的解释都是猜。
5. 给补救：设计阶段能改的（抽样、盲法、随机化）优先；分析阶段只能部分修正（分层、回归、敏感性分析）。
**常见失分点**：把效应修饰当混杂去"控制"，或只说"存在偏倚"不说方向与补救。

### 题型四：干预方案题（社区、职业、营养、传染病）
1. 先定目标人群与可测量结局，把"降低发病率"落成具体指标、观察期与判定阈值。
2. 用三级预防定位：这项措施落在哪一级、改变哪个环节（暴露、易感性、早发现、并发症）。
3. 措施按层级排序：工程控制优先于组织管理，组织管理优先于个体防护，最后才是健康教育。能改环境的不要只改人。
4. 写实施要素：谁做、对谁做、频次多少、依从性怎么保、经费与伦理审查怎么走。
5. 写评价：对照组或前后比较、过程指标与结局指标、随访时点、最可能出现的偏倚及其应对。
**常见失分点**：通篇只写健康教育，不写工程与管理措施，被判为不可持续。

## 7. 常见误区

1. **用患病率当发病率** → 错在分子含旧病例、分母含已患病者；应先固定观察期，只数新发病例再算。
2. **在病例对照研究里报发病率和 $RR$** → 错在没有暴露人口分母；应报 $OR$，并写明"疾病罕见"这一近似前提。
3. **看到 $P<0.05$ 就说有因果关系** → 错在把统计显著当因果；应先排除选择、信息偏倚与混杂，再用 Hill 准则逐条评估。
4. **想靠提高灵敏度来救低阳性预测值** → 错在 $PPV$ 主要由患病率决定；应限定高危人群、做两步筛检，或改用似然比报告。
5. **把职业接触限值当"安全阈值"** → 错在限值绑定平均时间与采样方式，且为保护大多数劳动者留有不确定度；应写明是 PC-TWA 还是 PC-STEL 再比对。
6. **用标化率描述本地实际负担** → 错在标化率是加权后的比较工具；应同时给粗率（实际负担）与标化率（可比性）。

## 9. 交叉专业与后续方向

- **和临床医学的区别**：临床问"这个人下一步做什么"，用敏感度、获益与风险说话；预防问"这群人的危险因素是什么、怎么把发生率降下来"，用发病率、$RR$、$AR$ 与人群归因分数说话。同一份体检报告，临床决定复查与治疗，预防决定筛检策略与干预优先级。
- **和统计学的区别**：统计负责"从这点数据能推断到什么程度"，给方法与不确定性；预防负责"选哪个设计、测哪个指标、偏倚从哪来、结论能不能落到人群"。统计给出区间与 $P$ 值，预防必须回答"该不该筛、筛谁、多久筛一次、值不值"。
- **和卫生管理、卫生政策的区别**：预防给技术方案与效果证据，管理给预算、组织与执行链条；缺任何一半，方案都落不了地。
- **不编造数据与限值**：本文件只讲口径与方法，不提供任何具体发病率、$RR$、$OR$ 数值或标准限值数字。作业与研究里这些必须来自课程指定教材、原始文献或标准原文，并注明版本与年份——凭记忆写数字是本专业最容易被一眼看穿的错误。
- **后续方向**：疾控中心的传染病、慢病与卫生监测岗；卫生监督与职业卫生技术服务；妇幼与社区公共卫生；营养与食品企业合规；环境健康影响评价；考研方向为流行病与卫生统计学、劳动卫生与环境卫生学、营养与食品卫生学、卫生毒理学，或 MPH。
