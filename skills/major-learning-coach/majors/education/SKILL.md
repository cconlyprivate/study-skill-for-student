# 教育学（education）

> 先读 `../../references/curriculum-rules.md`（难度与排序）与 `../../references/learning-card-template.md`（讲解结构）。
> 本文件只给这个专业的知识骨架与专业习惯。

## 1. 这个专业在训练什么

教育学靠三件事吃饭：把“学生没学会”这类抱怨拆成可观察的学习事实；用学习理论解释它为什么发生；设计一个能在真实课堂里跑、并且能被证据检验的干预。它生产的不是正确答案，而是**可被反驳的因果主张 + 可复制的教学方案**。

外人最常误解的一点，是以为教育学 = 当老师 + 背教育家名言。实际上拉分的是研究设计与测量：一道教学设计题背后是目标分类学与“目标—评价—活动”一致性，一段现象分析背后是竞争解释与证据取舍。

分界线：心理学解释“人为什么会这样学”，教育学则问“在班级、课标、课时的约束下该怎么教，并且怎么证明教有效”；教育技术学接着问“用什么流程、资源与技术把它落地”。心理学可以只给机制不管可行性，教育学必须同时交机制、方案和证据。

**最容易误解的一点**：以为“懂教育”靠经验积累。实际考的是你能不能把经验转成可检验的假设——先补 K04（研究方法）与 K05（测量），再谈教学主张，否则写出来的只是口号。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能把一条国家教育目的逐层拆到一节课的可观察目标，四层不串位。
2. 能写出一课时教案：目标、评价任务、活动一一对应，并写出未达成时的调整动作。
3. 能用一套学习理论解释一个真实的学习困难，同时给出竞争解释与区分它们的证据。
4. 能为一个教学干预设计准实验或混合方法方案，写清抽样、工具、分析与伦理。
5. 能对一份试卷或量表给出效度、信度、难度、区分度的证据判断，并说出该改哪一题。
6. 能从课标与教材原文摘出可测要求，判断一份现成教案是否对标。
7. 能写出一篇 3000 字论述：概念界定、立场、三个分论点、最强反驳与回应。
8. 能在 10 分钟教研发言里用数据说清一个班的学习问题与下一轮改进。

## 5. 术语与符号约定

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| 教育目的 / 培养目标 / 课程目标 / 教学目标 | 四层逐级具体化，上一层管方向，下一层管可测 | 从国家文件落到一课时 | 层级串位是最高频硬错：把“培养全面发展的人”直接抄成一节课的目标 |
| 教学目标 ABCD | 对象 Audience、行为 Behavior、条件 Condition、程度 Degree | 一条目标四要素齐 | 写“学生能感受诗歌之美”，没有行为动词与程度，无法观察，也没法评 |
| 行为动词分级（布鲁姆：知识—领会—运用—分析—综合—评价） | 目标的可测层级 | 低阶到高阶 | 一条目标塞三个动词就测不出来；高档动词仍必须配可观察的行为 |
| 教学重点 / 教学难点 | 重点由课标决定，难点由学生起点决定 | 两者可重合也可不重合 | 把难点写成“内容难”；难点必须落到具体学生的具体卡点 |
| 三维目标 / 核心素养 | 旧框架为知识与技能、过程与方法、情感态度价值观；新框架为素养加学业质量 | 新课标用后者 | 借核心素养之名写三维目标的旧格式，评课时会被指框架混用 |
| 形成性评价 / 终结性评价 | 学习中为改进教与学 / 学习后为判定与分流 | 形成性看反馈回路是否闭合 | 把小测验一律叫形成性；没有反馈与调整，它只是迷你终结性 |
| 诊断性评价 | 教学前定位起点与先备知识 | 常与分班、补差相连 | 与形成性混为一谈；诊断完不改教学，等于白测 |
| 常模参照 / 标准参照 | 与他人比 / 与标准比 | 高考偏常模，学业质量偏标准 | 用常模排名解释达标率，会把“没达标”误读成“名次靠后” |
| 效度 / 信度 | 测到想测的东西 / 重复测量是否稳定 | 信度是效度的必要不充分条件 | 写“信度高所以有效”是硬错；高信度低效度的测验很常见 |
| 内容效度 / 结构效度 / 效标效度 | 三种效度证据来源 | 试卷主要看内容效度，量表看结构效度 | 只说“专家看过”就算内容效度，却不给双向细目表 |
| Cronbach α / KR-20 | 内部一致性系数 / 二分题型的内部一致性 | 0–1，课堂测验 0.6 以上常被接受 | α 高不代表单维；题目越多 α 越高，别把它当质量唯一指标 |
| 难度 P / 区分度 D | 通过率 / 高分组与低分组通过率之差 | $P=\bar{X}/X_{\max}$，$D=P_H-P_L$ | 难度不是 $1-P$；$P$ 在 0.5 附近区分度才可能最大 |
| 最近发展区（ZPD） | 独立水平与在帮助下可达水平之间的区间 | 一个区间，不是一个点 | 当成“难点”或“下一章内容”；ZPD 要用前测与分级提示实验测出来 |
| 支架（scaffolding） | 随能力提升逐步撤除的临时支持 | 必须递减并撤除 | 做成永久保姆：步骤表一直给，学生一撤支架就退回原点 |
| 建构主义 / 行为主义 | 知识由学习者主动建构 / 行为由刺激—反应—强化塑造 | 适用条件不同，不是谁取代谁 | 把建构主义等同于“学生随便讨论”，把行为主义等同于“过时”；技能自动化仍靠后者 |
| 量化 / 质性 / 混合方法 | 变量与统计推断 / 意义与过程解释 / 两者互补 | 按研究问题选，不按时髦选 | 用质性材料下因果结论；用问卷均值去解释个体经验 |
| 三角互证（triangulation） | 多来源、多方法、多研究者交叉验证 | 至少两种独立来源 | 把同一份问卷的多道题当多来源，其实同源，互证等于自证 |
| 霍桑效应 / 期望效应（罗森塔尔） | 被观察改变行为 / 教师期望改变学生表现 | 教育实验的首要效度威胁 | 只设实验组不设对照，效果分不清是干预还是被关注 |
| 前测—后测 / 对照组 | 准实验的基本结构 | 教育现场常无法随机分配 | 有前测无对照，或对照班换了教材，差异无法归因 |
| 效应量 $d$ / $p$ 值 | 差异有多大 / 差异是否可能由抽样误差造成 | $d\approx0.2$ 小、$0.5$ 中、$0.8$ 大 | 小样本显著性检验功效不足；只报 $p$ 不报 $d$，读不出实际意义 |
| 抽样：随机 / 分层 / 方便 / 整班 | 样本如何代表总体 | 教育研究常用整班取样 | 用两个班的结果推全省；不报样本来源与流失率 |
| 行动研究 | 教师在自己课堂里改—观察—再改的循环 | 计划—行动—观察—反思 | 把经验总结当行动研究：缺数据、缺迭代记录、缺同行观察 |
| 课堂观察记录（时间取样 / 事件取样） | 按时间片或事件单位记录行为 | 需预先定义行为编码 | 只写印象式评语，算不出频次，也做不了一致性检验 |
| 学业质量 / 增值评价 | 达到课标要求的程度 / 扣除起点后的净增长 | 增值需同一批学生的前后测 | 用一次期末均分给学校排名，忽略生源差异与回归效应 |

## 6. 典型题型与解题套路

### 教学设计题（给一篇课文或一个知识点，写一课时或一单元教案）
1. 先定四层落点：国家教育目的、课标学段要求、单元目标、本课时目标各是什么，只把最后一层写进教案。
2. 每条目标按“行为主体 + 行为动词 + 条件 + 程度”写，动词只选能当场看到的（说出、画出、比较、设计）。
3. 先写评价任务再写活动：每条目标配一份能收上来的证据（一道题、一个作品、一次口头解释），活动只为产出这份证据服务。
4. 用一个三题前测说明学生起点，难点要写成具体卡点（“分不清周长与面积”而不是“空间观念弱”）。
5. 补一句“如果这个班没达成，下一步改哪里”——没有这句，教案只是流程单。
**常见失分点**：目标写成“培养核心素养”这类不可测的话，活动和评价各自为政。

### 教育现象分析题（给一段课堂、学校或政策现象，要求解释）
1. 先把现象拆成“谁、在什么场景、发生了什么、可观察的证据是什么”，把抱怨改写成事实描述。
2. 选解释框架并说明为什么选它：发展规律、学习理论、社会功能、制度约束，只选一到两个，不要四套一起上。
3. 从框架推出可检验的中间机制，而不是直接贴标签（“因为他是留守儿童”不是解释，是分类）。
4. 给一条竞争解释，并写出什么证据能把两条解释分开。
5. 落到可执行的干预，并说明怎么判断它起效。
**常见失分点**：通篇价值判断（“这样不对”“应该减负”），既没有机制也没有证据。

### 研究设计题（给一个研究问题，要求写方案）
1. 把问题写成含自变量、因变量、对象的可检验假设，并写明预期方向。
2. 定抽样与分组：能否随机？不能就写准实验的配对方案，并列出要控制的混淆变量。
3. 每个变量配一个工具：优先用已有量表，自编题要写清维度来源，并给出信度效度的检验计划。
4. 写量化分析计划：哪个假设用哪个统计量回答，样本量够不够。
5. 补质性材料与伦理：访谈观察补机制，知情同意、匿名、退出权写全。
**常见失分点**：变量与工具对不上（研究“兴趣”却只测分数），只写方法名不写具体操作。

### 论述题（“谈谈”“评析”“结合实际说明”）
1. 开头三句交底：界定核心概念、给出立场、列出三个分论点。
2. 每个分论点按“主张—依据（理论或研究）—例子（课堂或政策）—小结”四步走，一段一个，不要串。
3. 依据要指名：写“维果茨基认为”比写“建构主义认为”稳，且要能对上教材与原著。
4. 加一段“反方最强理由 + 我的回应”，这是论述题与简答题的分水岭。
5. 结尾回到题干本身，给出可操作的两条启示，不要空喊口号。
**常见失分点**：只堆观点不给出处；三段并列却都在说同一件事。

## 7. 常见误区

1. **把教育目的当教学目标写** → 错在层级串位；应先查课标学段要求，再落成本节课可观察的行为与程度。
2. **先写活动再补目标** → 错在评价与目标脱钩；应逆向设计：目标→证据→活动，顺序反过来就必然对不上。
3. **把形成性评价等同于“多考几次”** → 错在缺反馈回路；应每考一次就改一次教学，并留下改动记录。
4. **用信度证明效度** → 错在混淆两个概念；应先给内容效度证据（双向细目表或专家一致性），再谈稳定性。
5. **把最近发展区当“难点”** → 错在没测潜在水平；应用分级提示实验找出“帮多少能做成”，再定支架层级。
6. **文献综述写成观点串联** → 错在没有争议点；应按“结论—样本—方法—局限”四栏做表，再写分歧与缺口。
7. **质性访谈只问“你觉得怎么样”** → 错在拿到的是评价不是过程；应追问具体事件与做法（“上一次你是怎么处理的”）。

## 9. 交叉专业与后续方向

- **和教育技术学的区别**：教育学则问“人怎样学会、什么样的教与学关系成立、凭什么说它有效”，教技问“用什么设计、资源、平台与评估工具把它落地”，产出是课程包、学习系统与评价方案。同一节课，教育学答目标与依据，教技答流程、资源与技术选型——教育学不能只会讲理念不讲可行性，教技不能只会做工具不问为什么。
- **和心理学（尤其发展与教育心理学）的区别**：心理学把行为拆成可测变量，追求可重复的因果机制，常在实验室与量表里做；教育学要在此基础上回答“在班级、课标、课时的约束下该怎么教”，必须同时处理价值判断与制度条件，因此离不开准实验与质性证据。心理学问“为什么会这样”，教育学接着问“所以该怎么教、怎么证明教有效”。
- **和社会学的区别**：社会学解释教育如何再生产分层与流动，教育学要在既定结构下给出还能做什么干预，并对干预负责。
- **和学科教学（语文、数学等）的区别**：教育学给通用框架（目标、评价、方法），学科教学给内容转化能力，也就是把学科知识转成学生能接住的表征，这块是 PCK 的地盘，教育学只能给一半。
- **后续方向**：教育学原理、课程与教学论、教育史、比较教育学、教育经济与管理、教育技术学等学硕；教育硕士（学科教学、教育管理）与 311 统考；中小学教师与教研员、课程与教材研发、教育测量与评估、教育政策研究。
