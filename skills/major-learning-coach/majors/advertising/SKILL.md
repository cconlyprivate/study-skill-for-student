# 广告学（advertising）

> 先读 `../../references/curriculum-rules.md`（难度与排序）与 `../../references/learning-card-template.md`（讲解结构）。
> 本文件只给这个专业的知识骨架与专业习惯。

## 1. 这个专业在训练什么

把商业目标**翻译成传播方案**：对谁说、说什么、在哪说、说完怎么知道有没有用。四个答案都要落到可执行的稿子、可买的版位、可测的指标上，缺一项就是半成品。

**一句话画像**：把商业目标翻译成能被记住的传播方案。

这行靠三件事吃饭：判断得准（策略）、说得动人（创意）、算得清楚（媒介与效果）。三件事的权重随岗位变，但没有一件可以完全外包给别人——只会写文案的人，改不了"这次为什么卖不动"。

**最容易误解的一点**：以为广告 = 写文案、拍片、有创意。创意是第三步。第一步是策略判断（K03），第二步是取舍（K05 的单一主张），第三步才是创意（K04）；顺序颠倒，稿子越漂亮越没用。

外人的第二个误解是"有创意就等于有效"。评奖与卖货常不重叠：评奖看新意，客户看目标达成。所以答题时先写清目标与指标，再谈创意好不好，否则再好的点子也拿不到采分点。

和新闻学的界线：新闻对事实负责，广告对效果负责——但广告不能靠编事实换效果，这是合规底线而不是风格问题（见第 9 段）。和市场营销的界线：营销决定卖什么、卖多少钱、铺到哪；广告只负责 promotion 这一支里的"怎么说"。

**最陡的三门课**：广告策划与创意（因为要在信息不全时先做一个可辩护的取舍）、消费者行为学（因为要抵住"我觉得用户会喜欢"的直觉）、市场调查与广告效果（因为要承认自己的投放可能没起作用）。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能把一句"提升品牌影响力"改写成含指标、基准、时间窗的传播目标，并说明为什么这个指标能验收。
2. 能在 90 分钟内写出单页 brief：五要素齐全，主张只有一句，且每条主张后跟着可核查的证据。
3. 能为一个品类画二维定位图，标出一个可选空位，并说清选它要放弃什么。
4. 能对同一卖点写出三种调性版本的文案，并说明各配哪类人群与哪个渠道。
5. 能算出一组投放数据的 CPM、CPC、CPA、ROAS、ROI，并指出哪个指标在被误读。
6. 能对一个 A/B 结果判断显著性，样本不足时明确写"方向性结论"而不是"验证成功"。
7. 能对 8 条待投文案逐条标出绝对化用语与不可证实功效，并改到可过审。
8. 能在 10 分钟内用一条主线讲完提案，并答住"钱为什么这样分"的追问。

## 5. 术语与符号约定

广告的"符号"是几套并行的心智模型和一堆口径不一的比率。写错的下场不是扣一分，是整段结论反转。

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| AIDA | 注意—兴趣—欲望—行动，受众对一条广告的反应顺序 | 四段，非线性 | 它是"广告反应"模型，不是购买决策路径：真实购买会跳段、回环，这里的 Action 常常只是点开，不等于购买 |
| 消费者决策五阶段 | 问题识别—信息搜索—方案评估—购买—购后行为 | 五段，可回环 | 别把 AIDA 与它逐段对号：一个讲单条广告的反应，一个讲品类里的行为，两套"行动"不是一件事 |
| 涉入度 | 购买的重要性和风险感 | 高 / 低两档 | 高涉入才走中心路径；用论证式长文案打低涉入品类，永远打不动 |
| USP | 每则广告给一个"买我不买别人"的具体利益，且对手没提过 | 一句话，必须可证 | 把"高品质、更好"当 USP：不可证也不独特；USP 是断言，不是创意手法 |
| 品牌形象论 | 产品同质化时靠形象与联想做长期差异化 | 长期资产 | 与 USP 混用：USP 答"为什么买"，形象答"为什么记住、为什么喜欢"；用短期销量考核会杀死形象广告 |
| 定位 | 在潜在顾客心智里占一个词，参照系是竞争对手 | 一个词或短语 | 把定位当口号；定位必须先说"相对于谁"，不舍弃一部分人就是没定位 |
| 品牌资产 | 认知、联想、质量感知、忠诚 | 四要素 | 把知名度当资产全部：只有认知、没有联想与忠诚，一降价就流失 |
| 广告目标 / 营销目标 | 广告管沟通效果，营销管销量与份额 | 广告目标须含指标、基准、时间窗 | 拿销量当广告 KPI：销量被价格、铺货、渠道左右，投放无法单独归因 |
| single-minded proposition | 一条广告只说一个主张 | 一句 | 一条片子里塞三个卖点；主张超过一句说明没做取舍，受众一个也记不住 |
| 创意简报五要素 | 背景、目标、目标受众、单一主张、支持证据 | 一页纸 | 写成一页要求清单或免责条款；缺"支持证据"的主张就是空话，执行层只能瞎猜 |
| 洞察（insight） | 受众没说出口、一听就认的真相 | 能引出"对，我就是这样" | 把观察当洞察："年轻人爱熬夜"是描述，撑不起主张；洞察要带张力 |
| 媒介组合 | 多渠道按角色分工：打认知、打转化、打复购 | 3–5 个主投 | 把"投得多"当组合；没有分工的组合只是把钱摊薄，复盘时说不清谁有用 |
| 曝光 / 触达 / 频次 | 曝光是次数，触达是人数，频次是人均看几次 | 频次常写平均数，$频次=\frac{曝光}{触达}$ | 把曝光当触达：1000 万曝光可能是 200 万人看了 5 次，也可能是 1000 万人看了 1 次 |
| CPM | $\text{CPM}=\frac{\text{花费}}{\text{曝光}}\times 1000$ | 元 / 千次曝光 | 各平台曝光口径不同（加载即算、还是可见才算），比 CPM 前先统一口径 |
| CPC | $\text{CPC}=\frac{\text{花费}}{\text{点击}}$ | 元 / 次点击 | CPC 低不等于便宜：点击便宜、转化贵，合起来看 CPA |
| CPA / CPL | 每次转化（或每条线索）的成本 | 元 / 次 | 各平台"转化"定义不同（加购算不算），口径不一不能横向比 |
| CTR / 转化率 | 点击率与转化率 | 0–1 | 分母写曝光还是触达、点击后访客还是全体访客，不写清结论就不可比 |
| ROAS 与 ROI | $\text{ROAS}=\frac{\text{收入}}{\text{花费}}$；$\text{ROI}=\frac{\text{收入}-\text{成本}}{\text{成本}}$ | ROAS 无上限，ROI 可为负 | 把 ROAS 2 说成 ROI 200%：ROAS 2 对应 ROI 100%，且还没扣制作费与人力 |
| A/B 测试 | 两版只差一个变量，随机分流后比较 | 单变量 | 同时改标题和主图，差异归因不了；分流不随机会直接污染结论 |
| 统计显著性 / p 值 | 假设两版无差异时，出现当前差异的概率 | 常用 $p<0.05$ | 把 p 值当效果大小：p 小只说明"不像偶然"，不说明这个提升值得投 |
| 最小可检测效应 | 在当前样本量下能可靠测出的最小提升 | 由基线转化率与样本量决定 | 几百次曝光就宣布"转化翻倍"；先算样本量再开测，测完不再加样本 |
| 归因窗口 | 点击或曝光后多少天内计入转化 | 常见 1、7、30 天 | 不同窗口的 ROI 直接对比；窗口越长数字越好看，因为混进了自然转化 |
| 增量（incremental lift） | 投放带来的、本来不会发生的那部分转化 | 需对照组才能测 | 把自然转化算成广告功劳；无对照组只能说相关，不能说因果 |
| 绝对化用语 | 最、第一、国家级、顶级、唯一等 | 广告法禁止 | 以为改成"更"就合规：没有依据的比较级同样构成误导 |
| 虚假宣传三要件 | 内容虚假或引人误解、足以欺骗误导、影响购买决策 | 行政处罚与民事赔偿 | 只查字面真假、不查"引人误解"：选择性引用真实数据一样违法 |
| 特殊品类审批 | 药品、医疗器械、保健食品、金融、教育等须审批或备案 | 按品类白名单 | 先投放再补批文；功效表述必须与批件一致，不能自行扩写 |

## 6. 典型题型与解题套路

### 策划案写作题（给品牌与目标，写一份 campaign 提案）
1. 先把客户给的目标翻成一句传播目标：对谁、改变什么（认知/态度/行为）、多久、用什么指标验收。写不出指标就回去问，不要先写创意。
2. 用 3C 与品类地图找空位：竞品都在说同一句话吗，哪句话还没人说、又确实是目标人群在意的。
3. 写单页 brief，把单一主张锁成一句话。这一步定不下来，后面每一页都会跟着变。
4. 按七段搭骨架（背景—问题—策略—创意—媒介—预算—评估），每节写结论式小标题，不写"创意展示"这种栏目名。
5. 交稿前把预算与评估对齐：钱怎么分、什么数值算达标、多久复盘，三者要能互相验证。
**常见失分点**：通篇没有"问题定义"就直接给创意和排期；评估段只写"提升知名度"，没有基准值和时间窗。

### 创意阐述题（给一句主张或一张稿，写创意说明）
1. 先写策略来源：承接哪条主张、对应哪个人群洞察。不要写"灵感来自生活"。
2. 再写创意机制：这个形式为什么能让人记住——冲突、意外、通感、场景还原，指出具体的那一下。
3. 写取舍：为什么用这个画面、这句话，而不用另外那个；评委要看的正是取舍。
4. 写合规检查：会不会被读成功效承诺、有没有绝对化用语、特殊品类要不要批文。
5. 最后给延展：这个概念还能怎么长成系列，证明它不是一次性点子。
**常见失分点**：通篇形容词（震撼、走心）没有机制；创意说明写得比稿子精彩，评委一看稿就落差。

### 消费者分析题（给数据或场景，做人群画像与洞察）
1. 先定口径：谁在买、谁在用、谁在付钱，三者不同就分开写。
2. 按决策五阶段摆事实：每个阶段他做什么、在哪做、卡在哪；卡点就是传播机会。
3. 区分"说的"与"做的"：问卷态度与后台行为矛盾时以行为为准，并解释矛盾从哪来。
4. 把发现压成一句洞察加一句主张：洞察要能引出"对，我就是这样"，主张要能被这句洞察撑住。
5. 标证据强度：每条结论注明来自访谈、问卷还是平台数据，样本多少。
**常见失分点**：画像写成年龄性别收入三行标签；把"年轻人喜欢个性化"这种万能句当洞察。

### 效果评估题（给投放数据，算指标并判断是否达标）
1. 先统一口径：曝光、点击、转化、收入各怎么定义，时间窗多长，含不含自然量。
2. 分三层算：媒介层（CPM、CPC、CTR）、转化层（CPA、转化率）、商业层（ROAS、ROI）。不要跳过前两层直接谈 ROI。
3. 做对照：有对照组就报增量，没对照组只报相关，并写明这是本次评估的局限。
4. 判显著性：算出提升率与样本量；样本不足就写"方向性结论，需扩量验证"。
5. 给结论与下一步：达标还是未达标、哪个环节最值得改、下一轮做什么实验。
**常见失分点**：用 ROAS 冒充 ROI；没有对照组却写"广告带来了 X 万销售"。

## 7. 常见误区

1. **先想创意再想策略** → 错在跳过"对谁说、说什么"；正确顺序是先写 brief 锁主张，再让创意去承接，否则改稿无终点。
2. **把 AIDA 当购买路径用来预测销量** → 错在模型错配；AIDA 描述对广告的反应，销量预测要用决策五阶段加实际转化数据。
3. **用 ROAS 冒充 ROI** → 错在分母不同；ROAS 只比收入与花费，ROI 还要扣制作、人力、渠道成本，报数时必须写清是哪一个。
4. **brief 写成一页要求清单** → 错在没有单一主张；把五要素各压成一句，主张超过一句就回客户那儿重新对齐。
5. **把曝光量当触达人数** → 错在混淆次数与人数；报数时同时给触达与频次，两个数一起才说得清"有没有被看见"。
6. **A/B 测试同时改多个变量** → 错在无法归因；一次只改一个变量，其余保持不变，样本量先算够再开测。
7. **只为过审把"最"改成"更"** → 错在仍无依据；比较级也要有可核查来源，否则仍是引人误解的虚假宣传。

## 9. 交叉专业与后续方向

- **和新闻学的区别**：新闻对事实负责，广告对效果负责。同一套文案技巧，约束反向：新闻不许有偿、不许夸张；广告的版位天生是买来的，但**不许靠编事实换效果**。写"新闻式软文"两边都不认——新闻嫌它有偿，广告监管嫌它不可识别。
- **和市场营销的区别**：营销决定卖什么、定什么价、铺到哪、怎么促销（4P 里的 product/price/place），广告只做 promotion 里的"沟通"这一支。营销问"这门生意怎么做成"，广告问"这句话怎么说才被记住、被相信、被行动"。所以广告题里出现定价与渠道，是背景条件，不是答题主场。
- **和传播学的区别**：传播学解释效果机制（为什么有效），广告要把机制换成预算内的动作（多少钱、买哪些版位、几天内出结果）。传播学作业可以只解释，广告作业必须落到可执行、可测量的方案。
- **和设计学的区别**：设计学以"解决问题 + 可用"为中心，广告以"目标达成"为中心。同一张海报，设计问信息层级与可用性，广告问它有没有让人记住那句主张。
- **合规底线（写任何广告文案与策划案都适用）**：不得作虚假或引人误解的宣传；不得使用"国家级""最高级""最佳"等绝对化用语；不得对商品性能、功效、疗效作无法证实的断言，涉及数据、排名、专利、认证必须标明来源与适用范围；保健食品、药品、医疗器械、金融、教育等品类须先取得审批或备案，功效表述不得超出批件。答题时把这几条当硬约束写在方案里，比事后删词更省事。
- **后续方向**：考研走广告学、传播学或新闻与传播专硕（MJC）；岗位有策略策划（planner）、文案（copywriter）、媒介策划与购买、品牌经理、增长与效果投放、广告效果研究；进阶课程为品牌管理、数据驱动的营销分析、计算广告、消费者神经科学。
