# 社会学（sociology）

> 使用前先读 `../../references/curriculum-rules.md`（难度与排序规则）与
> `../../references/learning-card-template.md`（讲解结构）。
> 本文件只提供"这个专业的知识骨架与专业习惯"，不要在这里重复通用协议。

## 1. 这个专业在训练什么

个人苦恼大多不是品德问题：失业、离婚、升学焦虑、被派单算法困住，都有超出个人选择的成因。社会学的活儿是把这个转换做出来——把"我怎么这么失败"改写成"哪一类人在什么结构位置上更容易遇到这件事"，然后问这个说法能不能被材料否证。

它靠两样东西吃饭：**理论给的机制**与**方法给的证据**。只有机制没有证据是评论，只有证据没有机制是数据搬运。

外人常以为它是"谈感想、讲道理、表个态"。它的判据恰恰相反：一句论断如果写不出"什么情况下它是错的"，就不算社会学的论断。

**最容易误解的一点**：以为社会学等于发问卷、做调查。问卷只是 K02 里的一道工序，真正决定研究成败的是先想清楚"比较谁和谁"（研究设计），以及承认自己的数字有多不可靠（测量与误差）。

**最陡的三门课**：社会统计学（因为要同时握住变量层次、抽样分布和"这个检验配哪种数据"）、社会学理论（因为考的是论证结构，不是人名主张）、因果推断（因为结论的可信度全押在几个无法直接检验的假设上）。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能把一句"我觉得"改写成含自变量、因变量、比较组与作用机制的可检验命题。
2. 能为一个研究问题写出抽样方案（抽样框、抽样方法、样本量、加权），并说出它最可能在哪一步失真。
3. 能读完一张列联表或回归表，说清系数含义、显著性、最可能的偏误方向，并指出这张表不能支持什么结论。
4. 能把一段访谈记录或一组开放题答案编码成 3–5 个类属，附编码规则与反例个案。
5. 能用三位古典理论家的机制对同一现象给出三种解释，并设计一个能区分它们的比较。
6. 能为一项政策设计准实验（DID、断点、工具变量），写出识别假设和一个真能做的检验。
7. 能对一篇已发表研究写 300 字评审意见，指出它的结论在哪一步超出了证据。
8. 能在论文措辞上分清相关与因果、样本与总体、描述与解释，并在同一段里不混用。

## 5. 术语与符号约定

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| 变量层次 | 定类（名义）、定序、定距、定比四种测量尺度，决定能算什么 | 定类只有类别，定序有顺序，定距等距但零点任意，定比有真零点 | 定序变量不能求算术平均（满意度 1–5 分算均值只是约定俗成的近似）；定距变量不能说"是两倍"（智商 120 不是 60 的两倍）；只有定比才能做比值 |
| 操作化 | 把概念拆成可观察的指标与问卷题目 | — | 操作化不是"编几道题"，要先写清概念的定义维度，再让每个维度至少落一个指标；跳过这一步是论文被拒的第一原因 |
| 信度 | 重复测量得到一致结果的程度（重测、折半、内部一致性） | 0–1（Cronbach α） | 信度高只说明稳定，不说明测对了；一份每次都测出同一个错误答案的问卷，信度可以很高 |
| 效度 | 是否测到了概念本身（内容、效标、结构效度） | — | 效度算不出来，只能用设计论证；"预调查通过所以有效"是错的，预调查查的是信度与可答性 |
| 抽样误差 | 抽到哪几个人带来的随机偏差，随样本量增大而缩小 | 用标准误表示，约与 $\sqrt{n}$ 成反比 | 只有概率抽样才有抽样误差；样本量再大也压不掉非抽样误差，两类必须分开说 |
| 非抽样误差 | 覆盖、无应答、测量、录入四类误差 | — | 不随 $n$ 下降；网上问卷 $n=5000$ 常比概率抽样 $n=1000$ 更不可信，因为误差大头在覆盖与无应答 |
| 抽样框 | 实际用来抽样的名单，与目标总体之间总有缺口 | — | 抽样框不等于总体；用手机号抽居民会漏掉不用手机的人，而漏掉的那批往往正是结论的关键 |
| 应答率与无应答偏差 | 应答者占应访者的比例，以及不答者与答者的系统性差异 | 0–1 | 应答率低本身不致命，致命的是无应答与因变量相关；报告时必须交代追访与加权做了什么 |
| 社会期望偏差 | 受访者按"应该怎样"而非"实际怎样"回答 | — | 自报家务时间、捐款、投票率会系统性偏高；解释时要说清偏差方向，别拿自报数当客观事实 |
| 李克特量表 | 一组同向陈述加 5 点或 7 点同意程度，多题加总成量表分 | 单题定序，加总近似定距 | 单题只能报频数与中位数；加总分的均值是约定不是事实；反向题必须先重新编码 |
| 标准差 $s$ 与标准误 $SE$ | 前者描述个体离散，后者描述统计量的抽样波动 | 与因变量同单位 | $SE=s/\sqrt{n}$；把标准误当标准差报，等于把"样本均值的精度"说成"个体的差异" |
| 显著性水平 $\alpha$ | 事前设定的第一类错误上限，常取 0.05 | 0–1 | $\alpha$ 事前定、$p$ 值事后算；"5% 水平显著"指 $p<0.05$，不是"有 95% 概率为真" |
| $p$ 值 | 原假设成立时，得到当前或更极端结果的概率 | 0–1 | 它不是"原假设为真的概率"；大样本下几乎任何差异都显著，显著必须与效应量一起报 |
| 置信区间 | 由样本算出的区间估计，重复抽样下约 $1-\alpha$ 比例覆盖真值 | 与参数同单位 | "95% 置信区间"不是说真值有 95% 概率落在里面；区间跨 0 等于该水平下不显著，宽度约随 $\sqrt{n}$ 缩小 |
| 卡方检验与期望频数 | 检验列联表中两变量是否独立 | 期望频数应 ≥5 | 期望频数小于 5 要合并类别或用精确检验；卡方显著只说"不独立"，强度要看 Cramér's V 或列百分比差 |
| 列百分比方向 | 按自变量分组去算因变量的百分比，才能读出方向 | % | 按因变量方向算百分比会把结论读反；表头注明"按 X 分组"，正文按同一方向读 |
| 回归系数 $\beta$ | 自变量每变一个单位，因变量平均变多少（其余变量不变） | 因变量单位/自变量单位 | 它含"平均"与"其他条件不变"，不能说"某个人会变多少"；只有对数-对数模型里系数才是弹性 |
| 相关与因果 | 相关是可观察的共变，因果需要一个可辩护的反事实 | 相关系数 −1 到 1 | 相关可能由第三变量造成；没有设计支撑时只能写"关联"，写"导致"就是把结论抬到了证据之上 |
| 内生性 | 解释变量与误差项相关，系数不再等于因果效应 | — | 三个来源：遗漏变量、双向因果、测量误差；工具变量要同时满足相关性与外生性，外生性无法用数据直接检验 |
| 反事实与平行趋势 | 因果效应 = 处理组实际结果 − 处理组未受处理时的同时点结果 | — | 这个差永远观测不到；DID 的可信度全押在平行趋势上，必须画处理前趋势图，不能只跑回归 |
| 社会资本 | 嵌入社会网络、可被动员的资源与信任规范 | 分个体层与集体层 | Coleman、Bourdieu 指个体可动员的资源，Putnam 指集体层的信任与参与；用一个层的指标解释另一个层的结果，就是层次谬误 |
| 结构与能动性 | 结构是相对稳定的关系模式与资源分布，能动是行动者的选择与抵抗 | — | 结构不等于"外部环境"，能动不等于"自由意志"；吉登斯要的是二重性（结构既是条件也是结果），不是二元论（谁决定谁） |
| 社会事实 | 涂尔干：外在于个体、对个体有强制力、普遍存在的行动与思维方式 | — | 社会事实只能用其他社会事实解释，不能用个体心理动机解释；这一步划开了社会学与心理学 |
| 理想类型 | 韦伯：为分析而构造、现实中不存在的纯粹类型 | — | 它是分析工具，不是"理想状态"；拿它当应然标准去评价现实，是最常见的误读 |
| 场域、惯习、资本 | 场域是相对自主的关系空间，惯习是内化的性情倾向，资本分经济、文化、社会、符号四类 | — | 惯习不是习惯，它有生成性；符号资本是"被承认的"资本，不能与经济资本加总成一个分数 |
| 基尼系数 | 收入分布不平等程度的面积比 | 0–1，0 为完全平等 | 分组数据算出的基尼是下界；跨群体比较要先说清是收入还是财富，财富基尼通常高得多 |
| 绝对流动与相对流动 | 绝对流动看多少人换了位置，相对流动看出身与去向的关联强度 | % 与优势比 | 结构变迁会抬高绝对流动率而相对流动率不变；判断机会是否更公平只能看相对流动率 |
| 网络密度与中心性 | 密度是实际连线占可能连线的比例，中心性分度、接近、中介三种 | 0–1 与排序值 | 三种中心性给出的答案常常不同，报告必须写明哪一种；密度依赖网络边界的定义，换边界就换结论 |

最常写错的三处：把定序变量当定距算均值还比较"3.7 比 3.5 高很多"；把标准误当标准差报；用集体层的社会资本指标解释个体层的结果。

## 6. 典型题型与解题套路

### 研究设计题（"要回答这个问题，你会怎么研究"）
1. 先把题目改写成一句可检验的比较：谁的什么，和谁比，差多少才算有差别。
2. 定分析单位与总体，写清抽样框、抽样方法、样本量与算样本量的依据。
3. 做操作化链：概念 → 维度 → 指标 → 变量层次，并标出最不可靠的那个指标会往哪边偏。
4. 选比较结构（横断面、追踪、DID、断点、实验），写出识别假设和一个真能做的检验。
5. 交代伦理与局限：知情同意、隐私、谁能接触原始数据，以及结论最可能被什么推翻。
**常见失分点**：只写"发问卷、做访谈"而不写比较结构，读者无法判断你凭什么说这是因果。

### 统计结果解读题（给一张表或一段软件输出）
1. 先读表头：分析单位、样本量、变量层次、标准误类型、缺失值怎么处理。
2. 逐系数按变量层次读：定类看组间差，定序看方向，定距与定比看单位效果，对数模型才读百分比。
3. 三件事一起报：效应大小、置信区间、显著性；三者打架时以效应大小为主线写结论。
4. 追问识别：可能漏了哪个变量、有没有反向因果、样本能不能外推，各写一句方向判断。
5. 最后补一句"这张表不能支持什么"，这往往是最能得分的地方。
**常见失分点**：只圈星号不读系数；把 $p<0.05$ 说成"影响很大"；把样本结论直接写成总体结论。

### 理论辨析题（"韦伯和涂尔干有什么不同"）
1. 先写两人各自要回答的问题，不要先背观点：问题不同，答案才不同。
2. 用同一组维度对照：分析单位（个体行动还是社会事实）、解释机制（理解还是因果功能）、结构的位置、方法主张。
3. 各配一个当代经验例子，说明按这套理论会去看什么变量、会忽略什么。
4. 写解释边界：这套理论解释不了什么，后来谁补的，补完留下了什么新问题。
**常见失分点**：把人名与主张背成标签对照，不写两人回答的是不同问题；只列差异，不写差异带来的经验后果。

### 访谈与问卷材料分析题（给一段记录或几道题）
1. 先判材料类型：访谈看意义与过程，问卷题看测量质量，两者判据不同。
2. 访谈材料按三层编码：说了什么、在什么情境下说、为什么这样说；单独标出与研究者预期相反的话。
3. 问卷材料逐题查四件事：是否双重问题、是否诱导、选项是否互斥穷尽、是否超出受访者的知识范围。
4. 写清材料能支持到哪一级：质性材料多数只能生成假设，要检验假设得另配设计。
**常见失分点**：把受访者的叙述直接当事实（要分"他怎么说"与"发生了什么"）；改问卷题只改措辞，不动测量层次。

## 7. 常见误区

1. **把个人困扰直接写成个人原因** → 错在跳过结构位置；应先问"哪一类人在这个位置上更容易遇到这件事"，再回到个案找机制。
2. **样本大就代表总体** → 错在把样本量当代表性；先看抽样框漏了谁、应答率多少、加权做了什么，再看 $n$。
3. **对定序变量算均值并比较大小** → 错在把定序当定距；应报分布与中位数，或明确声明加总分只是近似约定。
4. **不显著就写"没有影响"** → 错在把"未能拒绝"当"证明无效"；应报置信区间与统计功效，样本太小时只能说"证据不足"。
5. **用社会资本解释个人收入，却拿社区平均信任做自变量** → 错在层次错配；个体层结论用个体层指标，集体层变量要写清它经由什么机制作用到个体。
6. **访谈里挑几句支持自己观点的话当证据** → 错在选择性引用；应先定编码规则、报出反例个案，再谈模式。
7. **把相关写成因果** → 错在没处理能力、家庭背景这类遗漏变量；要么改成"关联"，要么补一个能识别的设计。

## 9. 交叉专业与后续方向

- **和心理学（psychology）的分界**：心理学以个体内部过程（认知、情绪、人格、动机）为分析单位，解释同一件事时找个体差异；社会学以关系模式与资源分布为分析单位，解释同一件事时找位置差异。同一份抑郁数据，心理学问"哪种人格更易感"，社会学问"哪类职业、哪种支持网络下患病率更高"。跨界的正确做法是先声明层次，再谈机制；用一个层的变量解释另一个层的结果，就是层次谬误。
- **和政治学（political science）的分界**：政治学以权力在国家与正式制度中的配置为核心，变量常是国家、政体、选举；社会学把国家当成众多组织场域之一，更关心国家之外的关系如何塑造政治结果。同一场抗议，政治学答"它如何改变选举与政策"，社会学答"谁被动员进来、靠什么网络、组织资源从哪来"。
- **和人类学（anthropology）的分界**：人类学传统上以小型社群的整体志为目标，重意义与情境；社会学更常做大样本比较与统计推断。做田野时借人类学的反思性，做推断时守社会学的抽样纪律。
- **和经济学（economics）的分界**：经济学从既定偏好与约束推行为，社会学追问偏好与约束本身如何被关系和制度塑造。同一道"为什么不上大学"，经济学算收益率，社会学看家庭资本与同伴网络。
- **后续方向**：考研可走社会学、社会工作、人口学、社会政策；就业常见于用户与市场研究、政策评估、公益与社会组织、数据指标岗；进阶课程是社会网络分析、多层模型、计算社会科学、历史比较方法。
