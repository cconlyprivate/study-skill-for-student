# 数学与应用数学（mathematics）

> 先读 `../../references/curriculum-rules.md`（难度与排序）与 `../../references/learning-card-template.md`（讲解结构）。
> 本文件只给这个专业的知识骨架与专业习惯。

## 1. 这个专业在训练什么

两件事：**把一句自然语言精确成定义，再从定义推出结论**；以及**判断这个结论在哪条边界上才成立**。前者是证明，后者是条件与反例——一致连续、绝对收敛、几乎处处，都是"边界"的具体形态。

它和中学数学的分界线不在难度，而在**没有现成算法**：中学的题给你一条路，大学的题先要你判断"这属于哪一类、这一步凭什么是合法的"。会算不等于会证，会证不等于知道反例在哪。

和统计学的分界：数学问"对任意分布这个不等式成立吗"，统计问"手上这份数据能支持什么结论、犯错的概率多大"。

**最容易误解的一点**：以为数学系是"更难的算题"。真正拉开差距的是 K01-4（ε-δ 与量词）、K03-4/K03-5（线性映射与 Jordan 形）、K06-3/K06-4（收敛与积分交换）——这三处考的是"能不能构造"和"能不能否定"，计算只占一小部分。

**最陡的三门课**：实变函数（因为要把"长度"重建成测度，旧直觉全部失效）、数学分析（因为 ε-δ 与一致收敛要求同时握住量词与放缩）、高等代数（因为从矩阵计算跳到线性映射要换一整套语言）。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能把一句自然语言命题改写成带 `\forall` / `\exists` 的量词串，并机械地写出它的否定。
2. 能独立完成一道 ε-δ 或一致连续的证明，δ 是自己构造出来的，不是引用现成结论。
3. 能对给定的级数、反常积分、函数列判断收敛性，并给出判别依据或一个反例。
4. 能把线性方程组、线性映射、二次型互相翻译，并说出同一对象在三种语言下的样子。
5. 能解一阶与二阶常系数方程，并把解的行为（稳定性、周期性、爆破时刻）讲清楚。
6. 能在 Lebesgue 积分框架下判断极限与积分能否交换，并指出缺的是哪一条定理的哪个条件。
7. 能对一道概率题写出样本空间、分布与数字特征，并说明近似用了哪个定理、误差多大。

## 5. 术语与符号约定

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| `\forall` / `\exists` | 对任意 / 存在 | 量词 | 否定时两个都要换：`\neg\forall x\exists y` 得到的是 `\exists x\forall y\neg`，只换一个必错 |
| `\varepsilon`-`N` | 数列极限定义 | `\varepsilon` 为正数，`N` 为正整数 | `N` 必须出现在 `\varepsilon` 之后，且可依赖 `\varepsilon`；先写 N 再说"对任意 ε"是逻辑倒置 |
| `\varepsilon`-`\delta` | 函数极限定义 | `\delta` 可依赖 `\varepsilon` 与点 `a` | `\delta` 若只依赖 `\varepsilon`，那是在定义一致连续，不是在定义极限 |
| `\lim_{n\to\infty} a_n` | 数列极限 | 指标 `n` 为整数 | 数列不能写 `\lim_{x\to\infty}`；`n\to\infty` 的下标不能省，省了就看不出是数列还是函数 |
| `\limsup` / `\liminf` | 上极限 / 下极限 | 总存在，可取 `\pm\infty` | 与 `\sup a_n` 不是一个东西：`\sup` 是一个数，`\limsup` 是部分上确界的极限 |
| `\sup` / `\inf` | 上确界 / 下确界 | 可以取不到 | 说"最大值"前先确认可达；`\sup` 存在不代表有最大元 |
| `\{x \mid P(x)\}` | 集合描述法 | 竖线读作"使得" | 竖线要写 `\mid`；空集写 `\varnothing`，`\{\varnothing\}` 是含一个元素的集合而不是空集 |
| `\subset` / `\subseteq` | 包含于 | 各教材约定不同 | 中文教材的 `\subset` 常含相等，英文常指真包含；答题时先声明用哪一种 |
| `f: X \to Y` | 映射 | 定义域与陪域 | 箭头只说明两端的集合，不等于满射；单射、满射、双射必须单独说 |
| `o(\cdot)` / `O(\cdot)` | 严格低阶 / 有界 | 必须注明趋近方式 | `o(x)` 与 `O(x)` 不能互换，且要写清是 `x\to0` 还是 `x\to\infty`，同一个式子在两处结论相反 |
| 指标起点 | 数列从 `n=1`，幂级数与矩阵元素从 1 | 整数指标 | 编程习惯从 0 开始，抄代码到证明里会整体错一位；`\sum_{n=0}^{\infty}` 与 `\sum_{n=1}^{\infty}` 差一项 |
| `dx` 的位置 | 积分变量与微分配对 | 写在被积式末尾 | 换元后 `dx` 必须一起换，只改上下限是最常见的错；二重积分里 `dx\,dy` 的次序要和区域写法对应 |
| 矩阵 `A=(a_{ij})` | 第 i 行第 j 列 | 行在前、列在后 | 写转置时把 `a_{ij}` 换成 `a_{ji}`，行列标签最容易被对调；`A^T` 不是 `A^{-1}` |
| `AB` | 矩阵乘法 | 内维相同才能乘 | 不可交换；`AB=0` 推不出 `A=0` 或 `B=0`；`(AB)^T=B^T A^T` 顺序要反 |
| `\lvert A\rvert` | 行列式 | 是一个数 | 矩阵是表、行列式是数；`\lvert A+B\rvert` 一般不等于 `\lvert A\rvert+\lvert B\rvert` |
| `\lambda` 与特征向量 | 满足 `Ax=\lambda x` 的非零 `x` | 特征向量不能是零向量 | 重根时几何重数不超过代数重数；求出 `\lambda` 后必须验证对应特征向量存在 |
| `\equiv` | 恒等 | 对定义域内一切点成立 | `f(x)\equiv 0` 与"某点函数值为 0"是两件事，证明里混用会被判错 |
| `\Rightarrow` / `\Leftrightarrow` | 推出 / 等价 | 逻辑联结词 | 只证了一个方向却写 `\Leftrightarrow`；逆命题不成立时必须给反例而不是省略 |
| 单调 | 不减 / 严格增 | 依教材而分 | 中文"单调递增"常指 `\le`，"严格递增"才是 `<`；用错会连带影响反函数与收敛定理的条件 |
| 收敛 / 绝对收敛 | 级数与反常积分 | 绝对收敛必收敛，反之不成立 | `\sum\lvert a_n\rvert` 收敛才叫绝对收敛；条件收敛的级数不能随意重排 |
| `P(A \mid B)` | 条件概率 | 要求 `P(B)>0` | 别写成 `P(A/B)`；`P(A\mid B)` 与 `P(B\mid A)` 一般不等，混用是概率题第一失分点 |
| `a.e.` | 几乎处处 | 除去一个零测集 | "几乎处处"不等于"处处"；实变里要写清等式成立的例外集测度为零 |
| `\lVert x\rVert` / `\lvert x\rvert` | 范数 / 绝对值 | 向量用双竖线，标量用单竖线 | 混用会让不等式不成立；`\lVert\cdot\rVert_p` 的 p 改变常数，估计时不能随手换 p |
| `\sum_{n=1}^{\infty} a_n` 收敛的必要条件 | 通项趋于 0 | 必要不充分 | 把 `a_n\to 0` 当收敛的充分条件，是判断收敛题最常见的错误 |

## 6. 典型题型与解题套路

### 证明题（ε-δ、中值定理、一致收敛）
1. 先把结论翻译成量词串，写清 `\forall\varepsilon` 与 `\exists\delta` 各自的依赖关系，再动笔。
2. 从要证的式子出发倒推：把 `\lvert f(x)-A\rvert` 放大成只含 `\lvert x-a\rvert` 的表达式，每步放缩注明用了哪个条件。
3. 由放缩结果反解 `\delta`（或 `N`），写成"取 `\delta=\min\{\cdot,\cdot\}`"的显式形式。
4. 回读量词顺序与"对任意"的作用范围，确认 `\delta` 没有悄悄依赖 `x`。
**常见失分点**：只写"当 x 充分接近 a 时"，始终没构造出 δ；放缩时用了尚未证明的估计。

### 计算题（极限、积分、行列式、通解）
1. 先定型：0/0、∞/∞、`1^{\infty}`、可分离、恰当、线性，类型决定方法，定型错了后面全错。
2. 先符号后数值：写出公式再代数，中间不四舍五入，最后一步才代入。
3. 用等价无穷小或泰勒把高阶项一次处理干净，不要反复洛必达。
4. 算完做检查：积分值的符号、概率是否落在 [0,1]、级数首项是否对得上。
**常见失分点**：用洛必达前不验证 0/0；换元后忘改 `dx` 与上下限；开方丢绝对值导致符号错。

### 判断与构造反例题（收敛性、可积性、可对角化）
1. 先把命题写成"对任意都存在"或"存在使得对任意"，明确要证还是要证伪。
2. 证伪优先找反例，从经典库里挑：Dirichlet 函数、`1/x`、交错级数、幂零矩阵、几乎处处收敛但不依测度收敛的函数列。
3. 反例要验三件事：满足全部前提、违反结论、计算可复核。
4. 判断收敛时先查必要条件（通项趋于 0），再按比较、比值、根值、Dirichlet 判别的顺序试。
**常见失分点**：举了个"看起来很怪"的例子却没验证前提；把"通项趋于 0"当成收敛的充分条件。

### 应用题（建模、概率、微分方程）
1. 先设变量，写清单位与取值范围（`t\ge 0`、`p\in[0,1]`、`n` 为正整数）。
2. 写守恒或平衡关系，列出方程或分布，逐项说明来源。
3. 求解后回到原问题解释结果，检查边界情形（初值、极端参数）是否合理。
4. 代一个可手算的特例（`t=0` 或 `p=0`）做量纲与数值的 sanity check。
**常见失分点**：设了变量却不写定义域；把条件概率写成联合概率；答案不带单位也不检查量级。

## 7. 常见误区

1. **用举例和画图代替证明** → 错在把"对这一个函数成立"当成"对一切成立"；应该先写量词，再对任意给定的对象构造论证。
2. **认为连续就可导、可导就连续可导** → 错在漏了 `\lvert x\rvert` 在 0 处这个反例；应该用左右导数分别算，并记住可导强于连续。
3. **交换极限与积分（或求和）次序不查条件** → 错在默认一切收敛都能交换；应该先确认一致收敛、单调或控制函数，指出用的是哪条收敛定理。
4. **把 `\sum a_n` 收敛与 `\sum\lvert a_n\rvert` 收敛混同** → 错在忽略条件收敛；应该先判绝对收敛，失败后再用 Dirichlet 或 Leibniz 判条件收敛。
5. **矩阵运算照搬实数直觉** → 错在假设 `AB=BA`、`AB=0` 推出零因子；应该每次先看维度，并记住可逆才谈消去律。
6. **条件概率方向写反** → 错在把 `P(A\mid B)` 当成 `P(B\mid A)`；应该先写样本空间与事件，再套定义 `P(A\mid B)=P(A\cap B)/P(B)`。

## 9. 交叉专业与后续方向

- **和统计学的区别**：数学证"对任意分布都成立的不等式"，统计答"这份数据支持哪个结论、犯第一类错误的概率多大"。
- **和计算机的区别**：数学要最一般的存在性与唯一性，计科要"多项式时间内能算出来"的构造；同一个问题，数学问有没有解，计科问能不能算。
- **和物理的区别**：物理从现象写方程并接受近似，数学要求先证方程有解、再谈解的性质与稳定性。
- **后续方向**：基础数学（分析、代数、几何与拓扑）、应用数学（偏微分方程、数值计算、优化）、概率统计与精算、金融数学；考研常见组合是数学分析加高等代数，转向应用则补数值分析与编程。
