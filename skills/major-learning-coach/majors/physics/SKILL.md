# 物理学（physics）

> 先读 `../../references/curriculum-rules.md`（难度与排序）与 `../../references/learning-card-template.md`（讲解结构）。
> 本文件只给这个专业的知识骨架与专业习惯。

## 1. 这个专业在训练什么

物理系的人靠三件事吃饭：**把一段现象压缩成"变量 + 方程 + 初值/边值条件"的模型**（建模）；**在数据不全时给出量级正确、方向正确的答案**（估算）；**优先用守恒律与对称性绕开中间过程的细节**（守恒）。所以同一道题，会算的人交出数值，会物理的人先问"选哪个参考系、该用哪条守恒律、哪些项可以忽略"。

它和"套公式算数"不是一回事。物理的难点在**选模型与定近似**，数学只是执行手段；会解微分方程不等于会建模。

它和数学的分界在**近似的合法性**：数学要求对一切情形成立，物理只要求在你声明的尺度与近似下与实验相符，且必须说清近似何时失效。

**最容易误解的一点**：以为物理成绩差是因为数学不够。真正拉开差距的是 K01-5（角动量与刚体）、K02-2（高斯面选取）、K05-2（薛定谔方程与波函数）、K06-1（麦克斯韦方程组）——这四处考的是"想到该建什么模型"，不是推导技巧。

**最陡的三门课**：电动力学（因为要同时握住矢量恒等式、边界条件与相对论）、量子力学（因为"轨迹"必须换成"概率幅"，中学图像全部失效）、热学（因为熵与第二定律的表述差一个字就判错）。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能把一段文字描述的现象写成"变量 + 方程 + 初值/边值条件"，并列出所用近似及其适用范围。
2. 能不查资料估出一个陌生物理量的量级，并说出每个因子的依据。
3. 能对多过程题先判断该用哪条守恒律，并逐条验证合外力（矩）为零、非保守力不做功等条件。
4. 能从麦克斯韦方程组推出波动方程，并指出每一步用到哪条矢量恒等式。
5. 能对一维势场写出定态薛定谔方程、解出能级与波函数，用 $|\psi|^2$ 解释一次测量的可能结果。
6. 能设计一个能区分两种假设的实验，写出测量公式与不确定度预算。
7. 能读懂一份实验报告，指出其数据处理与误差估计里站不住脚的地方。

## 5. 术语与符号约定

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| 量纲式 $[\mathrm{L}]^a[\mathrm{M}]^b[\mathrm{T}]^c$ | 用基本量表示导出量的幂次 | SI 七个基本量，力学只用到 L、M、T | 量纲只能否决不能确认：$v=at$ 量纲对却漏了初速度；逐项写量纲核对，比"再检查一遍"有效 |
| SI 基本单位 | m、kg、s、A、K、mol、cd | 其余单位由它们导出 | 单位要一路带着算；$pV$ 得到的是 $\mathrm{Pa\cdot m^3}$，不化成 $\mathrm{J}$ 就与能量项相加会错 |
| 量符号与单位符号 | 量用斜体、单位用正体 | $m$ 与 $\mathrm{m}$、$T$ 与 $\mathrm{T}$ | 写"$5m$"等于自造符号；$T$ 可指周期、温度或特斯拉，$A$ 可指面积、振幅或安培，必须靠下标区分 |
| 数量级估算 | 结果写成 $a\times10^n$，$1\le a<10$ | 通常只要求落在一个量级内 | 只报幂次不给依据等于猜；把锚点记成尺子：室温 $kT\approx\frac{1}{40}\,\mathrm{eV}$、$N_A\approx6\times10^{23}$、$c\approx3\times10^8\,\mathrm{m/s}$ |
| 参考系与惯性力 | 惯性系中牛顿定律成立；非惯性系补 $\boldsymbol{F}_{\text{惯}}=-m\boldsymbol{a}_0$ | 平动加速系与转动系各有一套惯性力 | 惯性力没有施力物体、不满足牛顿第三定律；受力图里必须注明"该力来自参考系选择"，否则力的清单对不上 |
| 保守力与势能零点 | 势能由力与零点共同定义，$\boldsymbol{F}=-\nabla E_p$ | 重力、弹簧、库仑力可定义势能 | 零点可任取但一题只能取一个；换零点只平移 $E_p$ 不改 $\Delta E_p$；势能属于系统，不能记在单个物体上 |
| 电势零点与无穷远 | $V=\frac{1}{4\pi\varepsilon_0}\frac{q}{r}$ 默认取无穷远为零 | 只适用于有限大带电体 | 无限长带电线、无限大带电面取无穷远会发散，必须换零点；把有限体的公式照搬是电磁学第一错 |
| 右手定则 | 叉积、安培环路、洛伦兹力三处各用一个 | 比划前先固定视线方向 | 三个定则说法不同却来自同一右手系；只凭手势容易左右镜像，应先用坐标算 $\boldsymbol{a}\times\boldsymbol{b}$ 再核对 |
| 高斯面方向 | 闭合面取外法线为正 | $\oint\boldsymbol{E}\cdot d\boldsymbol{S}=Q_{\text{内}}/\varepsilon_0$ | 高斯面必须闭合且取外法线；取内法线则通量整体差一个负号，而 $Q_{\text{内}}$ 只算面内那部分 |
| 环路绕向与电流正负 | 先定绕向，再用右手螺旋定电流正方向 | 安培环路与法拉第环路同一套约定 | 绕向一改两边同时变号；只改一边必错；闭合回路要先定法线，且法线与绕向成右手关系 |
| 磁通与感应电动势符号 | $\varepsilon=-\frac{d\Phi}{dt}$，负号即楞次定律 | $\Phi$ 与 $\varepsilon$ 共用一套法线约定 | 先算大小再定方向最容易丢负号；正确顺序是定法线、算 $\Phi$ 符号、求导、再用"阻碍变化"复核 |
| 态函数与过程量 | $U$、$S$、$T$ 是态函数，$Q$、$W$ 是过程量 | 态函数只依赖初末态 | 写 $Q=U_2-U_1$ 是把过程量当态函数；循环一周 $\Delta U=0$ 但 $W\ne0$，这是热学第一失分点 |
| $\Delta$ 与 $d$ 与 $\delta$ | 有限差 / 全微分 / 非全微分 | 数学上不严格但物理通用 | $dQ$ 习惯写 $d$，严格应是 $\delta Q$；只需清楚它不可积、不能写成 $Q_2-Q_1$ |
| 有效数字 | 末位与不确定度对齐 | 中间结果多留一位 | $1.20$ 与 $1.2$ 精度不同；$1000$ 写 $1\times10^3$ 才能表明只有一位有效数字；不能由公式反推位数 |
| 不确定度 A 类与 B 类 | 重复测量取 $s/\sqrt{n}$；仪器误差限取 $a/\sqrt{3}$ | 置信概率约 68% | 仪器允差不是标准差；只测一次就只剩 B 类；两类应平方合成，不能相加再除 2 |
| 不确定度传播 | $u_c^2=\sum_i\left(\frac{\partial f}{\partial x_i}\right)^2u_i^2$ | 要求各分量互不相关 | 加减用绝对不确定度、乘除用相对不确定度，混用会系统性高估；求偏导前先把函数化到最简 |
| 常量取值与精度 | $c$、$g$、$e$、$h$、$k_B$ | 位数必须与题给数据一致 | 数据只有两位有效数字时把 $g$ 写成 $9.80665$ 是假精度；改写常数等于伪造精度，必须注明取值 |
| $E$ 的多重身份 | 电场强度、能量、杨氏模量 | 视语境 | 同一题里 $E$ 可能既是场强又是能量；一律加区分：$\boldsymbol{E}$、$E_k$、$E_p$、$E$（模量） |
| $p$ 与 $P$ | 压强 / 动量 / 功率 | $\mathrm{Pa}$、$\mathrm{kg\cdot m/s}$、$\mathrm{W}$ | 压强与动量同用 $p$ 是教材常态；流体与碰撞混合题里必须声明，否则看不懂 $p=\rho v$ 是哪个 $p$ |
| $T$ 与 $t$ | 热力学温度 K、摄氏温度 °C、周期 s、张力 N | 热学公式一律用 K | 把 $27$ 直接代进 $pV=nRT$ 会得荒谬结果；建议温度写 $T$、时间写 $t$、周期写 $T_0$ 并在首行声明 |
| $\omega$、$\nu$、$\bar\nu$ | 角频率 rad/s、频率 Hz、波数 $\mathrm{cm^{-1}}$ | $\omega=2\pi\nu$，$\hbar=h/2\pi$ | 把频率当角频率是振动与量子题的常见错；$E=h\nu=\hbar\omega$ 一旦混用就整体差 $2\pi$ |
| 光程差与相位差 | $\Delta=n\,d$，$\delta=\frac{2\pi}{\lambda_0}\Delta$ | 相位换算必须用真空波长 | 用介质波长换算会多乘一个 $n$；半波损失只能在反射的那一束上加一次，加两次就反了 |
| 相位与初相 | $x=A\cos(\omega t+\varphi)$ | 相位差的正负表示谁超前 | "超前/滞后"在时间与空间两种语境下方向相反；答题写 $\pm\Delta\varphi$ 的数值，不要只写形容词 |
| 本征值、期望值与简并度 | $\hat{A}\psi=a\psi$，$\langle A\rangle=\sum_i\lvert a_i\rvert^2a_i$ | 测量值只能是本征值 | 叠加态不能说"测得 $a_1$"；能级简并度 $g$ 必须乘进态数与配分函数，漏乘就少算了自旋 |

## 6. 典型题型与解题套路

### 计算推导题（受力/场 → 守恒律 → 解方程）
1. 先写研究对象、参考系、已知量与待求量，画出受力图或场图，标出每个力的施力物体。
2. 逐条判断能否用守恒律：合外力为零用动量，合外力矩为零用角动量，只有保守力做功用机械能。能用就先绕开过程细节。
3. 不能用守恒律再列微分方程或积分式，符号推到最简，最后一步才代数值并带单位。
4. 代三个极端情形（$t=0$、参数取 0 或 $\infty$、忽略某个力）检查符号、量纲与极限行为。
**常见失分点**：一上来就分解力、列完方程却没发现守恒律能一步跳过；在有摩擦的题里默认机械能守恒。

### 证明题（对称性、守恒、量纲）
1. 把结论写成"若 P 则 Q"或"对任意 x 存在 y"的形式，圈出前提里能用的每一条。
2. 选工具：对称性论证（高斯面、镜像法）、守恒律、量纲分析、反证法。
3. 每步只做一件事并注明依据；近似（$r\gg a$、小角、非相对论）必须显式声明并写出适用条件。
4. 收尾检查前提是否全用上；有前提没用，多半证得不完整。
**常见失分点**：用待证结论去推中间步骤；不声明就做小量展开，近似失效的边界没交代。

### 估算题（费米问题、量级判断）
1. 把问题拆成 2–4 个可独立估计的因子（尺度、密度、速率、时间）。
2. 每个因子只留一位有效数字，写成 $a\times10^n$，并注明依据是常识、题给数据还是已知常数。
3. 用锚点换算：人体密度≈水、室温 $kT\approx\frac{1}{40}\,\mathrm{eV}$、$N_A$、$c$、$\hbar c\approx200\,\mathrm{MeV\cdot fm}$。
4. 幂次相加后检查答案是否落在物理上可能的区间；与已知值差 $10^2$ 以上要回头找漏项。
**常见失分点**：把估算写成三位有效数字；丢了 $4\pi$ 或 $\frac{1}{2}$ 这类无量级因子就宣布"数量级错了"。

### 实验误差分析题（不确定度预算）
1. 写出完整测量公式，列出每个直接测量量、所用仪器、量程与分辨力。
2. 逐个量判断 A 类（重复测量统计）与 B 类（仪器误差限），给出各自的标称不确定度。
3. 按函数结构选合成方式：加减取绝对量、乘除取相对量，复杂函数先取对数再求偏导。
4. 写成 $y=\bar y\pm u_c$（两者末位对齐）并给相对不确定度，指出贡献最大的那一项。
5. 与理论值比较时算 $|y-y_0|/u_c$，落在 $2u_c$ 内才说"相容"，不要只写"基本吻合"。
**常见失分点**：把仪器允差当标准差；只测三次就报四位数字；漏掉单次测量量的 B 类分量。

## 7. 常见误区

1. **用守恒律不看适用条件** → 错在只记住"动量守恒"却没验证合外力为零，或忘了某个方向的分量各自守恒；应逐方向判断，并写出该方向力相互抵消的理由。
2. **高斯面随手画成球** → 错在没利用对称性，导致 $\boldsymbol{E}$ 提不出积分号；应先判断对称类型（球、柱、面），再让高斯面与场线正交或相切。
3. **列方程时就把数字代进去** → 错在中间四舍五入并混进不同单位；应符号推到最简，数值只在最后一步出现，全程带单位。
4. **把 $dQ$ 当全微分去积分** → 错在以为 $Q$ 是态函数；应走 $\Delta U=Q-W$，路径相关的量要用可逆路径或分段计算，不能直接积分。
5. **误差分析写成定性描述** → 错在只写"误差较小"或"结果基本一致"；应给出 $u_c$、相对不确定度与最大来源，再用 $2u_c$ 判断是否相容。
6. **量子题沿用经典轨道图像** → 错在给电子画轨迹、说"绕核速度"；应改用本征值、$|\psi|^2$ 与期望值，势阱基态能量不为零正是因为不能静止。

## 9. 交叉专业与后续方向

- **和数学的区别**：数学证"对任意情形成立"，物理答"在这个尺度、这个近似下算出可检验的数"。同一道题，数学问方程有没有解、解是否唯一；物理问这个解对应哪个实验、误差多大、近似何时失效。
- **和电子/电气工程的区别**：电子与电气从器件和端口出发，关心电路特性、信号与实现；物理从场与微观机制出发，关心为什么会有这个端口特性。同一道 RC 题，电气答时间常数与滤波特性，物理答电荷弛豫与能量去向。
- **和材料/化学的区别**：材料问"这个成分与工艺给出什么性能"，物理问"这个性能背后的机制能否用一个模型算出来"；交汇点是固体物理与表征手段。
- **底线：不编造实验数据与常数精度**：不替用户"补"一组测量值让曲线好看，也不凭空给出实验值；常数一律写到与题给数据相同的精度（数据两位有效数字时 $g$ 就写 $9.8$），缺数据时明说缺什么、需要什么条件才能测。
- **后续方向**：理论物理（凝聚态、粒子物理、引力与宇宙学）、实验物理（光学、低温、加速器与探测）、计算物理与科学计算、量子信息与量子计算、医学物理与能源；考研常见组合是普通物理加量子力学或电动力学。
