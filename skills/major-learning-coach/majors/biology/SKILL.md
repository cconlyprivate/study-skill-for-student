# 生物科学（biology）

> 先读 `../../references/curriculum-rules.md`（难度与排序）与 `../../references/learning-card-template.md`（讲解结构）。
> 本文件只给这个专业的知识骨架与专业习惯，不重复通用协议。

## 1. 这个专业在训练什么

生物科学训练的是**跨尺度找因果**：同一个现象要能在分子、细胞、个体、群体四层之间来回翻译，并且说清哪一层是机制、哪一层只是现象。

它和"背名词"不是一回事。名词只是坐标，真正拉开差距的是把"表型 → 细胞行为 → 分子事件 → 证据"连成一条能被实验推翻的链：这条链断在任何一环，答题就退化成背教材段落。

它也不是工程。生物工程问"能不能放大、产率多少、成本几何"，生物科学问"为什么会这样、证据够不够、换一个体系还成立吗"。

**最容易误解的一点**：以为生物是"看图说话"的软科学。实际上它是最依赖对照与统计的实验科学之一：没有对照的图不能下结论，没有重复的差异不能算发现。

| 学期 | 课程 | 模块 | 先修 | 难度感受 |

| 大一下 | 生物化学 | K02 | K01 | 从形态转到分子，要同时管结构和能量 |

| 大二下 | 遗传学 | K04 | K03 | 概率与系谱一起上，一步算错全题作废 |
| 大三上 | 分子生物学 | K05 | K02、K04 | 机制链条长，调控部分背不完只能推 |
| 大三上 | 实验方法与生物统计 | K06 | — | 公式不多，但"该用哪个检验"最容易错 |

**最陡的三门课**：生物化学（因为代谢通路要在结构、能量、调控三层同时记）、遗传学（因为每一步都带着概率，比例还有前提）、分子生物学（因为调控是组合逻辑，只能靠推）。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能对任一生物现象写出"表型—细胞—分子"三层因果链，并标出哪一环有实验证据、哪一环只是推断。
2. 能根据杂交结果或系谱算出基因型概率，并用卡方检验判断是否符合预期比例。
3. 能给一组酶动力学数据求出 Km 与 Vmax，并据图形判断抑制类型。
4. 能读懂琼脂糖凝胶、SDS-PAGE、扩增曲线与显微图，先判断对照是否成立，再谈结论。
5. 能为一个假设写出含处理组、阴性与阳性对照、生物重复和统计方法的实验方案。
6. 能判断结论的适用范围：体外还是体内、模式生物还是人、相关还是因果。
7. 能查原始文献，指出结论对应哪张图、样本量多少、有没有独立重复。

## 5. 术语与符号约定

生物记号的坑集中在三处：**方向**（谁读谁、谁传给谁）、**相对量**（内相对外、观测相对理论）、**样本单位**（n 到底是什么）。下面每条都对应一个真实扣分点。

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| 中心法则方向 | DNA→RNA→蛋白质，默认单向 | 以模板链读向为准 | 把逆转录当"推翻中心法则"；应写"RNA→DNA 是补充路径，不改变主方向" |
| 模板链与编码链 | 模板链被聚合酶读，编码链与 mRNA 同序列 | — | 两条链写反，mRNA 就写成互补链；先在图上标 5' 与 3' 再动笔 |
| 5'→3' 方向 | 核酸链的书写与合成方向 | 逐段标注 | 基因上下游与引物朝向都按转录方向叙述；不标方向等于没写 |
| 基因型与表型 | 等位基因组合与可观察性状 | — | 把表型直接当基因型；应写"表型 = 基因型 + 环境 + 发育随机性" |
| 显性、隐性、共显性 | 杂合子的三种表现方式 | — | 共显性是两种产物都检出（AB 血型），不完全显性是中间表型（粉花），常被写成同一个 |
| 遗传比 9:3:3:1 | 双因子杂交的期望比例 | 比例 | 套比例前先写前提：自由组合、完全外显、无致死、受精随机 |
| 卡方 χ² | 观测与理论偏离的标准化平方和 | 无单位 | 自由度 = 类别数 − 1；合并类别或估计过参数都要改自由度 |
| P 值 | 原假设成立时出现当前或更极端结果的概率 | 0–1 | P 小不等于效应大，P 大于 0.05 不等于"证明无差异"；要同时给效应量与置信区间 |
| n 与 2n | 染色体组数与倍性 | 人类 2n = 46 | n 是一组的条数不是总条数；写"2n = 46，n = 23"，不要写"n = 46" |
| 生物重复与技术重复 | 独立个体与同一样本的多次测量 | 统计的 n 只算生物重复 | 用技术重复凑 n 会人为缩小误差，把噪声当发现 |
| Km | 速率达 Vmax/2 时的底物浓度 | 与底物同单位，常用 mmol/L | Km 小表示亲和力高；"Km 大所以亲和力大"是最常见的反写 |
| Vmax | 底物饱和时的最大速率 | 如 μmol/(L·min) | 双倒数图纵轴截距是 1/Vmax，横轴截距是 −1/Km，负号常丢 |
| kcat 与 kcat/Km | 每分子酶的转换数与催化效率 | s⁻¹ 与 M⁻¹s⁻¹ | 比较不同酶要用 kcat/Km；只比 Vmax 会被酶量差异误导 |
| 膜电位 Vm | 膜内相对膜外的电位差 | mV，静息约 −70 mV | 符号约定是"内减外"；去极化是变正，超极化是变负，别按绝对值叙述 |
| 平衡电位 | 某离子净电流为零时的膜电位 | mV，由能斯特方程给出 | 价数代错，或把自然对数写成常用对数；25 ℃ 时 RT/F 约 25.7 mV |
| 电化学驱动力 | 浓度梯度与电场的合力 | mV | 只看浓度梯度判流向会错；K+ 平衡电位接近 −90 mV，静息时仍有外流倾向 |
| 浓度梯度方向 | 高到低为顺梯度 | — | 顺梯度可被动，逆梯度必须耗能；写运输方式前先写清梯度朝哪边 |
| PCR 循环 | 变性、退火、延伸三步 | 温度与时间 | 退火温度过高扩不出，过低出杂带；产物按指数增长，不是线性累积 |
| 电泳判读 | 按大小与电荷分离 | 核酸 bp 或 kb，蛋白 kDa | 琼脂糖胶上小片段跑得快，标尺从下往上增大；条带亮不等于表达高，要有内参与上样量对照 |
| 模式生物 | 果蝇、线虫、斑马鱼、小鼠、酵母、拟南芥 | — | 外推到人前要说明基因与通路的保守性，不能把小鼠剂量直接换算成人 |
| 基因频率 p、q | 等位基因在群体中的比例 | 0–1，p + q = 1 | 与基因型频率 AA、Aa、aa 混用；平衡时 Aa = 2pq，不是 2p |
| 连锁距离 cM | 1% 重组率记为 1 cM | cM | 中间发生双交换时重组率会低估图距，远距离必须做校正 |
| 外显率与表现度 | 携带致病基因者是否发病与病得多重 | 0–100% | 外显率不全时系谱不按孟德尔比例出现，别急着判"新发突变" |
| 母系遗传 | 线粒体与叶绿体基因随母传递 | — | 与 X 连锁隐性区分：线粒体病父亲几乎不传，X 连锁病儿子只从母亲得 |
| 对照 | 空白、阴性、阳性、载体与未处理对照 | — | 缺阳性对照时"没信号"分不清是实验失败还是真阴性 |
| 检出限 LOD | 能可靠检出的最低量 | 与检测方法同单位 | 低于检出限写"未检出"，不能写"含量为 0" |

## 6. 典型题型与解题套路

### 机制解释题（问为什么会这样）
1. 先把现象写成一句可检验的因果句：A 变化经过哪一步导致 B。
2. 定位尺度：分子（构象、亲和力）、细胞（运输、信号）、个体（调节）、群体（频率、选择），不同尺度的解释不要混在一句里。
3. 画通路，标出被扰动的那一环，并写出"扰动 → 中间量 → 表型"的方向（升、降、失活）。
4. 补一句可证伪的预测：如果是这个机制，敲掉 X 后应看到 Y。
5. 最后区分"教材机制"与"本实验证据"，没做过的环节明说是推断。
**常见失分点**：只写结论不写中间环节，或把一句跨尺度的话当成完整机制。

### 遗传计算题（比例、系谱、卡方、群体频率）
1. 先写基因型符号与显隐关系，确定是常染色体还是性连锁。
2. 由亲代推配子，再用棋盘法或分支法算子代比例；多基因时先分开算再相乘。
3. 算卡方：期望值由假设算出，自由度按类别数减一，查表给 P 与结论。
4. 系谱题先判遗传方式（有无隔代、男女比例、患者双亲表型），再算条件概率，注意"已知表型"会改变分母。
5. 群体题先检验哈代-温伯格平衡，再代入 p、q；数字异常时回头查群体假设。
**常见失分点**：套 9:3:3:1 不写前提；系谱里漏掉"表型正常但为携带者"的概率。

### 实验设计题（给假设，让你设计验证）
1. 写出自变量、因变量与要固定的混杂因素，并给出可量化的判读指标。
2. 设三组：处理组、阴性对照（溶剂或空载体）、阳性对照（已知能出效应），必要时加剂量梯度。
3. 定重复与统计：n 按生物重复算，先说明用哪种检验与显著性阈值。
4. 预先写"什么结果支持、什么结果推翻"，以及失败时的排查顺序。
5. 写清样本量、随机化与盲法；涉及动物或人体要说明伦理审批。
**常见失分点**：只有处理组没有对照，或把技术重复当生物学重复。

### 图表判读题（凝胶、曲线、显微、生长曲线）
1. 先读坐标轴与单位，再读图例与对照泳道，确定"比较的基准是什么"。
2. 描述趋势与关键点（起点、平台、峰值、异常点），先不下结论。
3. 把图形特征对应到机制：条带位置对应大小，曲线斜率对应速率，饱和段对应限制因素。
4. 检查对照能否支撑结论：上样量、内参、阴性泳道是否干净。
5. 写结论的边界：这张图能证明什么、不能证明什么。
**常见失分点**：只看处理组的一条带就下结论，不读标尺也不看上样对照。

## 7. 常见误区

1. **看到条带亮就说"表达量高"** → 错在没做上样量与内参归一；应先跑内参、同批定量，再比较相对值。
2. **P 大于 0.05 就说"两组没有差异"** → 错在把"未检出差异"当"证明相等"；应给置信区间，并说明样本量能否排除有意义的效应。
3. **把体外结果直接搬到体内** → 错在忽略浓度、微环境与代偿；应写明体系层级（细胞系、类器官、个体），并标注外推风险。
4. **遗传比直接套 9:3:3:1** → 错在漏前提（自由组合、无致死、完全外显）；应先列前提，比例不符时先查前提再查数据。
5. **把相关当因果** → 错在没有扰动实验；应补敲除、敲低或回补，并说明对照与回补是否恢复表型。
6. **中心法则背成单向铁律** → 错在把默认路径当唯一路径；应能说出逆转录、RNA 复制与朊病毒各自例外在哪一步。
7. **为了让结论好看而改数据** → 错在编造；应保留原始记录，写"未观察到显著差异"并给出效应量与置信区间。

## 9. 交叉专业与后续方向

- **和生物工程、生物技术的区别**：这两个是工科（本仓库未收），问的是"能不能放大、产率多少、成本与纯化收率几何"；生物科学问"机制为什么成立、证据够不够"。同一个"大肠杆菌产胰岛素"，科学侧问表达调控、折叠与修饰，工程侧问发酵罐溶氧、补料策略与下游纯化。用户若问菌株构建与发酵放大，先按本文件的机制部分回答，并说明工科侧需另找生物工程或化工资料。
- **和基础医学、临床医学的区别**：三者都研究人体，生物科学问机制本身，基础医学问机制与疾病的关系，临床医学问这个病人的下一步处置。同一份表达数据，生物科学看调控逻辑，临床看能否作为标志物。
- **和化学的区别**：化学用结构与机理预测产物，生物科学还要加一层"这个反应在细胞里被谁调控、有没有生理意义"。
- **和生物信息学、计算生物学的区别**：那两个偏算法与统计建模，前提是生物科学把问题定义清楚；交汇点是组学数据分析与序列比对。
- **后续方向**：考研常走生物学一级学科下的细胞生物学、生物化学与分子生物学、遗传学、发育生物学；就业方向包括科研院所与高校、医药与生物技术研发、检测与诊断、科学出版与科普、中学生物教师。
- **不编造实验结论**：这是本专业的底线。没有做过的实验就说"教材结论"或"推测"，并给出可验证的预测与对照；引用文献要能落到具体图表与样本量。答题时宁可写"数据不足以判断"，也不要编一个漂亮的机制。
