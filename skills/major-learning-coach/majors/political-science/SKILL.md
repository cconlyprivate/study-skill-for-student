# 政治学与行政学（political-science）

> 使用前先读 `../../references/curriculum-rules.md`（难度与排序规则）与
> `../../references/learning-card-template.md`（讲解结构）。
> 本文件只提供"这个专业的知识骨架与专业习惯"，不要在这里重复通用协议。

## 1. 这个专业在训练什么

训练两件相连的事：**权力怎么配置**（谁有权决定什么、这些权力之间怎么制衡），以及**制度怎么影响行为**（换一条规则，同样的官员、议员、选民会做出什么不同选择）。它靠的不是立场，而是"给出机制 + 给出能推翻它的证据"。

它和"关心时政、爱评论新闻"不是一回事。评论只需要观点，这个专业要求你把观点写成**可证伪的因果命题**：如果制度真是这样起作用，那么换一个案例、换一段时间，我们应该观察到什么、又不应该观察到什么。

它和思想政治教育也不是一回事：后者问"应该认同什么"，这里问"在什么条件下人会自愿服从、政策会走样、改革会卡住"。

**最容易误解的一点**：以为这个专业 = 背政体名称与宪法条文。条文只是数据，真正拉开差距的是 K03（比较制度）与 K04（公共行政）——它们决定你能不能解释"同一段制度文本，为什么在两个国家跑出了两种结果"。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能把一个含混的政治判断改写成含自变量、因变量与作用机制的假设，并写出证伪条件。
2. 能对两个以上国家的宪制安排做结构化比较，指出哪一条差异最可能解释结果差异。
3. 能画出一项政策从议程到执行的组织链条，标出三个最可能失真的环节。
4. 能区分"合法性"与"合法"、"权威"与"权力"，并在同一段论述里各用一次而不出错。
5. 能用案例比较、过程追踪或简单统计中的一种，为一条因果主张给出可核对的证据。
6. 能对一项行政改革写出受益方、受损方与三条可观测的行为变化。
7. 能读懂一份政策文本与一份统计公报，指出口径、指标与因果表述三处最容易误读的地方。

## 5. 术语与符号约定

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| 国体 | 国家的阶级性质，即哪个阶级掌握政权 | 定性表述 | 国体问"谁掌权"，政体问"权力怎么组织"；把国家性质填进政体栏，是最常见的整题错位 |
| 政体 | 政权的组织形式，即立法与行政的关系安排 | 议会制、总统制、半总统制、委员会制 | 判据是"政府由谁产生、向谁负责、能否被解散"，不是"有没有总统" |
| 合法性（legitimacy） | 被统治者认为统治正当而自愿服从 | 定性，韦伯三分：传统、卡里斯玛、法理 | 它是信念问题；一个政权可以很合法却不具合法性，两栏必须分开写 |
| 合法（legality） | 行为符合现行法律与程序 | 二值判断 | 合乎程序只是合法性的一种来源，不是全部；考"合法性危机"答成"违宪"就整题跑偏 |
| 权力 | 在他人反对时仍能实现自己意志的能力 | 关系性，不是可占有的东西 | 写"某人拥有权力"必须补上"对谁、在什么事上"，否则无法验证 |
| 权威 | 被认可的命令权，无需强制即可被服从 | 传统、卡里斯玛、法理三型 | 权威含正当性，权力不含；"有权无威"与"有威无权"要分开诊断 |
| 权力三副面孔 | 决策、非决策、塑造偏好 | 三层，逐层加深 | 第一面孔看"谁赢了"，第二面孔看"什么进不了议程"，第三面孔看"想要什么被塑造"；三层混写等于只答了第一层 |
| 制度主义 | 制度塑造行为与结果 | 历史、理性选择、社会学三流派 | 制度不只是法律条文，还含非正式惯例；说"制度决定"必须给出它通过谁的哪种激励起作用 |
| 行为主义 | 用可观察行为与数据检验命题 | 个体层面 | 它反对的是"只做规范思辨"，不是"反对制度研究"；把两者当敌对，方法论题必错 |
| 官僚制（bureaucracy） | 按层级、分工、非人格化规则运作的行政组织 | 韦伯式特征 5 条以上 | 中性义是效率装置，批判义才指繁文缛节；答题先声明用哪个义项，否则自相矛盾 |
| 委托—代理 | 委托人授权代理人办事，信息不对称产生代理成本 | 逆向选择、道德风险 | 方向最容易写反：委托人是授权方（选民、上级），代理人是受托方（官员、下级） |
| 逆向选择与道德风险 | 事前隐藏信息 / 事后隐藏行动 | 一对，按签约时点分 | 签约前不知道能力是逆向选择，签约后偷懒是道德风险；时点写反，整道题的机制就反了 |
| 路径依赖 | 早期选择因递增收益被锁定，改道成本随时间上升 | 历史制度主义 | 它不否认变革，而是要求解释"关键节点"上的选择；"历来如此"不是路径依赖 |
| 关键节点（critical juncture） | 制度分支点上短期的、影响深远的决策窗口 | 历史制度主义 | 节点必须同时有偶然性与真实的选择空间；把必然结果说成节点，等于没有解释 |
| 否决点（veto point） | 能单方面阻止政策改变的位置 | 按宪制逐个计数 | 否决点越多越难改变现状；"改不动"不等于"制度坏"，先数否决点再下判断 |
| 迪韦尔热定律 | 单一选区相对多数倾向于两党制 | 经验倾向，不是铁律 | 有强区域性政党时会失效；只写定律不写失效条件，比较题拿不到分析分 |
| 有效政党数 | 按得票或席位加权算出的政党数量 | $N=1/\sum p_i^2$，$p_i$ 为份额 | 用席位算与用得票算结果不同，跨国比较前先对齐口径 |
| 比例代表制与多数制 | 席位按得票比例分配 / 选区第一名全取 | 选举制度两个家族 | 比例制看门槛与选区规模，多数制看选区划定；只评价"公平"而不给维度，等于没答 |
| 单一制与联邦制 | 权力由中央授予 / 由宪法在两级间划分 | 央地关系 | 判据是"地方权限由谁说了算"，不是"地方有没有选举" |
| 国家能力 | 国家贯彻目标、汲取资源与维持秩序的能力 | 与政体类型正交 | 强能力不等于民主或不民主；把"能力"和"类型"当同一条轴，比较结论必错 |
| 党政体制 | 党组织与国家机构并行的领导结构 | 中国政府与政治 | 描述要用"领导—嵌入—归口"，不要用"两套班子各管一摊"这种外行话 |
| 街头官僚 | 直接接触公众、握有大量裁量权的一线执行者 | 政策执行 | 偏差来自裁量与资源不足，不是"素质差"；归因错了，后面给的建议一定空 |
| 政策试点 | 先局部试验、评估后再推广的决策方式 | 中国政府与政治 | 试点不等于随机实验，选择偏差要主动写出来，不能当因果证据直接用 |
| 新公共管理 | 引入市场机制与结果导向的行政改革范式 | 思潮，不是单一措施 | 它不等于私有化，核心是结果问责与竞争；把手段当定义，评价就会跑偏 |
| 概念拉伸 | 把概念套到不适用的情境，外延扩大、内涵变薄 | 方法论 | 比较研究最常见的硬伤；说"某国也有民主"之前，先交代操作化标准 |
| 最相似与最不同设计 | 控制变量、或控制结果的案例选择策略 | 比较方法 | 最相似是"同中求异"，最不同是"异中求同"；名字的方向最容易记反 |

**最容易写反的两组**：国体与政体、合法性与合法。前者错在把"谁掌权"和"怎么组织权力"合成一句话，后者错在把"合乎程序"当成"被认可"。写任何制度题之前，先用一句话把这两组各说一遍，说顺了再动笔——这两处一错，后面的机制分析再漂亮也是白写。

## 6. 典型题型与解题套路

### 题型一：概念辨析（国体/政体、合法性/合法、权威/权力）
1. 先各写一句最小定义，只保留区分所必需的那一个特征，不要抄教材整段。
2. 找出**判据**：拿哪个可观察的东西能判断它属于 A 而不属于 B（国体看谁掌握政权，政体看政府如何产生与负责）。
3. 造一个"两边都像"的边界案例，说明它为什么落在其中一边。
4. 补一句"混用的后果"：把两者写反，会让后面哪个结论跟着反。
**常见失分点**：只给两个定义，不给判据与边界案例，采分点只拿到一半。

### 题型二：制度比较（议会制 vs 总统制、单一制 vs 联邦制、选举制度）
1. 先锁定 3–4 个比较维度：谁产生政府、谁能否决谁、任期是否同步、席位如何换算，维度定完再动笔。
2. 逐维度做"同—异—后果"三栏，差异必须落到**激励**（连任压力、组阁成本、问责归属），不落到形容词。
3. 给一个可证伪的预测：若该维度真起作用，A 国应比 B 国更常出现什么现象。
4. 写清失效条件与竞争解释：政党纪律、选举周期、外部危机都可能盖过制度本身。
**常见失分点**：把"效率高""更稳定"直接当结论，不给它对应的可观测指标。

### 题型三：案例分析（一次政策执行走样、一场地方改革）
1. 先还原事实链：谁决策、谁执行、钱从哪来、考核由谁打分，四条缺哪条就补哪条。
2. 定位失真环节：目标被改写、指标被替代、裁量被滥用，各找一句文本或一组数据作证。
3. 找对照：同一政策在另一地或另一时段的差异，明确写出你用的是哪一种对照。
4. 归因到机制：信息不对称、激励错配、能力不足，选一个主因，并说明排除了哪个竞争解释。
5. 落到可执行建议：改哪一条指标、加哪一道核查、由谁承担后果。
**常见失分点**：通篇描述"我们县是怎么做的"，没有对照也没有机制，读完不知道结论是什么。

### 题型四：论述题（"试论""结合实例谈谈"）
1. 开篇三句话交底：我的命题是什么、我用哪个机制支撑、我用什么证据检验。
2. 主体按"机制—条件—反例"三段展开，每段先给一句判断句，再给理由与例子。
3. 主动写一段"反方最强论证"，然后说明它为什么不成立、或在什么条件下成立。
4. 收尾给条件式结论："在 A 与 B 同时满足时成立，缺 B 时预期反转"。
**常见失分点**：写成态度表态，没有可证伪的命题，字数再多也进不了高分档。

## 7. 常见误区

1. **把"合法性"当"合法"** → 错在把信念问题当成程序问题；应先问"谁自愿服从、为什么"，再谈"是否合乎程序"。
2. **用政体名称代替机制** → 错在"因为它是总统制，所以结果必然如此"这类句式后面没有任何机制；应写出"谁能否决谁、任期是否同步"这两条规则如何改变激励。
3. **比较时只比条文不比执行** → 错在把纸面制度当实际制度；应补上执行者、资源与问责三条，否则结论出了案例就不成立。
4. **案例分析只叙述不设对照** → 错在没有反事实；先写"如果没有这项政策会怎样"，再找可观察的差异。
5. **论述题通篇立场表态** → 错在没有可检验命题；应写成"在 A 条件下我预期 B，因为机制 C，若观察到 D 则我错了"。
6. **把"制度决定一切"当口头禅** → 错在忽略行为主义提醒的个体与选择；应说明制度是通过谁的哪种激励起作用的。

## 9. 交叉专业与后续方向

- **和公共事业管理（public-administration）的区别**：两个专业都被叫"行管"，但问的问题相反。政治学问"权力怎么配置、为什么这样配、配置方式如何改变行为"；公管问"给定这套权力结构，怎么把事办成"——预算怎么排、绩效怎么考、人手怎么配。同一道"基层执法难"的题，政治学答"谁有权执法、问责链断在哪"，公管答"编制、经费与考核怎么调"。判断该用哪个：问"为什么这样安排"找政治学，问"怎样做更好"找公管。
- **和法学（law）的区别**：法学问"这个行为合不合法、构成要件齐不齐"，政治学问"这条规则是谁定的、凭什么能定、定了之后谁的行为变了"。同一部行政法，法学做释义与适用，政治学做权力配置与执行偏差的因果分析；法学要结论可适用，政治学要结论可检验。
- **和国际政治（international-relations）的区别**：都研究权力与制度，但分析单位不同——一个是国家内部的权力配置，一个是无政府状态下国家间的合作与冲突。
- **和社会学（sociology）的区别**：社会学把政治当作社会结构的一个面向，政治学把权力与制度当作独立的解释项；同一份调查数据，社会学问阶层如何再生产，政治学问制度如何改变参与。
- **后续方向**：政治学理论、比较政治、中外政治制度、行政管理、公共政策等考研方向；党政机关与事业单位、政策研究与智库、基层治理与社会组织、公共部门人力资源；进阶课程有政治学方法论（因果推断）、地方治理、比较政治经济学、公共政策评估。
- **一句边界**：本文件只给分析框架与解题方法，不对具体政治事件作立场判断；涉及现行制度的具体表述，以权威发布为准。
