# 药学（pharmacy）

> 先读 `../../references/curriculum-rules.md`（难度与排序规则）与
> `../../references/learning-card-template.md`（讲解结构）。
> 本文件只给这个专业的知识骨架与专业习惯，不重复通用协议。

## 1. 这个专业在训练什么

药学的人靠两件事吃饭：把一个有活性的分子做成能进人体、能在货架上放两年还稳定的剂型；以及用一套别人能复现的方法，证明这一批产品和上一批一样。

给一个结构，要能说出它的酸性碱性、脂水分配系数、大概怎么被代谢，然后回答三件事：做成什么剂型、剂量怎么定、用什么指标判定合格。这三件事任意一件说不清，另外两件就只是背下来的结论。

**外人最容易误解的一点**：以为药学 = 背药名 + 抓药。药名只是检索入口。真正拉开差距的是 K04（药代动力学）和 K07（质量控制）：前者决定你给的剂量与给药间隔能不能自洽，后者决定你说的"合格"能不能被第三方照着做出来。

它和临床医学的分界线很干脆：临床医学面对一个具体的人，问"该不该用、用多少、什么时候停"；药学面对一个分子和一个批次，问"能不能做成稳定有效的产品、怎么证明每批都一样"。同一个药名，临床看适应证与禁忌，药学看晶型、溶出曲线与杂质谱。

它和化学的分界线同样干脆：化学追的是结构与机理的普适规律，药学只追"这个分子在人体内和货架期内会怎样"，为此愿意用经验模型和法定方法。

**最陡的三门课**：药理学（因为要同时握住"作用在哪"和"体内还剩多少"两套坐标，只握住一套就只会背结论）、药剂学（因为处方是权衡题，每个辅料都在拿稳定性换溶出）、药物分析（因为"测得出来"和"测得准"是两件事，方法学验证才是分水岭）。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能对一个候选分子写出 pKa 与 logP 的量级，据此判断成盐形式与口服吸收的可行性。
2. 能由半衰期、生物利用度与表观分布容积算出稳态浓度、达稳态时间与负荷剂量，并给出给药间隔。
3. 能写出一个剂型的完整处方（主药、辅料、用量、工艺），并逐项说明每种辅料解决什么问题。
4. 能为一个制剂设计稳定性试验方案，写清条件、时间点、考察项与判定标准。
5. 能对一个含量测定方法写出方法学验证方案，给专属性、准确度、精密度的接受标准。
6. 能读懂一张色谱图，区分主峰与杂质峰，写出含量与有关物质的完整计算式。
7. 能对一份批记录找出三处不符合 GMP 的记录，并说明各自违反哪条要求。
8. 能对一个用药案例指出相互作用发生在哪个环节、方向如何，并说明依据来源。

## 5. 术语与符号约定

药学的记号有两套：化学的（结构、电离、分配）和统计的（浓度、时间、比例）。下面每一条都对应一个真实的扣分点，尤其是分母是谁、方向朝哪、单位差几个数量级。

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| 构效关系（SAR） | 结构改动与活性变化的对应 | 定性为主，配 IC50 或 EC50 | 只写"活性增强"不写改的是哪个位置；SAR 必须成对写"改什么—变多少" |
| 药效团 | 与活性直接相关的结构要素集合 | 通常 2–4 个要素 | 把整个分子当药效团；药效团恰恰是可以被别的骨架替换的那部分 |
| $\mathrm{p}K_a$ | 半数分子电离时的 pH | 无量纲，常见 2–12 | 酸性药成碱盐、碱性药成酸盐；写反了成盐形式和溶解度全错 |
| $\log P$ / $\log D$ | 脂水分配系数 / 指定 pH 下的分布系数 | $\log P$ 常见 0–5 | 中性分子用 $\log P$，离子化体系必须用 $\log D$；讨论肠道吸收却忽略 pH 是常见错 |
| 首过效应 | 口服药经肠壁与肝代谢后在进体循环前的损失 | 可使 $F$ 降到 10% 以下 | 把它等同于"肝代谢"；肠壁酶与外排转运体同样算首过，且首过损失不等于药无效 |
| 生物利用度 $F$ | 进入体循环的药量占给药量的比例 | 0–100%，分绝对值与相对值 | 绝对 $F$ 的分母是静脉给药，相对 $F$ 的分母是参比制剂，两个数不能直接比 |
| 表观分布容积 $V_d$ | 剂量与血药浓度的比例常数 | L 或 L/kg | 它不是真实空间；$V_d$ 大说明药跑进组织，血药浓度反而低，别解读成"分布广所以血里多" |
| 半衰期 $t_{1/2}$ | 血药浓度下降一半所需时间 | h，一级动力学下为常数 | 一级动力学里 $t_{1/2}$ 不随剂量变；"加量就延长半衰期"是零级动力学的特征，两者别混 |
| 清除率 $CL$ | 单位时间内被完全清除的血浆体积 | L/h 或 mL/min | $t_{1/2}=0.693V_d/CL$，三个量知二求一；把 $CL$ 与 $V_d$ 当成独立可任意指定的数会算出矛盾方案 |
| 稳态浓度 $C_{ss}$ | 给药速率与消除达平衡时的浓度 | ng/mL 或 μg/mL | 达稳需 4–5 个 $t_{1/2}$；负荷剂量只缩短达稳时间，不改变 $C_{ss}$ 本身 |
| 治疗窗 | 有效浓度下限与中毒浓度上限之间的区间 | 因药而异，常以谷浓度界定 | 窗窄才需要监测；判断"要不要测"比会测更重要，窗宽的药做监测只是浪费 |
| 治疗药物监测（TDM） | 测血药浓度并据此调剂量 | 以谷浓度为主 | 必须写清采血时间点；峰浓度与谷浓度不能互相代用，稳态前后的同一条曲线也不能直接比 |
| 治疗指数 | $LD_{50}$ 与 $ED_{50}$ 的比值 | 无量纲，越大越安全 | 它只描述半数点；两药指数相同而量效曲线斜率不同，危险程度并不相同 |
| 肝药酶诱导/抑制 | 改变 CYP 等酶活性从而改变清除速率 | 诱导需数天至数周，抑制可即时 | 诱导要几天才显现、停药后也要几天才消退；抑制是即时的，两者时间尺度完全不同 |
| 药物相互作用 | 联用后效应发生改变 | 分药动学与药效学两类 | 只写"有相互作用"不给机制与方向；必须落到吸收、代谢还是效应层面 |
| 剂型 | 主药与辅料构成的给药形式 | 片剂、胶囊、注射剂、贴剂等 | 剂型不是包装；同一主药换剂型可使 $F$ 差数倍，换剂型等于换剂量 |
| 释药行为 | 药物从剂型中释放的规律 | 零级、一级、Higuchi 等 | 缓释不等于控释：控释要求近似零级，缓释允许一级；两条曲线混称会判错处方 |
| 溶出度 | 规定条件下溶出的百分比 | %，常见 30 min 或 45 min 限度 | 溶出度合格不等于生物等效；介质必须写清 pH、体积与表面活性剂浓度 |
| 含量测定 | 测主成分占标示量的比例 | 标示量 %，常见 95.0–105.0% | 分母是标示量不是称样量；滴定还要写清滴定度与换算因数 |
| 方法学验证 | 证明方法适用于预期用途的一组试验 | 专属性、准确度、精密度、线性、范围、耐用性 | 准确度要在三个浓度各做三份；只做中浓度一份不叫准确度，叫单点回收 |
| 有关物质 | 主成分之外的同源杂质 | 单个杂质与总杂质分别设限 | 报告限、鉴定限、界定限是三件事；低于报告限的峰不必积分，但要在方案里说清 |
| 稳定性与有效期 | 规定条件下保持合格的时间 | 月，常见 24–36 个月 | 有效期从生产日期算、复检期从检验日期算；加速试验 6 个月不能直接当有效期 |
| GMP 与批记录 | 生产质量管理规范及其可追溯记录 | 按批号逐批记录 | 批记录必须同步填写，不得追记；"事后补录"本身就是缺陷项，不是笔误 |
| OOS | 检验结果超出法定标准 | 按偏差流程调查 | OOS 不能靠复测了事；必须先查实验室差错再查工艺，复测条件要事先写进方案 |
| 剂量单位 | mg、μg、IU、mg/kg | 1 g = 1000 mg，1 mg = 1000 μg | mg 与 μg 差 1000 倍，手写处方最易错；IU 不能与 mg 换算，必须查说明书 |

## 6. 典型题型与解题套路

### 题型一：剂量与半衰期计算题
1. 先定动力学：看清是一级还是零级。一级才可用恒定 $t_{1/2}$ 与 $C_t=C_0\cdot 0.5^{t/t_{1/2}}$，零级按恒速消除单列。
2. 统一单位与符号：$D$ 用 mg、$V_d$ 用 L、$t_{1/2}$ 用 h、$\tau$ 用 h；$F$ 的百分数先换成小数再代入。
3. 按链条算：维持给药时用 $C_{ss,av}=\dfrac{F\cdot D}{CL\cdot\tau}$，单次给药时先由 $D\cdot F/V_d$ 得 $C_0$ 再按时间衰减。
4. 负荷剂量用 $D_L=\dfrac{V_d\cdot C_{target}}{F}$，算完核对它应明显大于维持剂量，通常 2–5 倍。
5. 三项回代检查：达稳时间为 4–5 个 $t_{1/2}$；$\tau$ 小于 $t_{1/2}$ 必有蓄积；算出的 $C_{ss}$ 要落在治疗窗内。
**常见失分点**：百分数当小数用、$V_d$ 的 L 与 mL 混用、负荷剂量公式漏除 $F$。

### 题型二：处方与剂型分析题
1. 先写清目标：给药途径、速释还是缓释、规格与日剂量，这三项决定整个处方骨架。
2. 列辅料角色表：填充剂、黏合剂、崩解剂、润滑剂、包衣各写"用量 + 解决什么问题"，不写角色就等于没写处方。
3. 找矛盾：崩解与溶出的取舍、润滑剂过量使溶出下降、包衣增重改变释放曲线，至少点出一处。
4. 给工艺参数：制粒方式、压片压力、包衣增重，并指明哪一个参数最敏感、超了会怎样。
5. 说验证方式：用溶出曲线与含量均匀度证明处方成立，而不是用外观与手感。
**常见失分点**：只列辅料名称不给用量与角色，处方题丢掉全部工艺分。

### 题型三：质量评价与方法学验证题
1. 先写标准来源：药典品种项下的项目与限度，写明依据年份，不自行放宽也不自行加严。
2. 分三层写方案：性状与鉴别、检查（有关物质、溶出度、含量均匀度）、含量测定。
3. 方法学逐项给接受标准：专属性看分离度、准确度看回收率区间、精密度看 RSD 上限、线性看相关系数。
4. 写清样品量与重复次数：几个浓度、每个浓度几份、平行几次、由谁复核。
5. 给判定与处置：合格如何放行，不合格走 OOS，复测的前提条件事先写进方案。
**常见失分点**：只写"按药典检验"，没有接受标准与样品量，方案无法被第二个人执行。

### 题型四：案例题（相互作用、TDM、不合格批次）
1. 先剥离事实：患者情况、联用药物、剂量、时间线、异常指标，按时间轴排成一行。
2. 定位环节：是吸收、分布、代谢、排泄，还是剂型与依从性问题，先排除最简单的解释。
3. 给机制与方向：酶抑制还是诱导，浓度会升还是降，效应会增强还是减弱，各写一句。
4. 给处置与监测：调整方向、复测时间点、观察指标，并说明依据来自说明书、药典还是文献。
5. 划边界：涉及具体品种的剂量与处方时，明确说明以说明书与医师处方为准，不自行给方案。
**常见失分点**：直接抛结论不排时间线，机制与方向写反，或把"可能"写成"一定"。

## 7. 常见误区

1. **把半衰期当"药效持续多久"** → 错在混淆浓度与效应；应分开写 $t_{1/2}$ 与作用持续时间，并说明效应还受受体结合与下游通路影响。
2. **用 $\log P$ 判断所有吸收问题** → 错在忽略电离与转运体；应改用指定 pH 下的 $\log D$，并说明是否存在外排转运。
3. **认为缓释就是把剂量做大** → 错在没做释放曲线；缓释靠释放速率控制吸收，剂量做大只会抬高峰浓度与毒性风险。
4. **含量测定只做一份样品** → 错在没有精密度与重复性；应按不同浓度各做平行样并给出 RSD，否则结果不可复核。
5. **把加速试验 6 个月直接当有效期** → 错在忽略外推边界；有效期须由长期试验数据支撑，加速数据只能支持短期判断与偏差排查。
6. **批记录事后补齐** → 错在丢失同步性证据；应按实际操作时间记录，出现漏记走偏差流程，而不是回头补签。
7. **只记药名不记机制** → 错在无法迁移；应按"靶点—通路—效应"记，遇到同类新药才能推。
8. **处方只抄教材例子不看主药性质** → 错在忽略晶型、粒度与稳定性；应先写主药的理化性质，再决定辅料与工艺。

## 9. 交叉专业与后续方向

- **和临床医学的区别**：临床医学的决策单元是"这个人的这一次就诊"，问该不该用、用多少、何时停；药学的决策单元是"这个分子与这个批次"，问能不能做成稳定有效的产品、怎么证明每批一样。同一个药名，临床看适应证与禁忌，药学看晶型、溶出曲线与杂质谱。交汇点在处方审核与治疗药物监测。
- **和化学工程与工艺的区别**：化工问"这个反应怎么放大到万吨级、传热与分离怎么算"，单位是吨与千瓦；药学问"这个剂型在体内释放成什么样、这批合不合格"，单位是 mg 与 ng/mL。交汇点在制药工程：制粒、压片、冻干、包衣两家都学，化工算收率与能耗，药学算含量均匀度与溶出度，而且药学还要多背一整套 GMP 与注册法规。
- **和化学的区别**：化学追结构与机理的普适性，允许"这个反应对所有人都成立"；药学只追一个分子在人体内与货架期内的表现，接受经验模型与法定方法。
- **和生物工程、生物制药的区别**：生物制药管大分子（抗体、疫苗）的表达、纯化与活性检定；传统药学以化学药与制剂为主。但两者的质量体系框架通用，转过去要补的是生物大分子的表征方法。
- **后续方向**：药物化学与合成工艺、制剂研发（处方与工艺放大）、药物分析与质量控制、药代动力学与临床药理、注册与药事管理、GMP 合规与生产管理；考研常考药学综合（有机化学、药物化学、药剂学、药理学、药物分析）。
- **边界提醒**：本文件只讲学习方法与答题结构。本文件不提供具体用药建议，处方与剂量以药品说明书和医师处方为准。涉及具体品种的用法用量、相互作用与警戒信息，一律以现行说明书、药典与官方通报为准；查不到就写"需查说明书或问医师药师"，不给编造的数字。
