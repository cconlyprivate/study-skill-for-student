# 会计学（accounting）

> 使用前先读 `../../references/curriculum-rules.md`（难度与排序规则）与
> `../../references/learning-card-template.md`（讲解结构）。
> 本文件只提供"这个专业的知识骨架与专业习惯"，不要在这里重复通用协议。

## 1. 这个专业在训练什么

把一笔已经发生的交易，翻译成**别人可以独立复算**的报表语言：谁欠谁、什么时候确认、金额多少、证据在哪。这门手艺靠三样东西撑着：**证据链**（原始凭证 → 记账凭证 → 账簿 → 报表，每一环都能倒着追回去）、**准则口径**（同一笔业务允许怎么做、为什么选这一种）、**恒等式约束**（$A = L + E$，即资产 = 负债 + 所有者权益，任何一笔分录都不能打破它）。

它和"算账、背分录"不是一回事。分录只是最后的落笔动作，真正决定水平的是前面两步：判断业务的**经济实质**（是销售还是融资、是自建还是采购），再在准则允许的空间里**选一种处理并说清后果**（这个选法让今年利润高多少、明年低多少）。所以练的时候要养成一个动作：每写一笔分录，都在旁边补一句"依据什么、影响哪张表哪个数"。

**最容易误解的一点**：以为会计有唯一正确答案。存货计价、折旧方法、收入确认时点都留了选择空间，考的是"你为什么选这个、它对报表影响多少"，不是"背下标准答案"。

**最陡的三门课**：中级财务会计（准则给的选择空间最大，每个选择都要能算出对报表的影响）、审计学（要把自己编的报表当成可能被造假的报表来查）、财务管理（现金流口径与折现率必须配对，错一次全盘皆错）。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能对任意一笔经济业务写出借贷科目、金额与明细，并说明依据哪条准则、为什么这样确认。
2. 能从原始凭证走完一个月的会计循环，交出一张借贷合计相等的科目余额表。
3. 能独立编制资产负债表、利润表与现金流量表，并让三张表在三处勾稽上同时对齐。
4. 能按成本对象与分配标准算出一批产品的单位成本，并说清换一个分配标准成本会怎么变。
5. 能用杜邦分解与利润的现金支撑，解释两家公司 ROE 差异来自经营、周转还是杠杆。
6. 能对一份报表设计 3 条实质性程序，判断错报是否超过重要性、应出具哪种意见。
7. 能算出一个项目的 NPV 与回收期，用税后现金流配税后折现率给出投或不投的结论。
8. 能指出一份报表里 3 处需要追问的会计政策选择，并说明各自对当期利润的影响方向。

## 5. 术语与符号约定

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| 借 / 贷（Dr / Cr） | 账户的左右方向，与"借入/贷出"无关 | 只表示方向 | 最容易记成"借=收入、贷=支出"；正确规则是资产、成本、费用增加记借方，负债、所有者权益、收入增加记贷方 |
| $A = L + E$ | 会计恒等式：资产 = 负债 + 所有者权益，任一时刻成立 | 期初、期末都成立 | 扩展式 $A = L + E + R - X$（收入减费用）只在结账前成立，两式混用会让试算表不平 |
| 权责发生制 | 按权利义务的发生确认，不看钱是否收到 | 利润表与资产负债表口径 | 收到钱不等于收入（预收是负债），付出钱不等于费用（预付是资产） |
| 收付实现制 | 按现金实际收付确认 | 现金流量表口径 | 拿它去编利润表，会把预收款算成收入，当期利润虚增 |
| 收入确认五步法 | 识别合同、识别履约义务、确定交易价格、分摊价格、履行时确认 | 按现行收入准则 | 顺序不能省，先分摊再确认；总额法与净额法选错，收入与毛利能差一个数量级 |
| 先进先出法（FIFO） | 先购入的先发出 | 与加权平均法互斥 | 涨价期期末存货高、当期成本低、利润高；换方法属会计政策变更，要追溯调整并披露 |
| 月末一次加权平均 | $\bar{p} = \dfrac{C_0 + C_1}{Q_0 + Q_1}$，即期初成本加本期购入成本除以对应数量 | 加权平均单价 | 分母漏掉期初结存；移动加权平均与月末一次加权平均算出的单价不同，期末存货也不同 |
| 折旧方法 | 直线法 $D = \dfrac{C - S}{n}$，双倍余额递减 $D_t = \dfrac{2}{n} \times NBV_{t-1}$ | 年或月 | 双倍余额递减前几年基数不扣残值 $S$，最后两年才改直线；方法变更属会计估计变更，不追溯 |
| 坏账准备与信用减值 | 按预期信用损失模型计提 | 货币金额 | 计提的对方科目是"信用减值损失"，不是"管理费用"；核销与转回的先后顺序常写反 |
| 递延所得税 | 暂时性差异 $\times$ 适用税率，结果记 $DTA$ 或 $DTL$ | 资产或负债 | 资产账面价值大于计税基础，形成应纳税暂时性差异，对应递延所得税负债，方向别写反 |
| 三张表勾稽 | 期末未分配利润 $= RE_0 + NI - Div$；现金净增加额等于货币资金期末减期初 | 三处必须对齐 | 净利润不等于经营现金流，差额来自折旧摊销与营运资本；补充资料的现金净增加额要等于货币资金变动 |
| 试算平衡 | 全部账户借方合计等于贷方合计 | 相等即通过 | 平衡只能排除单边记账；重记、同方向漏记、科目错用都不会让表不平 |
| 期末结转 | 收入费用转入本年利润 | 每期一次 | 结转后损益类账户应无余额；漏结转会让利润表与资产负债表对不上 |
| 重要性水平 | 错报超过它才算重大 | 常用税前利润 5%–10%、营业收入 0.5%–1% | 重要性是金额加性质两个维度；舞弊与关联方交易，金额再小也要看 |
| 审计意见类型 | 无保留、保留、否定、无法表示意见 | 四种基本类型，可加强调事项段 | 无法表示意见是范围受限查不清，否定意见是查清了但整体不公允，两者不能互换 |
| 管理层认定 | 存在性、完整性、准确性、截止、分类、权利与义务 | 审计目标的落点 | 完整性查漏记（低估），存在性查虚构（高估），两者测试方向正好相反 |
| 控制测试 / 实质性程序 | 前者测内控是否有效，后者直接查金额 | 两者都要有结论 | 控制测试替代不了实质性程序；内控有效不等于金额没错 |
| 可容忍错报 | 实际执行的重要性，通常取整体重要性的 50%–75% | 货币金额 | 用整体重要性去卡每一个科目，会把该查的漏掉 |
| 流动比率 / 速动比率 | 流动比率 $= \dfrac{CA}{CL}$；速动比率再剔除存货与预付 | 倍 | 速动资产不是"流动资产减存货"就够了，预付费用也要剔；期末突击还款能美化比率 |
| 资产负债率 | $D/A$，负债总额除以资产总额 | % | 分子含全部负债；跨行业比这个数没有意义 |
| $ROE$ 杜邦分解 | $ROE = \dfrac{NI}{Sales} \times \dfrac{Sales}{Assets} \times \dfrac{Assets}{Equity}$ | % | 三个因子要统一口径（同用期末或同用平均）；杠杆抬起来的 ROE 不是经营改善 |
| 利润的现金支撑 | $OCF/NI$，经营活动现金流除以净利润 | 倍 | 长期小于 1 要追问应收与存货；扩张期单期为负不等于造假 |
| $NPV$ / $IRR$ | $NPV = \sum_{t=1}^{n} \dfrac{NCF_t}{(1+r)^t} - C_0$，$IRR$ 是令 $NPV = 0$ 的 $r$ | 货币 / % | 现金流多次变号时 IRR 会多解或无解，只能用 NPV；两者冲突以 NPV 为准 |
| 折现率口径 | 税后 $WACC$ 配税后现金流，$WACC = \dfrac{E}{D+E} r_e + \dfrac{D}{D+E} r_d (1 - T)$ | % | 用税后折现率去折税前现金流，是最常见的一处口径错 |
| 约当产量 | 在产品数量 $\times$ 完工程度，材料一次投入按 100% | 件 | 材料在生产开始时一次投入的，按 100% 算而不按完工率；只有加工费按完工率 |
| 制造费用分配率 | $R = \dfrac{OH}{B}$，制造费用除以分配标准合计 | 元/工时 | 换分配标准结论就变，答案里必须写明为什么选这个成本动因 |
| 变动成本法 / 完全成本法 | 固定制造费用是否计入产品成本 | 利润口径不同 | 产量大于销量时完全成本法利润更高，差额等于存货吸收的固定制造费用 |
| 标准成本差异 | 价格差异 $= (AP - SP) \times AQ$，数量差异 $= (AQ - SQ) \times SP$ | 货币 | 有利与不利的符号方向常写反，先固定"实际减标准"再分解 |

**最容易搞混的一件事**：借贷只是一对方向符号，与"借入/贷出"无关。判断方向时先在纸上写"这项业务让哪类要素增加"，再套规则——资产、成本、费用增加写借方，负债、所有者权益、收入增加写贷方；用银行存款付费用是"借：费用，贷：银行存款"，收到货款不是收入而是"借：银行存款，贷：应收账款"。凡是看到自己写"借：收入"，立刻停下来重判要素。

## 6. 典型题型与解题套路

### 分录编制题
1. 先用一句话说清业务实质：钱从哪来、货或服务往哪去、谁承担义务（销售、融资、代收、自建四类先分清）。
2. 定要素与方向：写出"哪项资产增或减、哪项负债或权益增或减"，再按借贷规则落方向，不要一上来就想借方科目。
3. 落科目与明细：含税价按 $X = P(1 + t)$ 反算不含税金额 $P$（$t$ 为适用税率），应交税费写到明细科目，税额别塞进采购成本。
4. 定时点：跨期业务按权责发生制拆开，本期只确认已履行部分，余额挂合同负债或预付账款。
5. 复核：把分录反译回一句中文，与原始业务逐项对照；再查借贷合计与恒等式是否仍然成立。
**常见失分点**：把增值税进项税额计入采购成本，或把收到的预收款直接确认为收入。

### 报表编制题
1. 先对账：总账与明细账核对，编试算平衡表；不平先查单边记账、同方向漏记、科目串户三类原因。
2. 做期末调整：折旧、摊销、减值、待摊与预提、所得税，照清单过一遍，漏一项后面对不上。
3. 分表填列：资产负债表取期末余额并按项目重分类（一年内到期的非流动负债要拆出来），利润表取本期发生额，现金流量表按收付实现制归集。
4. 间接法编经营现金流：净利润加回折旧摊销等非付现项，减掉非经营活动损益，再调营运资本变动。
5. 三处勾稽校验：货币资金期末减期初等于现金净增加额；未分配利润期末等于期初加净利润减分配；资产等于负债加所有者权益。
**常见失分点**：只把资产负债表做平就交卷，现金流量表补充资料与主表对不上。

### 比率分析题
1. 先统一口径：分子分母同期间（平均余额对平均余额）、同合并范围、同会计政策；口径不同就先说明再比。
2. 三类各取 2–3 个：偿债（流动、速动、资产负债率）、营运（应收、存货、总资产周转）、盈利（毛利率、净利率、ROE）。
3. 用杜邦把 ROE 拆开，判断差异主要来自净利率、周转率还是权益乘数。
4. 回到报表找证据：应收与存货的增速是否超过收入增速、非经常性损益占比多少、有没有会计政策变更。
5. 结论写成一个可被推翻的判断："若应收账款周转天数继续拉长，这轮盈利改善不可持续"。
**常见失分点**：分母全用期末数，却与用平均余额的同行数据直接排名。

### 审计判断题
1. 先定认定：这笔错报违反的是存在性、完整性、计价与分摊，还是截止与分类；认定决定测试方向。
2. 再判重要性：金额与性质两个维度，舞弊、关联方交易、刚好把亏损做成盈利的事项不看比例。
3. 区分两类情形：范围受限（查不下去）指向保留或无法表示意见；查清后报表确实错报，指向保留或否定意见。
4. 判广泛性：影响是否遍及报表整体，只有广泛才升到否定或无法表示意见。
5. 落笔写"意见类型 + 触发条件 + 广泛性判断"，不要只写"发表非标准意见"。
**常见失分点**：把无法表示意见与否定意见写反；认为内控测试通过就可以不做实质性程序。

## 7. 常见误区

1. **把借贷当成"借入/贷出"** → 错在把方向符号当成了经济含义；应先按要素分类，资产增加记借方、收入增加记贷方，再落具体科目。
2. **用收付实现制的思路编利润表** → 错在把预收款当收入、把预付当费用；应先按权责发生制确认，收付实现制只用于现金流量表。
3. **为调利润随手更换存货计价方法** → 错在把会计政策变更当成估计变更；应做追溯调整，并披露变更性质与对可比期间的影响额。
4. **折旧只算直线法，且残值从第一年就扣** → 错在双倍余额递减前几年基数不扣残值；应对同一资产用两种方法各算一年，说明对前期利润与税负的影响。
5. **试算平衡了就说报表没错** → 错在平衡查不出重记、同方向漏记与科目错用；应做三表勾稽，并把明细账与附注交叉核对。
6. **审计看到内控有效就出无保留意见** → 错在把控制测试当实质性程序；应对重大错报风险高的科目单独设计实质性程序并留底稿。

## 9. 交叉专业与后续方向

- **和财务管理专业的区别**：会计回答"已经发生的交易记对了吗、报表能不能被第三方复算"，财务管理回答"未来的钱投到哪、从哪筹、留多少流动性"。会计用历史成本与证据链，财务管理用预测现金流与折现率。本专业也开财务管理课，但那是学"用报表做决策"，不是学"记账"。
- **和审计学专业的区别**：会计是管理层的编报立场，审计是独立第三方对报表是否公允发表意见。同一笔收入，会计问"该不该确认、怎么确认"，审计问"凭什么相信它已经确认、错了会不会重大"。审计不重做账，靠证据与重要性水平说话。
- **和工商管理（business-administration）的区别**：工商管理在资源有限时做取舍（战略、营销、组织），会计提供取舍所需的可核对数据与约束（成本、预算、绩效计量）。同一份报表，工商管理问"下一步资源怎么调"，会计问"这些数对不对、口径一致吗"。
- **后续方向**：会计学硕士、会计专硕（MPAcc）、审计硕士（MAud）；岗位常见于企业财务与合并报表、会计师事务所审计、内审与合规、税务、财务 BP 与 FP&A；进阶课程有高级财务会计、合并报表、国际财务报告准则、管理会计、税务会计、信息系统审计。
- **一句边界**：本文件只讲方法与原理，不构成真实财务或税务意见；具体账务处理、报表披露与纳税申报，必须依据现行企业会计准则、税法条文与主管税务机关口径，并由执业注册会计师或税务师按个案判断。
