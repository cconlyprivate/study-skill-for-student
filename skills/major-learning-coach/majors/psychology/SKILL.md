# 心理学（psychology）

> 先读 `../../references/curriculum-rules.md`（难度与排序）与 `../../references/learning-card-template.md`（讲解结构）。
> 本文件只给这个专业的知识骨架与专业习惯。

## 1. 这个专业在训练什么

心理学靠一套**方法**吃饭，不靠"懂人心"。它的标准动作是三步：先把一句日常抱怨拆成可观测的因变量（心率、正确率、回避次数、反应时），再把可能影响它的自变量写成可操纵或可分类的水平，最后把剩下的替代解释逐一排掉。这三步走完，才允许说"因为"。

外人最常误解的是以为心理学 = 共情 + 常识 + 性格测试。真正拉开差距的是方法学：一个结论能不能站住，取决于它有没有操作定义、有没有对照、效应量多大、能不能被重复。所以你会发现，本专业最硬的课不是流派史，而是实验设计、统计、测量。

分界线先说清：心理学问"这个行为的函数关系是什么，在控制条件下它由哪些变量决定"；教育学接着问"在班级、课标、课时的约束下该怎么教、怎么证明有效"；神经科学问"哪套神经机制实现了它"。同一份"学生上课走神"的材料，心理学答注意资源如何分配、用什么范式测出来，教育学答课堂怎么改，神经科学答哪条环路在放电。

**最容易误解的一点**：以为"相关"就是"导致"，以为 $p<.05$ 就是"效应重要且为真"——这两句是全专业最高频的失分点（见 K02-4、K03-3、K03-5）。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能把一句日常说法改写成含自变量、因变量、混淆变量的可检验假设，并给每个变量配操作定义与测量工具。
2. 能为同一个假设画出被试间与被试内两种设计的分配表，说清各自要平衡什么、代价是什么。
3. 能对三组以上的数据判定该用 $t$、ANOVA 还是回归，并写出含统计量、自由度、$p$、效应量、置信区间的一句话结果。
4. 能读一篇实证论文的方法与结果，指出至少三处效度威胁或可疑分析痕迹。
5. 能用同一批数据的两套理论各写一段解释，并指明什么证据能把它们分开。
6. 能按规范写出一份含知情同意、风险告知、欺骗后解释的实施方案。
7. 能对一份量表给出信度与效度证据判断，并说明它能不能用于某个具体决策。

## 5. 术语与符号约定

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| 操作定义 | 用可观察、可测量的操作把构念说清（焦虑 = 状态焦虑量表得分 + 演讲前心率） | 每个变量至少一条，两条更好 | 用同义词替换构念（"攻击性"写成"有攻击倾向"）等于没定义；只给一条指标就估不出测量误差 |
| 构念 / 变量 / 指标 | 想测的心理属性 / 可取值变化的属性 / 用来近似它的观测 | 构念不可直接观测 | 把指标当构念本身：把"反应时"直接叫"智力" |
| 自变量 IV / 因变量 DV / 混淆变量 | 被操纵或分类的 / 被测量的结果 / 与 IV 共变且影响 DV 的第三变量 | IV 至少两个水平 | 把"额外变量"（该恒定控制的）与"混淆变量"（已与 IV 共变的）混用；"控制变量"不是"混淆变量" |
| 随机分配 / 随机抽样 | 分组时随机 / 从总体取人时随机 | 前者管因果，后者管推广 | 最高频硬错：随机分到两组不等于样本能代表总体；写"随机"却不写随机化单位（个体还是整班） |
| 双盲 / 单盲 | 被试与主试都不知分组 / 仅一方不知 | 安慰剂与期望效应的标准配置 | 把"被试不知道研究目的"当成实现了盲法；不做操纵检查（问被试猜自己在哪组）就无法验证盲法 |
| 信度 / 效度 | 重复测量的一致性 / 测到目标构念的程度 | 信度 0–1；信度是效度的必要不充分条件 | 用"信度高"证明"有效"；α 高只说明题目同质，不说明测对了东西 |
| Cronbach α / 重测信度 / 评分者一致性 | 内部一致性 / 跨时间稳定性 / 多评分者一致（Kappa 或 ICC） | α 常以 .70 为可接受线 | α 随题目数上升，删题后 α 下降不等于题目变差；α 假设单维，多维量表要分维度报 |
| 内容效度 / 结构效度 / 效标效度 | 题目覆盖全域 / 内部结构与理论吻合 / 与外部标准相关 | 三类证据互补 | 只写"专家审过"就算内容效度；用同一份数据先探索再验证结构，等于自证 |
| p 值 | $H_0$ 为真时，得到当前或更极端结果的概率 | 0–1；APA 写 $p = .03$ | 说成"$H_0$ 为真的概率"或"结论为错的概率"；$p>.05$ 说成"无差异"而不是"证据不足" |
| α（显著性水平） | 犯第一类错误的概率上限，常取 .05 | 与 Cronbach α 同符号、不同含义 | 一个 α 两种意思混用；把 α 当成"结果显著的概率" |
| 第一类 / 第二类错误 | 弃真 / 取伪 | 对应 α、β；功效 = $1-\beta$ | 只谈显著性不谈功效；小样本不显著就宣布"效应不存在" |
| 效应量 Cohen's d | 两组均值差除以合并标准差 | 约 0.2 小、0.5 中、0.8 大 | 只报 $p$ 不报 $d$；不说清分母是合并 SD 还是对照组 SD，数值不可比 |
| 95% 置信区间 | 重复抽样下有 95% 的区间覆盖真值 | 与效应量一起报 | 说成"真值有 95% 概率落在这一区间"；CI 跨 0 与 $p>.05$ 等价，别当两条独立证据 |
| 自由度 df | 估计方差时可用的信息个数 | $t$ 检验 $df=n_1+n_2-2$ | 报 $F$ 或 $t$ 时不写 $df$，结果无法复核 |
| 单尾 / 双尾检验 | 备择假设是否带方向 | 无方向预期用双尾 | 看完数据再选单尾；把单尾 $p$ 当双尾报 |
| 随机分配 / 匹配 | 大样本随机化 / 小样本按关键变量配对 | 匹配不能替代随机化 | 匹配完仍声称"消除了全部混淆"；不说匹配了哪几个变量 |
| 复现危机 / p-hacking | 大量已发表效应在重复实验中缩水或消失 / 反复分析直到 $p<.05$ | 可疑操作：选择性剔除、换 DV、加被试到显著 | 把复现失败一律解释成原研究者造假；复现失败也可能来自样本、情境、测量不同 |
| 预注册 / 开放数据 | 分析前登记假设与流程 / 公开数据与代码 | 据此区分探索性与验证性 | 预注册后仍改分析却不标为探索性；把探索性结果写成验证性结论 |
| 交互作用 / 主效应 | 一个因素的效应随另一因素水平而变 / 忽略另一因素时的平均效应 | 2×2 起可检验 | 有交互时还单独解释主效应；把"两组都上升"说成"没有交互" |
| 顺序平衡（拉丁方 / ABBA） | 抵消练习与疲劳的顺序效应 | 被试内设计必做 | 被试内设计不做平衡，把练习效应算成处理效应 |
| 量表水平（称名/顺序/等距/比率） | 测量允许的运算层级 | 决定能不能算均值 | 对顺序量表算均值与标准差；把单题李克特当等距变量 |
| 反应时 RT / 正确率 ACC | 刺激到反应的毫秒数 / 正确反应比例 | ms；0–1 或 % | 只看正确率不看 RT（或反之）；不做速度—准确性权衡就下结论 |
| 标准分数 z / IQ | $z=(X-M)/SD$；IQ 常以 $M=100$、$SD=15$ | 无量纲 | 把不同常模的 IQ 直接比；把 z 与百分等级混用 |
| M / SD / N / n | 均值 / 标准差 / 总样本量 / 子组样本量 | 报告用斜体 | 用 SD 冒充标准误；N 与 n 混用，读者会错判每组样本量 |
| 知情同意 / 欺骗后解释 | 研究前告知可随时退出 / 事后说明真实目的与必要性 | 欺骗须经伦理审查且风险最小 | 认为"签了同意书"就够；欺骗后不解释，或解释时又泄露他人隐私 |
| 霍桑效应 / 需求特征 / 实验者期望 | 被观察改变行为 / 被试揣测假设并配合 / 主试无意影响结果 | 三条彼此独立的威胁 | 把三者当一回事；只用双盲应付需求特征，却不做操纵检查 |

## 6. 典型题型与解题套路

### 实验设计题（给一个日常疑问或一个假设，要求设计实验）
1. 先把说法改写成"操纵什么、测什么、和什么比"：写出 IV 的水平数与分配方式（被试间还是被试内）、DV 的测法与单位，以及至少要排除的两个替代解释。
2. 给每个构念写操作定义，并说明这个指标为什么能代表它——这一步是主要采分点，跳过直接丢一半分。
3. 定分配与平衡：被试间写随机分配与样本量估算，被试内写顺序平衡（拉丁方或 ABBA），并说明它为什么能抵消练习与疲劳。
4. 列混淆变量与控制动作：主试期望、时段、材料难度、被试变量。能随机化的随机化，不能的匹配或恒定，并把剩下没控住的写成局限。
5. 预演结果：写出"若假设成立，两组均值差与交互图长什么样"，再补一句"什么结果会让我放弃这个假设"。
**常见失分点**：只写"随机分组"不写随机化单位与样本量；DV 写成笼统的"表现变好"。

### 统计解读题（给一张表、一段结果或一句结论，要求判断）
1. 先定位检验族与设计：几组、被试间还是被试内、几个因素，决定该看 $t$、$F$ 还是回归系数。
2. 抄关键量：均值与标准差、统计量、$df$、$p$、效应量、95% CI；缺哪项就在答案里点明"报告不全"。
3. 翻译成一句话：不写"显著"，写"在 $\alpha=.05$ 下，A 组比 B 组平均高 0.6 个标准差，95% CI 为 [0.2, 1.0]"。
4. 判断能否下因果：看有没有随机分配与操纵检查；只有相关就只写"关联"，并给一条第三变量解释。
5. 查分析自由度：是不是多重比较、跑了几轮、样本量是否事后决定；可疑就写明"需校正或需预注册"。
**常见失分点**：把 $p<.05$ 读成"效应大"或"假设为真"；只报 $p$ 不报效应量与 CI。

### 理论辨析题（给两套理论或两个概念，要求区分与评判）
1. 先给一句本质差异：分歧在"机制是什么"、"边界在哪"还是"用什么证据算数"，不要一上来罗列人名。
2. 用同一现象各推一遍：两套理论对同一批数据分别预测什么，写出能被分开的那条预测（这就是关键实验）。
3. 举出区分证据：哪项研究支持 A 而不支持 B，并说明它控制了什么、样本是谁。
4. 划定适用条件：在什么任务、什么人群、什么时间尺度上各自成立。
5. 收一句"目前证据更支持谁、还缺什么设计"，允许答"证据不足，需要某类实验"。
**常见失分点**：用"两者都有道理、应结合"收尾；只背主张不许可检验预测。

### 案例分析题（给一个行为现象、一段访谈或一份数据）
1. 先把叙述拆成事实与解释：哪些是可观察行为（频次、时长、强度、情境、对象），哪些是当事人或旁人的归因。
2. 把行为写成变量，选一个可测的 DV 并说明测量方式，再点明取样单位。
3. 给三条竞争解释（个体差异、情境、观察或测量偏差），对每条写"如果它对，应该额外看到什么"。
4. 说清用什么设计或数据能区分这三条，给一个最小可行方案（一周行为记录加一次操纵）。
5. 收尾写边界与伦理：结论只覆盖这个样本与情境；涉及自伤、虐待、成瘾时写明转介。
**常见失分点**：直接贴诊断标签或做道德评价，不给可观察行为，也不给替代解释。

## 7. 常见误区

1. **把相关说成因果** → 错在没排除第三变量与反向因果；应先写出两条替代解释，再问设计里有没有随机分配。
2. **用"显著"替代"重要"** → 错在只看 $p$；应同时报效应量与 CI，并对照该领域的实际意义阈值。
3. **一个构念只用一个指标** → 错在估不出测量误差；应至少两个指标，或用有信度报告的量表。
4. **被试内设计不做顺序平衡** → 错在把练习与疲劳算成处理效应；应用拉丁方或 ABBA，并在结果里检查顺序主效应。
5. **先收数据再想假设** → 错在把探索当验证；应先预注册，事后分析一律标注为探索性。
6. **复现失败就归为造假** → 错在忽略样本、情境、测量与分析的差异；应先做最接近的直接复现，再谈概念复现。
7. **把脑区激活当成心理解释** → 错在把相关当机制；应说明该区参与哪些已知过程，并给出行为层面的可区分预测。

## 9. 交叉专业与后续方向

- **和教育学的区别**：教育学问"在班级、课标、课时的约束下该怎么教、怎么证明教有效"，产出是教案、课程与干预方案；心理学问"这个行为的机制是什么、在控制条件下由哪些变量决定"，产出是可重复的效应与模型。同一份课堂走神记录，心理学答注意资源如何分配、用什么范式测出来，教育学答这节课怎么改。心理学可以只交机制不管可行性，教育学必须机制、方案、证据一起交。
- **和神经科学的区别**：神经科学问"哪套神经机制实现了它"，靠脑成像、电生理、损伤与动物模型；心理学问"行为的函数关系是什么"，靠操纵与测量。看到"某脑区激活"不能直接说"某心理过程发生"——反向推理要求该区对目标过程有已知的选择性（K04-6）。两者交汇在认知神经科学，但训练重点不同：一个练实验设计与统计，一个练信号处理与神经解剖。
- **和统计学的区别**：统计学给方法与保证（估计、检验、模型假设），心理学负责把构念变成变量、把假设变成可操纵的设计。同一份数据，统计学问"模型设定对不对"，心理学问"这个操纵真的改变了构念吗"。
- **和临床医学、精神病学的区别**：精神病学做诊断与处方，非临床方向的心理学只做行为与机制的描述与检验；临床与咨询方向需要专门的学历训练与执业资质，本科课程不授予这些资格。
- **边界声明**：本文件不做心理诊断、不替代专业咨询。如果用户描述的是持续两周以上的情绪低落、自伤或伤人念头、幻觉、进食与睡眠严重紊乱，本文件只帮他把现象写成可观察的描述，并建议联系学校心理咨询中心或精神科；给诊断标签、给治疗方案都不在本文件范围内。
- **后续方向**：基础心理学、发展与教育心理学、应用心理学（工业与组织、消费、用户体验）、认知神经科学等学硕与专硕；用户研究、心理与人才测评、学校心理教师（需相应资质）、特殊教育、人机交互与可用性测试；进阶课程为心理测量学、多元统计与结构方程、认知神经科学方法、质性研究方法。
