# 地理科学（geography）

> 使用前先读 `../../references/curriculum-rules.md`（难度与排序规则）与
> `../../references/learning-card-template.md`（讲解结构）。
> 本文件只提供"这个专业的知识骨架与专业习惯"，不要在这里重复通用协议。

## 1. 这个专业在训练什么

地理科学靠**空间解释**吃饭。任何结论要能回答三个问题：为什么在这里（位置）、为什么这样分布（格局）、换个尺度还成立吗（尺度）。证据是地图、遥感影像、野外记录和口径可核对的统计量，不是印象。

它和"背地名、记省界、讲旅游"不是一回事。地名只是索引，真正拉开差距的是三块：把格局还原成过程（K01、K02）、把图读成可量算的证据（K03）、用 GIS 与遥感把证据做成可复现的图层（K04、K05）。

**一句话画像**：把空间分布讲成机制，把地图读成证据。

和隔壁的分界先记一句：地理科学问"为什么这样分布"，地理信息科学问"这套数据模型与算法建不建得出来、精度多少"，测绘工程问"坐标与几何量测得准不准"。同一份数据，三者验收方式不同（详见第 9 段）。

**最容易误解的一点**：以为地理是文科背诵。真正卡人的是空间尺度——同一结论在流域尺度成立、到县域可能反转，而多数失分都出在没声明尺度。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能在无标注的地形图上找出山脊、山谷、鞍部、陡崖各一处，并画出带垂直比例尺的剖面。
2. 能判断一幅地图用了哪类投影，并指出它在图幅范围内的主要变形方向。
3. 能对一个区域的气候、地貌、水文、土壤植被写出要素耦合链，而不是并列罗列。
4. 能用人均、比重、区位商等指标比较两个区域，并说明口径不一致会把结论改成什么样。
5. 能在 GIS 里跑通"投影—裁剪—缓冲—叠加—统计—制图"一条流程，交付要素齐全的地图。
6. 能根据波段与 RGB 的对应关系判断假彩色影像中植被、水体、建成区的表现，并说出依据。
7. 能为每条结论标注证据来源与尺度适用范围，缺数据时明确写"这里只能给量级"。
8. 能区分空间相关与因果，并对自己的解释给出一个可推翻它的观察。

## 5. 术语与符号约定

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| 空间尺度 | 研究覆盖范围与分析单元大小的组合 | 全球/区域/局地；幅度与粒度两维 | 尺度不是"地图放大"；换分析单元会改结论（可塑性面积单元问题） |
| 尺度转换 | 由细到粗聚合（升）或由粗到细推断（降） | — | 升尺度不能靠取平均掩盖内部差异；降尺度是推断，必须写明假设 |
| 比例尺 | 图上距离与实地距离之比 | 1:5 万等，分母越大比例尺越小 | "比例尺大"指分母小、内容详细；答题把大小说反是最常见的零分点 |
| 等高线 | 地面上高程相等点的连线 | 同一幅图内等高距固定 | 等高线不相交（陡崖除外）、不分支；示坡线指向低处而不是高处 |
| 等高距 | 相邻两条等高线的高差 | 如 10 m、20 m | 相对高度 = 等高线条数差 × 等高距；别把它当绝对高程 |
| 地形剖面 | 沿剖面线切出的垂直断面 | 水平与垂直比例尺可不同 | 垂直比例尺放大会夸大起伏；读图先看两轴比例尺，答题要注明是否夸大 |
| 坡度 | 坡面的倾斜程度 | 角度或百分比，$\tan\theta=\Delta h/\Delta l$ | 图上量的坡长要先按比例尺换成实地距离；百分比坡度不是角度 |
| 坡向 | 坡面法线水平投影的方位 | 0–360°，正北为 0°，顺时针 | GIS 里常以 0 表示北、−1 表示平地；别写成"东为 0°" |
| 地图投影变形 | 球面展开到平面的长度、面积、角度误差 | 按用途分等角、等积、等距 | 不存在无变形的投影；先问用途再选投影，别问"哪个投影最准" |
| 地理坐标 | 经纬度，球面坐标 | 纬度 −90°~90°，经度 −180°~180° | 中国境内写东经北纬，别漏符号；度分秒与十进制度换算时 1°=60′ |
| 投影坐标 | 投影到平面后的 $x,y$（或 E,N） | 米 | 在 GIS 里 $x$ 是东向、$y$ 是北向；经纬度不能直接相减算距离 |
| 高程基准 | 高程的起算面 | 我国常用 1985 国家高程基准 | 不同基准可差数十厘米到米级；跨数据源先统一，别默认都是同一基准 |
| DEM / DOM / DSM | 数字高程模型 / 正射影像 / 数字表面模型 | 米 | DSM 含植被与建筑，DEM 不含；算坡度坡向只能用 DEM |
| 分辨率四要素 | 空间、光谱、时间、辐射 | 米、nm、天、bit | 空间分辨率不等于成图比例尺；混合像元会让分类精度整体掉一档 |
| 波段与假彩色合成 | 把不同波段分别赋给 R、G、B 通道 | 如近红外赋红、红赋绿、绿赋蓝 | 假彩色颜色不对应真色；标准假彩色里健康植被是红色，凭直觉答绿必错 |
| NDVI | 近红外与红光反射率的归一化差值 | −1~1 | 要用反射率或定标后数据，不能拿原始 DN 值算；水体为负 |
| 叠加分析 | 两层空间数据按位置求交并合并属性 | 输出类型分点、线、面 | 叠加前必须统一坐标系与投影；属性合并规则（谁保留、冲突怎么定）要写清 |
| 缓冲区 | 距要素不超过给定距离的区域 | 米 | 在经纬度坐标下做缓冲区会随纬度变形；大范围先投影再做 |
| 空间自相关 | 邻近单元的属性相似程度 | Moran's I 约 −1~1 | 先定义空间权重矩阵再算；显著只说明有格局，不说明有因果 |
| 中心地理论 | 用门槛人口与最大销售距离解释中心地等级 | 市场区理想形状为六边形 | 六边形是模型推论而非实测形状；别把"城市都是六边形"当结论 |
| 推拉因素 | 迁出地推力与迁入地拉力的组合 | — | 同一因素对不同人群方向可能相反（如老家房价对老人是拉力对青年是推力） |
| 人口迁移 / 流动 | 是否改变常住地 | 迁移改变常住地，通勤等属流动 | 统计口径（户籍、常住、居住证）不同，数字能差一大截，引用必须写口径 |
| 区位商 LQ | 地区某行业占比与全国该行业占比之比 | 大于 1 表示相对专业化 | 分子分母口径必须一致；LQ 大于 1 不等于有竞争优势，只是相对集中 |
| 城镇化率 | 城镇常住人口占常住总人口比重 | % | 与"非农人口比重"不是一个口径；两套数据混用会凭空多出几个百分点 |
| 地带性与非地带性 | 纬度、经度、垂直分异 vs 海陆、地形、洋流 | — | 垂直带谱的基带与该地水平自然带一致；答题要把两类原因分开写 |
| 方位与三北 | 真北、磁北、网格北 | 磁偏角、子午线收敛角 | 地形图默认上北下南，但网格北与真北有夹角；用罗盘量图要修正磁偏角 |

## 6. 典型题型与解题套路

### 地图判读题（地形图、专题图、遥感影像）
1. 先读图外要素：图名、比例尺、图例、高程基准与坐标网格类型，缺哪项就先声明假设。
2. 定方位：分清经纬网与方里网，明确真北、磁北、网格北的差别。
3. 提地形骨架：按等高距数等高线定高程，用"凸向低处为山脊、凸向高处为山谷"判脊谷，再找鞍部、陡崖、盆地。
4. 按问题做量算：水平距离按主比例尺换算，剖面另标垂直比例尺，坡度用高差除以实地水平距离。
5. 收尾写成"证据—推理—结论"三句，不要只留一个结论。
**常见失分点**：把图上量的厘米直接当米；剖面画完不标垂直比例尺，或夸大了起伏却不说明。

### 机制分析题（为什么这里热/这里旱/这里聚人）
1. 先定位定时：经纬度、海陆位置、地形部位，加上季节与太阳直射点位置。
2. 列要素清单：气候（光热水）、地形、水文、土壤植被、人类活动，每项只写与本问有关的那一条。
3. 写因果链：用"要素 → 过程 → 结果"的箭头句，每步落到机制名词（焚风、雨影、逆温、狭管效应）。
4. 做边界检验：换一个尺度或时段是否仍成立，给一个反例并说明它在什么条件下失效。
5. 收束成一句直接回答"为什么在这里、为什么这样分布"。
**常见失分点**：只堆要素不写过程，把"靠海所以降水多"当机制；没有反例意识，答案无法被证伪。

### GIS 操作题（选址、适宜性、变化检测）
1. 先写数据清单：图层、几何类型、坐标系、关键字段、栅格像元大小。
2. 写流程并标输入输出：投影转换 → 裁剪 → 缓冲或重分类 → 叠加 → 统计 → 制图。
3. 给全参数：缓冲距离与单位、叠加的属性保留规则、重分类阈值、像元大小。
4. 做量级核验：面积总数、目标区占比是否合理，异常值回查是哪一步引入的。
5. 交付成图：图名、图例、比例尺、指北针、坐标网格、数据来源与处理时间缺一不可。
**常见失分点**：没统一坐标系就叠加；只写"用软件做缓冲区"而不写距离、单位与保留规则。

### 区域综合题（区域特征、差异比较、发展建议）
1. 先声明"哪一区域、哪个尺度"，尺度写错后面全错。
2. 搭三段框架：自然本底（气候、地形、水文、土壤植被）→ 人文过程（人口、产业、交通）→ 问题与约束。
3. 选指标并标注来源与年份；记不清的数字只写量级与趋势，绝不编具体值。
4. 做纵横对比：横向找同类区域，纵向看发展阶段，说明结论的适用范围。
5. 措施落到可执行动作：每条写清针对哪个环节、代价是什么、由谁承担。
**常见失分点**：为凑"完整"编造统计数字或"某年某图"来源；只写优势不写限制。

## 7. 常见误区

1. **把"靠海所以降水多"当机制** → 错在跳过水汽输送与抬升；应写成"盛行风把水汽带到迎风坡→抬升冷却→凝结"，并指出雨影区在哪一侧。
2. **在经纬度坐标下直接量距离或做缓冲区** → 错在把度当米；应先投影到合适的等距或等积坐标系，或改用大圆距离公式。
3. **按真色读假彩色影像** → 错在把波段组合当可见光；应先确认波段与 RGB 的对应，标准假彩色里健康植被是红不是绿。
4. **把坡度百分比当角度** → 错在漏了 $\arctan$；10% 坡度约 5.7°，写成 10° 会让剖面判断与工程结论一起偏。
5. **把空间相关当因果** → 错在只看两图层重合；应给出一个能推翻自己的观察，比如控制第三变量后关系是否消失。
6. **叠加分析不先统一坐标系** → 错在直接求交；结果是整体偏移，且偏移量随位置变化，越到图幅边缘越大。

## 9. 交叉专业与后续方向

- **和地理信息科学（偏工科一侧）的区别**：地理科学问"这个格局为什么这样、证据链够不够"，验收看解释力能否经受反例；地理信息科学问"这套数据模型、算法与系统建不建得出来、精度多少、能不能扩到百万级要素"，验收看跑通与误差。同一份土地利用数据，地理科学读"这条分界线说明了什么过程"，地信读"这个缓冲区在百万要素上如何索引才不超时"。按现行本科专业目录，地理信息科学仍列在理学门类的地理科学类，遥感科学与技术列在工学门类的测绘类；具体归属与学位以学校当年培养方案为准，别替学校下结论。
- **和测绘工程的区别**：测绘保证坐标与几何量测得准，地理科学接着问测出来的东西意味着什么；前者交付控制点与地形图，后者交付机制解释。
- **和环境科学、生态学的区别**：环境科学以污染物与标准为中心，生态学以种群与能量流为中心，地理科学以空间格局与区域差异为中心，三者常在"区域"这个对象上会合。
- **和城乡规划的区别**：规划做决策与方案落地，地理科学做本底评价与机制判断；规划图上的每条指标，地理这边都要能追到数据来源。
- **一条硬规矩**：不编造统计数字，也不编造地图或影像的来源。记不清就写量级、趋势与"该项数据缺失"，并注明口径、年份与出处；编一个看起来合理的数字，比空着更容易被判为学术不端。
- **后续方向**：考研走自然地理学、人文地理学、地图学与地理信息系统；岗位多在自然资源调查监测、国土空间规划、遥感应用、GIS 开发与中学地理教学；进阶课程是空间分析、地统计、全球变化与土地利用覆被变化。
