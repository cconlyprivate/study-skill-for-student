# 音乐学（musicology）

> 先读 `../../references/curriculum-rules.md`（难度与排序）与 `../../references/learning-card-template.md`（讲解结构）。
> 本文件只给这个专业的知识骨架与专业习惯。

## 1. 这个专业在训练什么

训练对象是**声音里的结构**，不是"感觉"。同一段贝多芬，音乐学要回答的是：第几小节离开了主调、靠哪个和弦当枢轴、这个结构选择造成了什么听觉效果、依据哪一版谱例可以证明。

靠这个吃饭的方式是**翻译**：把"这里好听"翻译成别人能复核的结构描述（音高组织、曲式位置、配器手段、史料出处），再据此写分析、写评论、写论文。

外人常以为这专业 = 会弹琴会唱歌、懂点乐理。实际的基本功是三件：把谱面读准（K01、K02）、把和声与曲式拆开（K03、K04）、把作品放回历史与版本里定位（K05–K08）。

**最常见的一条界**：音乐表演把作品变成声音，音乐学把声音变成可被第三人复核的判断。同一首曲子，表演考核看完成度，音乐学考核看证据。

**最容易误解的一点**：以为"听得多"就会分析。没有记谱能力与结构词汇，听一百遍也只能说"好听"，说不出第几小节为什么好听。

**最陡的三门课**：和声学（因为规则互相牵制，改一个声部会牵动另外三个）、曲式与作品分析（因为结构判断必须与终止式、调性布局同时成立）、视唱练耳（因为靠日积月累，考前突击无效）。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能在 10 分钟内给一段 16 小节谱例标出调性、和弦级数、转位与全部终止式。
2. 能画出任何一首中小型作品的曲式结构图，标到乐句一级，并写出起止小节号。
3. 能听一段 3 分钟的音乐，交出含时间点、编制、织体、结构判断的听辨报告。
4. 能把 4 件移调乐器的记谱音高换算成实音，并说出各自的常用音域。
5. 能对同一作品的两个版本指出具体记号差异，并说明取舍依据。
6. 能就一个音乐史问题写出 1500 字论述，每条判断后面跟着史料或作品出处。
7. 能识别出自己无法核对的作品号、调性与谱例，并改成可核对的表述。

## 5. 术语与符号约定

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| 音组（c¹ / C4） | 绝对音高的记法 | 中国分大字组、小字组、小字一组；英美术语用 C4 | c¹ 就是 C4，两套起点差一组，抄外文谱例时先对齐再写 |
| 音级与和弦级数 | 调内音的位置，和弦用罗马数字 | 音级用 1–7，和弦用 Ⅰ–Ⅶ | 音级阿拉伯数字、和弦罗马数字，同一行里混写会被判概念不清 |
| 音程度数与音数 | 度数按音级数算，音数按半音数算 | 增四度与减五度都是 6 个半音 | 度数由字母定、音数由键盘定，只看半音数会把增四写成减五 |
| 音程转位 | 根音冠音对调 | 度数相加为 9 | 大转小、增转减、纯转纯；写成"相加为 8"整题作废 |
| 调性与调式 | 调性 = 主音 + 调式；调式 = 音阶内部关系 | 如 a 小调、C 宫 | "调性不明"不等于"调式不明"；中国五声调式写"宫"不写"大调" |
| 调号与临时记号 | 调号管整行，临时记号只管本小节同音高 | 升降号写在谱号之后 | 还原必须写 ♮；下一小节不自动延续，要再写一次 |
| 和声功能 T–S–D | 主、下属、属三个功能组 | 斯波索宾体系；英美写 Ⅰ–Ⅳ–Ⅴ | 功能字母与罗马数字不是一套，别在一行里混着标 |
| 和弦转位标记 | 数字低音：⁶ 为第一转位，⁶₄ 为第二转位 | 原位不写数字 | 爵士与流行标记里 V6 常指加六音和弦，同形不同义 |
| 终止式 | 全终止 V–Ⅰ、半终止停在 V、阻碍 V–Ⅵ、变格 Ⅳ–Ⅰ | 全终止分完满与不完满 | "完满"要三条同时满足：低音 V→Ⅰ 根音进行、旋律落主音、落在强拍 |
| 二部与三部曲式 | 二部 AB，三部 ABA | 三部的第三部分必须是再现 | AAB 不算三部；带再现的二部被误判成三部是最常见的错 |
| 回旋曲式 | ABACA，叠部至少三次回到主调 | 叠部 refrain 与插部 episode | 插部不离开主调就只是变奏，不构成回旋 |
| 奏鸣曲式 | 呈示部、展开部、再现部，靠主部与副部的调性对比成立 | 常带引子与尾声 | "奏鸣曲"是体裁、"奏鸣曲式"是结构，答题时两词不能互换 |
| 移调乐器 | 记谱音高与实际音高不同 | B♭ 单簧管记谱高一个大二度；F 圆号记谱高纯五度；低音提琴记谱高八度 | 算音域和读总谱前先换算，直接按记谱音高判断会系统性地错一个音程 |
| 音区写法 | 用具体音域，不用"高音区" | 如 c²–g³（实音） | 必须注明是实音还是记谱音高，对移调乐器两者差一个音程 |
| 配器（orchestration） | 把乐思分配到各组乐器 | 按木管、铜管、弦乐、打击分层记 | 写"弦乐加厚"要说明是加声部还是加八度；不核对音区与移调就写配器分析，等于没写 |
| 首调与固定调 | 首调 do 随调移动，固定调 do 恒为 C | 简谱 1=E 表示 E 唱 do | 同一句在两套里音名不同，答"这是什么音"前先声明用哪套 |
| 工尺谱 | 谱字按首调唱名排列 | 上尺工凡六五乙为七声 | 宫音位置随调名变化，不能当绝对音高读；译谱第一步是定宫 |
| 作品号体系 | Op. 出版商编号，K. 莫扎特，BWV 巴赫，Hob. 海顿，D. 舒伯特 | 各成一套，互不通用 | 一部作品只用一套能核对的编号；混用或凭印象编，阅卷直接判错 |
| 小节计数 | 弱起是否计入第 1 小节 | 两种惯例并存 | 引用"第 12 小节"要说明按哪种计数，否则对方定位不到 |
| 拍号与速度 | 4/4 与 C 等价，2/2 为 alla breve | ♩=120 指每分钟四分音符数 | ♩ 与 ♩. 的数值不可直接换算；变拍子要标出新拍号的小节 |
| 谱号与中央 C | 高音、低音、中音、次中音谱号 | 中音谱号第 3 线、次中音谱号第 4 线都是 c¹ | 把中音谱号当"高音谱号下移三度"读会系统性读错 |
| 净版（Urtext） | 依据手稿与初版、不掺编者建议的版本 | 常见骑熊人、亨乐等社 | 不同版本的连线、力度、装饰音可能不同，引谱例必须写版本 |
| 演奏实践（HIP） | 按历史证据决定音高、律制、编制与装饰 | 巴洛克 A 常取 415 Hz | 415 与 440 差约半音；只说"巴洛克音高"不给数值，等于没给信息 |
| 和弦外音 | 经过音、辅助音、倚音、延留音、先现音 | 不占独立功能 | 判外音前先确认它不构成独立和弦，否则会把经过和弦当外音 |
| 织体 | 主调（homophony）、复调（polyphony）、单声 | 与曲式不是一回事 | 赋格是复调体裁不是曲式类型；"主调"也不等于"主调性" |

## 6. 典型题型与解题套路

### 和声分析题（给谱例或数字低音，标功能与终止式）
1. 先定调：看调号、开头的和弦、最后一个和弦，三处一致才写"调性为某调"；只用调号下定论，遇到转调就全错。
2. 逐小节标"小节.拍 + 级数 + 转位 + 功能"，如"9.1 Ⅴ⁶ D"；遇到变化音先分三类：副属、变和弦、经过性变化音。
3. 找终止式并标在小节号上，把全终止、半终止、阻碍终止连成骨架，乐句边界自然出现。
4. 圈出 T–S–D–T 的功能段，再用枢轴和弦说明离调与转调；离调写成"某调的 V–Ⅰ"，转调写成"由某调至某调，枢轴在某小节"。
5. 写完通读一遍，确认每个变化音都有归属，没有"不知道为什么升"的音。
**常见失分点**：只写和弦性质（大三、小三）不写级数与转位；把所有 ♯ 都当转调，答不出枢轴和弦。

### 曲式分析题（划分部分，画结构图）
1. 先数小节并编号，写清弱起算不算第 1 小节，再标调性布局。
2. 用终止式切乐句，一条终止式一个句读；不要按"主题听起来像不像"切。
3. 定部分看再现：A 材料在属调或主调上完整回来才算三部，不回来就按二部处理。
4. 画结构图：横轴小节号，纵轴层级（部分—乐部—乐句），每层标调性与终止式。
5. 最后一句写"这个结构支撑了什么效果"，把分析接回听觉印象，否则报告只有骨架没有结论。
**常见失分点**：只写"ABA"三个字母，不给小节号与调性；把奏鸣曲式的展开部当成一个独立乐部。

### 听辨描述题（听音频，写听辨报告）
1. 第一遍只听骨架：编制、速度、拍感、大致分几段，这一遍不写形容词。
2. 第二遍盯低音与和声：记终止出现的位置、有没有转调、织体是主调还是复调。
3. 第三遍抓特征手法：独奏乐器进入点、音区变化、配器加层与撤层。
4. 报告按"客观描述—结构判断—依据"三段写，每条判断后面跟一个可复听的时刻，如"0:42 加弱音器"。
5. 检查每条判断能不能被第三个人复听后同意；不能的删掉或降级为推测。
**常见失分点**：通篇写"优美、震撼"，没有时间点与小节，阅卷无法核对。

### 音乐史论述题（给一个现象或一个人物）
1. 先定边界：时间、地域、体裁，把题目里的概念换成可查的机构、作品或人物。
2. 立一句可辩护的判断，写成"因为某机制，所以出现某现象"，不写"某时期音乐很繁荣"。
3. 给三条证据：一条史料、一部作品、一条制度或技术条件，每条注明出处与可靠性。
4. 处理一个反例：找出不符合判断的作品或人物，说明它为什么不推翻判断。
5. 收尾写适用范围：这个判断在哪个时段、哪种体裁、哪类史料里成立。
**常见失分点**：堆时代背景不落到机制；把教材结论当自己的判断，且不标出处。

## 7. 常见误区

1. **用"好听/震撼"当结论** → 错在没把听觉印象拆成结构位置与手法；应写成"第 24 小节属七延迟解决，期待被拉长"，再指回听到的效果。
2. **看到临时记号就判转调** → 错在漏掉副属、变和弦与经过性变化音；判据是有没有出现新调的属—主进行并形成终止式。
3. **首调与固定调混着说** → 错在同一句里两套唱名并存；答"这是什么音"前先声明用哪套，音名与唱名分列。
4. **曲式按主题相似度划分** → 错在忽略终止式与调性收束；先标终止式再定乐句，乐句定了部分才定得下来。
5. **和声分析只写和弦性质** → 错在丢了级数、转位与位置；每个和弦写成"小节.拍 + 级数 + 转位 + 功能"四件套。
6. **凭印象写作品号** → 错在把 Op.、K.、BWV、Hob. 混用或自造；写不出就只写作曲家与作品名，编号宁缺不编。
7. **把录音当唯一证据** → 错在录音含演奏者的速度与配器改动；引用要写演奏者、录音年代与版本，并与谱面核对。
8. **按记谱音高给移调乐器算音域** → 错在忘了移调；写音域前先查乐器调，实音与记谱音高分别标注。

## 9. 交叉专业与后续方向

- **和音乐表演（本仓库未收）的区别**：表演专业把作品变成声音，考核看完成度与风格把握；音乐学把声音变成可复核的判断，考核看证据与论证。同一个学生两条线可以都走，但答题标准不同：表演答"我怎么处理"，音乐学答"我依据哪一小节这样判断"。
- **和戏剧影视文学的区别**：戏文以剧本与视听叙事为对象，判断落在人物、冲突与镜头语言；音乐学以乐谱与音响为对象，判断落在音高组织、结构与体裁。同一部歌剧，戏文谈戏剧结构，音乐学谈音乐结构与戏剧节点如何对齐。
- **和美学、艺术学理论的区别**：美学问"音乐为什么动人"这类普遍命题；音乐学要求在具体作品的具体小节上给证据，普遍结论必须由个案支撑。
- **和音乐教育的区别**：音乐教育问"怎么教才会被学会"，音乐学问"这部作品如何构成"。两者在考研与就业上常交叉，但一个交教案与测评，一个交分析与论文。
- **后续方向**：考研方向有音乐学理论、作曲技术理论、民族音乐学、音乐教育；岗位有中小学与高校教师、乐团与剧院节目策划、乐评与音乐编辑、艺术管理与版权、录音与制作；进阶课程为复调、配器法、音乐分析学、民族音乐学田野方法、音乐声学。
- **作答底线**：不虚构作品号、调性与谱例。编号记不清就写作曲家与作品名；调性拿不准就写出两个候选与各自判据，让判断可被检验；谱例记不清就写"某段落的某特征"，并注明所依据的版本与小节号。
