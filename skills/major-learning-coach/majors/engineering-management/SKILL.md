# 工程管理（engineering-management）

> 先读 `../../references/curriculum-rules.md`（难度与排序）与 `../../references/learning-card-template.md`（讲解结构）。
> 本文件只给这个专业的知识骨架与专业习惯。

## 1. 这个专业在训练什么

把一个技术方案换算成三样东西：**要花多少钱、要占多少天、出了问题谁担责**。技术方案说"能这么造"，工程管理要回答"这么造值不值、排得开排不开、白纸黑字写清了没有"。

核心能力是**在约束下取舍并留下可核对的证据**。取舍靠工程经济学（K01）与进度计划（K04），证据靠合同、变更、索赔、计量支付（K02、K03、K05）。算得再准，没有一份站得住的书面依据，钱一样要不回来。

外人以为工管 = 土木课 + 管理课各学一半。实际上它有自己的硬核：网络计划的时间参数、挣值的三参数、清单计价的组价规则、索赔的程序时限，这四样在土木和工商管理里都不会教。

**最容易误解的一点**：以为造价 = 算量套价。算量只是入口，真正决定造价的是**合同类型与风险分配**——同一张图，总价合同和单价合同报出来的价、结算时能争的钱，完全不是一回事。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能把一个项目的收支画成现金流量图，算出 NPV、IRR 与动态回收期，并给出投或不投的判据。
2. 能对寿命期不同的互斥方案用年值法或增量分析比选，写清结论对折现率的敏感程度。
3. 能按现行计价规则算出给定构件的工程量，组出综合单价，说清每一项费用的归属。
4. 能把单位工程分解成可派工的工作包，画出网络图并手算出关键线路与总时差。
5. 能对一份月度报表算出 PV、EV、AC 与 CPI、SPI，预测完工费用并指出偏差成因。
6. 能对给定事件判定索赔是否成立，写出通知与报告的时限、依据条款、应补的工期与费用。
7. 能排出含流水段与总平面的施工组织方案，指出工期、成本、场地三者冲突的位置与取舍理由。

## 5. 术语与符号约定

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| `i` 折现率 / `i_c` 基准收益率 | 折算时点用的利率 / 行业或企业规定的最低可接受收益率 | % | `i_c` 不是银行贷款利率，也不是项目实际融资成本；NPV 随 `i` 增大而减小，`i` 取错结论直接反 |
| `n` 计息期数 | 按**计息期**计的期数 | 期 | 题目说"年利率 12%、按季计息、5 年"，则 `n=20` 且须用季利率，仍用 5 期是最高频错误 |
| 名义利率 `r` / 实际利率 `i` | $i=(1+r/m)^m-1$ | % | `r` 与 `i` 混用会让同一方案的 NPV 差几个百分点；比较方案必须统一到同一口径 |
| 现金流量图时点 | 投资与收益默认画在**期末**，$P$ 恒在 0 点 | 年/月 | 把"年初投入"也画到第 1 年末，等值结果整体差一个 $(1+i)$ |
| `NPV` | $\sum (CI-CO)_t(1+i_c)^{-t}$ | 货币 | 是绝对额且依赖 `i_c`，报 NPV 必须同时给折现率；不同折现率下的 NPV 不可比大小 |
| `IRR` | 使 NPV = 0 的折现率 | % | 现金流多次变号时 IRR 可能多解或无解，此时只能报 NPV 或修正 IRR，不能硬报一个数 |
| $\Delta IRR$ 增量内部收益率 | 用"大投资减小投资"的差额现金流算出的 IRR | % | 互斥方案不能直接比 IRR 高低；规模不同时 IRR 高的那个往往 NPV 更低，判据是 $\Delta IRR \ge i_c$ |
| 寿命期不同 | 用年值 $AW$ 或最小公倍数法拉到同一比较期 | 年 | 直接比 NPV 等于默认寿命相同，结论会系统性偏向寿命长、总额大的方案 |
| `WBS` 工作包 | 按可交付成果逐层分解到能派工、能计量、能验收的最低层 | 通常 3 到 4 级 | 用 100% 规则核对：子项之和必须等于父项，漏项与重项都在这一层产生；分解过细会让管理成本超过收益 |
| 折旧 | 直线法、工作量法、双倍余额递减法、年数总和法 | 货币/年 | 折旧本身不是现金流，但通过所得税影响现金流；双倍余额最后两年改直线这一条最常漏 |
| 分部分项工程费 | 清单计价下实体项目的费用合计 | 货币 | 与老定额口径的"直接费"不是一回事，两套费用构成不能混着列 |
| 项目编码 | 清单项目 12 位阿拉伯数字 | 位 | 前 9 位按附录取定、后 3 位由编制人编；自造前 9 位属于清单编制错误 |
| 综合单价 | 人工费 + 材料费 + 机械费 + 管理费 + 利润（+ 风险费用） | 元/计量单位 | **不含规费和税金**；把税金塞进综合单价是本专业最常见的组价错误 |
| 定额消耗量 / 清单工程量 | 定额按工序算且含损耗 / 清单按图示净量算 | 计量单位 | 两者口径不同，把定额含量直接当清单量会导致报价虚高且无法结算 |
| 措施项目费 | 不构成实体但施工必需的费用 | 货币 | 安全文明施工费不可竞争，不能作为让利项砍掉；其余措施费可按方案自主报价 |
| 暂列金额 / 暂估价 | 发包人掌握、用于不可预见变更的金额 / 暂定的材料设备单价 | 货币 | 暂列金额不属于承包人，结算按实际发生计；把它当收入做资金计划会虚增现金流 |
| 总价合同 | 承包商承担工程量风险与价格风险 | — | 报价里含风险溢价；工程量不确定时若仍用总价合同，承包商日后只能靠变更与索赔找回，双方程序成本都更高 |
| 单价合同 | 业主承担工程量风险，承包商承担单价风险 | — | 结算按实际工程量乘合同单价；把中标价直接当结算价是漏算变更、调价与索赔 |
| 成本加酬金合同 | 业主承担几乎全部成本风险 | — | 只适用于工程内容不清、工期紧迫的项目；必须配套费用审核与酬金上限条款 |
| 索赔程序时限 | 知道或应当知道事件后 28 天内提交索赔意向通知 | d | 逾期视为放弃权利；且工期索赔还要证明延误落在关键线路或超过总时差 |
| 变更程序时限 | 承包人收到变更指示后 14 天内提交变更估价申请 | d | 与索赔的 28 天不是一个时限，两个数字互换是案例题的标准错法 |
| 总时差 $TF$ / 自由时差 $FF$ | $TF=LS-ES$ / $FF=\min(ES_{紧后})-EF$ | d | 延误不超过 $TF$ 不影响总工期，超过 $FF$ 才影响紧后工作；两个阈值不能混用 |
| 关键线路（`CPM`） | 总时差为 0 的工作串成的线路，决定总工期 | — | 关键线路可能不止一条；压缩工期只能压关键工作，且每压一次必须重算，否则关键线路转移 |
| `PV` `EV` `AC` | 计划工作预算费用 / 已完工作预算费用 / 已完工作实际费用 | 货币 | `EV` 必须用**预算单价**乘实际工程量；用实际单价算 `EV`，`CPI` 会被抹平 |
| `SPI` `CPI` | $EV/PV$ / $EV/AC$ | 无量纲 | 指数小于 1 是不利，偏差小于 0 也是不利，方向相反；抄公式时正负号最容易反 |
| `BAC` `EAC` `ETC` | 完工预算 / 完工估算 / 完工尚需 | 货币 | 偏差偶发用 $EAC=AC+(BAC-EV)$，偏差持续用 $EAC=AC+(BAC-EV)/CPI$，选错公式差一截 |
| 流水步距 $K$ | 相邻两个施工过程先后投入的最小时间间隔 | d | 等节奏 $T=(m+n-1)t$；无节奏用累加数列错位相减取大差，不能拿节拍最小值当步距 |
| 虚工作 | 只表达逻辑关系，不消耗时间与资源 | — | 双代号图中漏画虚箭线，紧前紧后关系就错，关键线路随之全错 |

## 6. 典型题型与解题套路

### 经济评价计算题（NPV、IRR、比选）
1. 先画现金流量图：定 0 点，把建设期投资、运营期收支、期末残值与流动资金回收逐项标在对应时点，投资记负、收益记正。
2. 统一口径：把名义利率换成计息期利率或把计息期换算成支付期，确认 `n` 是期数不是年数，确认单位统一到万元。
3. 先符号后数值：写出 NPV 表达式再代数；求 IRR 时先试算两个折现率夹住零点，再线性插值，并说明插值是近似。
4. 判定：单方案看 $NPV\ge 0$ 且 $IRR\ge i_c$；互斥方案改算增量现金流，判据是 $\Delta IRR\ge i_c$，或直接比年值。
5. 交卷前查量级：回收期不应超过计算期、IRR 应落在合理区间、折现率与期数必须是同一口径。

**常见失分点**：把"年利率 12%、按季计息"直接当折现率而 `n` 仍按年数取，等于改了利率却没改期数。

### 进度计划题（网络图、时间参数、工期优化）
1. 先把文字逻辑翻成紧前紧后表，逐条核对有没有把可以平行的工作写成必须先后。
2. 画双代号图：节点编号由小到大、箭线从左向右，跨逻辑关系用虚箭线，不许出现无头箭线或两张图共用节点。
3. 算参数：正向推 `ES`、`EF`，逆向推 `LS`、`LF`，再算 $TF=LS-ES$、$FF=\min(ES_{紧后})-EF$；把 $TF=0$ 的工作串起来就是关键线路。
4. 压工期：只在关键工作上按赶工成本斜率从低到高选，每压一次重算一遍，防止关键线路转移或压到最短持续时间以下。
5. 判延误：先看该工作实际延误是否超过总时差，再看延误原因归谁，两条都满足才能谈工期索赔。

**常见失分点**：算出总工期却指不出关键线路；或压缩了已被挤出关键线路的工作，工期一天没省。

### 成本与挣值计算题（PV、EV、AC、CPI、EAC）
1. 先列三列：报告期的计划工作、已完工作、实际费用分开写，每列注明乘的是预算单价还是实际单价。
2. 算三参数：$PV=$ 计划量 $\times$ 预算单价，$EV=$ 已完量 $\times$ 预算单价，$AC=$ 已完量 $\times$ 实际单价；`EV` 与 `AC` 的差别只在单价。
3. 算偏差与指数：$CV=EV-AC$、$SV=EV-PV$、$CPI=EV/AC$、$SPI=EV/PV$，并统一表述成"小于 1 或小于 0 均为不利"。
4. 预测完工：先判偏差是偶发还是持续，偶发用 $EAC=AC+(BAC-EV)$，持续用 $EAC=AC+(BAC-EV)/CPI$，并把选哪个的理由写出来。
5. 下结论：说清是"花了更多钱干了更少活"还是"进度慢但没超支"，再对应到具体纠偏动作。

**常见失分点**：用实际单价计算 `EV`，使 `CPI` 恒在 1 附近，整道偏差分析失去意义。

### 合同与索赔案例题
1. 先定性：把事件归入变更、索赔、违约、不可抗力中的一类，不同类别的程序与计价规则不同。
2. 查程序：从合同条款找出通知时限（索赔意向 28 天、变更估价 14 天）、提交对象与形式，先判程序是否成立。
3. 定责任：对照合同责任划分，判断事件属于业主风险、承包商风险，还是按约定分担的不可抗力。
4. 算量与钱：费用只计实际发生且合理的部分；工期只有落在关键线路或超过总时差的部分才予补偿。
5. 写结论：给出"成立与否 + 依据条款 + 天数 + 金额"，不要只写一句"应当索赔"。

**常见失分点**：一上来算钱，不判程序时限；或把非关键工作的全部延误都算成可索赔工期。

## 7. 常见误区

1. **互斥方案直接比 IRR 高低** → 错在忽略投资规模差异，IRR 高往往对应绝对收益低；应改算增量 IRR 或直接比年值，并回答"多投的那部分钱值不值"。
2. **认为总价合同对业主最省事** → 错在忽略风险溢价与索赔成本；工程量不确定时应选单价合同，把量差风险留给能控制它的一方。
3. **用实际单价算 EV** → 错在把已完工作的价值与已花的钱混成一个数；`EV` 只能用预算单价，否则 `CPI` 被抹平。
4. **把合同价当结算价** → 错在漏掉实际工程量调整、变更、索赔与价格调整；单价合同的结算价必须逐项重新算。
5. **索赔先干活后补手续** → 错在错过 28 天意向通知即丧失权利；应建立"事件台账 + 时限倒排表"，事件发生当天登记。
6. **压缩工期只盯关键工作而不重算** → 错在压缩后关键线路会转移、可能出现新的关键线路；每压一轮必须重画网络图并复核最短持续时间。

## 9. 交叉专业与后续方向

- **和土木工程（civil-engineering）的区别**：土木回答"这个东西凭什么叫安全、怎么造得出来"，工程管理回答"谁在什么时候、用多少钱把它造出来，出了事谁担责"。同一根梁，土木算配筋并签计算书，工程管理算它占多少工日、排在哪个流水段、拖一天罚多少。分界点是**签字对象**：承载力计算书归土木，进度款支付证书与索赔报告归工程管理。
- **和工商管理（business-administration）的区别**：工商管理在企业层面配置资源、选择市场与战略，决策可以撤、业务线可以关；工程管理在单个项目、单份合同内交付，有明确起止、验收标准与违约条款。工商管理问"这条业务线该不该做"，工程管理问"这个项目已经签了，怎么在合同工期内不亏本地交付"。工商管理的资本预算算的是企业级现金流，工程管理的经济评价算的是单项目现金流且必须落在合同价内。
- **和会计学、财务管理的区别**：会计按准则记账、按期间出报表；工程管理按合同计量支付、按节点要钱，考的是"这笔钱该不该算给承包商"而不是"这笔支出记哪个科目"。
- **造价与规范数据以现行版本为准**：本文件只讲方法与程序，不给具体数值。计价规范、消耗量定额、费用定额与税率、清单项目编码前 9 位、合同示范文本的时限天数与条款编号都会随版本更替；做题和做项目时一律查项目适用的现行版本与合同约定，不要背数字。
- **后续方向**：考研可走管理科学与工程、土木工程建造与管理、建筑与土木工程；专业学位是工程管理硕士（MEM）。典型岗位是造价与成本管理、项目管理（施工方或业主方）、招投标与合同管理、监理与咨询。执业证书方向是一级建造师、一级造价工程师、监理工程师，考试内容与本文件 K01 至 K07 高度重合。
