# 汉语言文学（chinese-literature）

> 先读 `../../references/curriculum-rules.md`（难度与排序）与 `../../references/learning-card-template.md`（讲解结构）。
> 本文件只给这个专业的知识骨架与专业习惯。

## 1. 这个专业在训练什么

训练对象是**文本**，不是感想。同一段《红楼梦》，中文系要回答的是：它用了什么叙述方式、这些方式在什么条件下出现、依据哪些原文可以证明这个判断。

**一句话画像**：读懂文本的形式与历史，并写出有依据的解读。

外人常以为这专业 = 会写作文、会背诗词。实际的基本功是三件：把字词音义说准（K01、K02）、把作品放回体裁与时代里定位（K03、K04）、把读出来的东西组织成有证据的论证（K05–K07）。

和历史的界线：历史学用史料回答"发生了什么"，中文用文本回答"这篇东西如何构成、为何这样写"。和哲学的界线：哲学要可普遍化的命题，中文接受"这一处文本如此"的局部结论。

**最容易误解的一点**：以为文笔好就能拿高分。阅卷看的是"有没有论点、有没有证据、证据有没有被解释"，文笔只影响读起来顺不顺。

**最陡的三门课**：古代汉语（因为要同时处理字词、句式、古注三层）、文学理论（因为概念必须落到文本才不算空话）、中国古代文学史（因为要在两千年的作品量与分期之间建立因果）。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能给任意一段现代汉语文本标出词性与句法成分，并指出两处可争议的切分。
2. 能独立标点并翻译 200 字文言文，特殊句式逐处标出，疑难词给出义项与依据。
3. 能判定一篇作品的文体、时代与流派，并写出判定所依据的三条形式特征。
4. 能就一首诗或一段小说写出 800 字分析，含 1 个论点、3 处引文、1 个反例。
5. 能就一个文学史问题写出 1000 字论述，给出两条落到机制的因果链与一条限定条件。
6. 能用一种理论工具解释一处文本，并说明这个解释在哪里失效。
7. 能按"作者·篇名·版本·页码"标注全部引文，交出格式统一、可被核对的论文。
8. 能在 3 小时内读完一篇中篇小说，写出可用的笔记（情节线、视角、语言特征）。

## 5. 术语与符号约定

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| 调值 55/35/214/51 | 阴平、阳平、上声、去声的五度标记 | 1–5 度 | 上声单念是 214，连读常变 35 或 21，别一律标 214 |
| 标调规则 | 声调符号标在主要元音上 | 优先级 a o e i u ü | iu、ui 标后者；ü 与 j q x 相拼写作 u |
| 国际音标 [ ] 与 / / | 方括号标实际音值，斜线标音位 | 注音与标音两套 | 拼音用于注音、音标用于标音，两套别混在同一行 |
| 声母/韵母 | 音节开头的辅音与其余部分 | 21 声母、39 韵母 | "零声母"指没有声母辅音，不是没有韵母 |
| 四呼 | 开口、齐齿、合口、撮口 | 按韵母开头元音分 | 只看韵母，与声母是否清浊无关 |
| 古今字 | 时代先后造出的两个字，古字兼义 | 如 莫—暮 | 古今字是历时分担，不是写错字 |
| 异体字 | 同音同义而字形不同 | 如 泪—淚 | 异体字可互换，古今字不能倒回去用 |
| 通假字 | 本有其字而借同音字代替 | 如 蚤—早 | 通假是"用错得合法"，须与错别字、古今字三者分开 |
| 六书 | 象形、指事、会意、形声、转注、假借 | 前四为造字，后二为用字 | 把"转注"当造字法是最常见的错 |
| 词类活用 | 名词、形容词临时用作动词等 | 如 左右欲刃相如 | 判活用要先证明"按本义讲不通"，不能见名词带宾语就判 |
| 使动/意动 | 使宾语怎样 / 认为宾语怎样 | 如 舞幽壑之潜蛟、美我 | "美我"是意动，译成"使我美"就错了 |
| 判断句 ……者，……也 | 文言判断的基本格式 | 也、乃、即、皆可作标记 | 文言判断句常不用"是"，"是"多为指示代词 |
| 被动句 见/于/为……所 | 主语是受事 | 三种标记可叠用 | "见"后接动词，"见……于"是两个标记，不能只译一个 |
| 宾语前置 | 否定句代词宾语、疑问代词宾语、之或是提宾 | 三类 | "句读之不知"的"之"是提宾标志，不是取消独立性 |
| 取消独立性 之 | 用于主谓之间，使小句不作独立句 | 如 臣之壮也 | 与提宾"之"、代词"之"同形，只能看位置判 |
| 偏义复词 | 两个语素只取其中一个的意义 | 如 作息、缓急 | 别把两个语素都译出来，译出会自相矛盾 |
| 互文 | 上下句义互相补足 | 如 秦时明月汉时关 | 逐句直译会把意思译窄，须合起来译 |
| 平仄 | 平为阴平阳平，仄为上声去声与入声 | 近体诗两字一顿 | 入声在普通话里已派人四声，按今音判平仄必错 |
| 对仗 | 词性、结构、平仄相对 | 律诗中间两联 | 只对词性不对结构，会漏掉"合掌"之外的毛病 |
| 词牌/曲牌 | 规定格律、句式与用韵，不限定内容 | 如 水调歌头 | 词牌不是题目，词题要另标；"填词"是按谱填字 |
| 意象/意境 | 意象是物象加情意的最小单位，意境是整体氛围 | 一首诗可有多层意境 | 把"意象"当"形象"用，就会写出只有名词没有判断的句子 |
| 母题/原型 | 反复出现的基本叙事单位与深层模式 | 如 还乡、复仇 | 母题是跨作品的，单篇里只能说"母题式要素" |
| 叙事视角 | 叙述者知道多少、站在哪里 | 全知、限知、客观白描 | 叙述者不等于作者，第一人称的"我"也不等于作者 |
| 引文标注 | 作者·篇名·版本·页码 | 古籍注卷次篇名，期刊注年份期号 | 只写书名不写版本页码；转引必须标"转引自" |
| 赋比兴 | 赋是铺陈直叙，比是比方，兴是先言他物以引起所咏 | 《诗经》三种表现手法 | 把"兴"当比喻、把"赋"当"铺排辞藻"，是两个最常见的错 |
| 知人论世/以意逆志 | 由作者与其时代论诗，由文辞逆求其志 | 孟子提出的两种读诗法 | 两法都不能替代文本证据，只能提出待证的假设 |

## 6. 典型题型与解题套路

### 作品分析与论述题（给一首诗、一段小说，或一道文学史大题）
1. 先读三遍：一遍求通，一遍标出反复出现的词与转折处，一遍写下三句自己的第一反应。
2. 定一个可辩护的论点，一句话写成"文本中的什么，因此怎样"；不写"这首诗很优美"。
3. 选 2–3 处原文作证据，每处按"引—释—扣"三步：引原文、解释字面、说明它支撑哪个判断。
4. 处理一个反例（看似相反的证据），说明它为什么不推翻论点；论述题则换成一条限定条件或反例史实。
5. 收尾回到论点，写清这个解释适用于哪一类现象。论述题在此步把"文本证据"换成"史实与作品"，因果链必须落到机制（科举、印刷、城市、读者群）。
**常见失分点**：通篇复述情节或翻译诗句，没有一句自己的判断；引文与论点之间缺"释"这一步。

### 古文翻译与训释题
1. 先断句：抓"者、也、矣、焉、耳"等句末标志与"夫、盖、若"等句首标志，标点后再译。
2. 逐句译，先补省略的主语、宾语、介词，补出的部分用括号标出。
3. 疑难词按"本义→引申→通假"顺序排查，写出所选义项及依据。
4. 特殊句式先还原语序再译，把宾语前置、被动、判断三类单独标在译句后。
5. 译完通读，检查人名地名是否误译、句意是否与上下文冲突。
**常见失分点**：意译过头，把虚词全删；遇难词跳过不译，或拿现代常用义硬套。

### 名词解释题
1. 第一句给定义，写成"属概念 + 种差"，控制在 40 字内。
2. 第二句给要素：时间、提出者、代表作或代表作品。
3. 第三句做辨析，点明与最容易混的那个概念的区别。
4. 第四句给例证或影响，落到 1 部作品或 1 处文本片段。
**常见失分点**：只给例子不给定义；把"赋比兴"三类混着说，写满却拿不到分。

### 材料作文与评论（给一段材料或一篇作品，自拟角度）
1. 先用一句话写清"材料在争什么"，把争议点定位到具体分歧。
2. 选一个能落到文本证据的角度，不选"谈谈我的感受"这类无法验证的角度。
3. 列三段提纲：立论—证据（引原文）—反驳（预设对方会怎么驳）。
4. 首段给判断，中间每段一个中心句，末段回到判断并说明适用范围。
**常见失分点**：通篇抒情没有论证；引材料只引一半，断章取义。

## 7. 常见误区

1. **用"时代背景"一段代替论证** → 错在把背景当原因；应写出背景通过什么机制影响写作（出版、科举、读者群、城市生活）。
2. **引文只贴不解** → 错在缺"释"这一步；每条引文后必须有一句"这句话里的哪个字或动作支撑我的判断"。
3. **把"兴"当"比"** → 错在混淆起头与比方；判据是"先言他物"与下文是否有意义上的直接对应，没有对应才是兴。
4. **文言翻译逐字套现代义** → 错在跳过"本义—引申—通假"的排查；先查工具书定义项，再定整句。
5. **术语越多越显得专业** → 错在术语替代了证据；每个术语后必须跟一处原文或一个可指认的现象。
6. **注释只写书名** → 错在缺版本与页码；同一本书不同版本页码不同，读者无法核对，等于没注。
7. **把叙述者当作者** → 错在混淆文本层与现实层；第一人称的"我"只是一个叙述位置，不是作者本人。
8. **背教材结论当论点** → 错在把他人判断当自己的发现；引用时要写明"某书认为"，再给出自己的证据。

## 9. 交叉专业与后续方向

- **和新闻学的区别**：新闻先核实再写，对事实负责；中文先解释再判断，对文本负责。同一篇报道，新闻问"信源够不够"，中文问"叙述框架怎么造出这个印象"。
- **和历史学的区别**：历史学以史料证事实，中文以文本证解释；共用一套版本与文献学工具。
- **和哲学的区别**：哲学追求可普遍化的命题，中文接受"这一处文本如此"的局部结论，但要求可被他人复核。
- **和外国语学院的区别**：同样做文本分析，中文的底气在古代汉语与文献，外文在语言对照与理论译介。
- **后续方向**：中国古代文学、中国现当代文学、汉语言文字学、文艺学、比较文学；岗位如中学语文教师、编辑出版、内容运营与文案、宣传与公文岗；进阶课程为文献学、音韵学、训诂学、西方文论、文化研究。
