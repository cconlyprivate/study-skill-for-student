# 公共事业管理（public-administration）

> 使用前先读 `../../references/curriculum-rules.md`（难度与排序规则）与
> `../../references/learning-card-template.md`（讲解结构）。
> 本文件只提供"这个专业的知识骨架与专业习惯"，不要在这里重复通用协议。

## 1. 这个专业在训练什么

训练**在多重公共利益互相冲突时，把一项公共服务设计到能被执行**：目标要能被测量，钱要能说清来源，责任要能落到具体岗位，受损的一方要能被提前安抚。它靠的是"问题界定 → 方案 → 指标 → 预算 → 问责"这一条链，文采和口号都不在生产环节里。

外人最容易把它当成"背政策文件、写公文"，或者"考公的预备班"。文件只是原料：真正的活儿是判断这条政策在本地、本预算、本编制下会不会走样，并把走样的地方提前写进方案。一篇合格答案，读完应该知道**谁在什么时候、用哪笔钱、按哪个指标、向谁交账**。

分界线在提问方式上。政治学问"权力怎么配置、为什么这样配"；公管问"给定这套权力与预算，怎么把事办成"。工商管理有利润这一个统一标尺，公共部门要同时向效率、公平、合法性与回应性交账，而且服务对象不能"用脚投票"退出。

**最容易误解的一点**：以为"公共利益"是一个可以加总出来的数。它是多方利益被程序化权衡后的结果，所以公管的答案里必须写明"谁受益、谁受损、凭什么这么定"。

模块与课程的对应：K01 管理学原理、K02 公共管理学与公共经济学、K03 公共政策、K04 公共部门人力资源、K05 社会调查方法、K06 公共服务供给与政府购买、K07 绩效评估与问责、K08 方案设计与政策分析实务。

**最陡的三门课**：公共政策（因为阶段模型人人会背，分数全在"目标能不能被测量"这一步）、社会调查方法（因为要把"我觉得"改写成"可抽样、可复现"的测量，抽样框一错，结论全废）、绩效评估与问责（因为要同时预测指标诱发的作弊行为，这是反向思考，课堂上很少练）。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能把一句"这事该管管"改写成问题界定：谁的问题、多大规模、现状与目标差多少，并给出三个可比较的方案。
2. 能为一项公共服务写出投入、产出、结果三层指标，每条带口径与数据来源，并预判两种操纵手法。
3. 能设计一份抽样调查方案，写明抽样框、样本量依据、误差量级与外推边界。
4. 能画出政策过程五阶段，标出最可能失真的两个环节与各环节的责任人。
5. 能写出一份购买服务合同的核心条款：服务标准、计价方式、验收、违约与退出。
6. 能做利益相关者分析，标出能否决方案的人与被牺牲的人，并给出补偿或沟通动作。
7. 能在三页内交出"问题—证据—选项—推荐—成本与风险"的政策建议书。
8. 能用公开统计核对一项政策的宣称覆盖与实际覆盖，写出差距与可能原因。

## 5. 术语与符号约定

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| 公共物品 | 同时具有非竞争性与非排他性的物品 | 两维四类：纯公共、俱乐部、公共池塘、私人物品 | 判定必须分别问"多一个人用是否减少他人可用量"与"能否把不付费者排除"；只答"政府提供的"，等于把供给主体当成了物品属性 |
| 公共价值 | 公共部门应当维护、不能化约为效率的标准 | 公平、回应性、合法性、透明 | 它不是"多数人的好处"，而是经过程序权衡后仍站得住的标准；写成"为人民服务"不算定义 |
| 外部性 | 一方行为对第三方造成的未计价影响 | 正为收益、负为成本，带符号 | 符号写反是最高频错误：污染是负外部性，疫苗接种是正外部性；答案要写清"谁对谁、影响了什么" |
| 市场失灵与政府失灵 | 市场无法有效配置 / 干预反而恶化配置 | 市场失灵四类：公共物品、外部性、垄断、信息不对称 | 市场失灵不等于"必须政府直接生产"，政府失灵也不等于"不要政府"；两者是并列诊断，不能互相否证 |
| 内部性 | 行政机关自身目标替代公共目标 | 预算最大化、部门扩张、避责 | 它比"官僚主义"具体：要写清是哪个激励让机构这样选，否则只是换了个贬义词 |
| 政策过程五阶段 | 议程设置、政策制定、政策执行、政策评估、政策调整与终结 | 顺序固定，现实中会回环 | 阶段是分析用的切片，不是时间线；"执行"不是最后一步，"评估"之后必须接调整或终结，只背五个词不给判据会丢一半分 |
| 政策工具 | 政府影响行为的强制、混合、自愿三类手段 | 强制：管制、许可；混合：补贴、税收、信息；自愿：市场、志愿组织 | 工具要与失灵类型匹配：外部性用庇古税或配额，信息不对称用强制披露；把"加强宣传"当万能工具是最常见的偷懒 |
| 利益相关者分析 | 按权力、利益与态度给相关方分层 | 权力—利益四象限：重点管理、保持满意、随时告知、最小关注 | 只列名单不做矩阵等于没分析；必须写出"谁能否决、谁会被牺牲、用什么补偿"，漏掉否决者，方案一定被卡住 |
| 投入/产出/结果 | 花了什么 / 做了多少 / 改变了什么 | 三层由内到外，结果层最慢也最难测 | 产出（output）与结果（outcome）混用是本专业第一大错：办了多少场培训是产出，失业率降了几个点是结果；把产出当结果，绩效永远好看而问题没解决 |
| 效率与效果 | 产出除以投入 / 结果除以目标 | 效率是比率，效果是达成度百分比 | 效率高不等于效果好：多发一倍传单是效率提升，若知晓率没动就是效果没达；指标题里两者必须各给至少一条 |
| 公共服务均等化 | 所有人能获得可及、可负担、质量达标的基本公共服务 | 机会均等与结果均等两种读法 | 均等化不等于平均化，也不等于"每个县建一个同样的馆"；先声明是机会均等还是结果均等，否则结论自相矛盾 |
| 可及性 | 服务在空间、时间、价格、信息上能否被真正获得 | 服务半径、等待时间、自付比例 | 有设施不等于可及：中心建了但班车不通、预约只在工作日开放，覆盖率再高也不可及 |
| 政府购买服务 | 政府出钱、承接主体按合同提供服务 | 购买主体是行政机关，承接主体是企业或社会组织 | 买的是"服务"不是"资产"或"人头"；把购买服务写成"甩包袱"或"变相用工"，是评审最常见的定性错误 |
| 社会组织（NGO） | 非政府、非营利、志愿性的组织 | 基金会、社会团体、社会服务机构三类 | 非政府不等于无政府，也不等于慈善；它的合法性来自登记与专业能力，答题要写清它替政府补的是哪一段能力 |
| 委托—代理 | 委托方授权代理方办事，信息不对称产生代理成本 | 委托方是政府（出资、定标准），代理方是承接机构 | 方向最容易写反；委托方也可能信息不足，所以合同要写验收与退出，不能只写"加强监管" |
| 抽样框 | 实际可抽到的那份名单 | 必须覆盖目标总体 | 抽样框缺失的人群就是系统性偏差：只抽到有电话的人，结论不能说成"全市居民"；代表性威胁要写在结论之前 |
| 概率抽样与非概率抽样 | 每个个体有已知入样概率 / 概率未知 | 简单随机、分层、整群、系统；便利、配额、滚雪球 | 非概率样本不能算抽样误差；把"发了 1000 份问卷"当代表性，是这个专业最贵的错误 |
| 样本量与抽样误差 | 样本量决定误差量级 | 比例估计 $n\approx\dfrac{z^{2}p(1-p)}{e^{2}}$，误差随 $\sqrt{n}$ 缩小 | 样本量大不等于有代表性；整群与分层的误差要乘设计效应，别套同一个公式 |
| 信度与效度 | 测得稳 / 测得准 | 信度是效度的必要非充分条件 | 信度高可以完全无效：同一把坏秤每次称出同一个数；只报 Cronbach's α 不报效度证据，测量题必扣分 |
| 变量层次 | 定类、定序、定距、定比 | 层次决定可用哪种统计量与相关 | 五点李克特量表常被直接当定距用，报告时要声明；对定类变量求均值是硬错 |
| 量表方向与反向题 | 正向题与反向题计分方向相反 | 常见 1–5 分，必须先统一方向 | 反向题不重编码，信度会掉到 0 附近；编码表要逐题标方向，不能凭题号猜 |
| 预算口径 | 钱在哪个账本、哪一年、含不含转移支付 | 一般公共预算、政府性基金、部门预算、年度 | 谈"投入多少"必须写口径，否则跨年跨地区不可比；把上级转移支付当本级财力，是预算题里最常见的错 |
| 成本效益与成本效果 | 效益折成钱 / 效果用自然单位 | 效益成本比、净现值；每单位效果的成本 | 效益难折价时用成本效果，别硬折；折现率与年限要写明，否则两个方案不可比 |
| 满意度 | 服务对象的主观评价 | 百分比或均值，须说明调查方式与样本 | 满意度高不等于服务好，可能是期望被管理；报满意度必须同时报回收率与抽样方式 |

**最容易写反的三处**：产出与结果、概率与非概率、均等化与平均化。前两处错在指标或样本的层次，第三处错在把"结果一样"当成了均等化。动笔前先用一句话把这三对各说一遍，说顺了再写方案；这三处一错，后面所有数字都会替你的错误作证。

## 6. 典型题型与解题套路

### 政策分析题（给一段材料，问问题出在哪、该怎么改）
1. 先把材料里的诉求改写成可判定的问题句：谁、在什么范围内、现状与目标差多少；能给数字就给数字，给不出就标注为待核事实。
2. 做失灵诊断：公共物品、外部性、垄断、信息不对称、政府失灵，选一条主因，其余只作补充，不要并列五条。
3. 定判据并排序：效率、公平、可执行性各一条，说明本题哪条优先、为什么；判据定完，备选方案才有可比性。
4. 给 2–3 个备选方案（工具组合），逐个写财政成本、受益方、受损方与执行主体。
5. 选一个，并写下"最可能让我判断错的那个假设"与一条能验证它的观测信号。
**常见失分点**：把材料复述一遍就落到"应加强管理、加大投入"，既没有失灵诊断，也没有备选比较。

### 方案设计题（设计一个购买服务、均等化项目或调研方案）
1. 先写服务对象与需求证据：覆盖多少人口、现有覆盖率多少、缺口在哪，禁用"群众需求强烈"这类无来源判断。
2. 定服务包：把服务拆成可计量单元（次、人次、小时、件），每个单元配一条质量标准。
3. 定供给方式：政府直接提供、购买、补贴还是志愿供给，写出选择理由与最大风险。
4. 定钱与人：预算来源与口径、执行主体与编制、时间节点与里程碑，四项缺一项方案就不可执行。
5. 定验收与退出：验收指标、抽检比例、违约认定、退出与接续安排。
**常见失分点**：只写目标与意义，不写服务单元和验收条款，第三方拿到方案无法照着执行。

### 绩效指标设计题（给一项服务，设计指标并说明怎么防操纵）
1. 先把服务目标写成一句可测的结果句：哪个人群、什么变化、多大降幅、多长时间内。
2. 按投入、产出、结果三层各给 2–3 条，每条写清分子、分母、数据来源与统计周期。
3. 标出"能被刷"的指标，并配对冲：结果类配产出类，数量类配质量类，自报数据配第三方抽查。
4. 给权重与底线：哪些指标一票否决，哪些只做监测、不进考核。
5. 写一条补救路径：谁有权改指标、多久复评一次、指标失灵时按什么程序换。
**常见失分点**：指标清一色是覆盖率与满意度这类容易达标的自报数，没有结果层，也没写口径。

### 案例题（某地做法 + 问你怎么评价、怎么办）
1. 还原事实链：谁决策、钱从哪来、谁执行、谁验收，四问缺哪问就补一条显式假设。
2. 找对照：同一政策在另一地、另一年或另一人群的差异，明确写出你用的是哪种对照。
3. 用五阶段定位问题出在制定、执行还是评估，并指出该环节的具体裁量点。
4. 归因到机制：激励错配、信息不对称、能力不足、合法性不足，选一个主因，并排除一个竞争解释。
5. 落到可执行改进：改哪条指标、加哪道验收、由谁承担后果。
**常见失分点**：只评价"效果好或不好"，既不定位环节也不给对照，"好"没有依据。

## 7. 常见误区

1. **把"公共"等同于"政府包办"** → 错在把供给主体当成物品属性；应先判竞争性与排他性，再在政府生产、购买、补贴、志愿供给里选一种。
2. **拿产出当结果报绩效** → 错在指标层错位；应把"办了多少场"换成"目标人群的哪个指标变了多少"，并同时给出分子分母与数据来源。
3. **用样本量给代表性背书** → 错在把数量当质量；应写明抽样框、入样概率与外推边界，非概率样本只能描述、不能推断。
4. **方案只有目标与意义，没有钱、人、验收** → 错在不可执行；应补齐预算来源、执行主体、验收指标与退出条款四条。
5. **先有结论再找证据** → 错在结论先行；应先做失灵诊断与判据排序，让备选方案互相竞争后再选。
6. **利益相关者只列名单** → 错在没有权力与态度判断；应做权力—利益矩阵，标出能否决的人、会被牺牲的人与各自的对冲动作。

## 9. 交叉专业与后续方向

- **和政治学与行政学（political-science）的区别**：两个专业都被叫"行管"，但公管问"怎么把事办成"，政治学问"权力怎么配置"。同一道"基层执法难"，政治学答"谁有权执法、问责链断在哪"，公管答"编制、经费、考核与购买服务怎么调"。判断用哪个：问"为什么这样安排"找政治学，问"怎样做更好、钱怎么花"找公管。
- **和工商管理（business-administration）的区别**：目标函数不同。企业只有利润一个标尺，公共部门要同时向效率、公平、合法性与回应性交账；顾客不满意可以走，辖区居民不能"用脚投票"退出。同一套目标管理与绩效工具，工商答"值不值"，公管还得答"对谁公平、凭什么合法"。
- **和财政学（public-finance）的区别**：财政管钱从哪来、怎么收（税、债、预算安排），公管管钱花出去后事办没办成（供给方式、绩效、可及性）。同一笔专项资金，财政问"该不该列、列多少"，公管问"买了什么、谁验收、效果如何"。
- **和社会学（sociology）的区别**：社会学解释结构如何产生结果，公管在这个解释之上做干预设计；同一份调查数据，社会学问"阶层如何影响参与"，公管问"哪类人没被覆盖、怎么补上"。
- **后续方向**：考研方向有行政管理、公共政策、社会保障、教育经济与管理、MPA；典型岗位在党政机关与事业单位、街道与社区治理、政策研究与评估机构、社会组织与基金会项目岗；进阶课程有公共经济学、政策评估方法、地方政府治理、非营利组织管理、应急管理，进阶阅读可看《改革政府》一类新公共管理著作。
