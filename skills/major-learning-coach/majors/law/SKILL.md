# 法学（law）

> 先读 `../../references/curriculum-rules.md`（难度与排序）与 `../../references/learning-card-template.md`（讲解结构）。
> 本文件只给这个专业的知识骨架与专业习惯。

## 1. 这个专业在训练什么

法学靠"在事实与规范之间来回看"吃饭。核心动作只有三步：**在事实里找到可用的规范（找法）→ 把规范拆成构成要件（拆要件）→ 把事实逐个塞进要件里（涵摄）**，最后给出一个能被反驳的结论。

它和"背法条""口才好"都不是一回事。法条是原料，考的是你在一堆互相竞争的规定里**选中那一条**，并且说清为什么不是旁边那一条。

**最容易误解的一点**：以为法学是记忆型专业。实际上记忆量只是入场券，真正拉开差距的是 K02（请求权基础）与 K05（涵摄）——同一份案情，不同的人找到的规范不同，结论就完全不同。

## 2. 课程地图

| 学期 | 课程 | 模块 | 先修 | 难度感受 |
|------|------|------|------|----------|
| 大一上 | 法理学 | K01 | — | 概念抽象，但它决定你后面每门课"怎么讲理" |
| 大一上 | 宪法学 | K01、K08 | — | 条文少、原理多，最容易背成口号 |
| 大一下 | 民法学（总则） | K02、K03 | K01 | 转折点：从"背概念"变成"找请求权" |
| 大二上 | 刑法学（总论） | K03 | K01 | 三阶层立住了，分论就顺；立不住就一路混 |
| 大二下 | 民法学（债法·物权） | K02、K03 | K02、K03 | 请求权基础最密集，也是考试主战场 |
| 大二下 | 行政法学 | K01、K08 | K01 | 合法性审查框架清晰，但法条分散 |
| 大三上 | 民事诉讼法 | K04、K06 | K02 | 举证责任是分水岭，前半学期几乎无人不晕 |
| 大三上 | 刑事诉讼法 | K03、K06 | K03 | 程序阶段与证明标准必须一起记，分开记必错 |

**最陡的三门课**：民法（因为请求权基础要在一堆规范里做选择，选错方向后面全错）、刑法（因为三阶层要同时握住事实与规范两层，换个案就要重建）、民事诉讼法（因为举证责任看不见摸不着，却直接决定胜负）。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能对一段案情列出全部可能的请求权基础，并按检索顺序逐一排除到只剩一个。
2. 能把一个请求权基础拆成若干构成要件，给每个要件标注对应的事实与证据。
3. 能写出完整涵摄链（大前提、小前提、结论），且每个要件都有事实支撑而不是"综合判断"。
4. 能对每个争点判断举证责任归属与证明标准，并说明倒置或过错推定改变了哪个要件。
5. 能区分"应当"与"可以"、"法定"与"约定"，并说出写错之后法律后果的差异。
6. 能对一条有争议的规范指出规范目的、适用边界与一处漏洞，并给出解释方案。
7. 能在 40 分钟内写完一道 1500 字的案例分析，结论明确、要件齐全、抗辩不漏。
8. 能在一道题里同时处理民事、行政、刑事三条线，并说明程序上的先后。

## 5. 术语与符号约定

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| 请求权 | 要求他人为或不为一定行为的权利 | 须落到一个请求权基础 | 请求权不等于债权；债权是权利本身，请求权只是它的权能之一 |
| 抗辩权 | 对抗已成立的请求权、使其效力受阻的权利 | 须由被请求方主动主张 | 抗辩与"否认"是两回事：否认是否定要件事实，抗辩是承认事实但另有权利 |
| 形成权 | 单方意思表示即可变动法律关系 | 受除斥期间限制 | 形成权不适用诉讼时效；把撤销权当时效处理是常见硬错 |
| 请求权基础 | 支持一项请求的具体规范依据 | 一个请求可对应多个基础 | 写"依据法律规定"不算请求权基础，必须落到可适用的规范 |
| 构成要件 | 规范中抽象出来的成立条件 | 逐项与事实对应 | 要件不等于事实：要件是抽象条件，事实是具体经过，两者不能混写在一段 |
| 涵摄 | 把案件事实归入构成要件之下的推理 | 三段论 | 涵摄不是"我觉得像"，要逐要件给出对应事实句 |
| 效力位阶 | 不同规范渊源的效力高低 | 宪法最高 | 同位阶才用特别法、新法规则；位阶不同直接适用上位法，不进行比较 |
| 应当 / 可以 | 义务性规范 / 授权性规范 | — | "应当"违反产生违法与责任，"可以"不行使不产生不利后果；互换等于改法 |
| 法定 / 约定 | 由法律直接规定 / 由当事人合意确定 | — | 约定优先只在法律允许处；强制性规定不得以约定排除 |
| 善意 / 恶意 | 是否知道或应当知道某事实 | 常由主张善意一方举证 | 善意是"不知情"，不是"好心"；它和刑法上的故意不是同一层级的概念 |
| 举证责任 | 要件事实真伪不明时谁承担不利后果 | 按要件逐项分配 | 提供证据的行为责任不等于结果责任；只写"谁主张谁举证"通常拿不到分 |
| 证明标准 | 对事实成立的确信程度要求 | 民事高度盖然、刑事排除合理怀疑 | 同一事实在不同程序中结论可以不同，因为标准不同，不矛盾 |
| 诉讼时效 / 除斥期间 | 前者影响胜诉权，后者消灭权利本身 | 时效可中止中断 | 超过诉讼时效仍可起诉，法院也不主动释明；两者期间不能互换 |
| 一审 / 二审 / 再审 | 三级审判救济 | 二审全面审查，再审事由法定 | 二审审理对象是一审裁判而非重新起诉；再审不是第三审 |
| 判决 / 裁定 | 判实体 / 判程序 | 上诉期不同 | 两类文书的救济期限不同，混用会直接算错期日 |
| 既判力 | 生效判决对后诉的拘束 | 有主观与客观范围 | 既判力一般只及于判决主文，不及于理由中的事实认定 |
| 要约 / 承诺 | 合同成立的两个意思表示 | — | 要约与要约邀请易混；商业广告通常是要约邀请，不是要约 |
| 过错 / 无过错责任 | 归责原则 | — | 过错推定不是无过错责任：它仍以过错为要件，只是把举证负担转给对方 |
| 违法性 / 有责性 | 三阶层的后两层 | — | 两层出罪理由不同；把"违法阻却"与"责任阻却"都写成"无罪"会丢分 |
| 正当防卫 / 紧急避险 | 违法阻却事由 | 限度条件不同 | 防卫针对不法侵害人，避险损害的是第三人利益，方向别写反 |
| 管辖 | 哪个法院有权审理 | 地域与级别两个维度 | 级别管辖看标的额与案件类型，不只看被告住所地 |
| 请求权竞合 | 同一事实产生多个请求权 | 择一行使 | 竞合不是"都告一遍"；选择后一般不得反复变更 |
| 合宪性解释 | 以宪法价值限缩或扩张解释 | — | 它是解释方法，不是直接援引宪法判案 |
| 法律漏洞 | 规范应有而无 | 目的性限缩或扩张填补 | 漏洞不等于含义不清：含义不清用解释，没有规范才叫漏洞 |

## 6. 典型题型与解题套路

### 案例分析题
1. 先用一句话写清"谁向谁、请求什么"，把诉讼请求定下来，别急着讲道理。
2. 列请求权基础：按合同、缔约过失、无因管理、物权、不当得利、侵权的顺序全列，宁可多列再排除。
3. 逐个基础拆要件，一个要件一段，每段写"要件、对应事实、结论"三句。
4. 单独检查抗辩：时效、履行、抵销、免责条款，凡由被告主张的另起一段。
5. 回到请求，给出"成立 / 部分成立 / 不成立"的明确结论。
**常见失分点**：只写一个请求权基础就下结论，被排除掉的那几个恰恰是采分点。

### 法条评析题
1. 先把条文内容写准（只引现行有效文本，并注明"条文以现行有效文本为准"）。
2. 拆规范结构：假定条件、行为模式、法律后果各是什么。
3. 指出规范目的：这条在保护谁、调和哪一对冲突。
4. 评适用边界与漏洞：举一个该条管不到、但按目的应当管的例子。
5. 收口：说明用哪种解释方法补，或提出立法建议。
**常见失分点**：把"我认为不合理"当成评析，没有回到规范目的与体系位置。

### 论述题
1. 开头三行内给出论点，不要用"随着社会发展"铺垫。
2. 用"规范依据 + 学说 + 案例"三层支撑，每层至少一个具体材料。
3. 主动写一个反对观点并回应，说明它在什么条件下成立、为什么不影响你的结论。
4. 结尾回到论点，交代结论的适用条件与限度。
**常见失分点**：通篇罗列各家学说，没有一句属于自己的判断句。

### 选择题
1. 先看清问的是"正确的是"还是"错误的是"，把否定词圈出来。
2. 把每个选项还原成"要件、事实"结构，看它缺哪个要件。
3. 排除绝对化表述（一律、任何情况下、必须），除非该处属于强制性规定。
4. 两个选项都像时，比较哪一个更贴合条文文义，而不是哪个更符合直觉。
**常见失分点**：凭"看起来最合理"选，而不是凭"能落到条文"选。

## 7. 常见误区

1. **先有结论再找法条** → 错在把法条当论据而不是前提；应该先定请求权基础，再让事实往要件上靠。
2. **把"应当"读成"可以"** → 错在把义务性规范当成授权性规范；前者违反产生违法与责任，后者不行使不产生不利后果。
3. **用"谁主张谁举证"一句话结案** → 错在没落到具体要件；应该逐要件分配，并指出倒置或过错推定改变了哪一个要件。
4. **要件和事实混在一段里写** → 错在阅卷人无法核对；应该一个要件一段，先抽象要件后本案事实。
5. **论述题只堆学说** → 错在没有判断；每段末尾要有一句"因此本文认为……"，否则不算论述。
6. **凭记忆写条文序号** → 错在条文序号随修订变动；应写规范名称与内容要点，条文以现行有效文本为准。

## 9. 交叉专业与后续方向

- **和政治学、思想政治教育的区别**：政治学问"权力应当如何配置"，法学问"依据现行规范，这个行为合法还是违法"，且结论必须能被规范检验。
- **和公共事业管理的区别**：管理关心执行效果与成本，法学关心权限来源与程序合法性；同一项措施，管理问"管不管用"，法学问"有没有权"。
- **和经济学的区别**：经济学用效率评价规则，法学用规范评价行为；法经济学是两者的交汇，但仍须回到现行规范下结论。
- **后续方向**：民商法、刑法、宪法与行政法、诉讼法的学硕或法硕；律所与公司法务、法官与检察官、公证与合规、立法与政策研究。
