# 园艺（horticulture）

> 先读 `../../references/curriculum-rules.md`（难度与排序）与 `../../references/learning-card-template.md`（讲解结构）。
> 本文件只给这个专业的知识骨架与专业习惯，不重复通用协议。

## 1. 这个专业在训练什么

园艺靠"把一株植物的生长节奏对齐到一个能卖钱的上市期"吃饭：品种决定上限，设施与环境调控决定上限能不能兑现，采后决定兑现的那部分会不会烂在路上。

它和"种地"不是一回事。种地靠经验累积，园艺要求在**季节窗口、设施能力、市场档期**三重约束下写出可执行方案：哪天播、留几个果、棚里控到几度、采下来几小时内降到几度。

**最容易误解的一点**：以为园艺 = 养花种菜。实际主线是"约束下的取舍"——同一株树多留果就少明年的花芽；同一个棚保温好就透光差；同一个冷库温度低就冷害。会算这些取舍，才写得出方案。

与农学的分界一句话：农学在大田尺度用品种、密度、水肥换产量；园艺在小地块与设施里管单株、管器官、管上市期（详见第 9 段）。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能对给定作物与茬口写出 12 个月的物候—农事—环境目标表，并标出 3 个风险窗口。
2. 能根据棚内外温光数据判断设施是否满足该作物该物候期的需求，并给出调控动作与阈值。
3. 能对叶片黄化、落花落果、畸形果各列 3 个候选原因，并为每个原因指定一条鉴别证据。
4. 能为一种果品或切花写出采收成熟度判据、预冷方式与贮藏温湿度、气调参数。
5. 能判断一个品种在本地区能否种植，并说清还需要哪些区域试验数据才能谈推广。
6. 能为一个育种目标选定育种途径，写清亲本选配、选择方法与鉴定指标。
7. 能写出嫁接、整形修剪、疏花疏果的操作要点与可验收的质量标准。
8. 能读懂一份园区生产档案，指出投入品、用工与产量记录上的异常并给出追查方向。

## 5. 术语与符号约定

园艺记号的坑集中在三处：**口径**（按株还是按亩、按鲜重还是干重）、**基准**（相对谁、减去谁）、**阈值**（低于会怎样、高于会怎样）。下面每条都对应一个真实的扣分点。

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| 需冷量 | 打破自然休眠所需的低温累积 | 常用 0–7.2 ℃ 累积小时，也有以冷量单位计的模型 | 写"需冷量 800"必须注明是小时还是冷量单位、用哪个模型；把"低于 7.2 ℃ 的天数"当小时数是最常见的错 |
| 花芽分化 / 花芽发育 | 生长点转向生殖生长，及随后各器官原基形成 | 物候阶段，不是日历日期 | 分化与发育是两个阶段，写"花芽分化期"要落到物候而不写"3 月" |
| 花芽质量 | 花芽饱满度与可坐果能力 | 描述性分级 | 只数花芽个数不看质量，会把"花多果少"错判成授粉问题 |
| 嫁接亲和性 | 砧木与接穗长期愈合共生的程度 | 定性判断，靠多年田间表现 | 亲和不等于成活：接口愈合了仍可能后期不亲和，表现为接口膨大、断裂、早衰 |
| 砧木 / 矮化砧 | 提供根系与部分抗性的基础 | — | 砧木影响树势、抗性、果个甚至品质；矮化砧不等于弱树，是"控势" |
| 负载量 / 留果量 | 单株或单位面积保留的果实数量 | 果/株、果/cm² 干截面积、t/hm² | 叶果比与枝果比两种口径不能混；按产量倒推留果数必须写明单果重假设 |
| 叶果比 | 每个果分摊的叶片数 | 比值，无单位 | $\text{叶果比}=\dfrac{\text{叶片数}}{\text{留果数}}$，写"40:1"要说明是片/果而不是叶面积比 |
| 整枝 / 修剪 / 短截 / 疏枝 | 改变枝量与光分布的手段 | — | 修剪是总称，答题必须给具体手法（短截、疏枝、回缩、拉枝、摘心） |
| 透光率 | 棚内光照占自然光的比例 | %，随季节与测点变化 | 不同位置差异大，报"透光率 70%"要说明测点；冬季低太阳高度角时更低 |
| 昼夜温差 DIF | 白天温度减夜间温度 | ℃ | 顺序是昼减夜，正负号有意义：负 DIF 可矮化；只写"温差 10 ℃"不说谁减谁等于没写 |
| 换气次数 | 单位时间换掉棚内容积的次数 | 次/h | 换气同时带走热量与水分，保温与降湿是一对矛盾，方案里必须交代取舍 |
| CO2 浓度 | 棚内二氧化碳体积分数 | 用 μL/L，等价于 ppm | μL/L 与 ppm 同值，但不能写成 mg/m³；阴天不补、晴天中午才补是最常见的时机错误 |
| 基质 EC | 根际盐分（电导率） | mS/cm | 基质 EC 与土壤 EC 测定方法不同（饱和浸提 vs 按比例水浸提），数值不能直接比 |
| 基质 pH | 根际酸碱度 | 无单位，通常 5.5–6.5 | pH 只写数值不带缓冲体系；灌溉液 pH 与基质 pH 不是一个东西 |
| 呼吸跃变 | 采收后呼吸速率出现峰值的现象 | 呼吸速率以 CO2 mL/(kg·h) 计 | 跃变型（苹果、香蕉、番茄）与非跃变型（柑橘、葡萄、草莓）处理策略相反，最常记混 |
| 乙烯 | 催熟与衰老相关的气态激素 | μL/L | 外源乙烯的浓度与处理时长必须成对写；1-MCP 是阻断乙烯作用，不是催熟剂 |
| 气调 CA / MA | 人工或自发调节贮藏环境 O2 与 CO2 | O2 常 1%–5%，CO2 常在 0%–10% 量级，因种类而异 | O2 过低会转为无氧呼吸，CO2 过高会造成伤害；"气调即真空"是错的 |
| 呼吸商 RQ | 释放 CO2 与消耗 O2 的摩尔比 | 无单位，正常约 1.0 | RQ 明显大于 1 提示无氧呼吸，多因 O2 不足或过熟；别把 RQ 当呼吸速率 |
| 冷害阈值 | 产品不发生冷害的最低安全温度 | ℃ | 热带亚热带产品低于阈值会凹陷斑、不能正常后熟，"越冷越好"是错的；贮藏温度必须写"高于阈值" |
| RH | 贮藏环境相对湿度 | % | 多数果品 85%–95%，但洋葱、大蒜要低湿；RH 高必须配防腐，否则烂得更快 |
| 品种区域化 | 一个品种只允许在审定区域内推广 | 行政区域加生态区 | 引种成功不等于可跨区推广；外地试验数据不能直接顶替本地区试 |
| 引种规律 | 纬度、海拔、气候相似性决定引种可行性 | — | "同纬度就能引"漏了海拔与海洋性/大陆性差异；高海拔引到低海拔常因需冷量不足失败 |
| 配合力 | 亲本杂交后代的平均表现（一般）与特定组合表现（特殊） | 相对值 | 一般配合力与特殊配合力是两件事，不能互换；配合力高不等于好品种 |
| 产量口径 | 常用 t/hm²、kg/亩、kg/株 | 1 hm² 等于 15 亩 | 亩与公顷差 15 倍；$\text{产量}=\text{株数}\times\text{单株留果数}\times\text{单果重}$，三个因子缺一个就无法核对 |

## 6. 典型题型与解题套路

### 栽培技术方案题（给作物、茬口、设施，写周年管理方案）
1. 先写约束：品种类型、目标上市期、设施类型、所在地气候带、可用劳动力与水源。约束不写，方案就是模板。
2. 按物候期排主干：育苗 → 定植 → 开花坐果 → 产品器官膨大 → 采收，每段只写"这一段要控什么"。
3. 每个物候期配 2–3 个关键动作（温度、光照、水肥、整枝），**每个动作带阈值和判据**，不写"加强管理"。
4. 标出最脆弱的窗口（花期低温、转色期高湿、连阴天）与对应的兜底动作。
5. 收尾用一张表：月份 × 物候期 × 农事 × 环境目标，再给 3 个验收指标（单果重、整齐度、上市期）。
**常见失分点**：通篇"适时播种、合理密植、加强肥水"，没有一个数字，评卷人无法判断你懂不懂。

### 生理障碍诊断题（给症状与棚内数据，问原因与处置）
1. 先定位症状落在哪类器官、哪个叶位：新叶还是老叶、上部还是下部、向阳面还是背阴面。这一步就能砍掉一半候选。
2. 分三类列候选：营养（缺素、盐害）、环境（温度、光照、湿度、有害气体）、水分与根系（沤根、干旱、伤根）。
3. 每条候选配一条**可验证的鉴别证据**：新叶失绿偏缺铁、老叶脉间失绿偏缺镁、叶缘焦枯偏盐害或钾不足、晴天中午萎蔫傍晚恢复偏根系吸水不足。
4. 看时间线：突发还是渐进，是否与某次打药、追肥、通风或降温重合。药害常在施药后 2–3 天集中出现且边界整齐。
5. 处置分两层：立即止损动作（通风、冲洗、遮阳、停肥），以及下一茬的结构性改造（换基质、改灌溉、加除湿）。
**常见失分点**：见黄叶就补氮；把药害或缺素当成同一种病，越补越重。

### 采后处理与贮藏方案题
1. 先定产品类型：呼吸跃变型还是非跃变型，决定能不能用乙烯、要不要除乙烯。
2. 写采收成熟度判据（可溶性固形物、硬度、色泽、盛花后天数），并说清早采与晚采各自的代价。
3. 排链路：采收 → 预冷（方式与时限）→ 分级包装 → 贮藏（温度、RH、O2/CO2）→ 冷链运输。**每一段必须给一个参数**。
4. 交叉检查参数是否互相打架：贮藏温度不能低于冷害阈值；RH 高要与防腐措施配套；气调 O2 不能低到诱发无氧呼吸。
5. 写 3 个监控指标与出库验收标准（失重率、腐烂率、硬度、可溶性固形物）。
**常见失分点**：只写"低温贮藏"不写温度值与冷害阈值；预冷与入库的间隔时间不写，链路等于没设计。

### 育种选择与品种区域化题
1. 先把育种目标写成可测性状：抗哪种病、果色、熟期、单果重区间、可溶性固形物下限。避免"品质好"这类词。
2. 选途径：引种（气候相似）、选择育种（已有变异）、杂交育种（组合目标性状）、优势育种（利用 F1）、诱变与倍性（特殊需求），并说明为什么不是另一种。
3. 写亲本选配依据与选择方法（系谱法、混合法），每一代写清"选什么、淘汰什么、用什么指标鉴定"。
4. 区域试验设计：参试点覆盖主要生态区、设对照品种、连续 2–3 年、记录产量与抗性，并写统计分析口径。
5. 结论要区分三件事：能引种、能推广、能审定。跨区推广必须走审定程序，外地数据不能顶替。
**常见失分点**：只写"选优良单株"不写选择差与鉴定指标；把引种成功直接说成可以跨区推广。

## 7. 常见误区

1. **见叶片发黄就补氮肥** → 错在把缺素当成唯一解释；应先看叶位与症状分布，再查基质 EC、含水量与根系，把缺素、盐害、沤根分开。
2. **留果越多产量越高** → 错在只看当年不看花芽；应按叶果比定留果数，并在方案里写明接受大小年还是控产稳树。
3. **修剪越重越通风** → 错在剪掉的是明年的花芽和今年的叶面积；应先定负载量与目标树形，再定剪口位置与剪量。
4. **贮藏温度越低越保鲜** → 错在忽略冷害阈值；热带亚热带产品必须写"冷害阈值以上的最低温度"，不能一律写 0 ℃。
5. **记不清就编品种名与产量数据** → 错在编造无法溯源的信息；应写审定名或文献出处，数据只能报"在某地某年份某条件下"的区间，不确定就直说不确定。

## 9. 交叉专业与后续方向

- **和农学的区别**：农学在大田尺度上用品种、密度、水肥换产量，决策单位是"亩"与"季"；园艺在小地块与设施里管单株、管器官、管上市期，决策单位是"株"与"天"。同一块地，农学答"怎么把平均产量提上去"，园艺答"怎么让这一批果在同一天达到同一个规格"。
- **和植物保护的区别**：植保负责"这是哪种病虫、该用什么药、抗性怎么管"；园艺负责"栽培制度怎么让病虫少发生、以及这个损失值不值得防"。园艺题里出现病害，先看是不是栽培措施（湿度、密度、连作）造出来的，再决定要不要转介给植保。
- **和生物科学的区别**：生物科学问机制是否成立，园艺问这个机制在田里能不能换来整齐度和上市期。分子标记在园艺里是加速选择的工具，不是结论本身。
- **和食品科学的区别**：食品科学管加工与安全，园艺管采后到货架这一段的新鲜度，两者的温度、湿度、气调参数服务的目标不同。
- **和风景园林的区别**：风景园林做空间与景观设计，观赏园艺做花材生产与花期控制。同一个花坛，前者定形式，后者保证那天有花可开。
- **后续方向**：果树、蔬菜、观赏园艺三个二级方向；设施园艺与无土栽培；采后与冷链；种苗与育种；考研常考园艺学一级学科下的栽培学、育种学、采后生理，以及农艺与种业专硕。
- **边界提醒**：本文件只讲学习方法与答题结构。涉及具体品种名、审定编号、产量与农药用量时，**必须给出处**（审定公告、地方标准、试验报告），拿不到出处就写区间与适用条件，宁可说"不确定"，不要编一个看起来合理的数字。
