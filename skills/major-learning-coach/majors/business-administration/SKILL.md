# 工商管理（business-administration）

> 使用前先读 `../../references/curriculum-rules.md`（难度与排序规则）与
> `../../references/learning-card-template.md`（讲解结构）。
> 本文件只提供"这个专业的知识骨架与专业习惯"，不要在这里重复通用协议。

## 1. 这个专业在训练什么

在**约束下做选择**，并把选择的后果说清楚。钱、人、时间三样永远不够，所以每个方案都必须回答"放弃什么"。它的产物不是标准答案，而是一个能被追问、能被追责的方案。

外人最容易把它当成"当领导"或"会说话"。真正拉开差距的是三件事：把模糊问题定义成可判定的决策问题（K01）、把人和组织的激励摆对（K03、K04）、用数字验证判断而不是用形容词（K06、K07）。框架只是提问清单，不是答案。

**最容易误解的一点**：以为工商管理 = 背框架 + 会表达。分数与绩效都在"证据够不够、取舍敢不敢、后果兜不兜得住"，而这三样都不在框架里。

**最陡的三门课**：战略管理（要同时握住行业、资源与财务约束，缺一块就写成行业简介）、财务管理（口径一处错就全题错，且错误不显眼）、组织行为学（理论彼此不覆盖，选错理论整段答偏）。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能在 30 分钟内把一句模糊的管理抱怨写成"决策问题 + 约束 + 判据"，并列出不少于三个选项。
2. 能对一个真实组织画出业务流程图与组织图，指出两者不一致的两个接口。
3. 能对一份年报算出 8 个关键比率并做杜邦分解，说出 ROE 差异主要来自哪一因子。
4. 能对一个行业用五力与价值链给出"该不该进、进哪一段"的结论，并主动写出反面证据。
5. 能设计一套考核指标，并预先指出它可能诱发的两种作弊行为与各自的对冲指标。
6. 能算出一个项目的净现值与保本点，并说明关键假设变动 10% 时结论是否翻转。
7. 能在 10 分钟内讲清一个案例的"问题—证据—选项—建议—风险"，并接住三个追问。
8. 能为一次真实的团队冲突写出可执行的调解步骤，而不是"加强沟通"。

## 5. 术语与符号约定

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| 计划 / 组织 / 领导 / 控制 | 管理的四类活动 | 无单位，按"主要动作"归类 | 一件事常同时踩两条线，定考核指标既像计划又像控制；判分看它主要解决什么，把"决策"写成第五职能会扣分 |
| 效率 vs 效果 | 省资源 vs 做对的事 | 效率是比率，效果是达成度 | 问"该不该进这个市场"是效果题，答"排班省了多少钱"是答错题 |
| 有限理性 | 信息与算力有限下的决策 | 求满意解，不求最优解 | 不是"人不理性"；答案里出现"最优"却没给满意门槛，等于没答有限理性 |
| 满意门槛 | 够用的判据线 | 与判据同单位 | 只说"够用"不给门槛就是拍脑袋；门槛必须能被第三方复算 |
| 沉没成本 | 已发生且不可收回的支出 | 货币 | 决策时应置零；"已经投了三百万"不是继续投的理由，是承诺升级的前兆 |
| 机会成本 | 放弃的最好那个备选的收益 | 货币 | 不进账但必须进决策；只算"最好的一个"，不是所有备选之和 |
| SWOT | 内部优势劣势、外部机会威胁 | 四象限 | S/W 是内部、O/T 是外部；它只做盘点不产出战略，缺"组合成选项"这一步就是四格填空 |
| 五力 | 行业利润池的五种挤压 | 行业层面 | 评的是行业吸引力，不是某家公司的竞争力；替代品与互补品别混 |
| 价值链 | 从投入到交付的增值环节 | 活动层面 | 用来找"哪一段创造并留住了价值"；把部门名原样抄成基本活动是最常见错 |
| VRIO | 价值、稀缺、难模仿、组织 | 四问按序判定 | 任一问为否就降级；"有资源"不等于"有优势"，第四问最常被跳过 |
| 组织结构类型 | 直线职能、事业部、矩阵 | 按划分依据区分 | 矩阵的标志是两个上级两条汇报线，不是"分了项目组"；矩阵里的虚线是协调线不是命令线 |
| 管理幅度 | 一个上级的直接下属数 | 人 | 幅度与层级反向；幅度只数直接汇报，不是部门总人数 |
| 集权 / 分权 | 决策权放在哪一层 | 决策层级 | 分权不等于放任，必须同时给权限额度与追责方式；只放权不配额度是最常见的错 |
| 马斯洛需要层次 | 生理到自我实现的五层 | 五层，顺序满足 | 只解释"缺哪层补哪层"，不解释同等条件下为何选 A；跨文化证据弱，别当定律用 |
| 双因素 | 保健因素与激励因素 | 两类，作用方向不同 | 保健因素缺失只产生不满，给足也不产生满意；把加薪当激励因素是最高频错误 |
| 期望理论 | $M=E\times I\times V$ | 三因子取 0–1，效价可负 | 是乘法，任一因子为 0 则动机为 0；效价可正可负，别默认正数 |
| 公平理论 | 投入产出比的横向比较 | 比值，无量纲 | 比的是比值不是绝对报酬；参照对象必须写明是自己过去、同事还是外部同行 |
| 领导 vs 管理 | 影响力与方向 vs 职位与流程 | 无单位 | 有职位不等于有追随者；问"是不是好领导"先看有没有人自愿跟 |
| 三张报表勾稽 | 利润表、资产负债表、现金流量表的对账 | 货币 | 净利润加回折旧、减去营运资本增加才是经营现金流；期末现金必须等于资产负债表货币资金 |
| ROE 杜邦分解 | $ROE=净利率\times资产周转率\times权益乘数$ | % | 三因子必须同期同口径；用期末权益还是平均权益要先声明，否则两年不可比 |
| 流动比率 / 速动比率 | 短期偿债能力的两个口径 | 倍 | 速动要扣存货；比率高不等于能还债，存货与应收的质量在比率之外 |
| 毛利率 vs 净利率 | 只扣成本 vs 扣完期间费用与税 | % | 两者同时下滑说明问题在成本端；毛利率稳而净利率跌，去查费用与财务费用 |
| 保本点 | $Q^*=\frac{F}{p-v}$ | 件 | 分母是单位边际贡献不是单价；多产品要按销售结构加权算综合边际贡献率 |
| 净现值 vs 内部收益率 | 绝对额 vs 折现率 | 货币 / % | 互斥项目规模不同或现金流多次变号时内部收益率会误导，决策看净现值 |
| STP | 细分、目标、定位 | 三个连续动作 | 定位句写成"我们品质好服务优"是无效定位；有效定位必须包含不服务谁 |
| 4P | 产品、价格、渠道、促销 | 四类决策 | 四项必须与定位同向；价格与渠道打架是最常见的自毁 |
| 客户终身价值 CLV | 一个客户全周期贡献的现值 | 货币/客户 | 折现率与留存期要先声明；把它当客单价用，获客预算会翻几倍 |

**本专业最容易写反的一件事**：把"目标"当"战略"。目标说"我们要成为最受信赖的品牌"，战略说"因此我们放弃低价市场、只做三个 SKU、把库存周转压到 45 天以内"。凡不能被否证、不涉及放弃的表述都是目标；看到这种句子，就在后面补一句"所以不做 X"。

## 6. 典型题型与解题套路

### 案例分析题（给一段公司材料，问该怎么办）
1. 先锁定决策问题：谁、在什么时点、要在哪几个选项里选。材料没写清的约束（预算、期限、老板红线）自己补上并标为假设。
2. 把材料切成四类证据：数字（收入、成本、周转）、人的反应（离职、抱怨、抵制）、外部（政策、对手动作）、时间线（什么时候开始变坏）。每条证据后面写一句"所以它支持哪个判断"。
3. 只留一条主线（通常是"战略与组织不匹配"或"指标把行为带偏了"），不要并列五条互不相干的原因。
4. 给 2–3 个选项，逐个写代价、谁承担、多久见效，再选一个并说明为什么不选另外两个。
5. 收尾写"最可能让我判断错的那一个假设"，以及能验证它的一个观察点。
**常见失分点**：通篇复述材料加套框架，没有一句"我选哪个、放弃哪个"。

### 战略分析题（这个行业、这家公司该怎么打）
1. 第一句先划边界：行业怎么定义、地域与客户群是什么。边界一改五力结论全变，所以边界必须写在结论前面。
2. 外部用五力找"利润被谁拿走"，每力给一条可核对的证据（价格战、集中度、切换成本），并指出哪一力当前不构成约束。
3. 内部用价值链定位增值环节，再用 VRIO 判一条：这项能力是"有"还是"优"。
4. SWOT 只做汇总，不许停在四格；必须写出 SO 与 WT 各一条战略选项，并给出取舍理由。
5. 最后落到"投什么、停什么、用什么指标验收"。没有资源重新分配的战略分析不算完成。
**常见失分点**：五力写成行业简介；SWOT 四条全是形容词，没有一个数字和一次放弃。

### 组织设计题（该设几个部门、权放给谁）
1. 先写战略与主流程：这家公司靠什么赢、从接单到交付经过哪几个环节。部门边界跟流程走，不跟人名走。
2. 选结构类型并给依据：单一产品用直线职能，多产品且各自核算用事业部，需要双向资源协调才用矩阵；选了矩阵就要写明双线冲突由谁仲裁。
3. 定幅度与层级：给一个上级的直接下属数，算出层级数；幅度加大必须同时补协调机制（例会、共享平台、接口人）。
4. 定集权分权：把"钱、人、价、新品"四类决策逐项写到层级，并配权限额度与追责方式。
5. 写接口：跨部门最容易掉的三件事（交付、质量、客户投诉）各指定一个 owner 与一条升级路径。
**常见失分点**：只画组织图不改流程与考核，部门设完没人对结果负责。

### 财务比率计算题（给两张报表，算比率并解释）
1. 先统一口径并写在算式前：时点还是时期、期末还是平均、合并还是母公司、含税还是不含税。
2. 按盈利、营运、偿债三组各算 2–3 个关键比率，不要能算的全算一遍。
3. ROE 差异用杜邦三因子定位，指出净利率、周转率、权益乘数各贡献多少、主要来源是哪一个。
4. 每个比率配一句"它高或低意味着什么"，再配一句"这个解释可能错在哪"（存货计价、一次性损益、季节性）。
5. 结论落到动作：提高周转就动应收与存货，提高净利率就动价格或费用，不写"加强管理"。
**常见失分点**：平均余额与期末余额混用；把权益乘数当成越高越好。

## 7. 常见误区

1. **一上来就套 SWOT、五力、PESTEL** → 错在把框架当分析；应先用一句话锁定决策问题与约束，再选一个真能回答它的框架，其余只用来查漏。
2. **默认答案应该是"最优解"** → 错在忽略有限理性；应写出满意门槛与信息成本，说明为什么停在这个方案。
3. **用"已经投入这么多"为继续投辩护** → 错在把沉没成本当理由；应只问"从今天起再投一元，能不能换回超过一元的增量"。
4. **把激励等同于加薪** → 错在混淆保健因素与激励因素；先判断缺的是"没有不满"还是"真有动力"，再用期望理论查 E、I、V 哪一环断了。
5. **组织图一改就宣布变革完成** → 错在只动结构不动考核与流程；应同步改三件事：谁考核、考核什么、跨部门争议谁仲裁。
6. **比率算完立刻下结论** → 错在没有参照系；至少给一个同行值与三年趋势，否则"高"无法判断。

## 9. 交叉专业与后续方向

- **和市场营销（marketing）的区别**：营销问"这个需求怎么被看见、被打动、被买走"，工商管理问"这门生意整体划不划算、资源该压在哪、谁为结果负责"。同一套 4P，营销答"怎么打动客户"，工商答"这套组合与公司能力、现金流匹配吗"。
- **和会计学（accounting）的区别**：会计把业务记成可核对、可审计的报表，回答"记对了吗"；工商管理把报表当输入，回答"接下来该做什么"。会计要合规与一致，工商要取舍并承担后果。
- **和工程管理（engineering-management）的区别**：工程管理管"一个项目在工期、成本、质量三角内交付"，边界清晰、有验收标准；工商管理管"多条产品线、多个项目之间怎么分资源"，边界模糊，问题要自己定义。
- **后续方向**：MBA 或管理学硕士；战略咨询、快消与零售管培、财务分析与投后管理、创业与家族企业接班；进阶课程有公司治理、运营与供应链、创业金融、商业分析。
