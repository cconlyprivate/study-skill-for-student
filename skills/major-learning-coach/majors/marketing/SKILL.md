# 市场营销（marketing）

> 使用前先读 `../../references/curriculum-rules.md`（难度与排序规则）与
> `../../references/learning-card-template.md`（讲解结构）。
> 本文件只提供"这个专业的知识骨架与专业习惯"，不要在这里重复通用协议。

## 1. 这个专业在训练什么

把"我想卖得更好"这句空话，压成三串能对账的答案：**服务谁**（细分与目标）、**凭什么被选**（定位与差异点）、**怎么被记住并买到**（品牌与渠道）。三串答案必须互相咬合——说服务 Z 世代却只铺商超主货架，就是没做完。

**一句话画像**：找到该服务谁、凭什么被选、怎么被记住。

这行靠"取舍 + 验证"吃饭。取舍体现在敢放弃哪些人群、敢砍掉哪些卖点；验证体现在每个判断都配一个指标、一个口径、一个时间窗。营销题丢分几乎都不在名词，而在"没有取舍"和"没有口径"。

**最容易误解的一点**：以为营销 = 推销 + 打广告 + 写文案。推销是把已有产品推给人（K01-2 的推销观念），营销是先决定为谁做什么产品；广告只是 promotion 这一支里的"怎么说"（见第 9 段）。

外人第二个误解是"营销靠创意和感觉"。实际最硬的是三块：K03 调研的口径与效度、K04 的 STP 取舍、K06 的定价算术。口径一错后面全错；取舍不做，方案必然"既要又要"；算术不算，折扣与渠道加价会把毛利吃穿。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能把一句"提升销量"改写成含目标人群、差异点、指标、基准与时间窗的营销目标。
2. 能对一个品类做完整 STP 方案，并用四条标准当众淘汰掉不成立的细分段。
3. 能设计一份可执行的问卷：抽样框、样本量、题项、量表、信度效度检验方案齐全。
4. 能算出给定产品的需求价格弹性、单位边际贡献与保本销量，并判断该不该降价。
5. 能画出渠道结构图、标出级数与宽度，并各指出一处水平冲突与一处垂直冲突的成因。
6. 能用品牌资产四要素给一个品牌做体检，并给出下一年的三条品牌动作。
7. 能算出给定 cohort 的 CLV、CAC 与回收期，判断一个获客渠道该加投还是该停。
8. 能写一份十页以内的营销计划书，使目标、预算、排期、复盘口径互相对账。

## 5. 术语与符号约定

营销的"符号"是几套并行的心智模型和一堆口径不一的比率。写错的下场不是扣一分，是整段结论反转。

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| STP | 细分 Segmentation → 目标 Targeting → 定位 Positioning | 三段，顺序固定 | 顺序不能倒：先切段才能选段，选完才有定位。最常见错误是先想出口号再倒推人群，方案经不起追问 |
| 4P / 4C | Product/Price/Place/Promotion 对 Customer solution/Cost/Convenience/Communication | 一一对应但不等价 | 4C 是视角切换不是换词游戏：Price 对应的 Cost 是顾客总成本（含时间、学习、风险），不只是标价 |
| 决策五阶段 | 问题识别→信息搜寻→方案评估→购买→购后 | 可回环、可跳过 | 不是线性流水线；购买者、使用者、付款者常是三个人，画像只写一个就漏了关键人 |
| 涉入度 | 购买的重要程度与风险感 | 高 / 低 | 高涉入才值得长篇论证；低涉入品类摆参数对比，等于把预算烧在没人读的位置 |
| 考虑集 / 排除集 | 进入评估环节的品牌集合 | 通常 3–7 个 | 知名度高不等于进考虑集；答题要写"怎么被想起"，不能只写"提升知名度" |
| 细分四标准 | 可测量、可到达、足够大、可操作 | 四条同时满足 | 只按年龄性别切，最先崩的是"可操作"：段必须能落到具体媒介、渠道与投放动作 |
| 市场份额 / 渗透率 | 份额看金额或数量占比，渗透率看买过的人占比 | 0–100% | 分母口径不写清就不能横比：品类边界一变，份额能从 5% 变成 15% |
| 价格弹性 $E_d$ | $E_d=\frac{\Delta Q/Q}{\Delta P/P}$ | 通常为负，比较取绝对值 | 降价不等于增收：只有弹性绝对值大于 1 才可能增收，还要确认边际贡献为正 |
| 边际贡献 / 保本点 | $CM=P-VC$；$BEP=\frac{FC}{CM}$ | 元/件、件 | 用毛利率替代边际贡献会漏掉变动费用；固定成本分摊口径一改，保本点跟着变 |
| 加成率 vs 毛利率 | 加成率分母是成本，毛利率分母是售价 | 0–100%，可换算 | 成本 80 加成 25% 得 100，毛利率是 20% 不是 25%；多级渠道加价连乘，不能相加 |
| 促销的代价 | 折扣会改写顾客对未来价格的预期 | 促销深度与频次 | 连促会把参考价格钉低，恢复原价即滞销；算促销账要连活动后三周的复购一起算，不能只报活动期 GMV |
| 渠道级数 / 宽度 | 级数=中间商层数；宽度=同层中间商密度 | 0–3 级；独家/选择/密集 | "两级渠道"指经过两层中间商，不是"两个渠道"；高端品配密集分销等于自毁价格 |
| 渠道冲突 | 水平（同层之间）、垂直（上下游之间）、多渠道（线上线下） | 三型，可并存 | 冲突不全是坏事，零冲突常意味着渠道没被激活；先判类型再给动作，不要一律"加强沟通" |
| 窜货 | 经销商跨授权区域或渠道低价销售 | 按授权区域与开票流向判定 | 只看终端价低就判窜货会误伤；判定要三件套：授权区域、开票流向、终端零售价 |
| 品牌资产 | 认知、联想、质量感知、忠诚 | 四项，均可测量 | 知名度是必要不充分条件；只有认知没有联想与忠诚，一次降价就清零 |
| 品牌联想 | 顾客提到品牌时想到的属性、利益、态度 | 按强度、有利性、独特性三维评 | 把"我们想传达的"当成"顾客实际想到的"；联想要顾客侧数据，不要内部共识 |
| 品牌延伸 | 用现有品牌进入新品类 | 契合度决定成败 | 只看品类相近不够，还要看形象契合；延伸失败会反向稀释原品牌 |
| CLV | 客户终身价值，未来贡献的折现值 | $\text{CLV}=\sum_t \frac{m_t}{(1+r)^t}$ | 拿收入当 CLV、不扣服务成本与折现，会把价值高估几倍；时间窗不写清就无法比较 |
| CAC / 回收期 | $\text{CAC}=\frac{\text{营销与销售费用}}{\text{新增客户数}}$；回收期 $=\frac{\text{CAC}}{\text{月贡献}}$ | 元/人、月 | CAC 分子要含人力与渠道费，只算投放费会低估；回收期超过客户生命周期就是亏 |
| 留存率 / cohort | 同一批获客在后续各期的存留比例 | 0–100% | 用总体平均留存掩盖早期流失；必须按获客批次画留存曲线 |
| NPS | 推荐者占比减贬损者占比 | −100 到 100 | 分母含被动者；NPS 是推荐意愿，不等于满意度，更不等于复购 |
| 信度 / 效度 | 信度=重复测量一致；效度=测到了该测的东西 | α 常取 0.7 以上 | 信度高只说明"稳定地测"，一致地测错也叫信度高；α 不能当效度证据 |
| 抽样 / 非抽样误差 | 前者来自抽样，后者来自问卷、访问、录入 | 置信区间只覆盖前者 | 只报"误差 ±3%"却不管引导题与拒访，等于只承认了一半误差 |
| Likert 量表 | 5 点或 7 点，锚点文字决定数据含义 | 5 点 / 7 点 | 中点写"一般"会吸走答案，要逼表态就用 6 点或双向锚点；反向题必须 recode |
| 漏斗与口径 | 曝光→点击→加购→支付，逐层转化 | 各层分母不同 | 不写口径的转化率不能横比；CTR 的分母是曝光还是触达，差一倍 |

## 6. 典型题型与解题套路

### 案例分析题（给一家公司的困境，要求诊断并给方案）
1. 先用一句话定性问题：是没人知道（认知）、没人信（态度）、买不到（渠道分销）、还是算不过账（价值与价格）。四类问题对应四套解法，判错类型后面全白写。
2. 分层摆事实：市场层（规模、增长、份额）、顾客层（谁买、为什么买或不买）、竞争层（对手占住哪个位置）、公司层（能力与约束），每层至少一条带数字的证据。
3. 找一条因果链，不写并列清单：把"份额下滑"追到"终端缺货 → 经销商转推竞品 → 返利按进货量而非动销结算"，一条链胜过十条现象。
4. 方案对齐 4P：改哪一 P、改多少、多久见效、用什么指标验收。三 P 同时改等于没方案。
5. 补风险与止损：最可能失败在哪一步，出现什么信号就回退。
**常见失分点**：把案例复述当分析；方案写成"加强品牌建设、加大投放"，没有动作、预算与验收指标。

### STP 方案题
1. 先定品类与市场边界：这个市场按什么算（谁在解决同一个需求）。边界不定，后面所有数字都不可比。
2. 选两个细分变量交叉（如场景/需求 × 支付能力与频次），切出 3–5 段，每段一句"他是谁、在什么场景、要解决什么"。
3. 用四条标准逐段打分淘汰：可测量、可到达、足够大、可操作。淘汰必须写理由，不能只留一段然后说"聚焦"。
4. 选目标段并写明放弃谁：按规模、增长、竞争强度、自身能力打分，选一个主攻段，明确写出"这轮不做谁"。
5. 写定位声明：参照系（相对于谁）+ 差异点（凭什么选我）+ 证据（凭什么信），再用感知图验证这个位置是否已被占、是否可达。
**常见失分点**：顺序颠倒（先写口号再补人群）；细分段既不互斥也不穷尽；定位声明只有形容词，没有参照系与证据。

### 调研设计题
1. 把"想了解什么"改写成 2–3 个可检验的研究问题，每个写明要估计的量（比例、均值、组间差异）。
2. 选研究设计：探索（深访、焦点小组）、描述（问卷、观察）、因果（实验、A/B）；预算或周期不够就降级，并写明降级的代价。
3. 定抽样：总体是谁、抽样框从哪来、用概率还是非概率、样本量按置信度与允许误差算；非概率抽样必须标注"不可外推"。
4. 写问卷：先框架后题项，一题只问一件事，避开引导、双重、暗示；量表定锚点，留 1–2 道反向题与陷阱题。
5. 先定分析计划再收数据：信度（α）、效度（内容/效标）、交叉表与检验怎么用，报告里标出不可外推的部分。
**常见失分点**：只写"发 500 份问卷"却不写抽样框与样本量依据；用 α 证明问卷有效；结论从样本直接推到全国市场。

### 定价与渠道计算题
1. 先列已知量与口径：单位变动成本、固定成本、现价与销量、各级渠道加价率、折扣形式。
2. 算三层数：单位边际贡献、保本销量、当前利润；再用弹性判断降价是否增收（看边际贡献是否仍为正）。
3. 渠道加价用连乘：出厂价逐级乘 $(1+\text{加成率})$，不能用加法；算完校验终端价是否落在目标价格带内。
4. 促销单独算账：满减、折扣、买赠各折算成实际单价与毛利变化，再算需要多少增量销量才不亏。
5. 给结论并写前提：该降还是该守、该加还是该减渠道层级，附一句"若竞品跟进则如何"的条件判断。
**常见失分点**：把加成率当毛利率；渠道加价相加；促销只算销量增量不算毛利；弹性套公式时丢了负号与绝对值。

## 7. 常见误区

1. **先想 slogan 再补人群** → 错在 STP 顺序倒置；应该先切段、再选段、最后写定位声明，让每句话都能追到一个人群与一条证据。
2. **把营销当推销加广告** → 错在只做 promotion；应该先回答 product 为谁做、price 凭什么、place 到哪，再谈怎么说。
3. **细分只按人口统计** → 错在四条标准里"可操作"不达标；应该补行为或场景变量，保证每段能落到具体媒介与渠道。
4. **用 α 证明问卷有效** → 错在把信度当效度；应该补内容效度（专家评审）与效标效度（与已知指标的相关）。
5. **降价冲量当增长** → 错在只算收入不算毛利与参考价格；应该先算边际贡献与保本增量，再评估对品牌价格形象的长期伤害。
6. **渠道冲突一律"加强沟通"** → 错在没判类型；水平冲突管区域与价格规则，垂直冲突重谈利益分配，多渠道冲突定主次与差异化。
7. **CLV 用收入代替贡献** → 错在没扣服务成本与折现；应该用毛利、按 cohort 折现，并同时报 CAC 与回收期。
8. **调研结论直接外推** → 错在忽略抽样框与非抽样误差；应该写明总体、样本与不可外推的边界。

## 9. 交叉专业与后续方向

- **和广告学的区别**：广告学管 promotion 里的"怎么说"——创意、媒介、传播效果；营销管"卖什么、卖给谁、卖多少钱、铺到哪"，广告只是其中一支。同一道题，广告答"这句主张怎么说才被记住"，营销答"这个人群值不值得做、这个价撑不撑得住渠道"。
- **和工商管理的区别**：工商管理在资源约束下做组织与战略的整体取舍（含财务、人力、运营）；营销是同一次取舍里负责市场侧那一半：需求从哪来、价值怎么定、通路怎么搭。工商案例要算组织与资本，营销案例要算人群与毛利。
- **和心理学的区别**：心理学解释机制（为什么这样决策、为什么会被影响），营销要把机制换成可执行的动作与可测量的指标。心理学可以停在"锚定效应成立"，营销必须回答"锚定用在哪一屏、预期提升多少、怎么验证"。
- **和统计学的区别**：统计学问"从这点数据能推断到什么程度"，营销问"这个推断值不值得投钱"。营销借用置信区间与检验，但结论必须落到预算与取舍，不能停在 p 值。
- **合规底线（写任何营销方案都适用）**：白牌（无品牌或贴牌）不等于免责——不得冒用他人商标、厂名厂址，不得虚标成分、产地、执行标准与检测数据，贴牌须有完整授权链；宣传不得作虚假或引人误解的表述，不得用"国家级""最高级""第一"等绝对化用语，数据、排名、专利、认证必须标明来源与适用范围，比较广告须有可核查依据；食品、保健食品、药品、医疗器械、化妆品、教育培训、金融等品类须先取得审批或备案，功效表述不得超出批件。答题时把这几条写成方案硬约束，比事后删词省事。
- **后续方向**：考研走企业管理（营销方向）、市场营销、新闻与传播专硕；岗位有品牌经理、产品营销、渠道与通路管理、定价与收益管理、消费者洞察、增长与效果营销；进阶课程为营销分析、定价策略、零售与全渠道、B2B 营销。
