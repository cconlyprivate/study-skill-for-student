# 财政学（public-finance）

> 使用前先读 `../../references/curriculum-rules.md`（难度与排序规则）与
> `../../references/learning-card-template.md`（讲解结构）。
> 本文件只提供"这个专业的知识骨架与专业习惯"，不要在这里重复通用协议。

## 1. 这个专业在训练什么

把政府当成一个有约束的决策者：收入侧靠税收，支出侧靠预算，两边都要回答**效率**（别把蛋糕做小）与**公平**（蛋糕怎么分）两件事。约束是财政平衡，取舍必须给出可比较的代价。

它靠三样工具吃饭：**弹性与归宿**（一笔税最终落在谁身上）、**福利分析**（多余负担有多大）、**预算约束**（钱从哪来、能借多少、借到什么时候出事）。

它和"会报税、会算个税"不是一回事。计算只是末端的动作，核心是判断这个税/这笔支出的**经济后果落在谁头上**。外人最容易把它当成会计的邻居，其实它更像应用微观经济学。

**最容易误解的一点**：以为税收的"法定纳税人"就是"税负承担人"。增值税的法定纳税人是企业，大部分却由消费者承担；企业所得税也可能通过价格与工资转嫁出去。归属写反，后面所有公平评价都跟着反。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能对一条税收或补贴政策画税前税后价格与数量，标出税负分担比例与净损失。
2. 能把一笔政府收支准确归入四本预算，算出赤字率与债务负担率，并说清两者口径为什么不能相减。
3. 能判断一项税制是累进、比例还是累退，并用平均税率与边际税率两个指标分开说清再分配效果。
4. 能对一个公共项目列社会成本收益流量表，选社会折现率并算出净现值，给出结论翻转的临界值。
5. 能区分实际赤字、结构性赤字与周期赤字，判断当年财政政策是扩张还是紧缩。
6. 能对一次转移支付或地方债改革，写出受益方、受损方与三条可观测的激励扭曲渠道。
7. 能读一份预算报告，指出收支分类、政府性基金与债务限额三处最容易误读的地方。

## 5. 术语与符号约定

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| 税基 | 据以计税的金额或数量 | 货币/实物 | 增值税税基是不含税销售额；题目给"价税合计"时先除以 $1+t$，直接乘税率会多算 |
| 税率 $t$ | 税额与税基之比 | % 或元/单位 | 从价税写百分数，从量税写"元/包"，两种税率的量纲不能代进同一个公式 |
| 起征点 | 税基达到该值才对**全额**征税 | 货币 | 起征点是"够线全征"，免征额是"先扣掉再算"，临界点上的税额跳变完全不同 |
| 免征额 | 先从税基中扣除、再对余额计税 | 货币 | 个税的基本减除费用是免征额不是起征点；答"起征点 5000 元"直接算错 |
| 名义税率与实际税负 | 前者是法定比例，后者是税额除以对应分母 | % | 实际税负的分母要写明：企业用营业收入还是利润总额，结论方向相反 |
| 宏观税负 | 政府收入占 GDP 比重 | % | 大中小三口径（政府收入、财政收入、税收收入）差好几个点，比较前先对齐口径 |
| 累进税 | 平均税率随税基上升而上升 | % | 超额累进与全额累进在临界点行为不同；个税是超额累进，别按全额累进算跳变 |
| 累退税 | 平均税率随税基上升而下降 | % | 比例税本身不累退，但低收入者消费占比高，消费税的实际负担因此累退 |
| 边际税率与平均税率 | 多一单位收入的税率；总税额除以总收入 | % | 谈劳动激励用边际税率，谈再分配用平均税率，两个数在同一税制里可以差一倍 |
| 税负归宿 | 税的最终经济负担落在谁身上 | — | 法定归宿看条文，经济归宿看价格变化；考试问"谁负担"默认指经济归宿 |
| 税楔与分担比例 | 消费者支付价与生产者得到价之差 | 元/单位 | 消费者承担比例 $=\dfrac{E_s}{E_s+\lvert E_d\rvert}$，弹性写反就把受益方算成受损方 |
| 超额负担（deadweight loss） | 征税导致的、未转化为税收收入的福利损失 | 货币 | 它不是税收收入的一部分，也不是征管成本；线性供需下 $DWL\approx\tfrac12 t\,\Delta Q$ |
| 拉弗曲线 | 税率与税收收入的倒 U 型关系 | — | 倒 U 型不等于"减税必增收"；只有处在下降段（税率高于收入最大化点）才成立 |
| 价外税与含税价换算 | 增值税税额单列于价格之外 | — | 含税价 $=P(1+t)$，反算 $P=$ 含税价 $/(1+t)$；把增值税当价内税叠进成本会连环错 |
| 财政赤字 | 当年支出减收入的流量 | 货币/占 GDP | 赤字是流量、债务是存量；当年赤字不等于债务增量，还有债务置换与资产处置 |
| 债务余额 | 累计未偿还的政府债务存量 | 货币/占 GDP | 跨国比较用占 GDP 比重，用绝对额比较没有意义，汇率还会误导 |
| 赤字率与债务负担率 | 赤字/GDP；债务余额/GDP | % | 两者分子不同，不能相减也不能互相替代；"赤字率 3%"不说明债务率安全 |
| 一般公共预算 | 四本预算的主干，税收与一般性支出在此 | — | 通常说的"财政赤字"默认这一本；把土地出让收入算进来会低估赤字 |
| 政府性基金预算 | 专款专用、以特定来源支撑特定支出的预算 | — | 国有土地出让收入在这本里；卖地收入下滑不直接等于一般公共预算减收 |
| 转移支付 | 上级政府向下级的无偿资金 | 货币 | 一般性可统筹、专项限定用途；把两者都当"地方可自由支配的财力"会高估自主权 |
| 事权、财权与财力 | 该谁办事、该谁收钱、实际能花多少 | — | 三者不是同义词：事权与支出责任匹配讲的是"办事与出钱"，财权不等于财力 |
| 公共品 | 同时具备非竞争性与非排他性 | — | 判断依据是两个特征，不是"由政府提供"；政府提供的很多是私人品 |
| 纵向加总与萨缪尔森条件 | 公共品需求按数量相同、价格相加；$\sum MRS=MRT$ | — | 公共品纵向加总、私人品横向加总，混用会把最优供给量算成市场均衡量 |
| 社会折现率与影子价格 | 公共项目评估用的折现率与机会成本价格 | % / 货币 | 不能用市场利率与市场价直接替代；存在垄断、关税、失业时二者会明显偏离 |
| 结构性赤字 | 按潜在产出计算的、剔除周期因素的赤字 | 货币/占 GDP | 实际赤字扩大可能是衰退造成的，不等于财政扩张，评价政策方向必须先做周期调整 |
| 粘蝇纸效应 | 上级拨款比本地同等增收更能推高地方支出 | — | 它是实证现象不是理论必然后果；解释时要给替代假说，不能当成定律背 |

**最容易搞混的一件事**：税率、税负、归宿是三件事。看到"某税税率 13%"，先问三个问题——税基含不含税、法定纳税人是谁、供需弹性谁更小。前两个决定算式，第三个决定结论归谁。这三问能挡掉本专业一半以上的方向性错误。

## 6. 典型题型与解题套路

### 题型一：税负归宿计算题（从量税、从价税、弹性分担）
1. 先解出税前均衡 $P_0,Q_0$，并确认题目给的是从量税（元/单位）还是从价税（%），两者不能混代。
2. 画供需图，把税楔放在两条曲线之间：从量税为 $P_c-P_s=t$，从价税为 $P_c=(1+t)P_s$。
3. 解税后均衡，分别读出消费者支付价 $P_c$ 与生产者得到价 $P_s$，各自与 $P_0$ 的差就是承担的税额。
4. 用 $E_s/(E_s+\lvert E_d\rvert)$ 校核分担比例，量纲统一到"每单位税额"，别把百分比当元。
5. 若题目追问效率，补算 $DWL\approx\tfrac12 t\,\Delta Q$，并说明它随税率平方增长。
**常见失分点**：把法定纳税人当成税负承担人，导致整个福利分配图都标反。

### 题型二：预算平衡与赤字债务分析
1. 先把收支按四本预算分开，确认题目问的是哪一本口径，九成题目默认一般公共预算。
2. 算赤字 = 支出 − 收入，赤字率 = 赤字/GDP；债务负担率 = 债务余额/GDP。分子一个是流量一个是存量，不能相减。
3. 若给出潜在产出，把赤字拆成结构性部分与周期性部分，再判断财政政策方向。
4. 用利率 $r$ 与名义增长率 $g$ 判断债务率走向：$r>g$ 时即使初级赤字为零，债务率仍会上升。
5. 结论必须落到三条可操作路径：增收、减支、提高增长率，并各给一个可观测指标。
**常见失分点**：把当年赤字直接当债务增量，或把土地出让收入算进一般公共预算收入。

### 题型三：政策评价（效率与公平双口径）
1. 先把政策目标写成一个可检验命题：谁受益、谁受损、总量变化多少。
2. 效率侧算净损失与边际成本，并比较替代工具（税、补贴、管制、产权）谁更便宜。
3. 公平侧算改革前后各收入组的平均税率与净转移，给出累进性变化方向。
4. 写出约束条件：预算约束、征管成本、行政能力、政治可行性，每条配一个指标。
5. 结论写成"在什么条件下值得做"，并主动写出最可能推翻它的那一个假设。
**常见失分点**：只用效率或只用公平单侧评价，不说出取舍付出了什么代价。

### 题型四：案例题（一次税改、地方债或转移支付调整）
1. 还原制度事实：谁征、向谁征、税基如何界定、几档税率、进哪本预算。
2. 用归宿工具定位负担落在谁身上，再用税种细节确认税基口径是否含税。
3. 找激励扭曲：劳动供给、企业投资、地方政府的土地出让与举债冲动。
4. 做一次量级估算（弹性 × 税基变化），给区间不给点值，并说明区间来自哪个参数的取值。
5. 收尾写"改哪一条参数、如何监测"，把评价变成可执行的建议。
**常见失分点**：通篇制度描述与立场表态，没有一处落到数字或可证伪的机制。

## 7. 常见误区

1. **把法定纳税人当税负承担人** → 错在混淆法定归宿与经济归宿；应先比较供需弹性，弹性小的一方承担更多。
2. **用"税率高"评价税负高低** → 错在忽略税基宽窄与抵扣链条；应算实际税负（税额 ÷ 对应分母）并写明分母是什么。
3. **把起征点当免征额** → 错在没区分"够线全征"与"先扣再算"；起征点在临界点处税额跳变、免征额处连续，同一组数字能差一个数量级。
4. **把赤字当债务增量** → 错在混淆流量与存量；应补上债务置换、结转结余与资产处置，再看余额变化。
5. **把土地出让收入算进一般公共预算** → 错在预算口径；它属政府性基金，专款专用，不能拿去补一般公共预算的缺口。
6. **用拉弗曲线论证减税一定增收** → 错在没判断当前税率处在曲线哪一侧；应先估收入最大化税率，再谈减税空间。

## 9. 交叉专业与后续方向

- **和经济学（economics）的区别**：经济学问"人为什么这样选、市场为什么失灵"，财政学问"政府用哪个工具、花多少、代价落在谁身上"。同一则减税新闻，经济学讲总需求，财政学讲税负归宿与预算约束。
- **和会计学（accounting）的区别**：会计把业务记成可核对的账并保证合规，财政学决定这笔钱该不该花、该由哪级政府花。会计问"记对了吗"，财政学问"这个项目的净现值是正的吗、负担公平吗"。
- **和金融学（finance）的区别**：金融给资产与风险定价，财政给公共项目与政策定价，用的是社会折现率而不是市场利率；同一笔钱，金融问"值多少"，财政问"该不该由公家出"。
- **后续方向**：财政学与税务硕士、公共管理硕士（MPA）；财政部门、税务系统、预算评审与绩效评价、财政科研院所；进阶课程有地方财政学、税收归宿实证、财政政策与债务管理、公共项目评估。
- **一句边界**：本文件只讲原理与分析框架，不构成税务筹划或投资建议；具体申报、筹划与交易安排必须依据现行税法条文并由执业税务师按个案判断。
