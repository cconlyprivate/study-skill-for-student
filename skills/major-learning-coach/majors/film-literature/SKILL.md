# 戏剧影视文学（film-literature）

> 先读 `../../references/curriculum-rules.md`（难度与排序）与 `../../references/learning-card-template.md`（讲解结构）。
> 本文件只给这个专业的知识骨架与专业习惯。

## 1. 这个专业在训练什么

训练对象是**一段人生的可拍摄化**：把散乱的事件压成因果链，再用画面与声音把它讲出来。同一场"分手"，戏文要回答的不是"他们为什么分"，而是这场戏在第几幕、主角要什么、谁挡着、结束时他失去了什么、观众看到的是哪个镜头。

**一句话画像**：用视听语言讲一个结构完整的故事。

外人常以为这专业 = 会编故事、会写台词、看电影多。实际顺序是反的：先学会**看**（K01 把镜头说准，不靠"感觉很美"），再学会**搭**（K02 结构、K03 格式），最后才轮到**写**；导演（K05）与美学（K06）决定搭起来的东西立不立得住，批评（K07）决定你能不能把它说清楚。灵感只在选题时有用，之后全是手艺。

和汉语言文学的分界：中文的终点是**文本**，戏文的终点是**可拍摄的影像**。同一个故事，中文问"它怎么写"，戏文问"它怎么拍、观众第七分钟看到什么"。
和播音与主持艺术的分界：播音以**声音与镜头前表达**为核心，稿子多由他人提供；戏文要自己造稿，并对结构负责。

**最容易误解的一点**：以为戏文靠天赋和感觉。课上的评分点几乎全是可核查的——这场戏有没有转折、轴线有没有错、剧本格式有没有混、引用有没有标时间码。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能把一部 100 分钟影片拆成镜头表与节拍表，两份表的时间点能互相对上。
2. 能写出 90–120 页合规剧本（或同长度的分场大纲），格式错误为零。
3. 能为一个场景写出目标、冲突、转折三行，并让转折落在动作上而不是台词上。
4. 能画出一段对话戏的分镜与关系轴线图，标出至少两种合法越轴方案及各自代价。
5. 能用形式证据写 1500 字影评，含 3 处可核查引用与 1 条反例。
6. 能说清一部影片在电影史与类型系统里的位置，并给出 3 条史实依据。
7. 能在 48 小时内完成 3–5 分钟短片的剧本、分镜与两天拍摄计划。
8. 能按"片名·导演·年份·时间码"标注全部引用，交出可被他人核对的文稿。

## 5. 术语与符号约定

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| 幕与幕长比例 | 建置、对抗、解决三幕 | 常见 25%/50%/25% | 写成三等分；第二幕必须最长，且由中点劈成两半 |
| 节拍表 | 把故事拆成 15 个功能节拍的清单 | 以页码或分钟定位 | 把"节拍"当"场景"；一个节拍可跨多场，一场也可含多个节拍 |
| 情节点 I / II | 把主角推进下一幕的转折事件 | 约 25% 与 75% 处 | 与中点混为一谈；中点改的是策略，情节点改的是方向 |
| 中点 | 第二幕中央的假胜或假败 | 约 50% 处 | 漏写中点，第二幕就塌成一连串没有升级的事件 |
| 人物弧光 | 从开场信念到结尾信念的变化轨迹 | 正弧、负弧、平弧 | 只写"他成长了"；弧光必须落到一个可指认的选择上 |
| 目标 vs 需要 | 主角自己想要的，与他真正缺的 | 两者必须互斥 | 混成一个；不冲突就写不出结局的两难 |
| 动机 | 角色为什么此刻做这件事 | 由前史与处境推出 | 用"他坏""他善良"当动机，等于没写动机 |
| 场景三要素 | 目标、冲突、转折 | 每场至少转动一次价值 | 写成过场：没目标、没阻碍、结束和开始一样 |
| 场景标题 | 内/外、地点、日/夜 | 一场一行，全片统一 | 漏日夜；把"连续"当地点；地点写得不可拍 |
| 动作描述 | 现在时，只写摄影机拍得到的东西 | 每段不超过 4 行 | 写心理活动（他很难过）；替导演写推拉摇移 |
| 对白 | 角色说出口的话 | 角色名居中，台词在下 | 让角色互相解释设定；对白干了动作该干的活 |
| 潜台词 | 台词底下真正的意图 | 与台词相反或错位 | 把潜台词直接写进台词，人物就变成解说员 |
| 括号提示 | 台词前的表演提示 | 一段至多一处 | 每句台词都加括号，等于替演员和导演把活干完 |
| 转场 | 两场之间的连接方式 | 现代剧本默认硬切不标注 | 每场都写"切至"；转场是剪辑决定，不是编剧必写 |
| 分镜与镜头表 | 把剧本拆成可拍镜头 | 一格一镜，标景别角度运动 | 与剧本混为一谈；分镜是执行文件，不是文学稿 |
| 景别缩写 | 大特、特、近、中、全、远 | ECU/CU/MS/WS/ELS | 中景与中近景混用；同一份分镜出现两套写法 |
| 机位角度 | 平视、俯、仰、过肩、主观 | 与景别是两个维度 | 只写景别不写角度，分镜别人照着拍不出来 |
| 轴线（180 度） | 沿两人关系线一侧取景 | 一侧 0–180 度 | 反打把人放到画框同一侧；越轴后观众以为两人换了位置 |
| 30 度原则 | 相邻两镜机位夹角要大于 30 度 | 与 180 度并用 | 只记 180 度忘了 30 度，剪出来会跳一下 |
| 合法越轴 | 骑轴、运动镜头、插入镜头、中性镜头 | 四种手段 | 以为越轴一律禁止；越轴是要付代价，不是不能做 |
| 蒙太奇 | 镜头并置产生新意义 | 叙事蒙太奇与表现蒙太奇 | 被当成"剪辑"的同义词，又与长镜头对立化 |
| 长镜头 | 一个镜头内完成一段完整动作 | 通常 30 秒以上 | 把镜头长当调度好；长镜头内部也要有节奏与信息变化 |
| 场面调度 | 画框内一切元素的安排 | 与剪辑相对 | 与分镜混用；调度在拍之前，剪辑在拍之后 |
| 画外音 / 声画对位 | 声源不在画内 / 声音与画面意义相反 | 画内、画外、对位 | 把旁白叫画外音；旁白是叙述层，画外音是空间关系 |
| 剧本页与时长 | 1 页约合 1 分钟银幕时间 | 90–120 页对应 90–120 分钟 | 按字数估时长；对白密的一场会比动作场短得多 |
| 类型惯例 | 观众与片方共有的预期契约 | 每条惯例都成对出现 | 当套路背；惯例的功能是管理预期，破坏时要给补偿 |
| 引用与出处 | 片名、导演、年份、时间码 | 台词、截图、片段 | 只写片名不写年份与时间码；转载截图不标来源等于抄袭 |

## 6. 典型题型与解题套路

### 剧本分析题（给一场戏或一段剧本，问它怎么起作用）
1. 先定位：这段在第几幕、第几个节拍，一句话写出它承担的结构功能。
2. 写三行：谁要什么、谁挡着、结束时什么变了；不写剧情复述。
3. 找形式证据：景别、机位、剪辑、声音各取一处，说明它怎样把冲突推到观众眼前。
4. 判成败：这场靠动作推进还是靠台词解释？靠台词的要说出代价。
**常见失分点**：把分析写成剧情简介；只评价"演得好、镜头美"，不指认是哪一处形式选择起了作用。

### 剧作改写题（给一个场景、一个梗概或一句设定，要求改写）
1. 先诊断：目标缺失、冲突太晚、转折无代价，三选一并指明在原稿第几行。
2. 定一条改写原则：晚进早出、挪信息、换视角、加障碍，只改这一条，其余不动。
3. 写改写稿，格式保持合规（场景标题、动作、对白三栏分明），标出页数变化。
4. 附 100 字说明：改了什么、为什么改、代价是什么（丢了哪条信息）。
**常见失分点**：整段重写却没有一句说明；改完冲突更强但主角目标也换了，等于换了另一个故事。

### 影评 / 批评题（给一部影片或一个片段，写评论）
1. 第一段给判断：一句话写出这部片在做什么、做得怎样，不写"震撼人心"。
2. 选 2–3 个可指认的形式证据（具体镜头、段落、声音处理），每个证据后接一句"所以"。
3. 用一条理论或语境视角把证据串起来（作者、类型、工业、意识形态），并说明它在哪里失效。
4. 处理一个反例：看似支持相反结论的段落，说明它为何不推翻判断。
5. 收尾把判断限定范围：在哪一类观众、哪一段、哪种读法下成立。
**常见失分点**：通篇堆评价词；引用台词或截图不标时间码与出处。

### 故事大纲题（给一句话设定，写出可拍的大纲）
1. 先写 logline：主角 + 目标 + 障碍 + 代价，一句话，不超过 50 字。
2. 排三幕与四个节点（情节点 I、中点、情节点 II、结局），各一句。
3. 写分场 15–20 条，每条只写"谁在哪里要什么、结果如何"。
4. 标人物弧光三个支点：开场信念、中点动摇、结尾选择。
5. 自查：删掉任意一场，主线是否受损；不受损的场次合并或删掉。
**常见失分点**：大纲只有事件没有因果；主角全程被动，被配角推着走。

## 7. 常见误区

1. **把三幕比例套到所有片上** → 错在把工具当规律；应先在时间轴上标出实际节点，再回头对照比例，作者电影常明显偏离。
2. **把故事写成事件清单** → 错在缺因果；每场结束必须让主角处境变好或变坏，不变的场次删或并。
3. **让角色用台词交代设定** → 错在把观众当需要被解释的人；改成让两人为某件事争执，信息从争执里漏出来。
4. **分镜只标景别不标角度与运动** → 错在别人执行不了；每格至少写清景别、角度、运动方向三样。
5. **越了轴指望剪辑来救** → 错在轴线是空间契约；要么补骑轴或插入镜头，要么承认空间已换并给出提示。
6. **把"我喜欢"当论点** → 错在不可反驳；改成可被证据检验的判断，并写明什么证据会推翻它。
7. **引用台词只写片名** → 错在不可核对；必须写片名、导演、年份，能给时间码就给时间码。

## 9. 交叉专业与后续方向

- **和汉语言文学的区别**：中文以文本为终点，版本、训释、文学史是主业；戏文以可拍摄的影像为终点，读完剧本必须能回答"这场怎么拍、观众看到什么"。同一部《红楼梦》，中文做版本与叙事分析，戏文做改编方案与分场。
- **和播音与主持艺术的区别**：播音练声音、气息与镜头前表达，稿件多由他人提供，评分看表达准不准、有没有感染力；戏文要自己造稿，评分看结构成不成立、场景有没有转折。两者都考即兴口语，但戏文的即兴是编故事，播音的即兴是控场。
- **和广播电视编导的区别**：广编偏节目形态、栏目策划与现场流程，重播出；戏文偏虚构叙事，重剧本与人物。做综艺、纪录片、晚会走广编，做剧情片、剧集、短剧走戏文。
- **和影视摄影与制作的区别**：摄影问"这个镜头怎么拍得成"，戏文问"这个镜头为什么必须有"；同一份分镜，摄影管实现，戏文管必要。
- **后续方向**：考研走戏剧与影视学、电影学、广播电视艺术学；岗位如编剧、剧本策划与责编、影视宣发文案、影评与媒体内容、短剧与广告创意；进阶课程为电影理论、类型研究、改编研究、制片管理。
- **不可越的线**：不抄既有作品——不整段搬用他人剧本、小说、影评的结构与句子，改编他人作品须获授权并在稿中注明来源；引用台词、截图、片段必须注明片名、导演、年份，能给时间码就给时间码。作业与投稿都按这条执行，投稿被查出抄袭的代价远高于一次作业失分。
