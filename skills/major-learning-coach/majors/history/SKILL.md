# 历史学（history）

> 使用前先读 `../../references/curriculum-rules.md`（难度与排序规则）与
> `../../references/learning-card-template.md`（讲解结构）。
> 本文件只提供"这个专业的知识骨架与专业习惯"，不要在这里重复通用协议。

## 1. 这个专业在训练什么

历史学的人靠**史料**吃饭。任何结论都要能回答三件事：这个说法出自哪份材料、这份材料凭什么可信、它能证明到哪一步为止。训练的就是这条链——找得到（K01）、读得准（K05）、说得清限度（K07）。

**一句话画像**：用史料回答问题，并说清证据能撑到什么程度。

中学历史考"是什么"，大学历史考"你怎么知道、凭什么是这样"。同一个"安史之乱的原因"，中学答三条要点，历史系要答"这三条分别由哪类材料支持、哪条最弱、有没有反例"。

和邻近学科的分界线先记一句：考古学从物质遗存反推行为与年代，文物与博物馆学做价值判断与保存展示，历史学从文字史料出发解释"为什么"和"这为什么被这样记下来"。三者共用材料，问题不同、结论的验收方式也不同（详见第 9 段）。

**最容易误解的一点**：以为材料多就等于结论稳。一百条互相转抄的材料仍是孤证，一条能独立来源的材料才叫第二重证据。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能给一份陌生材料写出"出处—作者—年代—载体"四行著录，并判断它是一手还是二手。
2. 能对同一书的两个版本列出异文，判定哪处是讹，并说明依据是本校、他校还是理校。
3. 能用外证与内证两道工序处理一份可疑材料，结论落到"可用、部分可用、存疑、不用"四档之一。
4. 能就一个题目编出 20 条以上的史料长编，每条注明出处与可靠性等级。
5. 能对一道史料分析题写出"结论—证据—限度"三段，并指出还缺哪类材料。
6. 能对同一史事给出结构解释与事件解释各一套，说明两者的检验方式和失效条件。
7. 能就分期问题说明自己采用哪套标准、这套标准牺牲了什么。
8. 能交出一篇格式统一的论文，每条引文可被第三人按脚注核对到版本与页码。

## 5. 术语与符号约定

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| 一手史料 | 当事人或同时代留下的、未经他人转述的材料 | 档案、日记、报刊原文、实物 | 史料汇编、影印选本已是二手加工；网页转载的原文不算一手，因为你没核版本 |
| 二手研究 | 后人依据材料写出的论著 | 专著、论文、教科书 | 引用研究结论时要说"某书认为"，不能写成史实陈述 |
| 外证 | 由外部信息判定材料真伪：作者、年代、流传、载体 | 结论只有四档：可用、部分可用、存疑、不用 | 只查了作者生卒就宣布"可信"，漏掉流传与载体两项 |
| 内证 | 在材料内部查语境、作者立场、书写惯例、前后矛盾 | 针对表述，不针对载体 | 把作者的褒贬当事实记录；把公文套话"臣某诚惶诚恐"当实情 |
| 二重证据法 | 王国维提出，以地下出土材料与纸上材料互证 | 两层证据须彼此独立 | 两层材料同源（同出一批人之手）时不能互证；"都出现了同一个词"不等于证明了同一件事 |
| 孤证不立 | 单一来源不能定论 | 一般要求至少两条独立来源 | 三种转述同出一本原书，仍是孤证；独立指来源独立，不是数量多 |
| 历史解释 | 对"为什么"的回答 | 与史实陈述分开写 | 解释不加检验条件；用动机替代机制（"因为他想"） |
| 因果 | 必要条件、充分条件、促成条件 | 与"相关""先后"分开 | 把"之后发生"当"因此发生"；只证了必要条件就说成原因 |
| 分期 | 按某一标准把历史切成时段 | 标准须写明：政治、经济或全球联系 | 把教科书分期当客观事实；两套分期混用而不交代 |
| 近代史起点 | 常见方案：1840 年、1839 年禁烟或 1842 年订约、晚明、1500 以降 | 每套方案对应不同问题 | 只答"1840 年"而不说这是哪套标准下的答案，遇到分期题必丢分 |
| 年号纪年 | 新君即位或遇事改元，一个皇帝可有多个年号 | 明清大体一帝一元，之前多改元 | 用公元思维假设一帝一号；忽略改元当年只有几个月 |
| 干支 | 十天干配十二地支，60 年一轮 | 不能单独定年 | 只写"甲午"就当成确定年份；干支必须锚定朝代或公元 |
| 公元前后 | 公元前 1 年之后直接是公元 1 年 | 无公元 0 年 | 算跨公元的间隔时忘记减 1；把公元前 221 年写成 −221 直接相减 |
| 世纪与年代 | 1 至 100 年为 1 世纪 | 17 世纪是 1601 至 1700 | 把 1600 年算进 17 世纪；"18 世纪末"指 1790 年代，不是 1800 年 |
| 庙号、谥号、年号 | 三种称呼并存，各朝习惯不同 | 汉魏多称谥号，唐宋多称庙号，明清多称年号 | 说"汉武帝的年号"；把"康熙"当庙号；同一人三种称呼在同一段混用 |
| 卷次与篇名 | 古籍引注到卷、篇、条 | 影印本另标原刻叶次 | 只写书名与页码，换版本就对不上；用整理本页码冒充原刻 |
| 脚注体例 | 作者、篇名、书名或刊名、年份期号、页码 | 首次注全，重复注可省 | 转引不标"转引自"；页码对不上被引观点所在的那一页 |
| 版本 | 同一书的不同刻本、点校本、影印本 | 引文必须锁定一版 | 不同版本页码混用；用电子书阅读器页码 |
| 档案编号 | 全宗号、目录号、案卷号、件号四级 | 各馆著录层级略有差异 | 只写"某档案馆藏"不写卷号，第三人无法核对 |
| 报刊的号与期 | 晚清民国报刊多用卷、期、版次 | 与今日期刊"年卷期"不同 | 把《申报》的版次写成页码；把"第 4 版"记成"第 4 页" |
| 正史与野史 | 正史指纪传体官修史书，野史指私家记述 | 这是体例分类，不是可信度分级 | 把"正史"当"正确历史"；把野史一律当谣言，两者都错 |
| 编年、纪传、纪事本末 | 三种史书体裁 | 同一事件三种读法 | 拿纪传体找时间线，拿编年体找人物全貌，都会漏 |
| 亩、石、两、银元、法币 | 历代度量与币值不同 | 折算须注明依据与年份 | 直接按今日银价折算清代一两的购买力；跨朝代比亩产不换算亩制 |
| 地名古今对照 | 政区沿革与治所迁移 | 用当时地名，必要时注今地 | 把明代"京师"当今天的北京城范围；把籍贯当出生地 |
| 存疑 | 证据不足时的显式标注 | 写"存疑"并列出所缺证据 | 为行文顺畅把不确定写成确定；或通篇"可能"却不给任何判据 |

## 6. 典型题型与解题套路

### 史料分析题（给一段材料，问它说明了什么）
1. 先著录再读：写出处、作者、年代、载体。缺字用 `□`，不确定的字后面标"（存疑）"。
2. 做外证：作者是谁、写于何时、什么载体、有无异本；当场给出可用性判断。
3. 做内证：分段归纳，圈出评价性词语与公文套话，把"记录"与"评论"分开。
4. 答题三段：结论（这段材料能证明什么）、证据（引原文关键词）、限度（它不能证明什么、还缺什么材料）。
5. 收尾一句："若要坐实，还需 A、B 两类材料"，把开放处留在明面上。
**常见失分点**：把复述大意当答案；引了材料不作解释；把材料里一句话当全部事实，不写限度。

### 论述题（"试论某某的原因/影响/评价"）
1. 拆题：写出时间范围、对象、要解释的关系，判断题目在问"是什么"还是"为什么"。
2. 立论：一句话给可辩护的论点，带限定条件；不写"影响深远"这类无法反驳的话。
3. 搭骨架：按"背景—机制—结果—反例"或"制度—经济—观念"分层列提纲，每层至少 2 条史实。
4. 落证据：每条史实给时间、地点、出处（作者、书名、卷或页），不用"据说""大家都知道"。
5. 收口：给一条反例或限定（哪种情况下论点不成立），再回到论点说明适用范围。
**常见失分点**：史实堆砌无因果；开头论点与结尾结论不一致；用"由于"直接跳到"所以"，跳过机制。

### 名词解释
1. 第一句给定义，格式是"属概念 + 种差"，控制在 40 字内。
2. 第二句给时空：朝代、年代范围、地域。
3. 第三句给要素：主体或提出者、制度内容或代表著作、关键数据。
4. 第四句给学术位置：它在史学史上的意义，或学界对它的主要分歧。
5. 记不准就写"具体年代存疑"并给出可核对的线索，绝不补一个像样的年份。
**常见失分点**：只举例不给定义；拿小说或影视情节当史实；为凑字数编年份与人物。

### 史学方法题（"这段材料可信吗""该用什么方法研究"）
1. 先定对象：要检验的是记载真伪、年代、作者，还是解释是否成立，四者方法不同。
2. 选工具：外证（作者、年代、流传、载体）→ 内证（语境、立场、惯例、矛盾）→ 互证（出土材料、异本、他国记载）。
3. 写判据：每一步写清"我依据什么下这个判断"，不用"显然""一般认为"。
4. 结论分档：可用、部分可用（说明是哪部分）、存疑（写明缺什么证据）、不用。
5. 说局限：这套方法在该材料上哪里失效，例如无同期异本、作者不可考。
**常见失分点**：只答"要批判地使用史料"这类空话；把方法名当论证；结论不分档，含糊收场。

## 7. 常见误区

1. **拿二手研究当一手史料** → 错在把转述当原件；应顺着脚注找到原始出处，核到那一页原文再引。
2. **引文凭记忆写** → 错在会改动字句甚至编出原文；应复制核对（版本加页码），核不到就改写为概述并注明"据某某转述"。
3. **一条材料就下结论** → 错在孤证；应再找一条独立来源，找不到就把结论降级为"可能"并写清缺什么。
4. **把分期当事实** → 错在把某一套标准当成历史本身；应先交代采用哪套分期及其代价，再在该框架内讨论。
5. **因果等于先后** → 错在 post hoc；应写出机制（谁做了什么导致什么）并给一个反例检验。
6. **名词解释写成小故事** → 错在缺定义与时空两要素；应第一句就给"属概念加种差"，故事性材料只作最后一句的例证。
7. **注释只写书名** → 错在缺版本与页码，读者无法核对，等于没注；每条脚注必须能被第三人按图索骥翻到。
8. **遇到不确定就含糊过去** → 错在掩盖证据缺口；应显式写"存疑"，并列出坐实它需要哪类材料。

## 9. 交叉专业与后续方向

- **和考古学的区别**：考古学靠田野发掘的物质遗存建立年代序列、推断人群行为；历史学靠文字史料解释"为什么"和"这件事为什么被这样记下来"。同一处遗址，考古答"这里什么时候有人、怎么生活"，历史答"谁记载了它、记载为什么偏成这样"。做先秦秦汉史时两者必须合用，但结论的验收标准不同：考古看地层与类型序列，历史看材料链与互证。
- **和文物与博物馆学的区别**：文博做价值判断、保存决策与展览叙事，历史学做史料解释与因果论证。面对一件青铜器，文博答"怎么修、怎么展、定几级"，历史答"铭文说了什么、能证哪一件事、还缺哪类材料"。
- **和汉语言文学的区别**：文学解释文本如何构成、为何这样写，历史用文本证外部事实；但历史也要处理文本性，所以两边共用版本、校勘、目录这套工具。
- **和哲学的区别**：哲学做规范性论证（应该怎样），历史学做经验性论证（据这些材料，最可能怎样），不给"应当"。
- **三条学术底线（本专业的评分点，也是 AI 协作时的硬约束）**：不虚构史料原文——引文必须逐字核到版本与页码，核不到就改写为概述并注明来源；不编造年份与人物——记不准写"约"或写"年份待考"，绝不用像样的数字填空；不确定处必须标注"存疑"并写明所缺证据。违反任何一条，整段论证作废。
- **后续方向**：中国古代史、中国近现代史、世界史、专门史（社会史、经济史、环境史、医疗史）、史学理论与史学史、历史文献学；岗位如中学历史教师、档案馆与方志办、博物馆与研究机构、出版编辑、公文与宣传；进阶课程为历史文献学、考古学通论、社会科学研究方法、数字人文与历史地理。
