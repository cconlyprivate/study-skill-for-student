# 机械工程（mechanical-engineering）

> 先读 `../../references/curriculum-rules.md`（难度与排序）与 `../../references/learning-card-template.md`（讲解结构）。
> 本文件只给这个专业的知识骨架与专业习惯。

## 1. 这个专业在训练什么

让一个零件在**受力、运动、材料强度**三件事上同时成立，并且能被画成图、被造出来、被装配上去。

外人以为机械 = 画图 + 拧螺丝。画图只是 K01，真正拉开差距的是：拿到一个工况，能判断**哪个截面最危险、哪个尺寸由强度定、哪个尺寸由结构或工艺定**。

它和材料专业的界线很清楚：材料问"这种成分与工艺做出的性能如何"，机械问"给定材料性能，这个零件该做多粗、用什么配合、怎么装得上"。

**最容易误解的一点**：以为强度不够就加粗。加粗会改变刚度分布、挤占配合空间、甚至让工艺做不出来——机械的答案是"改结构、换材料、改热处理"三选一，而不是只改一个数字。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能对给定机构或结构画出受力图，并写出足够的平衡方程解出全部未知反力。
2. 能画出梁的剪力图与弯矩图，标出危险截面并说明判断依据。
3. 能对拉压、扭转、弯曲三种基本变形分别做强度与刚度校核，并给出不满足时的改法。
4. 能数出机构的自由度，判断曲柄存在条件，算出行程速比系数与轮系传动比。
5. 能按标准选出齿轮、轴、轴承、键的规格，并说明为什么不是相邻那一档。
6. 能读懂一张零件图上的尺寸、公差、配合与形位公差，指出哪里过定位、哪里装不进去。
7. 能为一个简单零件编出工艺路线，并用尺寸链算出封闭环的公差。

## 5. 术语与符号约定

| 符号/术语 | 含义 | 单位/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| 力 $F$ | 物体间的机械作用 | N、kN（1 kN = $10^3$ N） | 题目给质量 kg 时先乘 $g\approx9.8$，别把 kg 当 N 直接代入 |
| 均布载荷 $q$ | 单位长度上的载荷 | N/m、kN/m | 合力 $ql$ 作用在分布段中点，只有矩形分布才在中点；三角形分布合力在距零端 $2l/3$ 处 |
| 力矩 $M$ | 力对点的转动效应 | N·m | 平面题先声明取逆时针还是顺时针为正（多数教材取逆时针），空间题用右手定则；约定写在解题第一行，中途不得换 |
| 力偶矩 $M_e$ | 一对等值反向平行力产生的转动效应 | N·m | 力偶对任意点取矩都相同，别把它当力去求合力 |
| 约束反力 | 解除约束后代替约束的未知力 | N | 固定铰 2 个分量、可动铰 1 个法向、固定端 3 个（2 力 + 1 力偶）；少画一个，平衡方程就不够用 |
| 二力杆 | 只在两端受力且平衡的杆 | — | 反力沿两铰连线；方向画反不报错，但后续内力符号全反 |
| 轴力 $F_N$ | 杆件轴向内力 | N、kN | 拉为正、压为负；轴力图必须标出正负号与最大值位置 |
| 剪力 $F_S$ / 弯矩 $M$ | 梁横截面上的内力 | N / N·m | 各校正负号约定不同，"左上右下为正"与"下侧受拉为正"必须与所画图统一 |
| 正应力 $\sigma$ | 单位面积上的法向内力 | MPa（1 MPa = 1 N/mm²） | 拉压有正负；GPa 与 MPa 差 $10^3$，代公式前统一到 N 与 mm |
| 切应力 $\tau$ | 单位面积上的切向内力 | MPa | 扭转时沿半径线性分布、表面最大；$\tau=T/W_t$ 与平均值 $F/A$ 不是一回事 |
| 许用应力 $[\sigma]$ 与安全系数 $n$ | 强度储备的量化 | — | 塑性材料用屈服极限、脆性材料用强度极限，没说明就写清取了哪一个 |
| 弹性模量 $E$ / 切变模量 $G$ | 材料抵抗弹性变形的能力 | GPa | 钢 $E\approx200$ GPa、$G\approx80$ GPa，且 $G=E/[2(1+\nu)]$，别只记 $E$ |
| 抗弯截面系数 $W_z$ / 抗扭截面系数 $W_t$ | 截面几何量 | mm³、cm³ | 实心圆 $W_t=\pi d^3/16$ 是 $W_z=\pi d^3/32$ 的两倍，这两个最容易抄反 |
| 惯性矩 $I_z$ | 截面二次矩 | mm⁴、cm⁴ | 平行移轴 $I_z=I_{zc}+Aa^2$ 别漏面积项；矩形 $I=bh^3/12$ 是对中性轴 |
| 柔度 $\lambda$ | 压杆的长细比 | — | $\lambda=\mu l/i$，$\mu$ 两端铰为 1、一端固定一端自由为 2；$\lambda$ 大于 $\lambda_p$ 才可用欧拉公式 |
| 自由度 $F=3n-2P_L-P_H$ | 平面机构的独立运动数 | — | $n$ 只数活动构件（不含机架）；$m$ 个构件汇交的复合铰链按 $m-1$ 个转动副算 |
| 虚约束 / 局部自由度 | 不改变运动的多余约束 / 不影响输出的自由度 | — | 必须先剔除再代公式；漏剔会算出 $F<1$，多剔会算出 $F$ 偏大 |
| 模数 $m$ / 压力角 $\alpha$ | 齿轮几何与受力方向的基本参数 | mm / ° | $d=mz$ 是分度圆，$d_a=m(z+2)$ 才是齿顶圆；标准压力角 20°，变位后中心距不再是 $m(z_1+z_2)/2$ |
| 传动比 $i$ | 输入转速与输出转速之比 | — | 减速时 $i>1$；外啮合反向、内啮合同向，周转轮系要把符号一并代入 |
| 配合代号 H7/g6 | 孔公差带 H7 与轴公差带 g6 的组合 | μm | 大写是孔、小写是轴；H 的基本偏差为 0、g 的上偏差为负，所以是基孔制间隙配合 |
| 基本偏差 | 靠近零线的那个极限偏差 | μm | 查表得到的是基本偏差与标准公差两个数，相加才是上下偏差 |
| 形位公差 | 形状公差与位置公差 | mm、μm | 同轴度、圆度、跳动是不同框格符号；标注不带基准就无法检验 |
| 表面粗糙度 $Ra$ | 轮廓算术平均偏差 | μm | 数值越小越光，1.6 与 3.2 是常用档；$Ra$ 不是 $Rz$，标注与检验方法都不同 |
| 轴承寿命 $L_{10}$ | 基本额定寿命 | $10^6$ 转或小时 | 可靠度 90% 的寿命，不是平均寿命；球轴承 $\varepsilon=3$、滚子轴承 $\varepsilon=10/3$ |
| 当量动载荷 $P$ | 折算成纯径向的轴承载荷 | N | $P=f_p(XF_r+YF_a)$，先按 $F_a/F_r$ 与判断系数 $e$ 决定 $X$、$Y$ 再代公式 |
| 传动效率 $\eta$ | 输出功率与输入功率之比 | 0–1 | 串联 $\eta=\eta_1\eta_2\eta_3$；由输出扭矩反求输入扭矩时要除以效率，不是乘 |

## 6. 典型题型与解题套路

### 题型一：受力分析与平衡计算题
1. 先选研究对象：能整体求就先取整体，未知力超过 3 个再拆成单个构件。
2. 逐处解除约束，按约束类型画反力；二力杆只画一个沿连线的力。
3. 建坐标系，写 $\sum F_x=0$、$\sum F_y=0$、$\sum M_A=0$ 三个独立方程，力矩中心选在未知力最多的交点。
4. 解出后回代未使用的方程验算；负号表示实际方向与假设相反，不要回头改假设重算。
**常见失分点**：漏画重力或摩擦力，或把固定端简化成一个力；整体与拆分两张图混用同一套反力。

### 题型二：内力图与强度校核题
1. 先求支座反力并标在受力图上，这一步错，后面全错。
2. 分段：集中力、集中力偶、分布载荷的起止点都是分段点，逐段写内力方程。
3. 用 $\frac{dM}{dx}=F_S$、$\frac{dF_S}{dx}=q$ 的关系校核图形：无载段剪力水平、弯矩为斜线，集中力偶处弯矩突变。
4. 定危险截面，算 $\sigma_{\max}=M_{\max}/W_z$，与 $[\sigma]$ 比较并给出明确结论。
5. 不满足时给改法：加大截面、改材料、改支承位置，并说明各自代价。
**常见失分点**：弯矩图正负号与"画在受拉侧"两套约定混用；把弯矩最大截面与应力最大截面当成同一个。

### 题型三：机构运动分析题
1. 先画机构运动简图，数活动构件 $n$、低副 $P_L$、高副 $P_H$，剔除虚约束与局部自由度后算 $F$；$F$ 与主动件数不符就先停下查图。
2. 速度分析：能取瞬心的先取瞬心，不能取的用合成运动，动点选在有相对滑动的接触点，动系固结在导杆上。
3. 写 $\vec v_a=\vec v_e+\vec v_r$ 并画速度平行四边形；加速度再补科氏项 $\vec a_k=2\vec\omega_e\times\vec v_r$。
4. 求出的量标清方向与转向，最后用"这个位置的速度该不该为零"做一次常识检查。
**常见失分点**：科氏加速度漏项或方向转反；把机架算进活动构件，导致自由度与主动件数对不上。

### 题型四：结构设计与选型题
1. 先列工况：载荷性质（平稳还是冲击）、转速、预期寿命、空间限制、装拆与维修要求。
2. 按失效模式选计算式：轴用弯扭合成、齿轮用接触与弯曲、轴承用寿命、键用挤压。
3. 算出最小尺寸后**向上取标准值**，再回代验算真实应力与寿命，不要停在计算值上。
4. 画结构：定位、固定、装拆、润滑与密封四件事各查一遍，标出过定位处。
5. 给两个方案并说清取舍：尺寸、成本、工艺可行性各让了多少。
**常见失分点**：算出 $\phi37.2$ 就写 $\phi37.2$，不取标准直径；只算强度不画结构，图纸上根本装不进去。

## 7. 常见误区

1. **先画反力再想约束** → 错在没有先判断约束类型与未知量个数；应该先写"解除哪个约束、相当于几个未知力"，再落笔。
2. **内力图不分段，一条曲线画到底** → 错在把分段载荷当常量；应该在每个集中力、集中力偶、分布载荷端点切开。
3. **强度校核只算正应力** → 错在漏掉切应力与挤压应力；弯曲梁要补验中性轴处，键与销要算挤压。
4. **数自由度时把机架算进 $n$** → 错在 $n$ 的定义；$n$ 只数活动构件，机架是参考系。
5. **把 $d=mz$ 当齿顶圆** → 错在分度圆与齿顶圆混用；齿顶圆是 $d_a=m(z+2)$，全齿高是 $2.25m$。
6. **选轴承只看内径** → 错在没算当量动载荷与寿命；内径相同、承载能力可以差一倍以上。
7. **配合代号凭手感写 H7/g6** → 错在没先定配合性质；应先判断要间隙、过渡还是过盈，再查基本偏差选代号。
8. **尺寸链从设计尺寸顺着推** → 错在没找封闭环；封闭环是加工中最后自然形成、不直接标注的那个尺寸。

## 9. 交叉专业与后续方向

- **和材料科学与工程的区别**：材料给"性能上限"（$\sigma_s$、$\sigma_b$、硬度），机械定"几何与结构"（多粗、什么配合、怎么装）；同一根轴，材料答能不能用，机械答做多大。
- **和土木工程的区别**：都学理论力学与材料力学，土木算整体结构在荷载下的内力重分布与整体稳定，机械算单个零件在应力集中与交变载荷下的寿命。
- **和自动化的区别**：自动化管"怎么让机构按指令动、动得稳"，机械管"这个机构能不能动、动得准不准、扛不扛得住"；机电一体化是两者的交集。
- **和车辆工程的区别**：机械是共性基础，车辆把载荷谱、轻量化与 NVH 压到具体工况上，考的还是同一套强度与机构分析。
- **后续方向**：机械设计理论（疲劳、摩擦学、优化设计）、机械电子工程（机电一体化、伺服与传感）、机器人机构学、智能制造与工艺；考研常考机械设计或机械原理加材料力学。
