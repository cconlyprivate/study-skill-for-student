# 伦理学（ethics）

> 先读 `../../references/curriculum-rules.md`（难度与排序）与 `../../references/learning-card-template.md`（讲解结构）。
> 本文件只给这个专业的知识骨架与专业习惯。

## 1. 这个专业在训练什么

伦理学靠**把「应该怎么做」的理由说到别人能逐条检查**吃饭。核心动作只有三步：把事实与价值分开（先描述清楚发生了什么）→ 找出互相竞争的理由（谁的权利、谁的利益、谁的角色义务）→ 给出一个能被反驳的结论，并写清它在什么条件下成立。

它和"教人做好人""背道德格言"不是一回事。格言是结论，伦理学要的是结论背后的理由链：同一句"不许撒谎"，康德靠可普遍化，功利主义者靠后果，两者在例外情形上必然分裂，你必须知道自己站在哪一条上。

它也和"价值观输出"不同：伦理学不要求你接受某种善观念，而要求你在承认合理分歧的前提下，仍能给出公共可检查的论证。这两件事的差别，决定了伦理学的答案是"在 X 条件下允许 Y，剩余风险由 Z 承担"，而不是"对"或"错"。

**最容易误解的一点**：以为伦理学要给出唯一正确答案。实际上它要给出**可复核的判断加条件**——换一个前提结论就要跟着变，写不出这句条件，答案就是直觉而不是论证。

## 3. 能力目标（毕业时能做的可检验的事）

1. 能把一段"应该怎么做"的争论拆成事实栏与价值栏，并标出争点落在权利、分配还是角色义务。
2. 能写出一个含两条以上前提的规范论证，并指出它实际依赖哪条没有写出来的隐含前提。
3. 能对同一案例用后果论、义务论、德性伦理各写一段评价，并说出结论分岔的具体判据。
4. 能识别并命名一个论证里的"是—应当"跳跃，当场补出缺失的规范前提。
5. 能在 800 字内写出一份可复核的伦理决策报告，含选项、依据、建议与复核条件。
6. 能对一个思想实验指出它改动了哪个变量、调动了哪种直觉、这直觉能否被理论解释。
7. 能对一条机构规则说明它施加的理由、适用边界与一处最可能的滥用方式。

## 5. 术语与符号约定

| 符号/术语 | 含义 | 层级/范围 | 本专业容易写错的地方 |
|---|---|---|---|
| 「是」/「应当」 | 描述性判断与规范性判断的分界 | 论证层：任何规范结论至少要一条规范前提 | 把「大家都这样」「历来如此」当理由，是描述前提冒充规范前提；只补事实永远补不齐这条缝 |
| 描述/规范/评价 | 三种语句功能：说事实、下指令、给品评 | 同一句话可兼有两种功能 | 「道德是相对的」是描述命题，「应当宽容」是规范命题，两者之间仍要一次跳跃 |
| 后果论 | 以后果好坏判定对错 | 评价对象可以是单个行为、也可以是一条规则 | 后果论不等于利己主义；行为功利与规则功利在同一反例上会给出相反结论 |
| 功利原则 | 最大多数人的最大幸福 | 效用须可比较、可加总 | 效用不可通约时不能硬加；「总量最大」本身不保护少数，必须另加约束 |
| 义务论 | 依准则与可普遍化判定对错，不看后果 | 评价对象是准则，不是事态 | 义务论不等于只讲动机；定言命令是检验程序，不是一张现成禁令清单 |
| 定言命令/假言命令 | 无条件要求 / 以某个目的为条件的命令 | 定言命令有普遍法则、人是目的等公式 | 「若想要 X 就该做 Y」是假言命令，拿它充当道德要求属于层级错误 |
| 德性伦理 | 以行为者的品格与功能判定 | 评价对象是人与其实践，不是单次行为 | 中道是相对于情境与行为者的适度，不是两端平均；勇敢不是不害怕 |
| 实践智慧 | 在具体情境中确定中道的能力 | 不可完全规则化 | 它不是「经验多了自然有」，而是可训练的判断力；缺它时规则落不了地 |
| 道德相对主义 | 道德判断相对于文化或框架 | 分描述层、规范层、元伦理层，三层相互独立 | 用描述事实直接推宽容要求，又是一次是—应当跳跃；三层不能互相顶替 |
| 宽容原则 | 对不赞同的实践不予干涉 | 有边界，不是无限度 | 对以消灭宽容为目标的实践不适用；不写边界判据，宽容就变成双标 |
| 双重效应原则 | 允许可预见但非意图的坏效果 | 四条件：行为本身可许、坏效果非手段、意图指向好效果、比例相称 | 把「预见到」写成「意图」直接判错；拿它当免责通行证，通常会漏掉比例条件 |
| 意图/预见 | 追求的目标 / 明知会随附发生 | 区分落在手段与副作用之间 | 扳道与推人的差别在于是否把人当手段，不在死的人数，写反就丢了整个论证 |
| 作为/不作为 | 主动造成 / 未阻止 | 因果链与责任归属不同 | 「不作为就没责任」是错的；存在救助义务或先行行为时，不作为可等同于作为 |
| 知情同意 | 有决定能力者的自愿授权 | 四要件：告知、明白、自愿、授权 | 签了字不等于同意；没反对不等于同意；治疗性例外要写清适用条件与记录方式 |
| 同意能力/自主 | 作出该项决定的能力 / 自我决定 | 按决定分层，不按人一刀切 | 自主不等于自由；尊重自主不只是照办，还包括充分告知与不干预 |
| 行善/不伤害 | 积极促进利益 / 不造成伤害 | 不伤害是消极义务，通常权重更高 | 两者冲突时默认不伤害优先；把「为你好」当万能理由会滑向家长主义 |
| 分配公正 | 同等情况同等对待，以及资源怎么分 | 四种标准：需要、应得、平等、贡献 | 四种标准给出不同结果，答题必须先声明用哪一个，再谈结论 |
| 道德地位 | 谁的利益本身值得考虑 | 边界判据：感受能力、理性、关系 | 「有生命」不等于「有道德地位」；道德地位与法律人格是两个问题 |
| 道德运气 | 结果受行为者不可控因素影响 | 影响评价，不改变应得 | 用结果好坏反推行为对错是结果论偏见；要分开评价尝试与完成 |
| 自然主义谬误/开放问题 | 用自然属性定义「善」 | 元伦理层，讨论定义 | 它与是—应当鸿沟不是同一条：一个谈定义能否成立，一个谈推演能否完成 |
| 反思平衡 | 原则与直觉互相调整到彼此一致 | 窄平衡只调原则，宽平衡还调背景理论 | 直觉要筛选，只保留无干扰条件下的判断，否则平衡到的是自己的偏见 |
| 滑坡论证 | 由 A 一路推到不可接受的 Z | 须给出机制、概率与可阻断的节点 | 「接下来就会出事」不给机制不算论证；滑坡可以成立，但举证责任在提出者 |
| 规定性/普遍化 | 道德语句既指导行动，又要求同等情形同等对待 | 语言层 | 从「我应当」到「任何人处此境况也应当」需要普遍化，不能跳到「人人实际都会」 |
| 角色义务 | 由职位与关系产生的特殊义务 | 与普遍义务并存，不能自动压倒 | 「我只是执行命令」不是理由；角色义务与普遍义务冲突时要说明优先次序 |

## 6. 典型题型与解题套路

### 案例伦理分析
1. 先把案情拆两栏：可核实的事实（诊断、剂量、时间、当事人能力）与有争议的价值判断，别让价值词混进事实栏。
2. 列利益相关者与各自受影响的核心利益，特别标出没有发言权的一方（胎儿、动物、后代、数据主体）。
3. 定争点类型：是权利冲突（自主对不伤害）、分配冲突（谁先得到），还是角色义务冲突。争点定错，后面全错。
4. 选框架并说明为什么选它；至少用第二套框架交叉检验，若两套结论一致，要说明是巧合还是收敛。
5. 结论写成「在什么条件下、允许或禁止做什么、剩余风险由谁承担」，末尾附一条最强反方意见。
**常见失分点**：直接给"应该"结论而不写条件，阅卷人无法判断你是在论证还是在复述直觉。

### 理论辨析（义务论、后果论、德性伦理）
1. 先问评价对象：评行为、评规则，还是评人。三套框架的评价对象不同，混着比必然错位。
2. 再问评价依据：后果总量、准则可普遍化，还是行为者的功能与品格。
3. 造一个让两者结论相反的判例（如冤枉一人以平息众怒），看各自能否承受，以及要付什么代价修补。
4. 说明收敛区间：在哪些问题上两者给同一答案，答题时要指出这个区间，否则像在强行对立。
5. 收口一句：在什么问题上必须选边，在什么问题上可以并用，并说明并用的判据。
**常见失分点**：写成"三种理论各有道理"，通篇没有一句自己的判据，采分点为零。

### 思想实验评析（电车、经验机器、无知之幕）
1. 还原它想撬动的直觉：改动的是哪个变量，让你在 A 案说可以、在 B 案说不行。
2. 检查是否单变量：把人数、亲缘、可控性、意图逐项对齐，找出被偷偷改动的第二变量。
3. 找误导性细节：推人案里的肢体接触会调动厌恶反应，这部分可能与道德判断无关。
4. 做反向实验：把该细节去掉再问一次，若结论翻转，说明直觉来自心理机制而不是原则。
5. 判定直觉的地位：能被现有理论解释就保留为证据，不能被解释就当成待修正的数据。
**常见失分点**：把"我的直觉很强"当论据；直觉是待解释的数据，本身不是前提。

### 伦理决策报告（机构、项目、研究方案）
1. 写清决策者、权限与时限：谁有权批、能改什么、多久必须定，超出权限的部分单列。
2. 枚举选项，必须包含"不作为"与"推迟并补充信息"，否则是假选择。
3. 每个选项按三维评估：后果（受益与受损者、可逆性）、权利（谁被越过、有无授权）、品格（这样做的人会变成什么样）。
4. 给建议加实施条件，并写复核触发点：出现什么信号就重开讨论。
5. 写不确定性与异议渠道：哪条前提被推翻结论会变，谁有权提异议，异议怎么记录。
**常见失分点**：只写推荐方案，不写被否掉的方案为何被否，报告无法被第二个人复核。

## 7. 常见误区

1. **把"多数人这么认为"当理由** → 错在描述前提冒充规范前提；应该补一条"多数人在此类判断上可信"的规范前提，并为它单独给理由。
2. **先选定框架再往案例上套** → 错在框架成了结论的化妆；应该先定争点类型（权利、分配、角色），再选框架。
3. **用相对主义取消论证义务** → 错在从描述事实跳到规范结论；相对主义只解释分歧来源，不减免你给出理由的责任。
4. **拿双重效应原则给任何坏结果开脱** → 错在漏掉"坏效果不得是手段"与比例条件；应该逐条核四条件，并单独写出比例理由。
5. **把知情同意等同于签字** → 错在把文书当授权；应该回到告知、明白、自愿、授权四要件，缺项就走例外程序并留记录。
6. **用心理学的描述结论反驳伦理规范** → 错在又一次跨过是—应当；"人实际上怎么做"推不出"人应当怎么做"，只能用来修正对人性的事实假设。

## 9. 交叉专业与后续方向

- **和法学的区别**：法学问"依据现行规范，这个行为合不合法"，结论有强制力；伦理学问"这条规范本身是否可辩护、规范没写到时该怎么办"，结论只是理由。同一个案例，法学要写请求权基础，伦理学要写原则冲突与权衡理由，不能互相顶替。
- **和政治学的区别**：政治学问权力如何配置、制度如何产生与维持，落点在可行性与稳定性；伦理学问制度与政策对个人施加的理由能否被辩护（权利的限制、分配的标准），落点在可辩护性。政治哲学是两者交汇处，但交作业时一个要制度设计，一个要规范论证。
- **和社会学、人类学的区别**：后两者做描述伦理，记录某个群体实际持有什么道德信念；伦理学说这些信念是否成立。把田野描述当规范结论，就是本专业最典型的越界。
- **后续方向**：伦理学、政治哲学、应用伦理（生命伦理、科技伦理、环境伦理）方向的学硕与博士；高校教学与研究、伦理委员会与科研诚信审查、企业伦理与 ESG 合规、政策研究与智库、公共传播中的伦理评论。
